5 Generating Matchmaking Voice Chat Errors

When the cause of an error is Matchmaking Voice Chat, the error codes differ depending on the library being used for that feature.

  • When the NEX library is used (the nn::nex::SmartDeviceVoiceChatClient class), the errors are 2307-XXXX error codes.
  • When the SmartDeviceVoiceChat library provided as part of NintendoSDK is used (the nn::ens::SmartDeviceVoiceChatClient class), the errors are 2219-XXXX error codes.
Info

For more information about Matchmaking Voice Chat, see Nintendo Switch Voice Chat Guide.


Error Code Description of Errors and Generation Procedure
2307-2115

Generated while the Matchmaking Voice Chat service is closed.

Occurs when the NEX library is used (the nn::nex::SmartDeviceVoiceChatClient class).

Set the development hardware to 5.1 Matchmaking Voice Chat Service Closed Mode to return the pertinent error when the target functions are called.

For more information about the target functions, see NEX API Reference. The target functions are those member functions of the nn::nex::SmartDeviceVoiceChatClient class that return QERROR(SmartDeviceVoiceChat, ServiceNoLongerAvailable), as stated in the API Reference.
2219-6499

Generated while the Matchmaking Voice Chat service is closed.

Occurs when the SmartDeviceVoiceChat library provided as part of NintendoSDK is used (the nn::ens::SmartDeviceVoiceChatClient class).

Set the development hardware to 5.1 Matchmaking Voice Chat Service Closed Mode to return the pertinent error when the target functions are called.

For more information about the target functions, see the NintendoSDK API Reference. The target functions are those member functions of the nn::ens::SmartDeviceVoiceChatClient class that return nn::ens::ResultSmartDeviceVoiceChatErrorServiceNoLongerAvailable.

Make sure in your application design that online play itself does not become unavailable when the error 2307-2115 or 2219-6499 occurs.

Info

When Lotcheck (the final testing process for applications, performed by Nintendo) checks the Nintendo Switch Guidelines in 0182: Supporting matchmaking when matchmaking voice chat is not available, they also check the handling of this error.
