4 Generating NEX Errors

Error codes that begin with 2306-XXXX represent errors related to NEX.

Info

Use the NEX Server Management System (NMAS2) and WebAPI to check errors in NEX. For more information, see the manual included in the NEX library.


Error Code Description of Errors and Generation Procedure
2306-0502

Generated when connection to the game server cannot be established.

In NMAS2, select Debug Assistance > Error Simulation > New and add the following settings to return an error that corresponds to the call to nn::nex::NgsFacade::Login by the application.

  • Principal ID: The principal ID of the user that caused the error to occur.
  • Server Function Name: Login
  • Return Code: X06-0502 QERROR(Transport, ConnectionFailure)
2306-0811

Generated when trying to log in while the server is undergoing maintenance.

In NMAS2, select Debug Assistance > Error Simulation > New and add the following settings to return an error that corresponds to the call to nn::nex::NgsFacade::Login by the application.

  • Principal ID: The principal ID of the user that caused the error to occur.
  • Server Function Name: Login
  • Return Code: X06-0811 QERROR(Authentication, UnderMaintenance)
2306-0819

Generated when trying to log in when an application version update is required.

In NMAS2, select Debug Assistance > Error Simulation > New and add the following settings to return an error that corresponds to the call to nn::nex::NgsFacade::Login by the application.

  • Principal ID: The principal ID of the user that caused the error to occur.
  • Server Function Name: Login
  • Return Code: X06-0819 QERROR(Authentication, ApplicationVersionIsOld)
