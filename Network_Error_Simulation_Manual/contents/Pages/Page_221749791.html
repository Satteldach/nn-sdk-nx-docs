2 Generating Network Interface Manager (NIFM) Errors

Error codes that begin with 2110-XXXX represent errors related to Network Interface Manager (NIFM).

Info

The application can use the same handling method to support all of the errors presented in the following table. For this reason, it is acceptable to generate any one of these errors (for example, 2110-2003) and confirm it is handled appropriately.

Error Code Description of Errors and Generation Procedure
2110-2003

Generated when unable to connect to a wireless access point.

Check by turning off the wireless access point you are using.
2110-3126

Generated when a client cannot connect to the proxy server, or when proxy account settings are incorrect.

Check by entering an incorrect value in the proxy server settings in Internet Settings.
2110-3127

Generated when DNS name resolution fails.

Check by disconnecting the WAN-side LAN cable from the wireless access point you are using.
