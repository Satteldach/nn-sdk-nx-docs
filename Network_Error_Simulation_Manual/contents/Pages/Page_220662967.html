3.1 Using Auth Debug Tool, a Web Tool for Authentication Debugging

Auth Debug Tool

Auth Debug Tool is a web tool that provides the following features for debugging issues with the Nintendo Authentication Server.

  • Simulation of errors caused by the authentication server
  • Viewing the authentication server access logs

To access Auth Debug Tool, use the following URL. Use your Nintendo Developer ID to log in.

https://telescope.nntt.mng.nintendo.net/

Note

To use Auth Debug Tool, there must be at least one viewable title that uses network features and has passed the title review process on OMAS.

Checking the System Serial Number

Auth Debug Tool uses the system serial number for error simulation and log viewing.

You can check your system serial number from the HOME Menu in System Settings > System > Serial Information.

The serial numbers for some systems, such as development hardware, may not include a check digit.

Figure 3-1 Checking the Serial Number

Error Simulation Feature

With Auth Debug Tool, you can configure specific errors to be generated when an application is started on a particular Switch. An error can be registered for a set combination of application and Switch. Errors cannot be configured to occur for only a particular account or for the same error on multiple applications with a single setting.

Also, the Switch system caches authentication information, so even if errors are configured using Auth Debug Tool, the errors do not occur while the cache is valid. The cached authentication information is cleared when the Switch is restarted, so restart the console after you have configured the errors using Auth Debug Tool.

Registering Errors

To register a new error, open the Application Errors page and click Create New Error.

To register the error, configure the following settings and then click Create.

Table 3-2 Token Log Search Criteria
Item Description Required? Notes
Serial Number Specify the serial number of the system for which the error will be generated. Required Refer to the procedure described in Checking the System Serial Number. Be careful not to omit the check digit.
Application Select the application for which the error is to be generated. Required

Only applications that can be viewed on OMAS by the logged in NDID can be selected.

You cannot select an application for which the use of network features has not been requested on OMAS.
Error Code Select the error to be generated. Required
Comment Write anything you want in these notes when registering the error. Optional

Displaying a List of Configured Errors

The Application Errors page displays the settings of the errors registered by the logged-in NDID. Errors set by NDIDs other than that of the logged-in user cannot be displayed.

To edit the settings of a registered error, click the pen icon on the right side of the page.

Select a check box on the left side of the page to activate the Delete button, which you can then click to delete the selected item.

Searching Token Logs

To check the token acquisition logs, open the Application Auth Logs page.

Token logs can be filtered by setting search conditions. Note that the Application item cannot be omitted.

Application Filter the log to exclude all entries except those for tokens obtained by the specified application. Required
