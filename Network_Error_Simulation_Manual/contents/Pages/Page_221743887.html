3 Generating Account and Authentication Errors

Error codes that begin with 2124-XXXX represent errors related to accounts and authentication.

Info

For more information about errors returned by the account library, see the following materials.

  • NintendoSDK Documents
    • Features > System > account Library

Errors That Can Be Generated Using the Web Tool for Authentication Debugging (Auth Debug Tool)

The following errors can be generated using the web tool for authentication debugging described in 3.1 Using Auth Debug Tool, a Web Tool for Authentication Debugging.

Info
  • Applications can handle all errors in the following table in the same way. For this reason, it is acceptable to generate any one of these errors (for example, 2124-3001) and confirm it is handled appropriately.
  • Note that you must restart the Switch if you want errors to be generated immediately after they have been set with Auth Debug Tool.
  • As shown in the table, the errors codes have changed for some errors on Switch systems that are system version 7.0.0 or later.


Error Code Description of Errors and Generation Procedure
System Version 7.0.0 or Later System Versions Earlier Than 7.0.0
2124-3001 2124-3001

Generated when the Nintendo authentication server is configured to only allow network connections from specific application versions or later. For more information, see the Nintendo Switch Independent Server Configuration Manual.

Use Auth Debug Tool to set Application update is required for the target system.
2124-4605 2124-4025

Generated when the Nintendo authentication server is configured to refuse being used as the authentication service for an application.

Use Auth Debug Tool to set Game card has been banned for the target system.
2124-4606 2124-4026

Generated when the application has not been authorized to use the Nintendo authentication server.

Use Auth Debug Tool to set Unauthorized application for the target system.
2124-4607 2124-4027

Generated when the Nintendo authentication server is not available due to conditions with the application service.

Use Auth Debug Tool to set Device has been banned by application for the target system.
2124-4608 2124-4028

Generated when the application service has not started.

Use Auth Debug Tool to set Application service is not started for the target system.
2124-4609 2124-4029

Generated when the application service has terminated.

Use Auth Debug Tool to set Application service is closed for the target system.
2124-4610 2124-4030

Generated when the application service is not available.

Use Auth Debug Tool to set Application service is not available for the target system. Note that the Switch must be restarted to apply this setting.
2124-4612 2124-4210

Generated when a problem has occurred in the Nintendo authentication service.

Use Auth Debug Tool to set Authentication service is not available for the target system. Note that the Switch must be restarted to apply this setting.
2124-4613 2124-4260

Generated when the Nintendo authentication service is undergoing maintenance.

Use Auth Debug Tool to set Authentication service is under maintenance for the target system. Note that the Switch must be restarted to apply this setting.

Verifying Operation When the Network Service Account Is Not Available

When a Nintendo Account or Network Service account is not available, in principle the application should call the account library and initiate the sequence to restore availability. For more information, see the following documentation.

  • NintendoSDK Documents
    • Features > System > account Library > Using Network Service Accounts
  • Nintendo Switch Guidelines
    • 0121: Implementing Handling When the Network Service Account Is Not Available

For more information about generating errors and pass/fail criteria, see the item noted in the Nintendo Switch Guidelines.
