5.1 Matchmaking Voice Chat Service Closed Mode

Matchmaking Voice Chat service closed mode is a mode for the dd1 development environment that simulates a state where only the Matchmaking Voice Chat service has ended. In this mode, Matchmaking Voice Chat is no longer available to the target Switch system. Services other than Matchmaking Voice Chat remain available just like in the normal dd1 environment.

For more information about the functions that return the error, see Description of Errors and Generation Procedure for either error code 2307-2115 or 2219-6499 in the table in 5 Generating Matchmaking Voice Chat Errors.

This mode can be used only in the dd1 development environment. This mode cannot be used in the lp1 production environment.

Info

To change the mode to Matchmaking Voice Chat service closed mode and to cancel the mode, you must set HomeMenu as the initial boot menu for the development hardware.

From DevMenu, select Debug > Initial Boot Menu > HomeMenu.

Changing to Matchmaking Voice Chat Service Closed Mode

Use the following procedure to change the mode to Matchmaking Voice Chat service closed mode.

  1. From the HOME Menu, select System Settings > Internet Settings.
  2. While the list of networks is displayed on the Internet Settings screen, simultaneously press and hold the + Button and the L Stick (or the - Button and the R Stick) for three seconds. A short sound plays to indicate success.
  3. From the list, select a network and then select Connect to this Network.
  4. When the software keyboard applet is displayed, enter bVwogJmE and select OK.
  5. After the configuration success screen appears, hold down the POWER Button to restart the Switch system.

Canceling Matchmaking Voice Chat Service Closed Mode

Use the following procedure to cancel Matchmaking Voice Chat service closed mode.

  1. Perform steps 1 through 3 as described earlier in Changing to Matchmaking Voice Chat Service Closed Mode.
  2. When the software keyboard applet is displayed, enter delete and select OK.
  3. After the configuration success screen appears, hold down the POWER Button to restart the Switch system.

Checking Which Mode Is Set

You can determine which mode is set by checking what is displayed in the software keyboard applet after performing steps 1 through 3 as described earlier in Changing to Matchmaking Voice Chat Service Closed Mode.

If the text "Matchmaking Voice Chat service closed mode[dd1]" is displayed in the software keyboard, it means that mode has been set.

If that text is not displayed in the software keyboard, you know that the Matchmaking Voice Chat service closed mode is not enabled.

Important Information

You can use the SmartDeviceVoiceChatClient::ShowAppPage() function to display a guide for downloading the Nintendo Switch Online smart device app on the web applet.

When this feature is used in Matchmaking Voice Chat service closed mode, a white screen opens in the web applet stating that the page cannot be displayed.

This is an inherent design feature of Matchmaking Voice Chat service closed mode.

There are plans to display a page in the web applet to inform users that the service has ended when the service has actually ended.
