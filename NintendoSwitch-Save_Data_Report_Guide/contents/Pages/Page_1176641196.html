3 Save Data Report Features

Included Features

Save Data Report includes the following features.

  • Nintendo Switch system features
  • Web tool
  • NsrarConverter

Nintendo Switch System Features

The Nintendo Switch system features include functionality for the user to upload save data to the Save Data Report server and to download save data from that server.

Web Tool

The web tool primarily provides the following features for developers.

  • Allowing users to upload and download save data
  • Getting the save data of users and submitting repaired save data
  • Managing web tool user permissions
  • Changing save data upload units

You can sign in to the web tool from the following URL. You need a Nintendo developer ID (NDID) to sign in.

https://sd-report.mng.nintendo.net/

NsrarConverter

NsrarConverter is a tool for extracting and archiving NSRAR files.

The user save data obtained by the web tool is archived in NSRAR file format. NSRAR files may contain one or multiple pieces of save data, depending on the upload unit settings.

To investigate issues in the save data and make repairs, you must extract the NSRAR file. To submit the repaired save data using the web tool, you must re-archive the data and convert it to an NSRAR file.
