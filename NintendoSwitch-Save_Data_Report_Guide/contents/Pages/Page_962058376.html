5 Save Data Report Usage Example

Usage Example

Save Data Report is expected to be used to collect or restore save data as part of responding to inquiries from users.

For this reason, this document uses a basic example, involving collaboration between the following two parties at the development company, to demonstrate operations.

  • User support representative who receives inquiries from the user
  • Developer who investigates and repairs the collected data

When Data Is Collected

Number

Person

Operation

Details
1 User Make an inquiry about the application
  • Make an inquiry about the application to the user support representative.
2 User support representative Allow upload
  • In the web tool, specify the application and the serial number of the user's Switch, and allow save data to be uploaded.
    • See 6.1.1 Allowing Uploads.
  • Tell the user how to upload their save data.
    • See 8 Using the Nintendo Switch.
3 User Upload save data
  • Upload save data to the Save Data Report server.
4 User support representative Contact the developer
  • Notify the developer of the contents of the inquiry and the report number displayed in the web tool.
5 Developer Get save data
  • In the web tool, use the report number to get the save data uploaded by the user.
    • See 6.2.1 Downloading Save Data Uploaded by the User.
  • Extract the obtained save data (NSRAR file), and investigate the data and conduct repairs on a PC or the development hardware.
    • See 7 Using NsrarConverter.

Restoring Repaired Save Data

Number

Person

Operation

Details
1 Developer Submit repaired save data
  • Convert the repaired save data to the format (NSRAR file) in which it can be submitted to Save Data Report.
    • See 7 Using NsrarConverter.
  • Submit the repaired save data to the web tool.
    • See 6.2.2 Uploading, Downloading, and Deleting Repaired Save Data.
2 Developer Contact the user support representative
  • Notify the user support representative of the report number of the repaired save data.
3 User support representative Allow download
  • Allow the repaired save data to be downloaded from the web tool.
    • See 6.1.2 Allowing Downloads.
4 User support representative Notify the user
  • Notify the user that repairs are complete, and ask them to download the repaired save data.
  • Tell the user how to download the save data.
    • See 8 Using the Nintendo Switch.
5 User Download save data
  • Input commands on the Switch to download the repaired save data from the Save Data Report server.

Other Use Cases

For internal use only, you can use Save Data Report for purposes like the following example.

  • Download save data that advances progression in a game to a Switch console owned by the publisher and use it for an event or promotion.
Note

Do not collect a user's save data for any purposes other than investigations or repairs.
