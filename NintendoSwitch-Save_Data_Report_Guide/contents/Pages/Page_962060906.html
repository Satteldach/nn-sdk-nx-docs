4 Advance Preparations for Using Save Data Report

Web Tool Settings

Registering Applications

This process registers applications that are supported by Save Data Report.

If a person with a Nintendo Developer ID (NDID) that has the Nintendo Developer Portal role of Company Admin signs in to the web tool, all released applications associated with that person's organization are registered to the Save Data Report feature.

If a new application is released after the Save Data Report feature has begun being used, an NDID with the Company Admin role can sign in to the web tool at that time to add that application.

Info

Registration takes several minutes. You can see the registered application if you wait a while and then sign in again.

Setting Web Tool Users and Roles

You can set the NDIDs and roles that can use the web tool. These settings are required for each application.

Immediately after an application has been registered, only NDIDs with the Company Admin role in the Nintendo Developer Portal are granted the Save Data Report Company Administrator role for that application.

Web tool users with the Company Administrator role can add other web tool users as needed.

For more information about operations, see 6.3 Managing Web Tool User Roles.

Info

Even after the Company Admin role has been rescinded for an NDID on the Nintendo Developer Portal, that user continues to have the Company Administrator role in the Save Data Report feature. Delete or change the role of other web tool users with the Company Administrator role as needed.

Setting Upload Units

You can select whether the save data is uploaded for only the user doing the uploading, or for all of the users on that user's Switch console.

For more information about operations, see 6.4 Change Upload Unit.

Note

When the upload unit is set to All Accounts, save data for all users on the Switch is also downloaded when downloading save data.

Getting NsrarConverter

The web tool handles save data in the form of NSRAR files.

You need the NsrarConverter tool to convert NSRAR files to save data that can be imported to the development hardware, and to convert save data exported from the development hardware to NSRAR files.

Get SaveDataReportServiceKit for NX from the Nintendo Dev Interface (NDI). NsrarConverter is in the following path.


NintendoSDK\Tools\CommandLineTools\NsrarConverter
