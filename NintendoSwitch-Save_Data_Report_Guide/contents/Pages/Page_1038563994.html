6.1.1 Allowing Uploads

Allowing New Uploads

  1. In Serial Number, enter the serial number of the user you want to allow to upload data.
  2. Click Select a Title. The Select a Title dialog box is displayed.
  3. In the Select a Title dialog box, select the application for which you want to allow uploads, and click Select.
  4. Click Allow Upload.
  5. Upload permission is created for the entered serial number and application (the status for Upload becomes OPEN) and a report number is issued.
Info

After the upload permission expires (seven days) or upload is complete, the status automatically transitions to CLOSED, and data may no longer be uploaded.

For any report number, only one of the Upload, Download (Repaired), and Download (Original) columns can be set to the OPEN status at any particular time.

Even if the report numbers are different, an error occurs if a permission with the OPEN status already exists for the same serial number and application.

Note

An upload permission is deleted 6 months after it is created. When that happens, the save data uploaded by the user and the repaired save data associated with the report number are also deleted.

Allowing Re-Uploads

  1. In the Permission List, in the Upload column for the target report number, click CLOSED.
  2. In the Change Upload Permissions dialog box, verify that Change Status To is OPEN, and click Change.
  3. The Upload status is changed to OPEN.
Info

You cannot change the download permission status to OPEN if it was changed to CLOSED because a user uploaded data.

You can only change the status to OPEN if it was changed to CLOSED because the permissions expired.
