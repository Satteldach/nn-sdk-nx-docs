6.3.2 Changing and Deleting Web Tool Users

Changing the Role of a Web Tool User

  1. From the Title drop-down menu, select the application for which you want to change web tool user roles.
  2. In User List, click Change for the web tool user for which you want to change roles.
  3. In the Change User Role dialog box, in the Revised Settings drop-down menu, select the role you want to change to, and then click Change.
  4. The web tool user's role is changed.
Info

If you select the Apply this change to other titles for which you have the Manager role check box, the same changes are applied to other applications for which you have the Manager or Operation Manager role.

Only web tool users with the Company Administrator role are permitted to change the role for web users with the Company Administrator role.

Deleting Web Tool Users

  1. From the Title drop-down menu, select the application for which you want to delete web tool users.
  2. In the User List, click Delete for the web tool user that you want to delete.
  3. In the Delete User dialog box, click Delete.
  4. The web tool user is deleted.
Info

If you select the Delete this user from other titles for which you have the Manager role check box, the same web tool user is deleted for other applications for which you have the Manager or Operation Manager role.

Only web tool users with the Company Administrator role are permitted to delete web users with the Company Administrator role.
