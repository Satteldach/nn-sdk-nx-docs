6.1.2 Allowing Downloads

This page describes the procedure to follow so users can download save data that has been repaired. You can allow users to download not only the repaired save data, but also the original save data.

Allowing Download of Repaired Save Data

  1. In the Permission List, verify that Ready is displayed in the Download (Repaired) column for the target report number.
  2. In the Download (Repaired) column, click CLOSED.
  3. In the Change Download Permissions (Repaired) dialog box, verify that Change Status To is OPEN, and click Change.
  4. The download permission status is changed to OPEN.
Info

Download permission remains valid for seven days, after which the status automatically transitions to CLOSED and the data can no longer be downloaded.

For any report number, only one of the Upload, Download (Repaired), and Download (Original) columns can be set to the OPEN status at any particular time.

Even if the report numbers are different, an error occurs if a permission with the OPEN status already exists for the same serial number and application.

Allowing Download of Original Save Data

  1. In the Permission List, verify that Ready is displayed in the Download (Original) column for the target report number.
  2. In the Download (Original) column, click CLOSED.
  3. In the Change Download Permissions (Original) dialog box, verify that Change Status To is OPEN, and click Change.
  4. The download permission status is changed to OPEN.
Info

Download permission remains valid for seven days, after which the status automatically transitions to CLOSED and the data can no longer be downloaded.

For any report number, only one of the Upload, Download (Repaired), and Download (Original) columns can be set to the OPEN status at any particular time.

Even if the report numbers are different, an error occurs if a permission with the OPEN status already exists for the same serial number and application.
