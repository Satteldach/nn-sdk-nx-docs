6.3.1 Adding and Copying Web Tool Users

Adding Web Tool Users

  1. From the Title drop-down menu, select the application for which you want to add web tool users.
  2. In Add User, select the NDID and role of the web tool user you want to add, and click Add.
  3. In Add User dialog box, click Add.
  4. The web tool user is added.
Info

If you select the Add this user to other titles for which you have the Manager role check box, you can add the web tool user to multiple applications at the same time.

The target applications are those for which the user has the Manager or Operation Manager role.

If the same web tool user already exists for these applications, their role is not overwritten.

Web Tool Users and Copying Their Roles to Other Titles

You can copy all of the web tool users and their roles for a certain application to another application at the same time.

  1. From the Title drop-down menu, select the application you want to copy from.
  2. In Copy User, in the Title of the Application Copied To drop-down menu, select the application you want to copy to.
  3. In the Copy User dialog box, click Copy.
  4. The web tool users and their roles in the copy source application are copied to the copy target application.


Info

If a web tool user from the copy source application already exists for the copy target application, that user's role is overwritten.

Web tool users that only exist for the copy target application are left as is.
