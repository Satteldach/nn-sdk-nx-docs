6.2.1 Downloading Save Data Uploaded by the User
  1. In Save Data List, in the Save Data (Original) column for the target report number, click Details.
  2. In the Original Save Data dialog box, click Download.
  3. The save data begins downloading.
Info

It may take some time for the downloading to start if the size of the save data is large.

Note

Save data uploaded by a user is deleted 6 months after the user was allowed to upload it.
