7 Using NsrarConverter

Extracting NSRAR Files

Command

NsrarConverter.exe dearchive <extraction source NSRAR file> <extraction target directory>
Argument Description
<extraction source NSRAR file> Specify the NSRAR file obtained from the web tool.
<extraction target directory> Specify the directory to which to extract the NSRAR file.

Export

Summary File/Directory Name Comments
Extraction target directory The extraction target directory specified when dearchive was run.

Save data directory <SDA ID>

When collecting save data from multiple user accounts, the number of pieces of save data is equivalent to the number of pieces of data in the user environment.
SDA ID is a unique ID assigned to each piece of save data.


Save data system directory <SDA ID>_data The directory to which one piece of save data is extracted.

Metadata <report number>_<date/time obtained>.csv

The following information is included as reference information.

Metadata Content Description

Item Name Description
survey_request_id Report number.
device_serial Serial number.
application_id Application ID.
user_uploaded_at Date and time when the user uploaded the data (UTC).
save_data_archive_id Save data archive ID.
local_user_id User ID of the user on Switch.
local_user_name User name of the user on Switch.

save_data_type

account (fixed value).

Extraction Example

In this example, the application creates a file like the following within the save data.

MountSaveData("save:/", userId);
CreateFile("save:/file.bin", 0);


If you run dearchive on an NSRAR file containing the save data of two users, it is extracted as follows.

NsrarConverter.exe dearchive 70259573_20210427014316.nsrar dearchived_dir
 
dearchived_dir/
dearchived_dir/146009606483030242/
dearchived_dir/146009606483030242/146009606483030242_data/
dearchived_dir/146009606483030242/146009606483030242_data/file.bin
dearchived_dir/164691363703859368/
dearchived_dir/164691363703859368/164691363703859368_data/
dearchived_dir/164691363703859368/164691363703859368_data/file.bin
dearchived_dir/70259573_20210427014316.csv

In this case, 146009606483030242 and 164691363703859368 are the SDA IDs that correspond to the save data for each of the two users.

The correlation between the SDA ID and the user is described in the CSV file.

Importing Save Data to Development Hardware

If you want to import the content of the extracted save data from the NSRAR file to the development hardware for testing or repairs, use the save data backup and restore functionality of DevMenu or DevMenuCommand alongside this tool.

For more information about DevMenu and DevMenuCommand, see NintendoSDK Documents.

The following procedure is an example.

  1. Start the application and create save data.
  2. In DevMenu, use the feature in the Save Data tab to back up the save data to a microSD card.

  3. Replace the content of the save data backed up to the microSD card with the content extracted from the NSRAR file.
    Example: Replace sd:/NintendoSDK/BackupSaveData/<yyyymmddhhmmss>_<applicationId>/<type>/<applicationId>/<xxxx>/file.bin with dearchived_dir/146009606483030242/146009606483030242_data/file.bin.

    Note

    At this time, make sure that you do not change or delete sd:/NintendoSDK/BackupSaveData/<yyyymmddhhmmss>_<applicationId>/<type>/<applicationId>/<xxxx>/__BackupSaveDataInfo.xml.

  4. In DevMenu, use the feature in the Save Data tab to restore the replaced save data from the microSD card.
Info

You can also use the feature to emulate the save data location (nn::fs::SetSaveDataRootPath()).

Archiving Repaired Save Data as an NSRAR File

If you want to restore the repaired save data for the user, you must archive the repaired data as an NSRAR file and upload it.

Typically, the process involves repairing and changing the files in the <SDA ID>_data directories in the directory for the extracted NSRAR file, and then specifying this extraction directory and archiving it as an NSRAR file.

Command

NsrarConverter.exe archive <extraction source NSRAR file> <repaired extraction target directory> <export target directory>
Argument Description
<extraction source NSRAR file> Specify the same file as the extraction source NSRAR file specified when dearchive was run.
<repaired extraction target directory>

Specify the extraction target directory specified when dearchive was run after overwriting the contents of that directory with the repaired save data.

Summary File/Directory Name Comments
<repaired extraction target directory> Any (The extraction target directory that was specified when dearchive was run.)

Save data directory <SDA ID> Do not delete or rename the directory.


Save data system directory <SDA ID>_data

Do not delete or rename the directory.

All of the content in this directory is restored to the user's save data.

<export target directory> Specify the directory to which to export the repaired NSRAR file.
Note

Make sure that you do not leave any unnecessary files (such as __BackupSaveDataInfo.xml files and BAK files).

If you collected save data from multiple users, make sure that you do not mix up the users.


Export

Summary Filename
Repaired NSRAR file <extraction source NSRAR file base name>_fixed.nsrar


Notes

  • If the tool crashes, a working directory called NsrarConverterTemporary is sometimes left in the same directory as the NSRAR file. In this case, delete the working directory.
