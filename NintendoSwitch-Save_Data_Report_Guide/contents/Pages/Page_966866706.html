8 Using the Nintendo Switch

This section describes the procedures that users follow to upload and download save data using Switch. Use these descriptions to provide appropriate guidance to users.

Note

To use these features, the system version of the Switch console must be version 13.0.0 or later.

Also provide this guidance where necessary.

Common Operations

  1. From the HOME Menu, select Settings.
  2. In Settings, select Data Management.
  3. In Data Management, point to any item, and press and hold the Left Stick or Right Stick and the + Button or − Button for 3 seconds or longer. (Example: Left Stick and + Button)
  4. The system transitions to the Send/Receive Save Data screen.

Uploading Save Data

  1. If save data can be uploaded for an application (if the status of Upload in the UL/DL Permission screen is OPEN for the application), Can be sent is displayed on Switch for that application. Select the application for which you want to upload save data.
  2. A confirmation dialog box is displayed. Click Send. Depending on the region setting for the Nintendo console, a EULA agreement might be required.
  3. The system begins uploading save data.


Downloading Repaired Save Data

  1. If repaired save data can be downloaded for an application (if the status of Download (Repaired) in the UL/DL Permission screen is OPEN for the application), Can be received is displayed on Switch for that application. Select the application for which you want to download save data.
  2. If there are no problems with overwriting the save data currently saved to the Switch with the repaired save data, select Overwrite in the confirmation dialog box.
  3. The system begins downloading repaired save data.
