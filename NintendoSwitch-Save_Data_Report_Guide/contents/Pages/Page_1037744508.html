6.2.2 Uploading, Downloading, and Deleting Repaired Save Data

Uploading Repaired Save Data

  1. In Save Data List, in the Save Data (Repaired) column for the target report number, click Details.
  2. In the Repaired Save Data dialog box, click Upload.
  3. When the dialog box for selecting a file on the PC is displayed, select the NSRAR file you want to submit.
  4. If there is already repaired save data, select the Confirm that the repaired save data already exists check box.
  5. Click Upload again.
  6. The save data begins uploading.
Note

This uploaded save data must be repaired data for save data that was uploaded by a user. Also, after downloading the repaired save data, you cannot re-edit and upload it.

Downloading Repaired Save Data

  1. In Save Data List, in the Save Data (Repaired) column for the target report number, click Details.
  2. In the Repaired Save Data dialog box, click Download.
  3. The save data begins downloading.
Info

It may take some time for the downloading to start if the size of the save data is large.

Deleting Repaired Save Data

  1. In Save Data List, in the Save Data (Repaired) column for the target report number, click Details.
  2. In the Repaired Save Data dialog box, click Delete.
  3. The save data is deleted.
Note

This operation cannot be reversed.
