5 Nintendo Switch Application Basics

As previously described, the Switch is positioned as a video game system that can be taken outside, where the user can select the play mode most suited to their situation. We will be calling the users' attention to this characteristic.

As a result, a basic feature of applications is that they support playing and switching between the three different play modes introduced previously.

The rest of this document describes basic policies for applications for Nintendo Switch and how to work with those policies. Refer to this material when planning and designing applications.

In most cases, you must follow this workflow for the overall platform when working with these basic policies. However, it is important not to limit development of new play styles by implementing stronger restrictions for all applications.

Consider following the basic policies as a means to increase the value of applications that will run on the Switch. If forcing support of this system would result in a large loss of value for the application, consider creating an exception title that supports only one or two of the play modes.
