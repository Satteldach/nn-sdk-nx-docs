5.3 Other Important Information

Attaching and Detaching the Joy-Con and Docking and Undocking the Nintendo Switch

Although not directly related to the basic policies, some system features (as noted in the previous section) allow users to choose the play style that best suits their situation by docking or undocking the Switch and attaching or detaching the Joy-Con.

The connections between the console and the Nintendo Switch dock and between the main unit and the Joy-Con are not as mechanically durable as the buttons and sticks.

For that reason, you must not use docking and undocking the console or attaching and detaching the Joy-Con as elements of gameplay.

Nintendo Switch Lite Considerations

The Nintendo Switch Lite cannot be placed in the Switch dock and does not support TV mode. In addition, as described in the following section, the Switch Lite controllers cannot be physically removed.

For these reasons, an application that supports only TV mode as the play mode cannot be played at all by Switch Lite users. Furthermore, in tabletop mode, which uses wireless controllers (either Joy-Con or Pro Controller), only Switch Lite users who own a wireless controller can play.

References to Switch in the Application

There is no need to add Switch Lite when displaying pictures of Switch or using the word "Switch" in application text. There is no problem with using pictures of Switch or the word "Switch" to represent both Switch and Switch Lite.

There is no method that would enable an application to determine whether it is running on Switch or on Switch Lite.

Joy-Con Controllers Do Not Detach

Unlike the Switch Joy-Con controllers, the controllers of the Switch Lite cannot be physically removed. As a result, from the application's perspective Switch Lite always acts like the Switch with the Joy-Con controllers attached. You can, however, pair wireless controllers with the Switch Lite.

When an application requires using a wireless controller, it calls the controller support applet or transitions to a scene for connecting a wireless controller in a proprietary way. With Switch, users can meet the requirement by detaching the Joy-Con and pairing it wirelessly or by pairing another wireless controller they happen to have. With Switch Lite, however, users might not have a separate wireless controller on hand, so you cannot assume that a wireless controller will be connected.

Under these circumstances, if the following problems occur within the application, consider using the corresponding workaround strategies.

Application Does Not Leave a Scene or Mode Until a Wireless Controller Is Connected

If the application is designed to wait for the connection of a wireless controller, users who are playing with Switch Lite could get stuck at that point. Change the specifications of the application to allow users to leave that scene or mode even without a wireless controller. For example, you could use a Switch Lite button to return to the previous scene. When you use the controller support applet, call it in a way that allows you to return to the previous scene.

Application Does Not Work With Wireless Controller Until Joy-Con Is Detached

In most cases with Switch, the system is in the state where the Joy-Con controllers have been detached when the application recognizes a wireless controller (especially the Joy-Con). However, because Switch Lite is always in a state where the controllers are attached to the system, Switch Lite users cannot play the application using a wireless controller if the application only supports using wireless controllers when the Joy-Con have been detached. For this reason, ask the user which controllers they are using, or allow the game to be operated with any controller.

Switch Lite has a system feature that provides a way for the user to disable controller button operations (as if the Joy-Con was detached). It is fine to ask customers to contact customer support when necessary.

Info

There is functionality planned for the SDEV and EDEV that emulates a state where the Joy-Con controllers are not removed. This functionality can be used for testing and debugging.
