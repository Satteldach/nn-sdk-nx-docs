6.2 Using Features That Vary by Play Mode

In addition to the performance differences, the various play modes also differ in the following ways.

Functionality and Characteristics TV Mode Tabletop Mode Handheld Mode
Touch Panel Unavailable Available Available
Accelerometer and Gyroscope in the Controller Available Available Unavailable
IR Motion Camera Available Available Available
Screen Size Generally assumed to be at least 40 inches 6.2 inch 6.2 inch
Screen is flat on the floor or table Generally difficult Easy Easy

This section describes the measures to take when a functionality used by the application cannot be used in some play modes.

Touch Panel

In TV mode, the screen display and touch panel input of the Switch console are forcibly turned off.

Although there are no issues if this is used with the intention of having the touch panel assist the controllers, if operations on the touch panel are required to make progress in the application, the user playing in TV mode will be forced to switch play modes.
Therefore, even for applications that use the touch panel as a main input device (where touch panel operations are an enjoyable element of gameplay), consider using some alternative form of controls, which will enable users to continue playing in TV mode.

Treat applications that can only be controlled using the touch panel, without supporting wireless controllers, as applications (or states) that only support handheld mode.

Examples of Alternatives
  • Command input using controller buttons or sticks
  • Pointing operations that use controller sensors (accelerometer and gyroscope)

Accelerometer and Gyroscope in the Controller

Getting the centers of gravity for two Joy-Con controllers

When getting the centers of gravity for two Joy-Con controllers for usage similar to gyro aiming, it is possible to have the same specifications when attaching Joy-Con controllers to the classic-grip accessory as when attaching Joy-Con controllers to the console. It is possible to play in all three play modes.

Using two Joy-Con controllers independently

Although it is possible to obtain the accelerometer and gyroscope values for the Joy-Con even in handheld mode, the Joy-Con are attached to the console when in handheld mode, so it is not possible to obtain the respective sensor values for the two Joy-Con controllers.
Therefore, as shown in the following, it is difficult to play applications that involve moving the two Joy-Con in different directions for handheld mode.

Figure 6-3 When Moving Left and Right Controllers Independently, and When They Are Attached to the Console

For applications where the main operation method involves moving the two Joy-Con independently, consider alternative controls that allow users to continue playing even when in handheld mode. For example, replacing the respective Joy-Con sensor input with input from the right and left analog sticks or buttons, or with touch panel operations.

If the application specifications are such that it is difficult to implement alternative controls, and they require accelerometer and gyroscope values respectively from the two Joy-Con controllers, set the application (or state) to not support handheld mode.

IR Motion Camera

The IR Motion Camera can be used in any mode.

However, from the viewpoint of providing the same gaming experience, in some cases, user experience may be much less satisfactory in handheld mode, due to the need to hold the console in one hand, or the difficulty of using the IR Motion Camera while viewing the console screen.

Depending on the specifications of the application, there may be no issue, but it would be user-friendly to prepare an alternative method.

As a result, consider preparing alternative methods to the handheld mode IR Motion Camera when supporting gameplay in places such as a moving train, where there are limited locations to place the console.

Specifications Calling for Specific Screen Sizes

Specifications that call for using a large-screen TV will work in TV mode but can cause problems in tabletop mode/handheld mode.

  • In some cases, the UI text on the screen, including parameters and character names, will become unreadable at the screen size used in tabletop mode/handheld mode.
    • Workarounds for this situation include limiting the display of UI text in tabletop mode/handheld mode, and maintaining a type size that remains legible even on the console screen.
    • A more user-friendly approach would be to implement a user-triggered feature that, for example, could switch display via the touch panel to make all the UI visible at any time.
    • Alternatively, to avoid such cases, we recommend checking the console screen each time there is detailed expression.

Specifications for Playing Opposite Other Players

As noted in 3 Three Play Modes, applications that call for playing opposite other players, with the console laid flat, would be possible for the tabletop mode if there is a flat surface on which to place the console. It would be difficult, however, for TV mode, because you cannot place a TV flat on a floor or table.

It is likely that in many cases, although basic policy requirements can be met in terms of also working in TV mode and enabling the application to proceed, it would effectively be impossible to provide a similar game experience with the same UI displayed on the TV in TV mode.

Multiplayer Play With One System

The situation where multiple users each hold a controller and engage in multiplayer play on one Nintendo Switch system is possible for TV mode and tabletop mode but not for handheld mode, due to its nature.

It would be obvious to the user that multiplayer mode is not possible in handheld mode.

For this reason, the situation where multiple players are playing using multiple controllers is one of the criteria that does not support handheld mode.

Info

A successful handheld mode implementation of this type would not be prohibited.
