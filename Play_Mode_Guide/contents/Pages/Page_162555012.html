6.1 Absorbing the Performance Differential

This section describes how to address the performance differential between TV mode, tabletop mode, and handheld mode.

If your game is similar to existing video games that have the following characteristics, you can satisfy the basic policies by implementing the support described in this section.

  • Single player only
  • Projecting the game screen on the TV
  • Supporting controller use that includes attaching two Joy-Con controllers to the classic-grip accessory, or using the Switch Pro Controller
  • Not using the acceleration or gyroscope functionality, or using two separate Joy-Con centers of gravity values or the Switch Pro Controller values
  • Not using the IR Motion Camera or touch panel

Because there is a performance differential between TV mode, tabletop mode, and handheld mode, if you complete an application using the maximum CPU and GPU performance for TV mode, restrict the application specifications by the performance differential for tabletop mode and handheld mode.

Prioritize for high performance differential absorption and low effect on users.

Changing the Screen Resolution

The specifications that affect users the most depend on the individual application. However, for hardware, first consider that the Switch console screen is 6.2 inches and 720p.

Rendering this screen at a resolution higher than 1280 × 720 in tabletop mode or handheld mode does not increase performance. For this reason, if the screen resolution in TV mode is 1920 × 1080, first consider lowering the resolution to 1280 × 720 or lower.

In many cases, depending on the application, the quality of the user experience in tabletop mode and handheld mode can be maintained with a lower resolution (such as 3D graphics at 854 × 480).

Detailed verification continues, but it appears that the performance differential can mostly be absorbed by appropriately adjusting the screen resolution.

Omitting the Least Critical Features for Portability

If the entire performance difference cannot be absorbed by dropping the screen resolution, start omitting the least critical features for portability beyond the living room, as follows, and keeping with the application specifications.

  • Use simple shaders
  • Lighten the load from anti-aliasing
  • Lower the frame rate

For more information about which method is effective at absorbing performance differentials, see NintendoSDK Documents > Features > Features Added by NX Add-Ons > NX Performance Management.
