6.3 Information for Users of Supported Play Modes and Definitions of Those Modes

This section describes the definitions of supported play modes and how to provide information to users about those modes.

Supporting Each Play Mode

Basically, we want every application to operate in every play mode so that the user can freely choose where they play.

As described in Policy 1 in 5.1 Basic Policies, it is important for the entire application to support each of the play modes so that the user can switch between them at any time and freely enjoy the game. However, if the user is playing in handheld mode while they are out of the house, and then encounter a situation where they cannot progress without switching to a TV, the user can no longer play the application at that point. For users to freely enjoy the application, it is important to avoid situations where they cannot progress without switching play modes. As a result, please add adjustments to avoid cases where progression is only possible in certain play modes so that the player can still progress in other play modes.

However, if "playing from beginning to end using a specific play mode without switching play modes" would greatly reduce the enjoyability of the game, designate at least one play mode that can be used throughout the entire application without switching. Otherwise, users who are unable to switch play modes may not be able to play the application all the way to the end.


Defining Supported Play Modes

An application supporting a particular play mode is defined as being one that users can play through the entire core content using only that play mode. The "core content" is the overall term for the modes and scenes in the application that you want the users to focus on playing. For information about how to determine what elements of the application are considered core content, see 7 Supported Examples.

For example, when the following specifications are incorporated into an application, the play modes are no longer supported.

  • When docking and undocking the console is a required element for playing core content.
    Requiring the console to be docked makes it such that the user is unable to continue playing in tabletop mode or handheld mode. Conversely, requiring the console to be undocked makes it such that the user is unable to continue playing in TV mode. If both of these elements are required, the user has to switch between play modes during the core content, and it is not possible to play through the entire application using a single play mode.

  • When attaching and detaching the Joy-Con controllers to and from the console is a required element for playing core content.
    If attaching Joy-Con controllers to the console is required, users without extra Joy-Con or wireless controllers are no longer able to continue playing in TV mode or tabletop mode. Conversely, if detaching Joy-Con controllers from the console is required, users who are only able to play in handheld mode are no longer able to continue playing in handheld mode. If both of these elements are required, the user has to switch between play modes during the core content, and it is not possible to play through the entire application using a single play mode.

Sharing Information About Supported Play Modes

To limit the situation where the user mistakenly purchases an application that is not suited to a particular play mode, based on the assumption that all games could be played using a desired play mode, we plan to indicate on the title sheet for each application, which can be examined prior to purchase, which play mode is supported for how many players and which play mode is not supported by the particular game. The following figure shows an example of the Supported Play Modes display. In this example, the field shows that the application does not support TV mode, can be played by one or two players in tabletop mode, and by one player in handheld mode.

Figure 6-8 Supported Play Modes Display

If no play mode is supported, it is necessary to shade all fields in Supported Play Modes, as with TV mode in the preceding figure.

If a particular play mode is not supported, but there are cases where it can be used, add a note as necessary outside of the field explaining, for example, that "some content may be played using this play mode."

Displaying Play Modes in Applications

When displaying play modes in the application itself, we recommend that you show the icon that represents the play mode alongside its corresponding description, to make it easier for the user to understand the play mode.

Use the icons provided in the Nintendo Switch Artwork Usage Manual (NX_hard_icon_XXX_YYYYMMDD.ai).
