7 Setting up the Joy-Con

Updating the Joy-Con Firmware

Required Tools

  • Updating the Controller Firmware
    UpdateControllerFirmware.bat in the NintendoSDK folder
    This tool is for updating the Nintendo Switch™ controller firmware.

Procedure

Procedure Operation
1

Start the controller firmware update tool.
Execute the UpdateControllerFirmware.bat file in the NintendoSDK folder.
2

Pair the Joy-Con™ to the EDEV.
Press the SYNC Button on the Joy-Con.

The connected Joy-Con are listed in Connected controllers.

Note
The Joy-Con firmware must be updated to 3.48.x.x and later to update firmware by connecting to the rails on the console.
If the firmware is earlier than version 3.48.x.x, connect the Joy-Con wirelessly to update it.
If the Joy-Con batteries are low, recharge them first using the console rail or the Joy-Con charging grip.
3 Simultaneously press the L Button and ZL Button or the R Button and ZR Button on the Joy-Con and then release them.
The firmware update starts when the buttons are released.
4

The firmware will be updated.
When updating the firmware, do not connect controllers that are connected via Bluetooth to the rails, or remove controllers that are currently connected to the rails.

During the Joy-Con (R) update, the Joy-Con will restart one time.
Although the connection to the console is performed automatically when the Joy-Con is restarted, the connection may fail on rare occasions due to the signal status.
If reconnection fails, press any button on the Joy-Con and reconnect manually. The update starts again after reconnection.

5

When the firmware update completes, "Firmware update completed" is displayed on the screen.
The updated Joy-Con is disconnected from the EDEV.

Note

Depending on the signal strength, the update may fail and display the "Verify error occurred" message.

If the update fails, try performing the update again.
Comments

Controller firmware updates can be performed consecutively. To update a different controller, repeat the procedure from step 2.

When the firmware update is finished, restart the EDEV. (Plans call for restarting to be unnecessary with future SDKs.)
