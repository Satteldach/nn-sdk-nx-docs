2 EDEV Operating Environment

The following environment is required for setting up the EDEV and running applications.

Operating system
  • Microsoft Windows 10 Pro (64-bit)
  • Microsoft Windows 11 Pro (64-bit)
Note

An account with administrator rights is required.

Note

Behavior is not assured if you change the system locale in the operating system to something other than the default value.

.NET Framework
  • Microsoft .NET Framework 4.7.2 or later
Info

If not already installed, download and install from the following link.

https://support.microsoft.com/en-us/help/4054531/microsoft-net-framework-4-7-2-web-installer-for-windows

.NET Core SDK

  • .NET Core SDK 3.1.420
Info

.NET Core SDK is required for the following versions of NintendoSDK.

  • Versions of NintendoSDK between 12.2.0 and 14.3.0
  • Versions of NintendoSDK between 15.0.0 and 15.2.0
Info

If not installed, use the installer located in the following path.

  • NintendoSDK\Installers\DotNetSdk\v3.1\dotnet-sdk-3.1.420-win-x64.exe
.NET 6 SDK

  • .NET 6 SDK 6.0.400
Info

.NET 6 SDK is required for the following versions of NintendoSDK.

  • NintendoSDK 15.x.x and later
  • NintendoSDK 14.x.x versions released after the release of NintendoSDK 15.0.0
Info

If not installed, use the installer located in the following path.

  • NintendoSDK\Installers\DotNetSdk\v6\dotnet-sdk-6.0.400-win-x64.exe
