9 Installing Applications (For Non-Developers)

Installing Applications via microSD Card

You can install an application by saving its NSP file on a microSD card, and then inserting the card into the development hardware.

Info

For more information about creating NSP files, see NintendoSDK Documents > Features > Building > Creating Application Images.


Procedure Operation
1

Save the NSP file to a microSD card.

Note

If the NSP file is larger than 4 GB, you cannot save the file if you do not use a microSD card that is at least 64 GB.
If you are using a microSD card of 32 GB or less, save the file using the following procedure.
2 Insert the microSD card into the EDEV.
3

In DevMenu, in Application, select Install from SD.
4

To install an individual application, select the appropriate NSP.

To install all NSP files, select Install All.


Info

For more information, see NintendoSDK Documents > Features > Controlling the Development Hardware > DevMenu.

Saving an NSP File Larger Than 4 GB to a microSD card of 32 GB or Less

Perform the following procedure.

Procedure Operation
1

Copy the \Tools\DivideNsp\DivideNsp.ps1 and \Tools\DivideNsp\DivideNsp.bat files from the directory where NintendoSDK is installed to the directory in the microSD card where you want to place the NSP file.
2 Drag the NSP file you want to save to the DivideNsp.bat file that was copied to the microSD card.
3 The process ends after a directory is created with the same name as the NSP file that you want to save.


Info
  • When you drag the NSP file you want to save in step 2 and a file with the same name already exists in the directory, an error message is displayed, stating that "***.nsp" cannot be created because a file or directory with the same name already exists.
    In this case, either delete the applicable files in advance or change the placement location to a different directory and perform the procedure again.
  • You can achieve the same result by using this procedure to save the NSP file and directory of the same name to some place other than an SD card, and then copying them to any directory on the microSD card.
