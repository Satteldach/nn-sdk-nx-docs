9.9 SDEV Not Recognized on PC

If the SDEV console was connected to another PC, the PC connection settings might have been changed from the default.
Without changing the settings, the SDEV may not be recognized when connecting to a new PC, so you must initialize the PC connection settings on the SDEV.

Before connecting the SDEV to a PC, initialize the PC connection settings using the following procedure.

  1. Attach the Wii U AC adapter to the AC adapter port on the top of the SDEV console while pressing the Recovery button on the back of the SDEV.

    Info

    Continue pressing the Recovery button until the LEDs on the back of the SDEV console (Game Card detector LED, Power LED, and SD card detector LED) all light up.

  2. Check that the LEDs on the back of the SDEV console (Game Card detector LED, Power LED, and SD card detector LED) are all lit, and then release the Recovery button.


    The SDEV turns on and starts in recovery mode.

    Note

    When the SDEV is started in recovery mode, operations are not ensured even if the screen displays. Regardless of whether the screen displays, an SDEV started in recovery mode must be initialized, as described in step 4.

  3. When configuring network connections with the iptables feature, or when it is unclear whether the settings have been configured, use the --clear option of the bridge-iptables subcommand in ControlTarget before initializing the SDEV to delete the iptables configuration file saved in the SDEV.

    Note

    When initializing the SDEV, if the iptables configuration file is still retained, the iptables rules are reapplied after the SDEV is initialized.

  4. Initialize the SDEV.
    For more information about initializing the SDEV, see Nintendo Switch SDEV Quick Start > Initializing the SDEV.

    Note

    When the SDEV starts in recovery mode, the PC connection settings on the SDEV are configured to automatically set the IP address, so change the network setting on the PC to automatic. For more information about the PC connection settings on the SDEV, see NintendoSDK Documents > Features > Controlling the Development Hardware > Target Manager.
