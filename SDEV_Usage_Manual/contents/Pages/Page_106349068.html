5.5 Pairing the Joy-Con

To use Joy-Con controllers that have not previously been connected to the SDEV, you must first register (pair) the controllers to the SDEV.

Information for up to 10 controllers can be registered in the SDEV, the same as with the Switch retail unit.

Before using the Joy-Con, perform the following procedure to pair the Joy-Con.

  1. Turn the SDEV on.
    For more information about turning the SDEV on, see 5.1 Turning the SDEV On and Off.

  2. Check that the DevMenu is displayed on the SDEV’s LCD screen, or that the application is running.

  3. Attach the Joy-Con to the SDEV console.
    Attach Joy-Con (R) to the right rail and Joy-Con (L) to the left rail.

    The Joy-Con pairing completes within one second.

  4. Check whether you can operate the Joy-Con.
    When pairing is complete, you can operate the Joy-Con attached to the SDEV console.

  5. Remove the Joy-Con from the SDEV console.

  6. Check the Joy-Con player LED.

    If pairing is complete, the player LED lights up corresponding to the assigned controller number.

    Info

    For more information about player LED lighting patterns, see the Nintendo Switch Controller Guide.

    If the Joy-Con still do not respond after performing this procedure, see 9.6 Unresponsive Joy-Con.
