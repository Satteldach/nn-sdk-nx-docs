8.6 Testing Local Communication Using Wired Communication

By connecting SDEV units together with a coaxial cable, you can use wired communication to test the local communication features used by the Switch application.

Note

Because wired communication using a coaxial cable differs in quality from actual wireless communication, use wireless communication when testing behavior during application development.

A coaxial cable is not included with the SDEV, so you must prepare one separately.

To connect the SDEV units together, turn off the second DIP switch on the back of the SDEV and attach the coaxial cable to the coaxial connector (Wi-Fi2).

When not using wired communication with the coaxial cable, turn the DIP switches that were off back to on.

Note

The SDEV uses a male coaxial connector.

When using a different type of coaxial cable or rod antenna, use the bundled SMA conversion connector to convert the type.
