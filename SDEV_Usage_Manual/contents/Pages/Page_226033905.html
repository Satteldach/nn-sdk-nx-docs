9.7 SDEV Units Cannot Communicate With Each Other

If SDEV units cannot communicate with each other, check the settings and connection according to the type of SDEV connection.

If SDEV Units Cannot Use Wireless Communication With Each Other

On the back of the SDEV, check that the first and second DIP switches are both ON.

If SDEV Units Cannot Use Wired Communication With Each Other

Check that the SDEV units are properly connected to each other.
For more information about connecting the SDEV with a wired connection, see 8.6 Testing Local Communication Using Wired Communication.
