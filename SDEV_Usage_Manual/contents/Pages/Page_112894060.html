8.1 Restarting the SDEV

If you need to restart the SDEV during application development or other times, perform the following operations.

Restarting From DevMenu
  1. In the upper-right corner of the screen, select the power icon.
  2. Select Reboot.


Restarting When the SDEV Is Connected to a PC

For more information about connecting USB devices, see 6.1 Connecting the SDEV and a PC.

  1. On the PC, from the Start menu, select Nintendo Target Manager or Nintendo Target Manager 2.

    Target Manager starts.
  2. Nintendo Target Manager:
    • Right-click the SDEV you want to restart and select Soft Reset from the menu.
  3. Nintendo Target Manager 2:
    • Right-click the SDEV you want to restart and select Power > Restart from the menu.
Restarting by Removing and Reinserting the Wii U AC Adapter
  1. Unplug the Wii U AC adapter from the SDEV and wait a short while before reconnecting.
  2. The SDEV restarts.
