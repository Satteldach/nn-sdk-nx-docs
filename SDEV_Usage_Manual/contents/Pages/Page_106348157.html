9.5 Flashing LED on the SDEV Cradle

If the TV output LED on the SDEV cradle is flashing, check whether there is a problem with the SDEV console and SDEV cradle connection.

If there is no problem with the connection, perform the following operations.

  1. Remove the SDEV from the SDEV cradle.
  2. Restart the SDEV.
    For more information about restarting the SDEV, see 8.1 Restarting the SDEV.
  3. Unplug the AC adapter from the SDEV cradle.
  4. Connect the AC adapter to the SDEV cradle.
  5. Connect the SDEV to the SDEV cradle.
