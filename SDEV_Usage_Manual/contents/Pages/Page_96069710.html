4.3 Components

This section describes the names of the components for the SDEV console and SDEV cradle.

The names of the Joy-Con components are the same as for the Switch retail product. See the Nintendo Switch Overview.

SDEV Console
Top View
Number Name Description
1 Game card slot

The slot where the NX development card is inserted.
2 Headset jack

Used to connect a commercially available headset.

The SDEV console does not have a built-in microphone. A commercially available headset must be connected to use voice chat or similar features.
3 Air vent The air vent for the cooling fan.
4 Volume buttons

Adjusts the volume using the + and - Buttons.
5 POWER Button

Used to enter and exit sleep mode.

You cannot turn the SDEV on and off by pressing the POWER Button. Attach and remove the Wii U AC adapter to turn the SDEV on and off.
6 AC adapter port

Used to connect the bundled Wii U AC adapter.

The SDEV console has no built-in battery, so always connect the SDEV using the Wii U AC adapter when in use.
7 Ethernet port Used to connect to a PC using an Ethernet cable that supports 1000BASE-T.
8 HDMI output port

Used to connect an HDMI cable.

You can connect to a TV and mirror the audio and video from the SDEV on the TV.
9 Debug controller port Used to connect the bundled Classic Controller Pro.
10 Coaxial connector (Wi-Fi2) Insert the coaxial cable when connecting SDEV units for wired communication.
11 Coaxial connector (Wi-Fi1/BT)
12 Air vent The air vent for the cooling fan.
Bottom
Number Name Description
13 USB Type-C™ connector
(USB Type-C connector)

Used to connect the SDEV cradle or a USB device.

When connecting USB devices, see the notes in 6.2 Connecting the SDEV and USB Devices.
14 Air intake The air intake for the cooling fan.
Rear View
Number Name Description
15 DIP switches

Changes the behavior of the SDEV.
16

Recovery button

Starts the SDEV in recovery mode.
17 microSD card slot The location where you insert a microSD card.
18 Game card detector LED Illuminates when an NX development card is inserted.
19 Power LED Illuminates when power is being supplied.
20 SD card detector LED Illuminates when a microSD card is inserted.
SDEV Cradle
Top View

Number Name Description
1 TV output LED

Illuminates when the SDEV cradle is correctly connected to a TV.
Also flashes when the SDEV cradle detects an error.

It also lights up temporarily when it receives power from the AC adapter and when it connects to the SDEV system.
2 Console connector

Used to connect to the USB Type-C connector on the bottom of the SDEV console.

The plug can be connected in either orientation.
Front

Number Name Description
3 HDMI connector

Used to connect an HDMI cable.

During TV mode, connects to a TV and outputs audio and video from the SDEV to the TV.
4 USB port (supports USB 3.0/USB 2.0)

Used to connect a USB 3.0 or 2.0 device.

Note

Do not use bus-powered USB hubs. Operation cannot be ensured for those devices.
5 AC adapter port

Used to connect the bundled AC adapter.

The plug can be connected in either orientation.

Info

Use the dedicated AC adapter for Switch (the HAC-002).
