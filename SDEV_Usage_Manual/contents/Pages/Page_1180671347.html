4.2 Differences Between SDEV and SDEV-D, and How to Distinguish Between Them

Differences

The size of the main memory is different between SDEV and SDEV-D. The SDEV memory is 6 GB, while the SDEV-D memory is 8 GB.

The size of the memory available to the application changes depending on the memory mode settings. In environments that are mixed SDEV and SDEV-D, take extra care if you are setting the same memory size for both. For more information, see NintendoSDK Documents > Features > Controlling the Development Hardware > Development Assistance Settings > Memory Settings; also see Features > Controlling the Development Hardware > DevMenuCommand > Development Assistance Settings > Controlling the Memory Mode.

Distinguishing Between Them

Info

There is no way to distinguish between SDEV and SDEV-D from the running application.

Distinguishing Based on Rating Label

The rating label applied to the back of the console is marked with SDEV or SDEV-D for each device.

Distinguishing Based on Development Hardware Control Features

Check the following information.

  • Target Manager
    • The target list type is SDEV or SDEV-D.
  • Target Manager 2
    • The target list hardware type is SDEV or SDEV-D.
  • ControlTarget
    • SDEV or SDEV-D is displayed for Hardware in list-target [--xml] [--csv] or detect-target [--xml] [--csv].
Distinguishing Based on Serial Number

The first five digits of the serial number are "XAL02" for SDEV and "XAL06" for SDEV-D.
