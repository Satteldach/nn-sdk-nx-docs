9.10 Cannot Detect USB Devices

If the USB device cannot be detected, check the settings and connection according to the type of USB device connection.

Info

If a USB-Ethernet adapter is connected for internet communication, consider using wireless communication.

If the USB Device Is Connected Using the SDEV Cradle

If the USB device is connected to the SDEV cradle, check the following.

  • Is the USB device correctly connected to the SDEV cradle?
  • IS the SDEV console correctly connected to the SDEV cradle?

For more information about connecting USB devices, see 6.2 Connecting the SDEV and USB Devices.

If you do not find any problems while checking these things, perform the following operations.

  1. Disconnect the AC adapter for the SDEV cradle from the power outlet and wait 10 seconds.
  2. Remove the SDEV console from the SDEV cradle.
  3. Restart the SDEV.
    For more information about restarting the SDEV, see 8.1 Restarting the SDEV.
  4. Connect the AC adapter for the SDEV cradle to a power outlet.
  5. Connect the SDEV cradle to the SDEV console.
  6. Connect the USB device.

If the USB device still cannot be detected after completing these operations, confirm that power is being supplied to the USB port by connecting another USB device to the SDEV cradle that lights up when power is supplied.
If power is not being supplied to the USB port, the SDEV or the SDEV dock might be damaged. For more information about requesting a repair, see 10 Repair Contact.

If the USB Device Is Directly Connected to the SDEV Console

Check that the USB device is properly connected to the SDEV.
For more information about connecting USB devices, see 6.2 Connecting the SDEV and USB Devices.

If there were no problems with the connection, restart the SDEV.
For more information about restarting the SDEV, see 8.1 Restarting the SDEV.

If the USB device still cannot be detected after completing these operations, confirm that power is being supplied to the USB port by connecting another USB device to the SDEV console that lights up when power is supplied.
If power is not being supplied to the USB port, the SDEV might be damaged. For more information about requesting a repair, see 10 Repair Contact.
