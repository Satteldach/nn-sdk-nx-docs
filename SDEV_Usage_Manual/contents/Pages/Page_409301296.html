6.1 Connecting the SDEV and a PC

The SDEV may need to be connected to a PC when installing applications or writing to an NX development card.

Connect the SDEV to a PC using one of the following procedures.

  • Connect the SDEV console directly to a PC.
  • Connect the SDEV to a PC using a network device such as a switch or router.
Connecting the SDEV Console Directly to a PC

Connect the SDEV and the PC, and set the network setting on the PC to Obtain an IP address automatically.

  1. Connect an Ethernet cable to the Ethernet port on the top of the SDEV console.

  2. Connect the Ethernet cable to the PC.

  3. On the PC, in Control Panel, select Networking and Internet > Network and Sharing Center.

  4. Select the Ethernet connected to the SDEV.
  5. Click Properties.
  6. Select Internet Protocol version 4 (TCP/IPv4) and then select Properties.
    If the Internet Protocol Version 4 (TCP/IPv4) check box is not selected, select the check box.
  7. Configure the following settings and click OK.
Connecting the SDEV to a PC Using a Network Device

Connect the SDEV to a PC using a network device such as a switch or router.

Info

You can connect the SDEV to a PC using a network device regardless of whether there is a DHCP server.

  1. Connect an Ethernet cable to the Ethernet port on the top of the SDEV console.
  2. Connect the Ethernet cable to a network device connected to the PC.
