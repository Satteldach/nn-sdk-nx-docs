5.2 Setting Up SDEV

When you obtain an SDEV, first set it up.

For more information about setting up the SDEV, see the Nintendo Switch SDEV Quick Start.

Note

If you are using an SDEV that was connected to another PC, the PC connection settings may have changed from the default. Without changing the settings, the SDEV may not be recognized when connecting to a new PC, so you must initialize the PC connection settings on the SDEV. In this case, see 9.9 SDEV Not Recognized on PC and initialize the PC connection settings.
