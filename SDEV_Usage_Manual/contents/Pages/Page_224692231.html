9.11 Cannot Run an Application

If an application cannot run on the SDEV, try changing the following aspects of the development environment.

Replace the LAN cable or USB hub.

Using a poor quality LAN cable can cause unpredictable communication issues. The situation might improve by replacing the USB hub, particularly when using Jumbo Frame.

Disable Jumbo Frame

If the PC, SDEV, or any other devices present on the network's communication route do not support Jumbo Frame, enabling Jumbo Frame causes communication issues.

Follow these steps to disable Jumbo Frame on the PC and SDEV.

  1. Use the Device Manager on the PC to display the network adapter.

  2. Right-click the applicable adapter and select Properties from the shortcut menu.

  3. On the Advanced Settings tab, disable Jumbo Frame.

    Info

    Depending on the network adapter you are using, Jumbo Frame may be shown as Jumbo Packet.

    Jumbo Frame is disabled on the PC.

  4. On the PC, from the Start menu, select Nintendo Target Manager or Nintendo Target Manager 2.

    Target Manager starts.

  5. Right-click the SDEV to configure, and select SDEV Settings from the shortcut menu.

  6. Clear the Enable Jumbo Frame check box.

    Jumbo Frame on the SDEV is disabled.
