Check that you have everything in the following set before using the SDEV.

  • SDEV main unit (HAT-001) or SDEV-D main unit (HAT-001(-01))
  • Joy-Con™ (L) (HAC-015), Joy-Con™ (R) (HAC-016) (Joy-Con (L), Joy-Con (R))

  • Classic Controller Pro (RVL-005(-02))
    Used as a debug controller.
  • SDEV cradle (HAT-003)
    Works just like the Nintendo Switch dock for the Switch retail product.
  • AC adapter (HAC-002)
    Used to supply power to the SDEV cradle and charge the Joy-Con.

  • Wii U™ console AC adapter (WUP-002) (Wii U AC adapter)
    Used to connect and supply power to the SDEV console.

    Info

    Some SDEV sets include the following instead of the Wii U AC adapter.

    • Conversion cable for AC adapter (UNI336-1524) and UNI336-1524

    To use, attach the conversion cable to the AC adapter.

  • Joy-Con strap (HAC-014)

  • HDMI Cable
  • Ethernet cable (Standard: Cat6, length: 3 m)
  • USB charging cable
  • SMA conversion connector
  • Bundled items list
