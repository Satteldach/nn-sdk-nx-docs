4.1 What Is the SDEV

The SDEV is an advanced development hardware for developing Nintendo Switch™ applications.

The SDEV can be connected and used with devices such as a TV, PC, and debug controller. For more information about the connection ports for each device, see 4.3 Components.

It has the following major differences compared to the Switch retail product.

  • The SDEV includes external interfaces that are useful for development but not found in the Switch retail product.
  • The SDEV does not come with a battery.
    When using the SDEV, always connect it to a power source using the Wii U AC adapter.
  • The SDEV motherboard has a built-in PCB for adding extra features, making the SDEV thicker than the Switch retail product.
    Use the SDEV cradle, because the SDEV cannot be placed on the Nintendo Switch dock.
