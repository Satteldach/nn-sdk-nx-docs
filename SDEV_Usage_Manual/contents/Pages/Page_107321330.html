9.6 Unresponsive Joy-Con

If the Joy-Con is not responding, perform the following operations depending on the state of the Joy-Con.

If the Joy-Con Is Detached From the SDEV Console

Reset the Joy-Con if the player LED is lit but the buttons are unresponsive.
Press the SYNC Button on the Joy-Con to reset it.

If the player LED on the Joy-Con is not lit, pair the Joy-Con.
For more information about pairing the Joy-Con, see 5.5 Pairing the Joy-Con.

If the Joy-Con Is Attached to the SDEV Console

Any Joy-Con controllers attached to the SDEV cannot be used when the SDEV is in TV mode. Switch the SDEV to handheld mode to remove the Joy-Con controllers from the SDEV.

For more information about switching the handheld mode, see 8.4 Switching Between Handheld and TV Modes.
