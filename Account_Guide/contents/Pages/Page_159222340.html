5.3 Supporting Guest Players

Switch user accounts are meant for users who will play applications and keep save data on that Switch system. When a friend comes over to the house and plays on a person's system without storing any save data, treat them like someone playing the game without creating a user account, as a guest player. The system features will only have limited support for guest players. Applications that need to handle guest players must implement that functionality in a proprietary way.

Note
Contact Nintendo when additional system features, such as applets, are needed to make your application plans a reality.

Sample Sequences

This section shows a sample sequence that supports guest players by presenting the option to play without leaving any save data, in scenes within the game where user accounts are selected.
The sample is organized by whether the account management applet is used by the application in a user account selection sequence.

Using the Account Management Applet

This sample corresponds to applications using a user account selection UI and the account management applet.

Not Using the Account Management Applet

In this case, a proprietary application UI is implemented. The account management applet is not used. The standard SDK provides a collection of features needed for implementation, including getting the user account nicknames and icons and adding user accounts via the account management applet.
