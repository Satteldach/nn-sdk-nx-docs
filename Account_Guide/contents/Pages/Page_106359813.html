3 User Account

A user account is a Switch system local account that can be created without a network connection. It is the means for grouping and managing save data and other assets stored on the Switch system individually for each user. The various services are designed and operated with the assumption that one user account is created and used for each user of that Switch system. Assuming there are multiple users, eight user accounts can be created per Switch system. When an application is running on the Switch, the existence of at least one user account is maintained.
