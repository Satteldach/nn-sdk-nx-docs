4.1 Network Service Account

The network service account is an account used by various Switch network services like NEX and the friends feature. This account is created and used automatically by the system. Only one network service account can be linked to each user account. For more information about NEX, see Nintendo Switch NEX Guide. For more information about the friends feature, see Nintendo Switch Online Play Guide.

Network Service Account Attributes

Network service accounts can store the following data as attributes. If the Applicable When column is anything other than -, that attribute only exists if the situation is applicable.

Attribute Applicable When Description
Internal ID - An ID that is globally unique among network service accounts within the same environment, and which cannot be changed. For more information about the server environment, see Nintendo Switch Independent Server Setup Manual. It is handled as a unique key by NEX and the friends feature on Switch. It is obtained from the application and used when specifying friends and the like. It is not displayed to the user.
The network service account internal ID is unique. IDs linked to Nintendo Switch systems for China do not overlap with the IDs linked to Nintendo Switch systems for other regions.
Nickname - Stores the nickname of the linked user account. In cases where the same Nintendo Account is linked to multiple Switch consoles, this nickname is synchronized across all user accounts that are linked to the same network service account.
Profile image - Stores the profile image of the linked user account. In cases where the same Nintendo Account is linked to multiple Switch consoles, this profile image is synchronized across all user accounts that are linked to the same network service account.
Information about the linked Nintendo Account Linked to a Nintendo Account upon creation

Stores information about the Nintendo Account linked to the network service account.
Information about the linked account for China Linked to an account for China upon creation Stores information about the account for China linked to the network service account.

With the exception of the internal ID, there is a possibility that these attributes will change while the application is running. (They might be changed by another Switch linked to the account, or by some other device.) Design your specification so inconsistencies do not arise even if these attributes happen to be changed while the application is running.

Creating a Network Service Account

When a Nintendo Account or an account for China is first associated with a user account on Switch, a network service account is automatically created. Network services become available when the user subsequently signs in with that network service account.

Linking and Unlinking User Accounts and Network Service Accounts

In consoles with system version 6.0.0 and later, users cannot remove links between user accounts and network service accounts. (Users can remove links on consoles with system versions prior to 6.0.0.) If a Nintendo Account is removed, the user account to which that Nintendo Account was linked cannot be linked to a separate network service account.

Similarly, on Switch for China, users cannot remove links between user accounts and network service accounts.

However, for reasons related to repair or customer support, the links between user accounts and network service accounts (or accounts for China) might be removed.

The following describes whether changes to the linked state between a user account and a network service account are possible while the application is running.

  • A user account that is not linked to a network service account can be linked to a new network service account at any time while the application is running. However, it is not a requirement for the application to follow this immediately.
  • A user account cannot be unlinked from a network service account while the application is running.
Info

When designing your application, note that the network service account linked to a user account can get changed even though the user account remains the same. This behavior is different from the Wii U account system. See the descriptions both in NintendoSDK Documents > Features > Save Data, and Nintendo Switch Online Play Guide.

Deleting Network Service Accounts

Network service accounts cannot be deleted by the user. However, when a Nintendo Account (or an account for China) is deleted, the linked network service account can no longer be used.

Supplemental Information: Guest Login Feature

A future feature (tentative name: Guest Login) is under consideration for accessing the information of an existing network service account without linking to the user account. This would allow a user to sign in to their Nintendo Account from inside an application for temporary access to the network service account that is linked to that Nintendo Account. As an example of how this feature might be used, a person could take the character they raised and upload it as online data, and then use that data on the Switch of a friend without the need to create a user account on that Switch.
