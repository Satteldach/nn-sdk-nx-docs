2.1 Account Structure of Switch for China

Nintendo Switch systems for China (Switch for China) use a different account system than Nintendo Switch systems for other regions (Switch for other regions).

On Switch for China, you cannot link user accounts to Nintendo Accounts. To use network services on a Switch for China, the user account must be linked with an account for China. A WeChat account is required for creating an account for China.

When an account for China is first associated with a user account on Switch, a network service account is automatically created.

The following four types of accounts are used on Switch for China. Subsequent sections provide information about each account type.

Name Description
User Accounts The same as the accounts for Switch for other regions.
Network Service Accounts

This account is used to identify a user for Switch network services.
The account is issued automatically when a user account on the Switch system is linked with an account for China (described later) and is not exposed to the user.
The friend system runs using the internal ID of the network service account to distinguish among users.
The network service account internal ID is unique. IDs linked to Nintendo Switch systems for China do not overlap with the IDs linked to Nintendo Switch systems for other regions.
Accounts for China

These accounts are equivalent to the Nintendo Accounts on Switch for other regions.
However, services offered and their formats may differ from those for Nintendo Accounts.
This account is exposed to users.
A WeChat account is required for creating an account for China.
Account for China are never linked to a Switch for other regions.
WeChat Accounts

Accounts for WeChat, which is a messenger application offered by Tencent.
A WeChat account is required for creating an account for China.
For this reason, users must have a WeChat account to use Switch network services on a Switch for China.
