2 Switch Accounts Overview

The emphasis of the Switch account system is the easy storage of user resources like save data at the level of individual users. To achieve this goal, the system design enables developers to require users to select accounts at a time that will assist users in understanding the importance of selecting accounts. The Switch system does not require users to select an account when the HOME Menu (see the following figure) is displayed at times like when the system is started or wakes from sleep. The system prompts account selection when starting each application from the HOME Menu or according to the sequence design of the application.


The following three types of accounts are used on the Switch system. The sections after the table provide information about each account type.

Name Description
User Account

User accounts are accounts for differentiating users and are the means for managing save data and other assets accumulated on the Switch system individually for each user.

You can create a maximum of eight accounts on a single console. In addition, user accounts can also be created in an offline environment.

This account is called the user within console features and elsewhere.
Network Service Account

This account is used to identify a user for Switch network services.
The account is issued automatically when a user account on the Switch system is linked with a Nintendo Account. It is not exposed to the user.

NEX (the library of extended communications features provided by Nintendo) and the Friend System run on Switch using the internal ID of the network service account as the user identifier.

In addition, smart device applications provided by Nintendo also use an account with the same characteristics.
Nintendo Account

This account is used for identifying users across multiple services, such as My Nintendo and smart device applications, and not just on the Switch.
It is used on the Switch for Nintendo eShop and the My Nintendo Rewards Program service.

It can be linked with external service accounts and the Nintendo Network ID (NNID).

There is a 1:1 correlation between this account and the network service account.

The following figure shows the correlations among the three accounts. For more information about the link status, see 4.4 Account Link Status.


One network service account and one Nintendo Account can be linked with each user account. These accounts are used by one person in real life. In other words, they operate as assets held by the same user.
