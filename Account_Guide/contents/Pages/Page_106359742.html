1 Introduction

Objectives and Content

This documentation describes the specifications for Nintendo Switch™ (Switch) accounts and describes how to use these Switch accounts in applications, presenting more detailed information than in Nintendo Switch Overview.

Intended Audience

This documentation is intended for planners and developers of Switch applications.

When to Read This Document

Read this documentation when you are planning and developing Switch applications. Before reading this documentation, read the documentation about accounts in Nintendo Switch Overview.

Related Documents

The Nintendo Switch Overview provides a simple overview of accounts. Before reading this documentation, read the section about accounts in Nintendo Switch Overview.

When implementing online play features, also see Nintendo Switch Online Play Guide.
