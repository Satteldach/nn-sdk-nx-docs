5.2 Different Designs for Supporting the Switch Account System

The Switch account system has the following characteristics.

  • User account selection or switching can be designed to occur at natural points within the application.
  • You can design your save data on the assumption that there will be one user for each user account.

In addition, Design 5 is provided for the purpose of porting to the Switch, such as for applications released on multiple platforms.
To improve the user experience on the Switch platform, we recommend using Design 1 or Design 2 instead of Design 5. For more information, see Reasons for Not Recommending Design 5 in 5.2.5 Design 5: Select One Account Before the Application Starts.

Notes About Different Designs for Supporting the Switch Account System

Provide a way in the application to return prior to selecting a user account so as to enable switching user accounts.
If returning is not possible prior to user account selection, the user experience will be poor because users will have to restart the application to switch to a different user account.
