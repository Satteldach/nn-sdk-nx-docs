5.1.2 Feature Group 2: Linking With Network Service Accounts

The following features for linking network service accounts are provided.

Function Notes
Getting the Availability for Using Network Service Accounts This information indicates whether the network service account is linked and confirms whether that account is in a usable state.
For example, the account will be considered unusable even when there is a linked Nintendo account that is an unusable state because the user has not agreed to the latest End User License Agreement.
Get the ID tokens for network service accounts

This feature is necessary for connecting to game servers that developers are building themselves.

For more information, see Nintendo Switch Independent Server Setup Manual.
