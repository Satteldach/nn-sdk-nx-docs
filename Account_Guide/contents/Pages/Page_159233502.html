6 Appendix: Characters That Can Be Entered for User Account Nicknames

The characters that can be entered for user account nicknames will match those that can be used for Mii nicknames on the Nintendo 3DS and Wii U in the Japan, North America, and Europe regions. In addition, on the Switch, the same set of characters can be used for the nicknames of Mii and amiibo owners.

The Unicode list is summarized in the following files. (The file format is different but the contents are the same.)

File format Link
XLSX file NX_user_nickname_character.xlsx
XLLT file NX_user_nickname_character.xllt
XLOR file NX_user_nickname_character.xlor
Info

The characters acceptable as entries for Switch for China are the same as those for Switch for other regions.
