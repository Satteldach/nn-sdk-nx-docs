3.2 Creating and Deleting User Accounts

Creating User Accounts

In the Switch system's initial startup sequence, one or more user accounts are created. Afterward, the existence of at least one user account is always maintained. A new user account can be created from the system's Settings menu. A feature is also provided in the form of an account management applet so that user accounts can be created at the time of user selection and when new save data is created. For more information, see 5 Application Support for Accounts.

Deleting User Accounts

Users can delete user accounts from the Settings menu on the Switch. When a user account is deleted, all save data for that user that exists in the Switch system is deleted. However, the application that is running must close to delete the user account.

For this reason, when seen from the application, a situation arises where the user account and its save data, which existed when the application was previously running, are lost the next time the application is started. Exercise care when designing applications with a dependency between the save data of different user accounts. For more information, see the Nintendo Switch Online Play Guide.

If a user account is deleted, associated network service accounts are not deleted.

Restrictions When Deleting User Accounts

To delete the user account, the application that is running must close. The state of at least one user account existing on a system is also maintained. When only one user account remains on a system, that account cannot be deleted.
