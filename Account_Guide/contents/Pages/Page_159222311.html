5.2.4 Design 4: Do Not Use Accounts

This design corresponds to situations where the application does not need to identify a specific user. In these cases, there is no need to support the Switch account system because there is no need to save any information that is dependent on the user account.

Advantages
  • Players can use applications and services without the need to select a user account.
  • There is no need to consider sequences specific to the Switch account system.
Important Information
  • Because the application runs entirely without any signed-in user account, the following kinds of online features that depend on a user account are not available.
    • Online ranking and data store.
    • Friend matchmaking and friend presence.
    • Linking outside of the Switch, such as to Web applications.
  • Save data cannot remain.
  • The profile activity log is not recorded.
