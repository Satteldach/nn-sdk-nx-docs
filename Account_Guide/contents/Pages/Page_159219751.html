3.1 User Account Attributes

User accounts can store the following data as attributes.

Attribute Description
Internal ID

An internal ID to identify user accounts on the Switch system. Its value never changes, ensuring uniqueness on the Switch system. Handle the value as one that is not globally unique. It is not displayed to the user. Use this ID as the key when applications identify or specify user accounts.
Nickname

A name set by the user that the user can change at any time. This nickname can be used as the name the application sometimes shows to other people, such as during online play.

  • The supported character encoding is UTF-8.

  • Up to 10 characters can be input.
  • It is never an empty string.
  • The symbols @, %, and \ cannot be used.
  • Each space is counted as a character.
  • Strings consisting only of spaces cannot be entered.
  • Up to five numbers can be entered as characters.
  • A profanity check is conducted when the name is entered. Names that include profanity cannot be set. (For this reason, there is no attribute that indicates a profanity flag for Mii.)
  • For a list of the characters that can be used, see 6 Appendix: Characters That Can Be Entered for User Account Nicknames.
Info

Profanity filtering for the language set in the system is applied to check nicknames for profanities.
This check is performed only when confirming and saving nicknames. Nicknames that have been set can continue to be used when the profanity filter applied is changed, in addition to when there are changes to the system language or updates to the profanity filter itself.
Profile image

An icon set by the user that the user can change at any time. The icon is selected from among the set of character images provided by Nintendo, or from Mii characters. This user icon can be used as the icon that the application sometimes displays to other people, such as during online play. The following image format is used.

  • Pixel size: 256 × 256
    Icons available via the internet are provided in 64 × 64 and 128 × 128 sizes.
  • Binary size: Maximum 128 KB (128 × 1024 bytes)
  • Format: JPEG

While the icon itself is designed to use the entire rectangular area, there are no trimming rules when using the icon for games. A circular area can be cut out, or the corners rounded. It can be used according to the design of the application.
Information associated with network service accounts

This information indicates whether the user account is linked with a network service account. Linking to a network service account may be changed later.

Info

In version 6.0.0 and later of the Switch system, users cannot clear that link by themselves. Unlinking can be done for repair or customer support.

In addition, the following information is managed separately for each Switch console.

Information Description
The listed order of user accounts The order at the time the user account list is obtained is managed as perpetuated information. This same order is used by the HOME Menu and other system features to display the list. Users can edit the list order from the Settings menu at any time.

Note About Getting Attribute Information

The internal ID is the only type of attribute information in the user account that must exist and cannot be changed. Handle other types of attribute information assuming that they may be modified or deleted. For example, if save data is managed using the nickname and list order as keys, the save data may no longer be correctly accessed when these are changed. For more information about save data, see Nintendo Switch Online Play Guide.

User nicknames, profile images, and list order of user accounts can be changed at any time, even while the application is running. Nevertheless, the application is not required to immediately indicate the changes even if this information is displayed within the application.

Note About Displaying Nicknames

To display nicknames in the application, we recommend supporting the display of characters described in 6 Appendix: Characters That Can Be Entered for User Account Nicknames. Even if a nickname contains characters that cannot be displayed by the application, handle it in a way that the display is not corrupted or the application is prevented from proceeding—for example, by using a substitute character. The range of characters available for nickname input may be extended in the future. Handle all unrecognized characters in the same way. Do not hide characters that the application cannot display, or replace them with blank spaces. The reason is that the nickname might accidentally end up looking like a profane word if characters were simply left out.

The Switch DevMenu will provide a feature for setting nicknames in the development and testing environments using characters other than those listed in 6 Appendix: Characters That Can Be Entered for User Account Nicknames. For the specific strings that can be set, see the DevMenu manual.

Info

The Switch system features can display all characters included in the system fonts and replace those characters not included in the system fonts with the alternate character "□" (the white square, Unicode 25A1). The list of characters included in the system fonts can be found in the Nintendo Switch System Features Guide under Shared Data > System Fonts.

Reference: User Accounts and Mii Characters

Unlike the Wii U, the Switch does not require the configuration of Mii settings. This serves the following purposes.

  • Reduces the effort needed to create a user account.
    It is easy for a user to create a user account when they want to.
  • Improves the degree of freedom in selecting a user profile.
    For the profile image, image assets other than Mii characters can be set (but not free-form images).
