5.1.3 Feature Group 3: Account Management Applet

The Switch has several system features for managing accounts. This library applet can be called and used from the application to comprehensively support those features that involve displaying a UI. The table lists the basic features provided by the account management applet. This page provides overviews of the features presented in the table. For more information, including the methods for specifying parameters in your implementations, see the API Reference bundled with the SDK documentation.

Feature Notes

Select user account

 Selects one from among the user accounts registered on the console. Profile images and names are displayed for the choices.
If save data thumbnails have been saved, the layout for displaying thumbnails is used.
Create user account Displays a UI for creating a new user account and conducts internal processing.
Activate network service account Provides guidance for making a network service account available to the specified user account and conducts internal processing.

In addition, an API is provided for saving the save data thumbnails that are displayed by the applet.

Info

All library applets including this account management applet have a common feature for specifying the coloring in the UI. For more information about this feature, see Nintendo Switch System Features Guide.

Select User Account

Selects one from among the user accounts registered on the console. Profile images and names are displayed for the choices. The following describes the distinctive aspects of this feature and the specifications that require attention.

  • A plus icon is displayed for adding user accounts.
    • This plus icon is not shown if the maximum number of user accounts has been reached.
    • The plus icon is disabled and does not work to add a user account if it is known that the user would not be able to sign in.
  • You cannot replace the text displayed by the account management applet.
  • All user accounts are shown without exception, whether or not they are signed in or linked with a network service account.
    • No distinctions are made in what is displayed.
    • By default, for system version 6.0.0 and later, user accounts that can sign in at that point in time are available to be selected.
      • Users who cannot sign in appear dimmed.
  • When the applet is called, the focus of the cursor is on the user account that was last signed in on the console.
    • The focus will be on the left-most user account if the console has just powered on, or if the user account that would otherwise be the focus has been deleted.

The available options are as follows.

Option Description

Activate network service account

 When this option is enabled, the selected user account is assured to be one with an available network service account.
If the selected user is not linked to a network service account or is in an error state, the applet displays guidance to link to a network service account or resolve the error.
This option is designed primarily for selecting a user account for gameplay in network mode.
Specify user accounts that cannot be selected When calling the applet, you can specify the user accounts that will be unavailable.
The selected user account is not available and cannot be selected.
The applet does not clarify the reason a user cannot be selected.
Allow automatic skipping

Use this option to allow the user-selection process to be skipped automatically when the system has only one registered user account.
When this option is enabled, the applet selects the existing user when it is called and quits without displaying the UI.
Display for selecting additional user accounts

This option is intended for scenarios where more than one user is selected within an application.
If the applet is called with this option enabled and there is a user account that is signed in, the applet behaves in the following way.

  1. The displayed text changes to Select another user to play with.
  2. The signed-in user account becomes unselectable automatically.
Display the Skip button

When this option is enabled, an additional button is displayed for skipping the UI.

The user can select this button to skip this user interface without creating or selecting a user account.
Also see the 5.3 Supporting Guest Players section.
Enable the selection of users who cannot sign in

If this option is enabled, all users, including those who cannot sign in at that point in time, can be selected. The option can be used when selecting users for purposes other than signing in.

Notes About Enabling the Option for Automatic Skipping

To allow automatic skipping, you must specify this option explicitly when calling the applet. If it is not disadvantageous to your sequence, we recommend enabling this option to automatically skip display so the process works as expected. The Switch's system features typically use this applet with this option enabled, including when the option to select a user account before starting the application is used.

Also note that you cannot simultaneously combine and use the following options.

  • Allow automatic skipping and Specify user accounts that cannot be selected
  • Allow automatic skipping and Display for selecting additional user accounts

Sequence of Processes Inside the Applet

Displaying Save Data Thumbnail Images

When one or more thumbnail images representing the save data are stored on the console, those thumbnails are displayed along with the screen for selecting a user account. These thumbnail images are 256 × 144 pixels.

Create User Account

This feature is for the sequence that is reached when the process inside the applet's feature for selecting a user account has proceeded to the sequence for adding a user account. If the maximum number of users has been reached, an error message is displayed at the entry to the started sequence and it is ended.

On consoles with system version 6.1.0 and later, if it is known that the user being added would not be able to sign in, a message with guidance is displayed at the entry to the started sequence, and the process is canceled and ended.

Sequence of Processes Inside the Applet

Activate Network Service Account

This feature provides guidance and conducts internal processing to make a network service account available to the user account specified in the application. If a network service account is not linked to the user account, the user is requested to do so (by signing in to a Nintendo Account) and guidance is displayed for required user operations, such as agreeing to the EULA again and subscribing to Nintendo Switch Online. If you want your application to display this guidance at some point, you can perform a process like the one described later. For more information about subscribing to Nintendo Switch Online, see Nintendo Switch Online Play Guide.

  1. Check the status by using Getting the Availability for Using Network Service Accounts in 5.1.2 Feature Group 2: Linking With Network Service Accounts.
  2. If no network service account is usable, call this feature from the account management applet.

In general, this feature does not need to be used inside the application because the system can be expected to guide the user when necessary. For more information about the error handling of the features needed for network service accounts, see documentation such as the programming manuals for the various features.
