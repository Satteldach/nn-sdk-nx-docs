4.2 Nintendo Accounts

A Nintendo Account is an account explicitly created by an individual user that can also be used on PCs and smart devices. By linking the Nintendo Switch with a Nintendo Account, the user can receive services on Switch that are linked to their email address or linked to other devices.

Note

Avoid direct use of the term Nintendo Account in your application. If you must use the term (for example to inform users that a Nintendo Account is required), call the Account Management applet. (For more information, see 5.1.3 Feature Group 3: Account Management Applet.) This way, any future extensions or changes to Nintendo Accounts and related services can be handled by system updates.

Using Nintendo Accounts

Contact Nintendo if your application will be designed to get Nintendo Account attributes (including those listed previously), or to link the Switch with web services or smart device applications.

To get Nintendo Account attributes, you must have an independent server. (For more information about independent servers, see Nintendo Switch Independent Server Setup Manual.) Each application must also get user consent to get the attributes.

For more information about creating Nintendo Accounts in the development environment (the server environment for application development, which differs from the production environment), see NintendoSDK Documents > Guide to Setting Up the Environment.

Relationship Between Nintendo Accounts and Licenses

The license information for downloadable applications and downloadable content bought and redeemed on Nintendo eShop is managed at the level of Nintendo Accounts.

For more information about how these licenses held by Nintendo Accounts are managed and shared on Switch, see the Nintendo Switch E-Commerce Guide.

Handling Users Under 13

Children under the age of 13 are not allowed to create their own Nintendo Accounts. A Nintendo Account for a child (a child account) can be created after the child's parent or guardian 18 or older has created their own Nintendo Account and has given their consent for the child to have a Nintendo Account. Children do not need to have an email address because the email address registered to the Nintendo Account of the parent or guardian is used for contact information.

For applications that use Nintendo Accounts, assume the existence of users under 13 and users without a registered email address and design specifications to avoid problems.

Info

With the implementation of the EU General Data Protection Regulation (GDPR) in May of 2018, users under the age of 16 in the relevant European countries and areas cannot create their own Nintendo Accounts.

Nintendo Account Creation Requirements

To create a Nintendo Account, the user must agree to the following conditions. You can provide network services on the Switch based on this assumption.

  • The user must agree to the privacy policies and terms of use stipulated by the network services offered by Nintendo that will be used with the Nintendo Account.
  • The parent or guardian must consent to the collection of personal information about the child, as based on the U.S. law known as the Children's Online Privacy Protection Act (COPPA).

Deleting a Nintendo Account

There is a procedure for users to delete their Nintendo Accounts. When a Nintendo Account is deleted, the Switch network service account and other assets and services associated with that account are no longer available. To assist users who have accidentally deleted a Nintendo Account, there is a feature for users to cancel the deletion request if it is done within a certain period of time.

Linking With a Nintendo Network ID

One Nintendo Network ID can be linked to each individual Nintendo Account. To link a Nintendo Account with a Nintendo Network ID, the country and date of birth information that have been registered separately to each must match. The email addresses set with a Nintendo Account and a Nintendo Network ID do not need to match.

There is an operation for the user to remove the link with the Nintendo Network ID. The link is also removed if the country registered in the Nintendo Account is changed so that they do not match anymore.
