5.2.3 Design 3: Select Additional Account/Switch Accounts Within the Application

This design covers playing within the application while adding or switching user accounts. This design assumes the creation of a proprietary UI for each application, primarily including applications that support guest users.

Advantages
  • You can implement adding or switching user accounts at any point that suits the application's specifications.
Important Information
  • Generally speaking, you must implement the UI for your application.
    • The basic feature provided by the account management applet is selecting a user account from among the accounts registered on the system, regardless of sign-in status.
    • It is possible that application specifications would allow for support via combinations of the various applet options.
    • When implementing a proprietary UI, you must provide support for users who cannot sign in. For more information, see 5.1.1 Feature Group 1: Displaying User Accounts and Changing Their States.
  • Sharing data among all users would require proprietary support that used the account save data region (allowing, for example, synchronization among different data instances).
    • See NintendoSDK Documents > Features > Save Data, and Nintendo Switch Online Play Guide for considerations about save data.
  • Talk to your NEX lead about your method for implementing the simultaneous use or switching of user accounts while in a NEX use environment within the application. The reason for this request is that the processes for signing in and out of the NEX server can affect server performance.

This design offers many variations, because it can be freely interpreted. As a result, this documentation includes three examples that are likely to be representative.

Design 3-1: Mini-Games

The first example envisions titles that are collections of mini-games, incorporating multiple game modes. General board game and karaoke titles could also be included in this type. The natural sequence for titles like these would be to begin with selecting either the game mode to play in or the number of players and settings, and then to proceed to selecting participating user accounts.


Design 3-2: Supporting Both Single and Multiplayer Mode

The second example envisions titles that support both single player (single play mode) and multiple player (multiplay mode). Account selection for single play can be skipped when title specifications denote using single play solely for offline practice modes. However, the single play history will not be saved in this case.


Design 3-3: Staged User Selection

In the third example, after selecting the first person's user account at the start of the game all other players are selected upon entry to multiplay mode. (This design is inherited from Designs 1, 2, and 5.) This design is a good fit for titles where specifications call for multiple players to play after selecting a leader or for multiple players to play in roles that assist the main user account. In both cases, play records would also accumulate for sub-players.

In this case, you can use the account management applet user interface with the Display the Skip Button option selected, even when the user accounts for two or more players have been selected.


Info

In version 6.0.0 and later of the NX system, a forced user selection can occur before starting an application, in conjunction with the application's license. However, in some cases user selection is duplicated for applications that have implemented this pattern in the HOME Menu and in the application.

As an option for avoiding this situation, a setting in SDK version 7.0.0 and later allows using selected user account data when the system has already performed user selection for reasons related to license. When this option is enabled, the application can get data about whether user selection occurred from the HOME Menu and data about the selected user. Using this data, you can achieve implementations that skip repeating user selection in the application when users were already selected in the HOME Menu.
