4.3 Accounts for China

Accounts for China are equivalent to Nintendo Accounts used on Switch for other regions. These accounts are created explicitly by users and are exposed to them.

Accounts for China can only be linked with Switch for China. Also, creating accounts for China requires having a WeChat account, which is an account for the WeChat messenger application provided by Tencent.

Note

Avoid direct use of the phrase "accounts for China" in your application. If you must use the term (for example to inform users that an account for China is required), call the Account Management applet. (For more information, see 5.1.3 Feature Group 3: Account Management Applet.)

Attributes for Accounts for China

Accounts for China can store the following data as attributes.

Attribute
Description
Internal ID

A unique internal ID that is automatically issued by the system when an account for China is created. The value cannot be changed. It is not displayed to the user.
User Name

The user's name. This setting is required.
This attribute can be modified by the user.
Gender The user's gender. This setting is required.
This attribute can be modified by the user.
Date of birth

The user's date of birth. However, only the year and month are required. The day cannot be set. This setting is required.
Although users themselves cannot make changes, changes may be possible under some conditions.
Linked WeChat Accounts

Information about the WeChat account specified when creating an account for China is stored.
Accounts for China and WeChat accounts have a one-to-one relationship. WeChat accounts linked to accounts for China cannot be changed.
Info

With accounts for China, there is no account state that corresponds to a Nintendo Account child account.

Creating Accounts for China in the Development Environment (dd1)

A WeChat account is required for creating an account for China in the production environment (lp1), but in the development environment (dd1), you can create accounts for China without a WeChat account.

For more information about creating accounts for China in the dd1 development environment, see NintendoSDK Documents > Guide to Setting Up the Environment in the document package included with NintendoSDK NX Add-On 9.4.0 or with NintendoSDK NX Add-On 10.1.0 and later.

Relationship Between Accounts for China and Permissions

Permissions for downloadable applications or downloadable content that were purchased or redeemed on Nintendo eShop are managed using the accounts for China.

The specifications for managing and sharing permissions possessed by accounts for China are the same as those for Nintendo Accounts. See the description of Nintendo Accounts in the Nintendo Switch E-Commerce Guide, but replace "Nintendo Accounts" with "accounts for China."

Deleting Accounts for China

There is currently no way for users to delete accounts for China. However, the accounts may be deleted via Nintendo actions.
