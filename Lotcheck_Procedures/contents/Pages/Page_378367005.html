4.12 Submitting Documentation for amiibo Support

For applications that support amiibo, you must submit the Request for Using amiibo and Lotcheck Submission Sheet.

Perform Lotcheck based on this content.

Related NDP Pages
  • Available from NDP > DEVELOPER SUPPORT > Nintendo Switch > Downloads
  • Submission: NDP > My Products > target_product > Releases or Downloadable Content > target_release > go to the guide on the right side of the screen > ROM Upload
Procedure
  1. Go to the NDP > DEVELOPER SUPPORT > Downloads page, and select and download the Request for Using amiibo and Lotcheck Submission Sheet (package name: amiibo Application Sheet).
  2. Create the checksheet, following the instructions within the file.
  3. Compress the file into ZIP format, and submit it on the ROM Upload screen. Click the Advanced button on the bottom of the screen to expand the screen for uploading additional files.
