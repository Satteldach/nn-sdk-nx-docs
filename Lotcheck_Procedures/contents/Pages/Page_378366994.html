1 Introduction

Purpose and Content

This document describes the processes surrounding the submission of the master ROM for a Nintendo Switch™ application, with a primary focus on Lotcheck.

It provides an overview of Lotcheck, and descriptions of tasks related to Lotcheck and the operations of related systems.


The information presented in Nintendo Switch Master ROM Submission Procedures > Submitting a Master ROM is described here in this document in greater detail.

Intended Audience

This document is intended for Switch application developers and for those responsible for submitting master ROMs.

When to Read This Document

Read this document when you are developing Switch applications, before submitting a master ROM. You can also refer to it, as needed, after submitting the master ROM.

Important Notes

Item names, buttons, and statuses shown in Nintendo Developer Portal are displayed in bold text.

Terminology Used in This Document

Terminology Description
Developers Software publishers and people working in application development within Nintendo.
NCL, NOA, NOE

The names of the separate business entities within the Nintendo group.

NCL is an abbreviation for Nintendo Co., Ltd., in Japan.
NOA is an abbreviation for Nintendo of America Inc., in the United States.
NOE is an abbreviation of Nintendo of Europe GmbH, in Germany.
NDP Licensing contact The contact department at Nintendo for software publishers. NCL, NOA, and NOE each have one contact. The company that signed the Nintendo Switch licensing agreement is responsible.
ROM The executable file for the application or demo software that users operate.
Master ROM A ROM file that is submitted to Lotcheck.
Release In this document, releasing refers to creating a retail version from the master ROM and then putting the version for sale in Nintendo eShop or as a packaged version in retail stores.
Patches A patch (also called update data) is a mechanism for adding functionality or fixing discovered bugs after an application's release. Patches must be submitted using the same procedures as for the master ROM because Lotcheck testing occurs before distributing patches.
Downloadable Content

Downloadable content is a system for adding more content after the release of an application. The downloadable content also goes through Lotcheck before it is released, so it must be submitted to Nintendo with the same process as used for master ROMs.

Release Dashboard

An online resource where necessary data is entered before submitting to Lotcheck, using the Nintendo Developer Portal (NDP). You can also upload master ROMs from this page.

Page location: Nintendo Developer Portal > My Products > product_name > Releases (or Downloadable Content) > release_name.
Lotcheck submission Requests for Nintendo to perform Lotcheck. Click the Submit button on the NDP Release Dashboard.

Related Systems


System Description URL
Nintendo Developer Portal (NDP) A website specifically for application developers working on the Nintendo platforms. https://developer.nintendo.com
Online Title Management System 2 (OMAS2)

The system for requests for server-supported network services, and for reports about network specifications, the distribution of patches, and the like.

https://omas2.mng.nintendo.net
BCAT Management Tool

This web tool is used for delivering News and data from the BCAT server. If the application supports BCAT data delivery, you must register the data for Lotcheck.

There is a URL for each server environment.

For more information, see the Nintendo Switch BCAT Management Tool Usage Manual.

Nintendo Content Management System (NCMS)

 A system for submitting the information and materials required for Nintendo eShop distribution. You can use this system to configure pricing for Nintendo eShop and to set distribution dates for titles and videos. https://ncms3.mng.nintendo.net/ncms3/login
Software Legal Information System (SLIM) This system for Nintendo Switch application developers is used for creating the Legal Information page that contains contact information and intellectual property information for users. https://slim.mng.nintendo.net/slim/login
