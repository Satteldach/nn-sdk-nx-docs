4.11 Configuring the System and Network Settings

The following settings for related systems and networks must be configured prior to master ROM submission.

Configure all of the settings that are applicable to your application, as described in Applicable Conditions, without exception.
Detailed procedures are presented in the documents listed in Locations of the Information About Procedures and Detailed Information.

OMAS

Applicable Conditions

The application implements any of the features described in Managing Network Features > List of Network Features in the OMAS2 Manual.

Why Settings Are Needed

If the application uses network features, a request must be submitted and approved on OMAS for each feature.
The OMAS requests initiate the process of setting up and configuring servers so the network features used by the title can be developed.

Applications that require an OMAS request as part of the applicable conditions cannot be submitted to Lotcheck until the OMAS request phase has progressed to During Development/Lotcheck Queue. Make sure that an OMAS request has been submitted before clicking the Submit button on NDP. Clicking the Submit button without progressing the OMAS request causes an error in NDP. (Reference: 10 FAQ/NDP Errors> item 11 on the table)

To avoid errors, your OMAS request must progress to the designated phase.
We recommend that you make your OMAS request at least two weeks before Lotcheck submission.

Locations of the Information About Procedures and Detailed Information

  • OMAS2 Manual: You can also view the information from the Help on the OMAS site.
  • (Reference) For NPLN: NPLN Manual > NPLN Guide > Workflow for Starting to Use NPLN
  • (Reference) For NEX: Nintendo Switch NEX Guide > Development/Usage Overview

Common Problems

BCAT

Applicable Conditions

The application is using the BCAT features.

Why Settings Are Needed

Lotcheck tests features that use BCAT.

The Lotcheck environment (sd1 or sp1) data is used at this point, so you must register the data before master ROM submission.

Locations of the Information About Procedures and Detailed Information

  • Nintendo Switch BCAT Data Delivery Guide > Operations
  • BCAT Management Tool Usage Manual

Independent Servers

Independent server refers to a server that is not provided by Nintendo but that applications can connect to. It is configured and operated independently by the developer.

Applicable Conditions

The application supports services from an independent server prepared by the developer.

Why Settings Are Needed

Lotcheck tests features that use independent servers.

Locations of the Information About Procedures and Detailed Information

  • Nintendo Switch Independent Server Setup Manual > Lotcheck
  • Nintendo Switch E-Commerce Guide > Workflow From Development to Distribution > Lotcheck
  • IP address used for Lotcheck testing: NDP > DEVELOPER SUPPORT > Nintendo Switch > Technical Information > Network Guidance > Canceling Access Control When Submitting a Title Using Independent Servers to Lotcheck

Common Problems

See 11 Common Problems and Bugs - Independent Server Settings.

Comments

When unavoidable maintenance of the independent server is scheduled while the title is in Lotcheck, contact Lotcheck by using the Messages tab. Lotcheck will work around the scheduled maintenance.

NCMS

Applicable Conditions

Applications that fulfill any of the following:

  • The application supports subscription and consumable service items.
  • The application uses the feature that gets information about products sold on Nintendo eShop (including content other than service items).

Why Settings Are Needed

Lotcheck reviews the sales data set for dd1 titles in NCMS after incorporating that data into a Lotcheck environment.
In dd1, be sure to set sales information for all regions where your product will be sold.

Locations of the Information About Procedures and Detailed Information

  • Nintendo Switch E-Commerce Guide > Workflow From Development to Distribution > Lotcheck > NCMS Settings for Lotcheck

Comments

Settings can be configured on NCMS after the product has been created on NDP.

NPLN Dashboard

Applicable Conditions

The application supports network services that use NPLN.

Why Settings Are Needed

Lotcheck tests features that use NPLN. When configuring these settings, the developer must copy the settings of the development environment (dd1) to the tenants for Lotcheck (sd1 and sp1).

Locations of the Information About Procedures and Detailed Information

  • NPLN Manual > NPLN Guide > Workflow From Lotcheck Submission to Release > Preparing the Lotcheck Environment
