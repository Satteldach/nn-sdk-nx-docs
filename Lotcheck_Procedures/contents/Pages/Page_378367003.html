4.10 Entering Rating Settings

To release an application for the Nintendo Switch, you must undergo a rating review from a ratings organization.

Get the ratings that correspond to the release regions and set this information on the Age Rating page.
You can also use this page to get the IARC ratings.

Related NDP Pages

NDP > MY PRODUCTS > target_product > Releases > target_release > go to the guide on the right side of the screen > Age Rating

Procedure

Proceed through the settings, following the instructions on the NDP screens.

Info:

Input data can be copied from another release. Click the button indicated in the red box in the following image. Follow the instructions on the screen to proceed through the operations.

Applications for China

You do not need to set rating information for applications for China.
For more information, see Nintendo Switch Master ROM Submission Procedures > Submitting a Master ROM > Applications for China, or see NDP > PUBLISH > Nintendo Switch > For China.
