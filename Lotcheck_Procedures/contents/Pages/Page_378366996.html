4 Preparing for Lotcheck

This page describes the preparations made by the developers up to Lotcheck submission.
Some content is prepared at the place of development, while other content is prepared on the Nintendo Developer Portal or other sites.

For more information, see "Table 4-1 Preparing for Lotcheck" on this page.

Preparation Steps

For more information about each step, see the pages linked in the table.

When all preparations corresponding to the steps are complete in the release dashboard, the Submit button is enabled.

Info:
  • For more information about how to use the release dashboard, see NDP > Help > My Products > Releases > What is release dashboard?
  • For more information about the procedures prior to those described here, see Nintendo Switch Master ROM Submission Procedures > Submitting Usage Requests and Preparing the Development Environment, and > Creating a Master ROM.
  • Also see the Lotcheck pre-submission checksheet, which is a collection of common issues that you can test for yourself.
