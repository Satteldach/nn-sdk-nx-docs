10 FAQ/NDP Errors

This page summarizes the FAQ and describes how to handle incorrect behavior in NDP.

Contact NDP Licensing if the issue is not resolved by referencing the information on this page. (Reference: 9 Contacts for Inquiries Before, During, and After Lotcheck Testing)


 Category Question Answer
1

Bug

 A developer discovered a bug after requesting Lotcheck for the product. What can we do?

See 5 Items for the Developer to Address During Lotcheck > What to Do When a Bug Is Discovered After Uploading the Master ROM.
2 Waiver Requests Are all waiver requests approved?

Not all requests are approved. The relevant departments at Nintendo will verify and discuss the situation, and determine whether to approve the request.

For more information about waiver requests, see 7 Waiver Requests.
3 Communication We have some requests for the language used for communication between developers and Nintendo. Is handling possible?

Only Japanese and English are supported.

In most cases, NCL communicates in Japanese and NOA and NOE communicate in English, but Japanese and English translations are available as needed. However, a time difference may occur for translations, depending on the situation.
4 Communication Although the NDP Licensing contact is NCL, application sales regions include the Americas and Europe.
Do I have to include both Japanese and English in the content entered in NDP?

Only Japanese is acceptable.

If NCL is the NDP licensing contact, the content is translated into English if necessary.
5 Communication Who will be informed of the Lotcheck results?

NDP sends notification emails only to the users registered with the Product Admin role on the NDP Members tab.

Note that the status displayed on the Releases tab and the Release Info page can be referenced by users with any role.
6 Submission

Is it possible to submit downloadable content to Lotcheck at the same time as the initial release or patches?

Yes, it is possible.

In addition, there are no restrictions on the order of Lotcheck submissions.
If the application supports downloadable content, the downloadable content and the initial release or patch that supports the downloadable content must be submitted to Lotcheck at the same time. Lotcheck is not complete unless both components are received.
7 Submission A rating has not been obtained for the application. Can I still submit a Lotcheck request?

Do not submit it to Lotcheck.

Lotcheck is not complete if official rating information is not submitted.
Make sure that you get the rating before submitting to Lotcheck.
8 Schedule If applications are submitted simultaneously, in what order does Lotcheck occur? Lotcheck occurs in the order applications are submitted. Test preparation, however, may cause testing to be advanced or delayed.
9 Schedule The application has already passed Lotcheck, but we want to change the release date. What can we do? You cannot revise the information on the Release Info page on NDP, including the release date information, after the application passes Lotcheck. Set the final release date in NCMS. The release date registered in NDP will not be applied to the actual release settings.
10 NDP We do not seem to have sufficient access privileges in NDP to enter information or submit applications for Lotcheck. What can we do? You can check your own access permissions on the Users tab. In addition, you can also see the operations that are permitted for each access privilege level in the Help.
Request access privilege configuration from the user with the Product Admin role in your company.
11 NDP Errors I clicked the Submit button for Lotcheck, but an error code and error message appeared. The ROM status remains as Submitting to Lotcheck and does not progress.

Click the link in the error message to refer to the NDP Help page (https://developer.nintendo.com/group/development/help/troubleshooting) with resolution methods.

For more information about errors related to OMAS request phase, see 4.11 Configuring the System and Network Settings > OMAS > Why Settings Are Needed.
12 NDP Errors On the Issues page, 0 is shown for all types of issues, and Issues on the Release Dashboard does not have a check mark. As a result, the Lotcheck Submit button is dimmed and cannot be clicked.

This is an NDP bug.

On the Features page, change any item and click Save. Then revert the change to the correct content and click Save.
You can click the Submit button after reloading the page.
13 NDP Errors Although all of the issues have been resolved on the Release Dashboard, the Lotcheck Submit button remains dimmed and cannot be clicked.

This behavior occurs when the Expected Lotcheck Submission Date entered on the Release Info page is in the past.

The time indicated is not the local time, based on the account settings, but UTC.
For convenience, change the Expected Lotcheck Submission Date to a date in the future and proceed with the Lotcheck submission. It is acceptable if the actual submission date and time is earlier than the date and time set for convenience.
