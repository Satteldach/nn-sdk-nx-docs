What Are Waiver Requests?

In some cases, due to special circumstances, issues cannot be fixed even when a part is not compliant with the guidelines or there is a general bug in the master ROM.

A "waiver request" refers to getting permission from Nintendo to release the product in its current state for the specified issue. If the waiver request is approved, Lotcheck performs testing for application specifications that match the conditions that were waived.

Two Types of Timing for Waiver Requests

Waiver requests are divided into two types, depending on when the request is submitted.

Before Submitting to Lotcheck

  • Content the developer knows is not compliant with the guidelines.
    For more information, see 4.4 Checking Compliance With Guidelines > Submitting a Waiver Request in this document, or see Master ROM Submission Procedures > Submitting a Master ROM > Submitting Waiver Requests.
  • Specifications that require Nintendo approval.
     For more information, see 4.2 Entering Features > Specifications Requiring Advance Notice to Nintendo > Specifications Requiring Nintendo Approval Prior to Submission to Lotcheck.
  • Lotcheck Issues that could not be fixed due to special circumstances when resubmitting a fixed release.
    From the release dashboard, select Issues > Lotcheck Issues > Resolved and make a waiver request for the corresponding issue.

During Lotcheck Testing

  • Content discovered during Lotcheck that is not compliant with the guidelines or has a general bug.
    View the Lotcheck Issues thread reported by the Lotcheck Department and deal with the situation.

Types of Waiver Requests

There are three types of waiver requests: temporary approvals, permanent approvals, and precheck approvals. This section describes the applicable conditions and characteristics of each type of request.

Temporary Approval

In most cases, select this option.
 This waiver approval only applies to the current release version. It is not valid for different release versions.

Select Temporary Approval when there are no instructions from Nintendo.
Instead of asking developers to fix the master ROM for the specific release version, Nintendo often sets the terms for approving the waiver to conditions such as fixing the issue via patch or improved user support.

Permanent Approval

Only select this option when Nintendo instructs you to.
 This permanent waiver approval applies not only to the current release, but also to future releases.

Precheck Approval

Select Precheck Approval when there is a required response item needing approval at the time of precheck submission.
 This waiver applies only to the version submitted for precheck.

You cannot submit to Lotcheck unless all Issues on the Release Dashboard in NDP have been resolved. As described earlier, if one of those Issues is interfering with Lotcheck submission, this waiver removes it temporarily.
It is only valid for the version submitted for precheck. Even if the release version is the same, this approval is not valid for the official Lotcheck submission.
