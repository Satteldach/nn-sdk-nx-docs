4.2 Entering Features

This page describes how to enter information for application features and provides related information.

Nintendo decides what kind of testing the Lotcheck Department will perform based on the information entered in Features by the developer.

The items extracted to Guidelines are based on the information entered in Features. As a result, if there are errors in what is entered or if the entries do not reflect the changes made to the specifications, these guideline items will not be extracted correctly.

Related NDP Pages

NDP > MY PRODUCTS > target_product > Releases or Downloadable Content > target_release > go to the guide on the right side of the screen > Features

Procedure
  1. Click Features.

  2. Enter information for each displayed item.
    Select the same language that you selected in Release Info > Language used for text entry in Features, Test Scenarios, and Lotcheck Submission screen.
    Only proper nouns related to the application can be entered in either English or Japanese.

    Info:

    Input data can be copied from another release.
    Click the button indicated in the red box in the following image. Follow the instructions on the screen to proceed through the operations.


    • Notes
      • In some cases, the language of the copied text does not match the language selected on the Release Info page for Language used for text entry in Features, Test Scenarios, and Lotcheck Submission screen.
        If that happens, change the text so that it is written in the same language as the language you selected.
        • Example:
          In your previous releases, you used Japanese as the input language for your release dashboard, but starting with this release, you decided to use English.
          You copied release data from a previous release. However, this copied data is in Japanese.
          In order to match the language used in this release, you translated the Japanese text into English, and used this English translation in the input field.

  3. At the bottom of the page, click Continue. The entered content is saved and you transition to the Guidelines page.
  4. If the specifications change after the entries have been made, edit Features again.
    The changes will be applied to the Guidelines page, and the number of extracted guideline items increase or decrease.

Specifications Requiring Advance Notice to Nintendo

Contact Nintendo as soon as possible when planning to implement any of the following features or specifications. (Reference: 9 Contacts for Inquiries Before, During, and After Lotcheck Testing)
Because it can often take a long time for parties within Nintendo to come to a consensus, contact us at a stage when there is still plenty of time to handle your inquiry, not immediately prior to Lotcheck.

Specifications Requiring Nintendo Approval Prior to Submission to Lotcheck

  • Using Mii characters
  • The inclusion of advertising language in the game.
    • Advertising language refers to the following:
      • Representations of an existing product or company (such as name, image, logo)
      • Inclusion of a URL or video
      • Collaboration with another title, or other properties
  • Communicating across platforms
  • Using a save data size that exceeds the size limitation specified in the Nintendo Switch NintendoSDK Documents
  • Exceeding the patch size limitation specified in the Nintendo Switch Guidelines
  • Using temporary storage
  • Using cache storage
  • Using amiibo
  • Any other specifications that require Nintendo's permission in the Nintendo Switch Guidelines

For the preceding specified items, if you enter Yes for the applicable item on the Features page, it is listed in the Waiver Requests section of Issues in the Release Dashboard.
You cannot submit to Lotcheck unless all of the content listed in Issues in the Dashboard has been approved. (Reference: 4.5 Resolving Issues and 7 Waiver Requests > Before Submitting to Lotcheck)

If Nintendo is informed of the waiver request before it is submitted, the approval process can go more quickly.


Note: The following type of message appears as you enter data on the Features page.

Specifications You May Want to Contact Nintendo About Before Submission

  • Implementing consumable items
  • Supporting both multiplayer and UGC
  • Specifying Not Required for any rating

These specifications are sometimes difficult to implement and often prone to mistakes.
Although there are no specific requirements for you to contact Nintendo prior to Lotcheck submission, if you contact us in advance we can advise you about implementation and answer any questions or concerns you may have.
