4.13 Additional Information About DLC

This section contains additional information to consider when requesting Lotcheck for the initial release or patch that supports downloadable content, or for the downloadable content itself.

For more information about downloadable content, see Nintendo Switch E-Commerce Guide > Downloadable Content > Developing Downloadable Content.

Related NDP Pages

NDP > MY PRODUCTS > target_product > Downloadable Content

Submit Both Initial Release/Patch and Downloadable Content for Lotcheck

Initial Release/Patch

The release version that supports the E-Commerce downloadable content feature is used to download the downloadable content in that test.
For this reason, submit it for Lotcheck along with the master ROM for the downloadable content. There are no rules for the order in which items are submitted for Lotcheck. Aim for a situation where the master ROMs of both items are available to the Lotcheck Department.

If you have not yet finished developing the downloadable content, submit a precheck version of the content for testing purposes.
For more information, see Nintendo Switch E-Commerce Guide > Workflow From Development to Release > Lotcheck > Downloadable Content.

Downloadable Content

Lotcheck for downloadable content is conducted by downloading it to a Nintendo Switch system and running the application.
For this reason, the Lotcheck Department must be able to use the release version corresponding to that downloadable content.
If you have not already, submit the release version that can run the downloadable content to be tested to Lotcheck, along with the downloadable content.
