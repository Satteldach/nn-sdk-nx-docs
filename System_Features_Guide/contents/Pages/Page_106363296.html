Capturing

Capturing Screenshots

Users can take application screenshots by pressing the Capture button. During capture, an overlay notification appears on the upper left of the screen for the application along with a sound effect.

Screenshots are saved either to the system memory or to an SD card. The user can select the save location using the system settings. By default, the SD card is used. Captured data will be saved to the system memory when no SD card is inserted, even when the option to use the SD card is selected.

The restrictions on the number of screenshots for each location are as follows. Saving will no longer be possible when the number restriction is met.

Table 3-3 Restrictions on Number of Screenshots by Save Location
Save Destination Number of Screenshots
System Memory 1000
SD Card 10000

Blocking Screenshot Captures

In some cases, you may want to prohibit the capture of screenshots. You can do this in the following ways.

  • In the NMETA settings file needed to create ROMs, provide a setting for blocking captures to universally block the feature across applications.
  • Offer capture blocking functions to block only certain scenes within applications.

Screenshot Captures by Application

Applications are now capable of taking screenshots without requiring the user to manually press the Capture button. (Effective from NintendoSDK NX Add-On 3.2.0.)

When you use this feature, you can enhance the user experience in the application by informing the user about taking screenshots and mentioning that images can be viewed in the album.

If screenshots are to be captured automatically, prepare a setting so that users can disable the feature so that they do not need to be concerned about running out of storage space.

Capturing Video

With system version 4.0.0 or later, users can take application videos by holding down the Capture Button. The scene captured in the video starts from a maximum of 30 seconds prior to pressing the Capture Button. The save location settings are identical to the settings for screenshots.

The restrictions on the number of screenshots for each save location are as follows. Saving is no longer possible when the number restriction is met.

Table 3-4 Restrictions on Number of Video by Save Location
Save Destination Number of Videos
System Memory 100
SD Card 1000
Note:

Videos can be captured only in the application running in the foreground.

The temporarily stored content is reset periodically, such as when transitioning to the HOME Menu, calling library applets, or when recovering from sleep mode.

Info:

In system version 5.0.0 and later, the audio component of captured video is saved as stereo, regardless of the play mode or the system settings. (Before version 5.0.0, the audio component was dependent on the play mode and the system settings and saved in the format of the audio output at the time of video capture.)

If surround sound is played, the system default downmix process is performed on the audio data. For more information about the system default downmix process, see NintendoSDK Documents > Features > Audio > audio Library> Manual > Features > Other.

Supporting Video Capture by Applications

Take note of the following whenever applications support video capture by holding down the capture button.

  • When building, you must use NintendoSDK NX Add-On 4.2.0 or later (3.6 or later if you are using the version 3 series).
    • Contact a Nintendo representative if it is difficult to switch to NintendoSDK NX Add-On as specified previously for an application under development.
  • 96 MiB of memory is used for the application.
    • When building with NintendoSDK NX Add-On 4.2.0 or later, the memory that can be used in the application will be 96 MiB less by default.
    • It is also possible to not allocate 96 MiB of memory by turning off the video capture feature in the NMETA settings file that is needed to create ROMs.
  • To be on the safe side, make sure that you perform the following checks.
    • When the video capture feature is enabled, system recording runs in parallel with the application.
    • We recommend making sure there are no issues such as delayed processing, because operations may be affected due to the processing state of the application.

Blocking Video Captures

When screenshot captures are blocked, video capture is also blocked.

You can block video capturing even when screenshot captures are permitted. This can be done using the following methods.

  • In the NMETA settings file that is needed to create ROMs, provide a setting that does not support video capture to universally block the feature across applications.
  • Offer video capture blocking API functions to block only in certain scenes within applications.

In NintendoSDK NX Add-On 13.0.0 and later, it is possible to mute video captured within a specified period.

Notes Applicable to Both Screenshots and Videos

Block capturing in applications (such as video-on-demand services or e-book services) that display content with rights retained by a third party, and in applications that display images obtained from an IR motion camera. For more information, see Nintendo Switch Guidelines.

Supplemental Information Applicable to Both Screenshots and Videos

  • NintendoSDK NX Add-On 5.0.0 and later includes a feature for integrating a copyright notice, as specified by the application, into screenshots and captured videos.
  • NintendoSDK NX Add-On 3.2.0 and later includes a feature for the application to specify the orientation of captured screenshots. NintendoSDK NX Add-On 6.1.0 and later also allows orientation to be specified for videos.
Info:

The orientation of the image or video is used when posting to social media. This feature is suitable for applications such as those that display the Nintendo Switch screen horizontally.

The specified orientation does not apply to viewing the album.

Viewing

To view screenshots or videos in order starting from the most recent captures, from the HOME Menu, select Album. Functionality to filter display based on application is available in case there are a lot of stored screenshots and videos.

A signature check is performed on screenshots and videos. They will not be displayed if it has been determined that screenshots were modified using a device other than the Nintendo Switch.

Info:

In NintendoSDK NX Add-On 5.1.0 and later, the album applet can be called from inside the application.

For more information, see 4.11 Album Applet.

Info:

In system version 5.0.0 and later, viewing videos is restricted according to the Restricted Software setting in the parental controls.


Editing

Editing Screenshots

You can write text on screenshots.

In Album, select the screenshot to edit. You can then use the Text Entry option from within the Edit menu. Text size, position, and color can all be customized.

Info:

Separate discussions are underway to implement editing features beyond text entry.

Figure 3-2 Text Input Feature Mockup Screen

Editing Videos

Videos can be trimmed.

In Album, select the video to edit. You can then use the Trim option in the Edit menu to trim down the video to any length. Using the Save Image option, you can save a single scene as a screenshot.

Info:

Separate discussions are underway to implement editing features beyond trimming.

Figure 3-3 Trimming Feature Mockup Screen

Posting

Screenshots and videos can be posted to social media. As of June 2024, posts can only be made to Facebook.

Select the screenshot or video to post within Album. Click the Post button. The account management applet will start. Select the user. The post screen will appear. Comments can be entered and posted along with the screenshot or video.

Info:

In System Version 6.0.0 and later, up to four screenshots may be submitted during a single post. Only screenshots captured with the same application can be posted together.

However, only one video can be posted at a time.

Info:

Consoles for China support posting to Weibo in system version 12.1.0 and later. You can post up to nine screenshots at a time.

The #NintendoSwitch hashtag is applied when posting to Weibo. It is also possible to add application-specific hashtags. For application-specific hashtags, Tencent provides guidance during the sales procedure, so follow those instructions.

Notes When Using the Posting Feature in the Development Environment (dd1)

A feature for calling the posting feature from inside the application, was added in NintendoSDK NX Add-On 3.2.0. Along with this change, the posting feature has been enabled in the dd1 development environment. However, there are several notes about using the feature in this environment.

  • The dd1 development environment does not support posting to Facebook.
  • The dd1 development environment does not automatically assign application-specific hashtags.

Transferring

In system version 11.0.0 and later, you can transfer screenshots and videos to smart devices wirelessly.

In Album, select the screenshots or videos you want to transfer and then click Send to Smartphone. A QR Code will be displayed. By following the on-screen instructions and using the smart device's QR Code reader, you can view and save screenshots and videos on the smart device. If the case of screenshots, up to 10 screenshots can be transferred at a time.

Info:

Nintendo Switch acts as an access point and an HTTP server. The smart device receives screenshots and videos from Switch using a Wi-Fi connection and a browser.

Two QR Codes must be read. If the smart device does not support the reading of QR Codes, you must manually enter the Wi-Fi connection settings and manually enter the URL in the browser. Trouble connecting? presents information about what to enter.

Info:

In system version 11.0.0 and later, you can also transfer to a PC via USB.

For more information, see 3.6 System Settings > Copy to PC via USB.
