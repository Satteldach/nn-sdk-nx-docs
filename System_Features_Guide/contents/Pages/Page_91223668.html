1 Introduction

Objectives and Content

This documentation describes the specifications for system features and describes in detail how to use them in applications.

Intended Audience

This documentation is intended for planners and developers of Nintendo Switch™ (hereafter known as Switch) applications.

When to Read This Document

Read this documentation when you are planning and developing Switch applications.

Related Documents

The Nintendo Switch Overview also presents a simple overview of system features. Before reading this documentation, read the System Features section in the Nintendo Switch Overview.
