2.2.1 Options
Figure 2-1 Option Menu Screen Mockup

You have options to perform the following operations and check the following information for the application selected in the HOME Menu.

Software Information

Nintendo eShop

Nintendo eShop starts and displays the page for the selected application.


The following three items are collectively referred to as "Software Legal Information."

Support Information

Information about publisher and contact details. The information for Japan/North America/Europe and Australia/Hong Kong, Taiwan, and Korea is displayed in different orders depending on the region set in the system settings.

Info:

On Switch consoles for the China region, only information for China is shown.

Important Information

Written text such as anti-piracy measures. The same information is displayed no matter which region has been set in the system settings.

Intellectual Property Notices

Notes about copyright information. The same information is displayed no matter which region has been set in the system settings.

Note:

When the required entries are entered into the Software Legal Information System (SLIM) https://slim.mng.nintendo.net/slim/ on the Nintendo Developer Portal, a ZIP file with Support Information, Important Information, and Intellectual Property Notices will be exported. Attach this ZIP file to the ROM using AuthoringEditor or by directly adding it to the NMETA file. It is required for all applications. For more information about implementing this feature, see Nintendo SDK Documents > Features > Building > Creating Application Images, or the documentation for AuthoringEditor.

Software Update

Updates the application to the latest state. In practical terms, it downloads and applies anything like patch data that is later than the application.

Info:

You can now match application versions with nearby people (close Switch systems). This works for system versions 4.0.0 and later. Updates are performed using local communication.

Data Management

Transfer Your Save Data

Jumps to the feature for transferring save data. For more information about this feature, see 3.6 System Settings.

Archive Software

The application is removed, but its icon will remain in the HOME Menu. Because that icon remains, it is easy to re-download the application. Options are also available. Save data is not deleted. You can delete the save data using Data Management > Manage Save Data / Screenshots and Videos. For more information about Data Management and Manage Save Data > Screenshots and Videos, see 3.6 System Settings.

Delete Software

Deletes the application. Save data is not deleted. You can delete the save data using Data Management > Manage Save Data / Screenshots and Videos. Unlike the Archive Software option, this operation also deletes the icon from the HOME Menu.

Save Data Cloud

A Nintendo Switch Online service for tasks like automatically backing up save data to a server and downloading the save data to a different console.
The options menu has a feature for checking the backup and download status of the save data for each user of the application. You can also transition from here to the screens for downloading and uploading save data. For more information about the transition destinations, see 3.6 System Settings.

Note:
  • Save Data Cloud does not work in the development environment.
  • The Options menu name of the feature for online backup of save data was changed to Save Data Cloud backup in system version 8.0.0.
Info:

The Save Data Cloud feature cannot be used on Switch consoles for the China region.

My Nintendo Rewards Program

You can receive an amount of Gold Points equivalent to the amount spent on a retail version product. To receive points, a Nintendo Account is required. For downloadable versions of applications, gold points are assigned automatically when purchasing the application from the shop. You do not need to do anything else. For more information about My Nintendo and Gold Points, see Nintendo’s official website.

Info:

The My Nintendo Rewards Program cannot be used on Switch consoles for the China region.
