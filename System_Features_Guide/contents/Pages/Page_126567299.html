2.1 Entrance

This screen is the welcome screen that is shown after turning on the system power or returning from sleep.
The following screens appear when you enter sleep mode while the application is running.

Figure 2-1 Entrance Screen Mockup

You can do the following, primarily.

  • Restarting paused applications
  • Jumping to News

You can either press the A Button or tap the application icon to resume the application that was being played before the system was put to sleep.
(To make it easier to resume without being limited by how the controller is held, buttons besides the A Button can also be made to operate in the same way.)

A list of identified News items is on the left. Press the Y Button (or tap (Y) News on the screen) to jump to the News.
You can jump to a screen with the news in detail by tapping the News picture.

In handheld mode, the system will automatically go into sleep mode if it is idle for more than ten seconds.

Info:

The application icon is a picture that appears in the HOME Menu, which is used to start an application. Application icons that have been created for the HOME Menu are applied. For more information, see Application Icon Creation Manual.

Entering Sleep Mode While Using the System Features

Application icons are not displayed in the Entrance. The icons for system features that were running before entering sleep mode are displayed. Use either of the following options to resume a paused system feature.

  • Press the A Button.
  • Tap the icon.

Screen Lock (Only When in Handheld Mode)

After the preceding screen, an Unlock screen appears to prevent erroneous operations.

If the system is placed into a bag, and is accidentally awoken from sleep mode, this screen prevents games from being unknowingly played.
Press the same button three times, or tap the touch screen icon three times, to jump to the screen that you want to resume.

You can also use the system settings to enable or disable this feature.
