This screen displays all installed applications.

Sort/Filter Feature

You can sort applications in the following four display orders.

  • By Time Last Played
  • By Play Time (Longest First)
  • By Play Time (Shortest First)
  • By Title
  • By Publisher

You can also filter the applications so that only downloaded applications are displayed.

Groups Feature

You can group applications. You can also change the display order of the applications within a group.
