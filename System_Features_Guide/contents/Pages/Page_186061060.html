7.2 Descriptions and Warnings for Nintendo Extended Characters

As a supplement, this section introduces descriptions and warnings for the Nintendo extended character font.

The list is separated by extended characters for Switch and those for earlier platforms, such as the 3DS and Wii U. The Switch list is full of glyphs newly added from Switch. Nintendo extended characters do not exist for the Wii U.

  • Table 7-1 Descriptions and Warnings for Nintendo Extended Characters (Switch)
  • Table 7-2 Descriptions and Warnings for Nintendo Extended Characters (Earlier Platforms)
Reading Descriptions and Warnings for Nintendo Extended Characters
  • Character
    • This column contains illustrations of the glyphs.
  • Character Code
    • This column contains the character codes.
      • The Nintendo extended characters use the following Unicode private use areas (PUAs).
        • U+E000 to U+E1FF
        • U+F000 to U+F1FF
      • The following ranges of these private use areas can be used without competing with the system fonts.
        • U+E200 to U+E6FF
        • U+E900 to U+EFFF
        • U+F200 to U+F5FF
  • Usage
    • This column describes how the glyphs are used.
    • It lists controllers that support the button types.
    • There are no specific usage restrictions for glyphs that leave the Usage section blank.
  • Warnings and Notes
    • This column describes notes and warnings during use.
    • Glyphs indicated as "extended character imported from an earlier platform" were all ported from Wii U system fonts. They include extended characters created with Nintendo DS systems, Nintendo 3DS systems, and the Wii. It is fine to use a character in Switch as long as "do not use as a Switch button" is not indicated in Warnings and Notes.
  • nintendo_ext_003
    • The name of the font that contains extended characters from earlier platforms, such as the 3DS and Wii U.
    • A check mark indicates that a corresponding glyph exists in nintendo_ext_003.
  • nintendo_ext_LE_003
    • The name of the font that does not contain extended characters from earlier platforms, such as the 3DS and Wii U.
    • A check mark indicates that a corresponding glyph exists in nintendo_ext_LE_003.
