4.3 Software Keyboard Applet

This applet is invoked by the application to allow users to enter their names, passwords, and other text when text input is required.

You can set parameters to, for example, enable and disable predictive text input or block the input of specific characters.

Note that the application must allocate the working memory, on the order of a few kilobytes, for this applet.

Note:

The Switch does not support input methods like handheld input and hand-drawn input that were supported on devices such as the Wii U.

Startup Parameters

You can easily customize the software keyboard by setting startup parameters.

You can configure the following parameters.

  • Keyboard type
  • Whether to enable predictive text input
  • Prohibited characters
  • Whether to enable the feature to hide character input
  • Whether to allow new lines
  • Maximum and minimum number of characters

Enabling or Disabling Predictive Text Input

Predictive text input can be enabled and disabled.

User Dictionaries

You can add user dictionaries, which are dictionaries created in the application, to the dictionary used for predictive text input.

You can also configure the software keyboard to not use dictionaries it normally would, and to use only user dictionaries instead.

Customized Dictionary

A customized dictionary was created that you can add for predictive text input on the PC.

Unlike the user dictionary, you can set a customized dictionary for each keyboard array.

When creating the customized dictionary, use the customized dictionary creation tool that is included in iWnn (the integrated language processing middleware).

Learning

Predictive text input learning occurs automatically by using the software keyboard. Applications cannot enable or disable this learning.

Learning data is saved for each user account. That data will continue to be available whenever the software keyboard is subsequently called.

Customers can delete learning data in the System Settings.


Note:

The ability to continue using learning data is only available when just one user is selected. Learning data is not used from one session to the next when no users are selected or when multiple users are selected.

Setting Prohibited Characters

You can use settings to block the input of the following types of characters.

  • Numbers
  • %
  • / (slash)
  • \ (backslash)
  • @
  • Spaces
  • All characters except those used for download codes
  • All characters except those used for Mii nicknames

All characters except those used for download codes

Any characters other than the following are blocked. You cannot enter a capital O, I, or Z.

  • 0123456789ABCDEFGHJKLMNPQRSTUVWXY

All characters except those used for Mii nicknames

Characters that are not included in Appendix: Characters That Can Be Used in the User Account Nickname in the Account Guide are blocked. For more information, see Nintendo Switch Account Guide.

Enabling and Disabling the Hide Input Text Feature

You can use settings to enable or disable the ability to immediately hide player input.

We expect this feature to be enabled at times such as when entering passwords.

Allowing or Prohibiting New Lines

You can set whether players can include new lines within entered text.

Setting the Maximum or Minimum Number of Characters

You can use settings to configure the maximum number of characters that can be entered, and the minimum number of characters required for valid input.

Working With Hardware Keyboards

Commercially available hardware keyboards can be connected to the Nintendo Switch dock USB connector and used to enter text. No particular support is required in applications.

Character input using the hardware keyboard has the following characteristics.

  • Even if the hardware keyboard is connected, characters can still be input as expected from devices other than the hardware keyboard.
  • Characters other than those described in the Text That Can Be Entered Using a Software Keyboard callout on this page, cannot be entered from the hardware keyboard.
  • You can switch the key layout of the hardware keyboard from the system settings by setting USB Keyboard.
  • When using Japanese, you can change the Japanese input by switching between single-byte and double-byte characters, or by pressing ALT+SPACEBAR.
  • When using Russian, pressing ALT+SHIFT switches to Russian input.
  • For Chinese, use the SHIFT key to switch between enabling and disabling Chinese input.
  • For Korean, use the right ALT key to switch between enabling and disabling Hangul input.
  • The following special keys are configured.
    • ALT+ENTER: Confirm the input content and exit the software keyboard.
    • ESC or ALT+BACKSPACE: Discard the input content and exit the software keyboard.
    • TAB or SHIFT+TAB: Switch between selection of conversion candidates.

Inline Keyboard

In addition to the regular software keyboard, a software keyboard (the inline keyboard) that allows the application to independently render a preview field is available. The inline keyboard differs from the regular software keyboard in the following ways.

  • The application can run processes even when the keyboard is being displayed.
  • The preview field must be rendered independently on the application side.
  • Items other than the preview field are passed to the application as data images.

Use the keyboard in situations where text input is required in parallel with applications, such as with chat.

The inline keyboard will be available in NintendoSDK NX Add-On 6.3.0 and later.
