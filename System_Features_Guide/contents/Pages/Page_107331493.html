2.2 HOME Menu

This menu can be opened at any time by pressing the HOME Button on the console.

Figure 2-1 HOME Menu Screen Mockup

The following diagram of all the functional translations centered on the HOME Menu shows the transitions to each feature.

Figure 2-2 Transitioning to Various Features from the HOME Menu

If the HOME Button is pressed while the application is being played, the system transitions to the HOME Menu, but you can select whether the application continues to run in the background or is suspended. The system can get application states to indicate whether an application is in the foreground or background.

Note:

We do not plan to release a feature that prohibits transitioning to the HOME Menu when the HOME Button is pressed while the application is being played. With the Nintendo 3DS system and the Wii U, you could skip transitions to the HOME Menu during online play and other times of communication. However, Switch does not support this implementation.
