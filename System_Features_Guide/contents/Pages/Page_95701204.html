3.6 System Settings

This feature encompasses a variety of system settings, such as internet connection and user settings.

A player can change those settings during gameplay by calling the system settings, which appear as System Settings in the HOME Menu.

However, for items such as language settings and user settings, the suspended application might have to be closed or the system itself might have to be restarted when the settings are changed. Some settings allow you to find out whether they were changed from a running application.

Restrictions Associated With Bluetooth Audio Use

The following restrictions occur with the use of Bluetooth audio.

  • Up to two wireless controllers can be used while connected to Bluetooth audio.
    • An overlay notification will appear indicating that no more devices may be connected if the user tries to connect 3 or more devices.
  • Bluetooth audio cannot be connected while using local communication.
    • If Bluetooth audio is connected when local communication is initiated, Bluetooth audio will be disconnected with an overlay notification to indicate that.
Note:

These restrictions are explained to users in System Settings and in overlay notifications. Constraints do not need to be explained on the application side.

However, we do recommend that the application clearly indicate that local communication is in progress, so that the user understands the cause of the Bluetooth audio disconnection.

Content Rating System

The rating system is used as a basis for determining software and News restrictions.

The choices are as follows.

  • PEGI (Europe)

  • USK (Germany)
  • Russian (Russia)
  • ESRB (US and Canada)
  • ACB (Australia)
  • OFLC (New Zealand)
  • CERO (Japan)
  • GSRMR (Taiwan)
  • GRAC/GCRB (Korea)

The default value is determined based on the language and region set in the Switch system.

To be specific, ClassInd (Brazil) and IARC Generic are included in the former but not in the latter.

Determining Software Startup

Prerequisites

The user has configured the following settings on the Switch console.

  • The rating system used as a basis for determining software startup and an age value, which is the value set in Restricted Software and News.

The following metadata is registered in the software.

  • The rating systems that it has passed through and the resulting age values (multiple instances can be registered).

For more information about the metadata settings, see NintendoSDK Documents > Features > Building > Creating Application Images > Writing the NMETA File.

Info:

Rating systems that cannot be set in the Switch system settings can also be registered in the software metadata (Note). For example, ClassInd (Brazil) cannot be set in the Switch system, but it can be registered in the software metadata. In such cases, the Switch system can appropriately determine software startup. For more information, see Startup Determination Process.

Note: If in the future, due to an update to the Switch system update, it will be possible to set additional rating systems in the system, and ratings registered earlier in the ROM can be used to determine startup.

Info:

For software titles that are exempt from game-rating evaluation, set the age value to 0.

If the age value is left blank, the title is regarded as being for ages 18 and up. (This handles an unintentionally omitted setting.)

Info:

Even for viewing News, the same determination is made based on the rating and age value set for each News article.

Info:

The settings for Content Rating System and Age cannot be specified on Switch consoles for the China region.

Software is always deemed playable.

Startup Determination Process

Rating System of the Switch Console Is Registered in the Software

The age value set in the Switch console is compared with the age value for the corresponding rating system registered in the software to determine startup.

For example: CERO is set in the Switch console, and CERO:12+ and ESRB:10+ are registered in the software.

CERO is set in the Switch console and also in the software, so the age set in the Switch system is compared with the CERO age (12+) registered in the software to determine startup.

In this case, if the Switch system is set to restrict software and News for ages 12 and higher, or if a younger age is set, the software does not start.

Rating System of the Switch Console Is Not Registered in the Software

If IARC Generic is registered in the software, the age value set in Switch is compared with that age value to determine startup.

If IARC Generic is not registered, the age value from the strictest rating system among the rating systems registered in the software is used to determine startup.

Example 1: PEGI is set in the Switch console, and CERO:12+ and ESRB:10+ are registered in the software.

CERO: 12+ is more strict than ESRB:10+, so the software is considered to be rated 12+. The age value set in the Switch console is compared with this 12+ value to determine startup.

In this case, if the Switch system is set to restrict software and News for ages 12 and higher, or if a younger age is set, the software does not start.

Example 2: PEGI is set in the Switch console, and ClassInd:14+ is registered in the software.

Only one rating, ClassInd, is registered in the software, so the ClassInd age value, 14+, is compared with the age set in the Switch console to determine startup.

In this case, if the Switch system is set to restrict software and News for ages 14 and higher, or if a younger age is set, the software does not start.


One exception is that if the rating system specified in the Switch console is USK, and USK is not registered in the software, the software is considered to be for ages 18 and up.

In this case, if the Switch system is set to restrict software and News for ages 18 and higher, or if a younger age is set, the software does not start.

Save Data Cloud

A Nintendo Switch Online service where you can perform tasks such as automatically backing up save data to servers or downloading it to a different system.
The following actions are available as management features for the Save Data Cloud service in the system settings.

  • Checking the backup and download status of save data.
  • Manually backing up and downloading
  • Enabling and disabling the automatic backup feature
  • Enabling and disabling the automatic download feature
  • Deleting save data backed up on the server

These actions require a Nintendo Switch Online Membership.

You can set whether to support these features for each application.


Note:
  • Save Data Cloud does not work in the development environment.
  • The name of this feature for online backup of save data was changed in system version 8.0.0.

Transfer Your Save Data

Transfers a user’s save data for each application via communication between two nearby consoles. Transferred save data disappears from the original system.

Unlike Save Data Cloud, this feature can be used without a Nintendo Switch Online membership. However, you must have an internet connection and a Nintendo Account to use it.

You can set whether to support these features for each application. However, an application that supports Save Data Cloud must also be set to support Transfer Your Save Data. This is because the Save Data Cloud feature can be used to perform the same operation of transferring save data, so support for Transfer Your Save Data should cause no problem for the application. (If there is a problem supporting Transfer Your Save Data, the same problem will probably occur with Save Data Cloud.)

Info:
  • We plan for users to be able to adjust compatibility settings when registering application information on the Nintendo Developer Portal.
  • Compatibility settings are managed individually for each software version. As a result, settings can be changed together with a patch release.
Note:
  • The transfer of save data does not work in the development environment.
  • Data cannot be transferred between consoles for China.


Manage Screenshots and Videos

Changing the Save Destination

You can change where screenshots and videos are saved.

  • System memory
  • SD card

If no SD card is inserted, the item itself does not appear. It appears when one is inserted.

Copy/Delete

You can copy and delete screenshots and videos in batches.
You can copy from system memory to an SD card, and vice versa.

With Manage Individual Images and Videos, you can transition to Album and copy or delete selected screenshots and videos.

Copy to PC via USB Connection

This feature copies screenshots and videos to a PC.

To use this feature, you connect the Switch to the PC via a USB cable. When connected, the PC will recognize the Switch as read-only external storage. The copying of screenshots and videos is performed by the PC.

Figure 3-1 Example of Display on PC (Windows 10)

Note:
  • You must use a USB-IF-certified USB cable that supports data transfer.
  • You must connect the Switch USB port and PC directly via USB cable. You cannot use this feature by connecting the PC to the USB port of the Switch dock.
  • The confirmed environment is Windows 10. This feature cannot be used in environments where MTP is not supported, such as on Mac computers.

Transfer Your User Data

This transfers one user and that user’s save data via communication between two nearby Switch consoles. The transferred user and that user’s save data disappear from the original console.

You can use this feature without a Nintendo Switch Online membership. However, you must have an internet connection and a Nintendo Account to use it.

Unlike Transfer Your Save Data, the save data is transferred for all software titles.

The downloadable software purchased by the transferred user is no longer playable on the original console. It can be played on the new console by downloading it from that console's Nintendo eShop.

Also, screenshots and videos captured on the original console are not transferred.

Note:
  • The transfer of users does not work in the development environment.
  • The name for this feature was changed from "Transfer Your User and Save Data" in system version 8.0.0.
  • Data cannot be transferred between consoles for China.

Themes

You can change the screen background and text color for the following features.

  • System menus, including the Entrance, HOME Menu, and Launcher
  • System applications
  • Library applets

Black and white color types are available. White is the default. More color types may be added in the future.

Setting Color Types From the Application

You can change the color type to suit the design or world view of an application. This can only occur for library applets called from the application. An API for setting color types is scheduled to be provided.

Any of the following values can be specified using that API.

  • The use of a color type specified by the application, although this is limited to the color types available in system settings.
  • The continued use of a color type configured by the player.
Note:

The applet will appear, using the color type that the player configured, when a library applet is called without specifying a color type. Color types other than black and white might be added in the future.

Note:

The following library applets do not support the specification of a color type. They are always displayed using the same color, regardless of the theme set by the user.

  • Create or Edit Mii Applet
  • Web Applet
  • Offline Web Applet
  • EC Applet

Control Using Device Buttons Feature

The following behavior occurs when this feature is disabled. (A wireless controller must be connected for the feature to be disabled.)

  • The HOME Button and Capture Button on the device, in addition to near-field communication, are disabled.
    • Wirelessly connected controllers, including Joy-Con or Pro Controllers, control the device.
  • This behavior is equivalent to removing the Joy-Con controllers from the Nintendo Switch. The NintendoSDK function, nn::hid::NpadAttribute::IsConnected, returns false.

System Update

The console stays up to date by performing a system update when there are new or updated system features.

The console takes the following steps to get the data required for a system update.

  • Via the internet
    • System Settings
      The console checks for an update under System Update. If there is an update, it gets the update data.
    • Background Processing
      The console checks for updates in the background when it starts and when it performs the actions configured for when the system is in sleep mode. If there is an update, it gets the update data.
  • Via Game Cards
    If a game card includes an update, the console gets that data when the game card is inserted.
    If the console's system version is later than the update version, the console ignores the update.

After the console gets the update, the installation begins after the user authorizes the system update. After the update completes, the console restarts.

System Version Compatibility Verification

The system version is updated when updating the system.

When system update data is released publicly, there is a mix of system versions in the market: the earlier version that is out-of-date and the latest version. Even when there are devices with different system versions in the market, the only requirement is that the firmware (system) version specified in Master ROM Submission Information on the Nintendo Developer Portal at the following link, has been used for testing when submitting an application's master ROM.

  • Master ROM Submission Information on the Nintendo Developer Portal

An application might also be used with a system version that is later than the version it was verified for during development, but Nintendo performs compatibility testing to make sure applications remain playable.

Region

Applications cannot get the region information set in the system settings.

To get information about the region in operation, use the country of residence information associated with the Nintendo Account.

For more information, see Nintendo Switch Account Guide.

Date and Time

Initialize Console

  • All software, save data, screenshots, videos, and user data stored in system memory is erased, and the system is restored to its initial state.
  • With the exception of screenshots and videos, the data for software stored on SD cards is no longer available. It is not erased.
  • The console system version does not change with initialization.
  • Nintendo Accounts are not deleted, but they are unlinked from the system.
Note:

Nintendo Accounts contain the user’s Nintendo eShop usage record and balance. After initialization, relinking the account to the console enables purchased software and downloadable content to be downloaded again.

However, if distribution of software has been suspended or terminated, it may not be possible to download it again.


Considerations When Using Development Hardware

  • If Idle Time Detection is turned off in DevMenu (the specialized menu with various features for operating the development hardware), the Screen Burn-In Reduction and Auto-Sleep features are disabled.
