3.1 Nintendo Switch Online

This is a system application for providing information about Nintendo Switch Online and using the service.

(Users without a Nintendo Switch Online membership can also start this system application.)

It primarily provides the following.

  • Nintendo Switch Online contract status and various pricing plans.
  • Information about the latest Nintendo Switch Online services and planned software.
  • Information about all currently available Nintendo Switch Online services and software.
  • Information about save data in the Nintendo Switch Online cloud.

Note:
  • The provisions of this system application differ depending on the country or region set for the Nintendo Account is set.
  • This system application is not usable in some countries and regions.
