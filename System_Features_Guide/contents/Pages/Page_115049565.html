2.4 Quick Settings

This screen brings together frequently used system settings, like the option to change screen brightness. A long press of the HOME Button (0.5 sec) displays this screen on top of the screen for the HOME Menu, applications, and other running processes.

Features

Quick Settings have the following characteristics.

  • They are displayed on the right side of the screen in the application. The display size is 720 × 460 pixels.
  • An application will not pause. It will continue to run in the background while Quick Settings are displayed. In such cases, application inputs will be received by Quick Settings.
