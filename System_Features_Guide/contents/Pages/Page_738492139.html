5.3 Alarms

Alarms can be set in applications that support the feature to send notifications at predetermined times.

In training-type games, for example, alarms can be used is to help encourage users who want to continue to play the application.

Behavior When Activated

The behavior of the activated alarm differs depending on the state of the Switch system.

When in Sleep Mode

If the Switch system is in sleep mode, the Joy-Con(R) vibrates and the HOME Button notification LED blinks when an alarm has been activated. It activates regardless of whether the Joy-Con is connected. If the Switch system is left unattended, the alarm will go off again after 5 minutes and again after 10 minutes.

When the Switch wakes, the user is prompted to start the application the alarm was set in.

If multiple alarms have arrived, the latest alarm is displayed. Older alarms are displayed by pressing the R Button.

Figure 5-1 Mockup of Alarm-Triggered Entrance Screen

Note:

In the following situations, alarms are not activated in sleep mode.

  • The power is off to the Switch console or the battery is low.
  • The controller battery is low.
  • The controller is located where wireless signals from the Switch console do not reach, or the system is set to airplane mode.
  • The controller is not paired.
  • The controller firmware is out of date.
    • If the firmware in the connected controller is out of date, you are prompted to update the firmware when the application calls the API for setting the alarm.


When Awake

When the Switch system is awake, an overlay notification appears in the upper-left part of the screen when an alarm has been activated.

Figure 5-2 Mockup of Alarm-Triggered Overlay Notification

Using the System Settings

Configured alarms can be checked, disabled, and deleted from Settings > Notifications > Alarm Notifications.

You can also choose to turn off notifications and controller vibrations while the Switch system is awake.

Application-Level Support

Note:

You must submit a request to use this feature. If you would like to use this feature, Contact Nintendo.

Up to eight alarms can be set on each Switch console.

The following settings can be configured for each alarm.

Element

Notes

Time

The time of the alarm, set for each individual day. The time does not have to be specified for every individual day.

Users

The alarm can be associated with a single person. It does not need to be associated with a user.

If the alarm is associated with a user, the following scenes show who the alarm has been set for.
・When the alarm notification appears in the Entrance
・When the alarm is checked in the system settings

Enable/disable alarm

In principle, alarms are enabled, but you can disable an alarm and still keep the setting for that alarm.

The setting for the alarm can be switched between enabled and disabled in the system settings while an application is suspended, so if necessary, sync the application when it returns.

Application parameter

This parameter is passed to the application via the alarm when the alarm is activated. You can set up to 1024 bytes for this parameter.

It is passed to the application only if the application has been started or resumed directly from the Entrance.

Notes About Support

If your application supports alarms, note the following points.

  • To set an alarm, you must clearly provide the date and time of the alarm and get the consent of the user.
    Setting an alarm without confirming the consent of the user is prohibited.

  • You must support the ability to remove alarms.

  • When multiple days or times of alarms are set, ensure they can be handled separately, based on user specifications and consent.

  • Do not provide specific information about what happens when an alarm is activated.
    The behavior might change in future system-feature updates. It is all right to say something like 'If an alarm has been set, you will be notified at the specified date and time even if the Switch is in sleep mode.'

  • The format of your time notation does not need to match the format used for system features.
    You are welcome to refer the notation in the system features, but consider that the content might change in the future.


Info:

In Ring Fit Adventure, alarms are set based on the days and times specified by users.
