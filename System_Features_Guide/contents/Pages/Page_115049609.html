4.9 Offline Web Applet

The Offline Web Applet is a web browser that displays the web content (offline HTML) added to applications.

Figure 4-1 Image Screen for the Offline Web Applet

Offline Web Applet Overview

The Offline Web Applet is a web browser for displaying web content added to applications. This web content may be comprised of elements such as HTML, CSS, images, video, JavaScript, and fonts.

The overall term for these files is offline HTML.

While the supported formats are identical to the web applet, this applet does not connect to the internet and cannot display pages that contain files on web servers.

The applet loads files from the application and displays pages in a short time after startup.

Due to these characteristics, this applet is suitable for displaying content similar to the content of the application itself.

Note:

The electronic manual that was required for Wii U and Nintendo 3DS has been discontinued. Developers are free to choose whether to include materials in their applications that was included in the e-manual, such as a gameplay guide. You can use the Offline Web Applet to display materials such as a gameplay guide, but there is no set location, such as in the System Menu, to display such content.

Using the Offline Web Applet

Operation Method

The supported operations are the same as those for the web applet. The space navigation and pointer controls support use of the controller, as well as operation via touching the screen.

Specifying Paths

To display offline HTML, it is first necessary to add the offline HTML to the ROM.

Specify the path of the page that you want to display from the added offline HTML.

For more information about the specifications on specifying paths, see NintendoSDK Documents > Features > Library Applets > Web Applet and Offline Web Applet > Offline Web Applet.

Customizing the Offline Web Applet

The Offline Web Applet can be customized in the same manner as the web applet.

It is also possible to permanently display the footer.

For more information, see NintendoSDK Documents > Features > Library Applets > Web Applet and Offline Web Applet > Information Common to Both.

Exchanging Information with the Application

As with the web applet, you can pass any parameters between the calling application and the Offline Web Applet.

However, note that the specifications differ from the web applet.

For more information, see NintendoSDK Documents > Features > Library Applets > Web Applet and Offline Web Applet > Information Common to Both.

Calling the Web Applet

While it is not possible to directly transition to online webpages from offline HTML, it is possible to call the web applet through the application.

For more information, see NintendoSDK Documents > Features > Library Applets > Web Applet and Offline Web Applet > Offline Web Applet.

Notes When Using the Offline Web Applet

Effects on System Update

System Update may also result in updates to the Offline Web Applet.

Due to Web browser properties and results of the update, the appearance or behavior of offline HTML content could vary.

Use the Offline Web Applet with consideration of the effects of system updates.

Termination by the System

If the user presses the HOME Button, and starts a system application from the HOME Menu while the Offline Web Applet is running, the Offline Web Applet will be terminated by the system.

For more information, see NintendoSDK Documents > Features > Library Applets > Web Applet and Offline Web Applet > Information Common to Both.

Displaying Online Webpages is Not Supported

Because the applet does not connect to the internet, it does not support the displaying of online webpages.

Use the web applet to display online webpages.

For more information, see 4.8 Web Applet.

Restrictions When Creating Content

When creating content, it is important to note that the Offline Web Applet, like the web applet, does not support certain features.

Follow the Nintendo Switch Guidelines when creating content that is to be displayed in offline HTML.

Note that, due to its nature, the Offline Web Applet has the following restrictions.

  • Cannot display pages that include files stored on a web server.
  • Does not support cookies and localStorage.
    • sessionStorage can be used.

Effective Usage Examples

The Offline Web Applet can also be used in the following ways.

  • As an e-manual
    • It can be used to describe how to play the game and the application controls.
  • As a pause screen
    • The application thread is stopped when the Offline Web Applet starts, so it can also be used as a pause screen.
  • As a collection of videos
    • It is possible to use the video player in the Offline Web Applet as a video collection.
  • As part of another application
    • The URL parameters or return value when the applet is terminated, can be used to exchange information between the application and offline HTML.

For usage examples, see NintendoSDK Documents > API Reference > Sample Backgrounder > Web.

Specifications

The Offline Web Applet specifications are based on the web applet.

However, the main difference is that the Offline Web Applet does not connect to the internet, so those features do not apply.

For more information, see 4.8 Web Applet.
