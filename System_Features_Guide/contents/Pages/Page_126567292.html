3.2 News

Users can receive game information such as the following.

  • Notifications with a strong promotional element
  • Application notifications
  • Notifications about the Switch system, such as how to use system features

To display a list of News items, select the News icon. For more information about a News item, click the item in the list. In addition to reading news articles and looking at images, you can also do things like play videos, jump to Nintendo eShop, or start a game from there.

Figure 3-1 News Mockup


Info:

Publishers can now create and distribute News for each application. The user can begin to receive news articles after applying the System Update (system firmware update) released in June, 2017. For more information about News, see Nintendo Switch News Delivery Guide.

Download Conditions

The following conditions must be met to download News items.

  • The user's Nintendo Account is linked
  • Internet connection
  • Channel has been registered
