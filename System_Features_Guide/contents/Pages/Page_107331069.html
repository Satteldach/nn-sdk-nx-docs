7.1 Interrupt Screens

This appendix introduces screens that can be displayed when the system interrupts an application. Refer to this documentation as necessary.

Features

This feature can interrupt the screen that is currently running to display a system-provided screen.

While an interrupt screen is being displayed, game processing is the same as if paused by a short press of the HOME Button to return to the HOME Menu during the game.

(Even if an application disables the HOME Button, there are cases where pausing may occur due to the occurrence of an interrupt screen.)

If other interrupt screens are triggered while one interrupt screen is being displayed, they are queued and displayed in order of priority.
