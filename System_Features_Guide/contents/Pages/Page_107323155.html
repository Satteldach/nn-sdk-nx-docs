3.5 User Page

A system application that brings together functionality and data specific to the user.

Figure 3-1 User Page Screen Mockup

Info:

In the development environment, the application icon and title name are not registered on the server, so the presence and other information on My Page may display "Could not read." This information is displayed correctly if you install the application to the console.

Profiles

The following options are available.

  • Check the profiles and the presence of your own user account.

Friend List

The following options are available.

  • Check the profiles and the presence of friends, set favorites, and delete friends.
  • Send, receive, accept, and delete friend requests.
  • Check the Player History.
  • Manage the blocked-user list.

Functionality is available for jumping to some of these features from within the application and for calling some of the involved processes. Using that functionality can reduce the implementation load for the UI and processing specific to friend features.

For more information about the friends features, see Nintendo Switch Online Play Guide > Friends > Using From Applications.

Info:
  • Friend requests (to players that might become friends) cannot be sent using the friend candidate feature on Switch consoles for the China region.
  • Friend relationships cannot be established between users playing on Switch consoles for China and users playing on Switch consoles for other regions.

Friend Invitations

You can check received friend invitations and start applications you were invited to.

If the application has not already been installed on your system, you jump to that application's page in Nintendo eShop.

For more information about friend invitations, see Online Play Guide > Friend Invitations and Online Play Guide > Using From Applications.

Trending

Displays applications that are trending among friends, based on their play histories.

If a trending application is installed on the console, it can be started from here. If the application is not installed, the system jumps to the Nintendo eShop product page.

User Settings

Displays an Advanced Settings screen for each user configured within the system settings.

The available options are identical to those in the relevant page within the system settings.
However, users cannot be deleted.
