7.3 How Display Languages Work

This section describes how to determine the language used to display text (the UI language) in application titles and icons on the HOME Menu and in applications.

The UI language is determined by the following items, specified in the NMETA file when creating the application image, and the language and region selected by the user in Settings.

  • Title
  • Icon
  • Supported Languages

For more information about application images, see NintendoSDK Documents > Features > Building > Creating Application Images.

System Language

Different application titles and icons can be set for each language.

However, this description uses language to refer to the system language, and not the language selected by the user in Settings.

System Language Definition

The user can select from nine different languages in Settings.

  • English
  • Français
  • Deutsch
  • Español
  • Italiano
  • Nederlands
  • Português
  • Русский
  • 日本語
  • 繁體中文
  • 简体中文
  • 한국어


In contrast, there are 16 different system languages.

  • American English
  • British English
  • French
  • Canadian French
  • Spanish
  • Latin American Spanish
  • Portuguese
  • Brazilian Portuguese
  • German
  • Italian
  • Dutch
  • Russian
  • Japanese
  • Traditional Chinese
  • Simplified Chinese
  • Korean
Info:

Brazilian Portuguese became available with the release of NintendoSDK NX Add-On 11.0.0.

The system language is the language setting used by the Nintendo Switch system, and is determined by the combination of language and region selected by the user in Settings.

UI Language Priority

The application title and icon is displayed as is if a title and icon, supported by the system language settings, was specified.
If none of the title and icon languages are supported by the language settings, the title and icon with the highest priority language, among those specified, will be displayed instead.

If the language of the application UI is one of the languages supported by the system language settings, it will be displayed 'as is' in that language.
If it is not a supported language, the supported language specified with the highest priority is used as the UI language.
(This corresponds to the return value of nn::oe::GetDesiredLanguage(), a NintendoSDK function. For more information, see NintendoSDK Documents > Features > Basic Features > oe Library > Manual > Features > Getting the Language.)

These priorities differ, depending on the system language in Settings.
The following table shows priorities for each system language, and the language with the smallest number is selected with the highest priority.

Note:

Language priorities could change in the future.
