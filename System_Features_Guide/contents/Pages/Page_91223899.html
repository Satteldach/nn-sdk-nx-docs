6.2 System Fonts

Describes Switch system font specifications and notes.

Font File Format

The provided system fonts are now scalable fonts. They use a BFTTF data format that is specific to the Switch. The system fonts do not include bitmap fonts.

Scalable Font

A scalable font is a font format that can be enlarged and reduced without loss of quality.
Scalable fonts only contain an outline of each character. When the characters are drawn, the system generates character image data (bitmap) from the outline information. Because outline information is more compact than image data (the difference is particularly pronounced for large character sizes), a greater variety of characters can be displayed with less memory. For example, it is a valid format when characters to be displayed cannot be predicted ahead of time, such as names of accounts and Mii characters. It also allows you to create the optimum bitmap for the size of character being displayed, ensuring that the characters appear sharp instead of blurry.

BFTTF

This font uses a data format that was created specifically for the Switch. It cannot be installed on a PC.

Bitmap Font

In this font format, character image data (bitmap) of a specific size is created in advance (pre-drawn) and images of the required characters are extracted for use. This format is widely used in game development and was provided with NintendoWare for systems such as the 3DS and Wii U. The Switch no longer provides system fonts in the bitmap format, but such fonts can be created by converting a BFTTF font. To convert a BFTTF font, use the FontConverter tool included with the font library.

Font Types

The system fonts are as follows.

UD Shingo R is the base for Japanese, North American, European, Hangul, and Simplified Chinese characters. AR UD Jingxi Gothic DB is the base for Traditional Chinese characters.

Japan/North America/Europe

This font mainly includes characters of languages for Japan, Europe and North America.

  • Font name: nintendo_udsg-r_std_003
  • 7768 characters
  • Example glyph with the maximum width: Single-byte W (U+0057)

For Hangul

This font mainly includes characters for languages that use Hangul.

  • Font name: nintendo_udsg-r_ko_003
  • 17,708 characters
  • Example glyph with the maximum width: Single-byte W (U+0057)

Simplified Chinese

This font mainly includes characters for languages that use simplified Chinese.

  • Font names: nintendo_udsg-r_org_zh-cn_003 and nintendo_udsg-r_ext_zh-cn_003
    • According to the font data specifications, combines a standard font and a supplemental font.
      Use the NintendoSDK features to set the priorities for the fonts to load.
      The priority of the supplemental font is greater than the priority of the standard font.
    • Standard font: nintendo_udsg-r_org_zh-cn_003
    • Supplemental font: nintendo_udsg-r_ext_zh-cn_003 (This font has far fewer characters than the standard font. Characters not in this font are taken from the standard font.)
  • 29,136 characters
  • Example glyph with the maximum width: Single-byte W (U+0057)

Traditional Chinese

This font mainly includes characters for languages that use traditional Chinese.

  • Font name: nintendo_udjxh-db_zh-tw_003
  • 14,551 characters
  • Example glyph with the maximum width: LATIN CAPITAL LIGATURE OE (U+0152)

Nintendo Extended Characters

This font is an outline font of encoded pictograms made within Nintendo that is intended for use as a system feature font.

  • Font names: nintendo_ext_003, which includes the extended characters for the Nintendo 3DS and the Wii U, and nintendo_ext_LE_003, which does not.
  • Example glyph with the maximum width: A Button (U+E0A0)
    Note: Excluding U+E06C through U+E0C9, the width of Nintendo extended characters is the same as the double-byte width for all Japanese, North American, and European fonts.

Supported Languages

For Japan/North America/Europe, Hangul, simplified Chinese and traditional Chinese, there are ranges of shared encoded characters (common) and not-shared encoded characters (only).
The supported languages for each scope are as follows.

  • Common encoded characters (common): characters included in and shared by 4 fonts. ASCII, European and North American characters, kana characters, and generic symbols.
  • Uncommon encoded characters (only): characters that are unique to the individual fonts. Chinese characters for Asian languages. Separated within Unicode specifications.

Supplemental Information

  • There is no variation in weight and typeface in regard to memory.
  • The fonts can be made italic or bold with the rendering engine.
  • There is no support for pictograms.
  • The system fonts do not contain pair kerning information.
  • Alternate characters are not specified for applications to use with the system fonts. In the system features, U+25A1 (white square) is specified as an alternate character.
  • Copyright notices are not necessary when you use the system fonts in applications.
  • When Traditional Chinese is set as the language in system settings, applications prioritize using a font for Traditional Chinese characters. However, the Traditional Chinese font is limited to the following ranges so the glyphs for alphanumeric characters match Japanese, US, and European fonts.
    • U+02B0 through U+02FF
    • U+2002 through U+2003
    • U+2574 through U+2574
    • U+2641 through U+2641
    • U+2E00 through U+303F
    • U+3100 through U+32FF
    • U+3400 through U+9FFF
    • U+F001 through U+F002
    • U+F900 through U+FAFF
