4.8 Web Applet

The web applet is a library applet that uses a Web browser equipped with the main HTML5 features and video playback functionality to display webpages specified by the application.

Figure 4-1 Web Applet Screen Mockup

Overview of the Web Applet

The web applet is a web browser for applications.

The application specifies the webpage to display and starts the web applet.

Users cannot specify URLs themselves.

A variety of features have been prepared to give the web applet the look and feel of the application.

Using the Web Applet

Operation Method

The web applet supports two broad methods of operation: using a controller for spacial navigation and moving a pointer, and operations based on touching the screen.

In spatial navigation, you use the Left Stick and the directional buttons to move the focus among the different elements displayed in the webpage, and you use the A Button to select an element to view.

With the pointer, you use the Left Stick similar to a mouse to move a cursor, and you use the A Button to select an element to view.

The user can switch between spatial navigation and the pointer at any time.

Selecting an element, such as a text box in a webpage, starts the software keyboard.

For more information, see 4.3 Software Keyboard Applet.

USB Keyboard Operations

You can connect a generic USB keyboard to the USB terminal of the Nintendo Switch dock and operate the web applet.

The directional keys on the USB keyboard correspond to the directional buttons on the controller, while the ENTER key corresponds to the A Button and the ESC key corresponds to the B Button.

Specifying the Webpage to Display

Unrestrained browsing of internet websites is not the purpose of the web applet, so users are not free to specify URLs.

The application specifies which webpage to display first, and defines which webpages are viewable.

If viewable webpages have been correctly specified, an attempt to open other webpages will result in the display of an error page, and further links will not be followed.

Use this specification so that only the necessary webpages can be viewed.

For more information, see NintendoSDK Documents > Features > Library Applets > Web Applet and Offline Web Applet > Web Applet.

Note:

Displaying HTTP pages is prohibited. Only HTTPS pages can be displayed for master submission versions of applications.
For more information, see NintendoSDK Documents > Features > Library Applets > Web Applet and Offline Web Applet > Web Applet > Specifying Accessible URLs.

Customizing the Web Applet

Customizations can be specified when the applet starts, or specified for a particular webpage.

Customizations specified when the applet starts, remain in effect until the applet ends.

Customizations specified for a particular webpage are enabled only when that webpage is being displayed.

By combining features, the web applet can be customized in just parts of the application.

For more information, see NintendoSDK Documents > Features > Library Applets > Web Applet and Offline Web Applet > Information Common to Both.

Adding Parameters to URLs to Pass Information

Information can be passed between the application and the web applet by adding parameters to URLs.

The URLs that can be used to pass information, are the URLs when the web applet starts and ends.

The URL when the web applet ends, can pass information to the application using the callback URL feature.

You can use this mechanism to start the web applet based on the state of the application, and to return information manipulated in the web applet back to the application.

For more information, see NintendoSDK Documents > Features > Library Applets > Web Applet and Offline Web Applet > Information Common to Both.

Notes When Using the Web Applet

Effect of System Updates

The web applet is also subject to updates when the system is updated.

Due to the characteristics of the browser, the update might change how the same webpage appears and behaves.

Consider the effects of system updates when using the web applet.

Termination by the System

If the user presses the HOME Button, and starts a system application from the HOME Menu while the web applet is running, the system might cause the applet to end.

For more information, see NintendoSDK Documents > Features > Library Applets > Web Applet and Offline Web Applet > Information Common to Both.

No Support for Display of Offline HTML

The web applet does not support the display of offline HTML files added to the ROM.

If you want to display offline HTML, use the Offline Web applet.

For more information, see 4.9 Offline Web Applet.

Restrictions When Creating Content

The web applet is not designed as a browser for the unrestricted viewing of publicly available websites. It does not have the following types of features common to standard web browsers.

  • Tabbing
  • Saving bookmarks
  • Search and address input

In addition, due to restrictions, the following types of features are not available.

  • Inline video playback
  • Flash playback
  • Viewing PDFs

In addition to these feature limitations, there are also other points to be aware of.

  • The applet might not be able to display webpages that place an extremely high load on rendering or consume a large amount of memory.
  • The content of the webpages must be directly relevant to the application.
  • The content of the webpages must not overstep the rating of the application.
  • The webpages viewable from the application must be continually available.
  • Make sure that the webpages are displayed correctly by the web applet.
  • Display only those webpages that have been sanctioned by the webpage administrator.
  • Make sure that the webpage content complies with the Parental Controls Compliance guidelines.
  • If rules have been set for the website being displayed, adhere to those rules.
Note:

Some websites rules require features for linking to other pages and for displaying ads.

Refrain from displaying such websites if adherence to their rules would preclude fulfillment of the other conditions required of the web applet, namely that "The content of the webpages must be directly relevant to the application" and "The content of the webpages must not overstep the rating of the application" and "Display only those webpages that have been sanctioned by the webpage administrator."

Note:

The webpages officially provided by Nintendo are not designed for display by the web applet. Make sure not to display official Nintendo webpages with the web applet.
