2 Introduction

Purpose and Content

This document describes how to use Nintendo eShop icons and logos, and important points when using them.

Follow the usage rules.

Intended Audience

This document is intended for application developers.

When to Read This Document

During planning and development of applications.

Required PC Environment

Adobe Illustrator CS6 or later is required.

File List

RGB format AI data is stored in the folder. The file creation date is entered in the YYYMMDD portion of some files.

Filename Description
Nintendo eShop_icon_rgb_YYYMMDD_Switch.ai Shop icon data for Switch.

Nintendo eShop_logo_rgb_YYYMMDD_Switch.ai

Logo data for Switch.
WUPN_HAE_JPlogo01_R_ad-1.ai Nintendo 3DS Family and Wii U logo data for Japan.
WUPN_HAE_logo01_R_ad-1.ai Nintendo 3DS Family and Wii U logo data for countries outside of Japan.
