3.2 Logos (for Switch)

This section describes the Nintendo eShop logos for Switch.

Shop Logo

Filename: Nintendo eShop_logo_XXX_YYMMDD_Switch.ai (for use in applications to be sold on Nintendo Switch outside of China)

Filename: Nintendo eShop_logo_XXX_YYMMDD_Switch.ai (for use in applications to be sold on Nintendo Switch for China)

Acceptable Uses

  • Representing Nintendo eShop
  • Indicating that products are sold on Nintendo eShop
  • Placement of items such as link buttons
  • Representing a link to Nintendo eShop
  • Seamlessly linking an application to Nintendo eShop

Rules for Using Artwork

Use the following recommendations when representing a link to Nintendo eShop or seamlessly linking an application to Nintendo eShop.

  • Use the logo without making changes.
  • Maintain the aspect ratio when reducing or enlarging the image size.
  • Use basic colors on this page.
  • Display over parts of the UI.

Using Keyboard Input Characters

As an exception, you can replace the logo with keyboard input characters using the font used in the application.

In such cases, apply the following rules.

  • Replace "Nintendo eShop" with keyboard input characters using the font used in the application.
  • When displaying a logo using keyboard input characters, place the eShop icon to the left of the entered characters to display the eShop icon next to the words "Nintendo eShop."
  • The color may be changed.

Basic Color

The basic colors have the following numerical values. The colors can be tailored to match the appearance of the game and the image of the product.

Minimum Margin

Set a fixed minimum margin around the icon to prevent it from merging with other notation. As a general rule, we do not recommend placing words or figures within the area.

About Giving Kana (Japan Only)

Starting with the Switch, we plan to not include kana (ニンテンドー イーショップ) in the eShop logo.

Although kana is included in the Nintendo 3DS Family and Wii U eShop logo for Japan (4.2 Logos (for the Nintendo 3DS Family)), you can omit the kana, as with the Switch eShop logo.
