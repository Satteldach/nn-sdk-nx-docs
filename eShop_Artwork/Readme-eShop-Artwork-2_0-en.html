1. Introduction

This package is a collection of artwork data for Nintendo eShop.

  • Nintendo Switch™
  • Nintendo 3DS Family
  • Wii U

This artwork can be used when developing applications.

For more information, see the Nintendo eShop Artwork Usage Manual.

Contact your Nintendo representative if you are unsure of how to use this artwork.

Support Information

For Nintendo titles, on the Nintendo Developer Portal, see Announcements (Internal) > Support Contacts for Artwork Collections, and contact the responsible team at Nintendo. For licensee titles, as with other packages, contact the responsible team at Nintendo.
