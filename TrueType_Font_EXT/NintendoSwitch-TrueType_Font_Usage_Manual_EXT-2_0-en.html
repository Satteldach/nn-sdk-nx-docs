TrueType Font Manual (Nintendo Extended Characters)

Introduction

This package includes the following fonts.

By installing these fonts on a Windows PC, you can use the TrueType fonts of the same design as the Nintendo Switch system fonts.

  • nintendo_ext_003
    Nintendo extended character font. Includes Nintendo 3DS and Wii U extended characters (such as controller buttons).
  • nintendo_ext_LE_003
    Nintendo extended character font. Does not include Nintendo 3DS and Wii U extended characters (such as controller buttons).
Note

See Descriptions and Warnings for Nintendo Extended Characters in the System Features Guide prior to using the Nintendo extended characters.

System Requirements

Installation

Right-click the font file you want to install, and select Install.
