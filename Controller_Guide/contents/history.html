Revision History

Version 8.0 (2021-09-30)

  • 2.3 Wireless Communication Restrictions
    • Added Maximum Number of Controllers When Connected to Bluetooth Audio.

Version 7.0 (2019-09-10)

Changes

  • 2.1 Introducing Controllers
    • Added information about Switch Lite.
  • 2.2 Pairing and Connecting Controllers
    • Noted that controllers cannot be paired and connected to Switch Lite via the rail.
    • Noted that controllers cannot be paired and connected to Switch Lite via the Switch dock.
    • Noted that up to seven controllers can be paired wirelessly at the same time by holding down the SYNC Button.
  • 3 Application Controller Support
    • Added a note about Switch Lite. There is no particular additional support required of application developers for Switch Lite.
  • 3.1 Supporting Different Play Formats and Grips (Required)
    • Noted that although the Switch Lite is treated the same as Switch with the Joy-Con attached, it is not equipped with either HD rumble or the IR Motion Camera.
    • Added a note about support for tabletop mode with Switch Lite.
  • 3.3 Implementation With Consideration of When Various Devices Are Not Included (Required)
    • Added features that cannot be used with Switch Lite. Noted the need to design applications so they do not get stuck and become inoperable because of the lack of some feature.
    • Added a note about Switch Lite. Warned application developers not to separate out actions on the presumption the system is a Switch Lite.
  • 3.5 Following Nintendo Switch Terminology (Required)
    • Noted that Switch Lite is always in the state equivalent to one where the Joy-Con is attached.
    • Added a description of the directional buttons.
  • 3.8 Other Recommendations
    • Added information about Switch Lite. Recommended that applications support operation of Switch with the Joy-Con attached unless there is special reason not to.
    • Revised the description of the value returned when failing to get color information.
