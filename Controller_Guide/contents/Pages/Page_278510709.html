3.3 Implementation With Consideration of When Various Devices Are Not Included (Required)

The Pro Controller and Switch Lite are not equipped with the following devices.

  • Pro Controller
    • IR Motion Camera
  • Switch Lite
    • IR Motion Camera
    • HD rumble

The Switch Lite cannot be used in TV mode, where the Joy-Con controllers are detached from the rails and the console is set in the dock. In addition, the Switch Lite does not come with Joy-Con as standard equipment.

Similarly, it is possible that future controllers and consoles will be offered that are not equipped with the various devices included with the current Switch, such as the accelerometers and gyroscopes. Design your application so it does not get stuck in a sequence and become inoperable, waiting for a value that will never come because some device is not present.
Consider implementing measures like the following so your application can proceed unobstructed.

  • Prepare a back button so users can escape from sequences that are waiting for values from devices.
  • Prepare a way for the application to advance even if a particular device is missing.


Info
  • The Switch Lite system features (system version 9.0.0 and later) include a user-operated feature to set the system as if the Joy-Con were removed. (The user sets this feature by selecting System Settings > Controllers and Sensors and clearing the selection for Console Button Input. The HOME Button and the Capture Button will remain enabled even when Console Button Input is disabled.) It is fine to ask customers to contact customer support when necessary.
  • There is functionality planned for the SDEV and EDEV that emulates a state where the Joy-Con controllers are not removed. This functionality can be used for testing and debugging.


Note

Do not implement sequences that presume the console is a Switch Lite based on the return values from devices like the IR Motion Camera. For example, having separate illustrations of the systems when showing users how to operate the application. It is fine to display a picture of Switch with the Joy-Con attached.
