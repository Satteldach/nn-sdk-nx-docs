2.2 Pairing and Connecting Controllers

Controllers must be paired before they can be connected. Paired controllers can perform the following operations.

  • Connect to the console using wireless communication.
  • Wake from sleep mode via the HOME Button.

The following description covers the basic information and methods needed to pair and connect controllers.

Pairing and Connecting Controllers

There are multiple ways to pair and connect controllers with the Switch. Descriptions of the methods for pairing controllers follow.

Table 2-2 Pairing and Connecting Controllers
Pairing and Connecting Corresponding Controllers Where Pairing Is Possible

1. Pairing and Connecting via the Rail

  • Joy-Con
  • When the console is on
  • When the console is in sleep mode (pairing after waking up)

Overlay notifications inform the user when pairing and connection is completed.

2. Pairing and Connecting via USB

  • Pro Controller
  • Joy-Con
    (Only for Joy-Con with the Joy-Con charging grip)
  • When the console is on

Overlay notifications inform the user when pairing and connection is completed.

3. Pairing and Connecting in Situations Where Pairing Is Possible

  • Press and hold the controller's SYNC Button for more than one second.
  • Pro Controller
  • Joy-Con
  • When the user calls Controller → Change Grip/Order on the HOME Menu
  • When the application has started the controller support applet

There is no SYNC Button on the Switch.
To place the console in a state that is awaiting pairing, you must use this procedure.



Note
  • Switch Lite does not have a rail for connecting the Joy-Con, so method (1) cannot be used to pair and connect a controller. In addition, the console is not structured to fit in the Switch dock, so method (2) also cannot be used to pair and connect a controller.
  • Using method (3), a maximum of seven controllers can be paired at the same time. An eighth controller can be paired by pressing the SYNC Button to disconnect one of the controllers that has already been paired.

The following information describes how to reconnect a controller after it disconnects after pairing and connecting using one of these methods.

Info

The controller vibrates when it is connected to notify the user of that fact.

Pairing Information

After pairing is complete, information about the controller paired with the console and information about the console paired with the controller is saved as pairing information.

Number of Paired Controllers

There is a maximum device count for pairing for both the console and the controllers.

  • The number of consoles that can be paired with one controller: one.
  • The number of controllers that can be paired with one console: 10.

Removals

Use the system settings to delete pairing information for controllers paired with the console.

Conditions for Disconnecting and for Blocking Connections

A controller can be disconnected or blocked from connecting when the following actions or states occur.

  • When turning the console off, or when putting it into sleep mode.
  • When In-Flight mode is turned on and Bluetooth communication with controllers is set to off in the System Settings (not applicable to Joy-Con attached to the system).
  • When the Reconnect controller setting in the system settings is called.
  • When pairing information for a controller is deleted from the system settings.
  • When the number of wireless connections exceeds the maximum.
  • When the number of supported devices is exceeded for the application, or when the application does not support the controller.
  • When you press the SYNC Button for less than one second.
  • When you lose power.
  • When there are problems with the wireless connection environment.
Note

A connected controller can become disconnected at any point during application operations, including when the application is starting up or restoring.

In particular, when the console enters sleep mode with multiple wireless controllers connected and then wakes up, it restarts in a state where everything is disconnected.

In that state, the user can connect a controller that is different from the one that was connected prior to the disconnection, as long as the application supports that controller.

Changing the Player LEDs Based on the Connection Status

The controller's player LEDs change, as follows, based on the connection status.

  1. Not connected
    Off.
  2. Connecting
    A flashing roulette pattern repeats.
  3. Connected
    Illuminates in conjunction with the assigned controller index. For more information, see 3.2 Assigning Controller Indexes (Required).
  4. When remaining battery power is low
    Flashes. Also displayed in overlay notifications.
  5. Disconnected
    The lights turn off. Also displayed in overlay notifications.
