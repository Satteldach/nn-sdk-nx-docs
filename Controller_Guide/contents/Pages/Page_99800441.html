2.1 Introducing Controllers

The Nintendo Switch has the following two types of controllers.

  • Joy-Con™

  • Nintendo Switch Pro Controller (called Pro Controller)

Info
  • A Joy-Con strap for increased safety and operability is included with the Switch system. For more information about the standards for using the strap, see the Application Safety Improvement Guide.
  • USB mouse devices and keyboards may also be used. For more information about mouse devices, see NintendoSDK Documents > Features > Input Device > hid Library > Manual > Features > Mouse. For more information about keyboards, see NintendoSDK Documents > Features > Input Device > hid Library > Manual > Features > Keyboard.

  • The NES controller for Switch and the Nintendo GameCube controller adapter are supported as special controllers by some applications. For other applications, these controllers operate like a Nintendo Switch Pro Controller lacking some features. Except for dedicated applications, no particular support is required for these devices.

Nintendo Switch Lite

The controller parts of Nintendo Switch™ Lite (Switch Lite) cannot be physically removed. As a result, from the application's perspective Switch Lite always acts like a Switch console with the Joy-Con controllers attached. Switch Lite can also use wireless connections if external controllers such as Joy-Con controllers or a Pro Controller are available.

It also has the following characteristics when compared to Switch.

  • There is no HD rumble feature.
  • There is no IR Motion Camera.
  • There is only one six-axis sensor.
  • The +Control Pad replaces four separate directional buttons.

Joy-Con Grip

The Joy-Con supports various grips. You use the two grips, left and right, when connected to the Switch console, or when disconnected. Other types of grips exist, and application developers can come up with other types and uses.

Joy-Con Grips Supported by System Features

The following Joy-Con grips are supported by the Switch system features. The assumption is that these grips will be supported by most applications.

Table 2-1 Joy-Con Grips Supported by System Features
Grip Image

Joy-Con (R) solo horizontal grip
Joy-Con (L) solo horizontal grip


Note
  • Switch Lite is handled the same way as Switch with the Joy-Con attached.
  • This feature does not differentiate between Joy-Con controllers connected to the grip and the dual-controller grip, and handles them the same way.
  • Applications can also support other grips. For example, it is acceptable to hold the Joy-Con (L) in the right hand or hold the Joy-Con (R) upside down. However, system features like the HOME Menu and the keyboard applet are designed to take input from these grips.

Number Available

A maximum of eight controllers can be connected wirelessly.

The following method is used for counting the number of controllers. When the Joy-Con controllers are connected to a console, they are not counted as wireless devices because they communicate through their physical connection to the console.
