3 Application Controller Support

This section describes the information for application controller support.


Info

For more information about implementation, see NintendoSDK Documents > Features > Input Device > hid Library > Manual > Features > Npad.

List of Controller Support Items

The following list shows the controller support items for applications. The items marked with (Required) are required to be supported. All other items are recommended.

  • 3.1 Supporting Different Play Formats and Grips (Required)
  • 3.2 Assigning Controller Indexes (Required)
  • 3.3 Implementation With Consideration of When Various Devices Are Not Included (Required)
  • 3.4 Displaying the Screen Showing and Describing How To Wear a Joy-Con Strap (Required)
  • 3.5 Following Nintendo Switch Terminology (Required)
  • 3.6 Controller Support Applet
  • 3.7 Controller Support Under Specific Conditions
  • 3.8 Other Recommendations


Note

There is no particular additional support required of application developers for Switch Lite. However, we recommend that developers consider that in some situations some features might not be available, both for Switch and Switch Lite. For more information, see 3.3 Implementation With Consideration of When Various Devices Are Not Included (Required).


Benefits Available When Configured Appropriately

The following benefits are available when these requirements are met.

  1. Inheriting operation mode for system features (HOME Menu and the like can be manipulated as is).
  2. The player LEDs light up appropriately (if using dual assignment, both the left and right Joy-Con controllers will light up the same).
  3. Assignment of appropriate play format, according to the number of controllers.
  4. Automatic disconnection for unsupported controllers.

1 through 3 are benefits for players, and 4 is a benefit for application developers.

For more information about supporting controllers within system features, including continuing operations when transitioning to system features, see 4.1 Supporting System Features. Refer to this documentation as necessary.

For more information about player LED illumination, see 3.2 Assigning Controller Indexes (Required).

For more information about automatically disconnecting unsupported controllers in the application, see 3.8 Other Recommendations.
