3.8 Other Recommendations

This section describes other recommendations.

Supporting Attached Joy-Con Controller Operations

Users can play in handheld mode when an application supports using attached Joy-Con controllers. If this use case is not supported, the application essentially becomes crippled in the following situations.

  • The system is not sending output to a TV and the mode is airplane mode.
  • The Joy-Con battery has run out so the user wants to play with the Joy-Con attached to the console.
  • The user is playing a Nintendo Switch Lite without using a wireless controller.

For this reason, support attached Joy-Con controller operations except in special circumstances such as those described in the following.

  • Applications that use motion controllers, such as when you have to wear a Joy-Con wrist strap.
  • Applications that assume a Joy-Con controller will be attached to a device other than the Switch for gameplay.
  • Applications that only offer TV mode or tabletop mode.
Info

Even when attached Joy-Con controllers cannot be used for the main portions of an application, such as character movement, we recommend making sure that the application supports using them to transition to the application and perform operations.

Pro Controller Support

The Pro Controller is available to enhance gameplay in TV mode and tabletop mode. For this reason, the Pro Controller is also supported, except under the following special circumstances.

  • Applications that use motion controllers, such as when you have to wear a Joy-Con wrist strap.
  • Applications for handheld mode only.
  • Applications using features that the Pro Controller does not offer, such as independent left and right accelerometer and gyroscope values, or the IR Motion Camera.

Supporting Controller Color Information

The color information is saved inside the Switch controller. The color information contains the 2 colors (RGB 888 × 2 = 6 bytes), main and sub, and is applied to and displayed on the controller icon shown on the screen and overlay that is displayed when calling the controller support applet. The main color is saved as a value similar to the color of the controller itself. As shown in the following image, the sub color is saved as a color that would be easy to identify for indicating buttons and other UI elements when displaying the controller.

Figure 3-11 Image of a Controller Icon With Color Information Applied


Though using the controller color information is not mandatory, using it makes it easier to identify the controller that the user is using. For example, it would be effective for party games and other scenarios in which there are multiple players.

Note
  • The sub color is not the actual color of the buttons on the controller.
  • The main and sub colors do not need to be used as a set. The main color can be used by itself.
  • If you want to apply color information to the controller icon in your application, we recommend adding a (green) frame around the icon so that the icon does not fade into the application background image.
  • There are no debugging features to rewrite the color information, etc. An actual controller needs to be prepared.
  • There might be more controller color variations in the future. Make sure that adding more controller color variations does not affect progress in the game.
  • If the action of getting the color information written to a controller fails, a black value is returned. This happens with the NES controllers for Switch, the Nintendo GameCube controller adapter, and the controller parts of Switch Lite.

Handling After Automatic Controller Disconnection

Controllers offering play formats not supported by the application, or controllers exceeding the maximum number of connections supported by the application, will be disconnected automatically.
For example, if an application only supports dual Joy-Con play, the Pro Controller that was connected when the application started, or was restored, will be disconnected. Similarly, such a device will not connect while the application is running. The application must perform handling after disconnection.
Note that Joy-Con controllers attached to the console cannot be disconnected because that connection is not wireless.
