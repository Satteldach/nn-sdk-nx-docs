4.1 Supporting System Features

Types and Number of Connected Controllers Handled by System Features

In general, all controllers supported by the Switch can operate system features, including the HOME Menu and the keyboard applet.

Up to four sets of controllers can be connected wirelessly in addition to using a Joy-Con/Switch combination. Usually, both the left and right Joy-Con controllers are used together as a set by one person. Each Pro Controller is used by one person.

Note

When you call system features, while the application is connected to at least five sets of wireless controllers, the connections are maintained.

In addition, if the application calls the system features when there are fewer than four pairs of wireless controllers connected, the number of connected controllers may increase to the maximum of four pairs.

However, if the number of connected controllers exceeds the number supported by the application, they will be disconnected when returning to the application. For more information about automatic controller connections, see 3.8 Other Recommendations.

Maintaining Different Play Formats and Grips

A variety of controller and Joy-Con grips are supported by the system features.

When transitioning from an application to system features, you can continue to operate, without changing your grip, if the application has appropriately configured the play format and the grip for a single Joy-Con.

Example: Maintaining Settings From the Application to the HOME Menu
  1. The application sets the Controller.1 Joy-Con to one-controller-each connection and solo horizontal grip. The player operates the Controller.1 right controller using horizontal grip.
  2. When the player presses the HOME Button, the HOME Menu appears.
  3. The player can then operate the HOME Menu, maintaining the Controller.1 Joy-Con (R) controller in a horizontal grip. In this case, the X Button corresponds to A, which is the button layout assigned when rotated 90° in the clockwise direction.

Footer Notation

In the system features, button operations are described on the bottom of the screen (footer). The footer notation changes depending on the types of controllers and their grips.

When the configuration is dual-controller grip, solo remote grip (right controller), Joy-Con/Switch combination, or Pro Controller, this notation will show ABXY.

Info

The up/down/left/right directional operation buttons (directional buttons or +Control Pad) are not displayed.

Note

Applications are not required to use controller icon notations, to differentiate the controllers, in the same way as the system features. It is acceptable to just use icons that allow the user to recognize the operation mode. Select the display appropriate to the properties of the application.
