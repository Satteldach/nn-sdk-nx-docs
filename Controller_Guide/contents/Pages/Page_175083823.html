3.7 Controller Support Under Specific Conditions

This section includes several examples of controller support under specific conditions. These examples use controller support applets. An application may also offer its own user interface (UI) with the same content, without using a controller support applet.

The following support features make it easy for the users to understand which controller is available and how to grip it. We particularly recommend using these features when there are numerous players because the combinations of users and controller grip techniques become complicated.

If There Is No Compatible Controller When the Application Starts or Resumes

For example, in the following situations, the application has started or resumed, but the controller configuration might not be supported by the application.

  • In handheld mode, tap the touch screen to start the application (or resume play).
  • When the application is started (or play is resumed) using a controller that the application does not support.
  • Although the application requires both a left and right controller, it was started (or resumed) using either a single left or right Joy-Con controller.

If the controller configuration is not supported when the application starts or resumes, we recommend calling the controller support applet.

If the Wireless Controller Connection Is Disconnected During Gameplay

For example, if the battery loses power and the wireless controller connection is disconnected while the user is playing the application, the application may progress, even though controller operation has been disabled.

In this case, we recommend calling the controller support applet when the controller that is in use can no longer be detected.

Figure 3-8 Flow When the Wireless Controller Connection Is Disconnected During Gameplay



However, when changing the play mode, if you call the applet immediately after the controller currently in use is no longer detected, this might cause inconvenience to the user.

To change between play modes smoothly, we recommend first allocating 5 seconds of wait time (with an additional 5 seconds of wait time if a transition from handheld mode to TV mode is detected) before calling the applet.

If the Controller Grip Is Changed

We recommend calling the controller support applet for applications where the supported controller differs for each minigame or requires the user to switch the controller grip during the game.

Info

When necessary, it is preferable for the application to explain the following before calling the controller support applet, or, more accurately, before changing the play format.

  • The method for handling controllers is being changed.
  • A controller that was used previously can no longer be used.
