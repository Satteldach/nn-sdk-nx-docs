3.2 Assigning Controller Indexes (Required)

Controller indexes are assigned when controllers are connected to the console. Indexes are assigned in order, starting from 1.

No indexes are assigned to Joy-Con that are attached to the console. Indexes can be used, however, when the application supports that configuration.

Info

If you use the controller support applet, you can simplify the process of setting the number of Joy-Con controllers for each user.

A user interface is included to prompt users to reconnect controllers and change grips in conjunction with the play format, grip, and call time specification selected by the application. For more information, see 3.6 Controller Support Applet.


Info

There are many different grips for Switch controllers in general and Joy-Con in particular. As a result, a player might use a grip that is not supported by the application.

We recommend describing in your application how to use controllers in general and the Joy-Con in particular, and how to configure settings such as the play format and grip.

Player LED Illumination

The player LED corresponding to the controller index will illuminate when an index has been set to a controller.

The Joy-Con (R) player LED illuminates for different indexes depending on whether the grip is vertical or horizontal. If the controller grip is vertical, the LEDs light up in order from the top, and if the controller grip is horizontal, the LEDs light up in order from the left. When you configure this setting in conjunction with the Joy-Con grip, the left and right Joy-Con illuminate using the same pattern.

Assigning Joy-Con Controller Indexes

There are two ways to handle the Joy-Con. One style of gameplay involves one player holding both the Joy-Con (R) and Joy-Con (L) in a dual-controller set. The other style involves two players, each holding one side of the Joy-Con in a shared configuration. You can use the hid library to configure whether to handle Joy-Con as a dual-controller set or as one for each controller index.

  • In a dual-controller set configuration,
    the right and left Joy-Con controllers form a pair. The same index is assigned to both. The player LED illuminates in the same pattern for both right and left controllers.
  • For a single-controller configuration, the right and left Joy-Con controllers are each assigned a different controller index.
    The right and left Joy-Con have different indexes when connected. The player LED illumination patterns are also different.

The following examples demonstrate these differences.

Example: Assigning all controller indexes as dual-controller sets:
  1. Controller.1 is assigned to the first Joy-Con (R) to be connected.
  2. Controller.2 is assigned to the second Joy-Con (R) to be connected.
  3. Controller.1 is assigned to the first Joy-Con (L) to be connected.
    Pairs with the first Joy-Con (R) connected in step 1.
  4. Controller.2 is assigned to the second Joy-Con (L) to be connected.
    Pairs with the second Joy-Con (R) connected in step 2.
