3.1 Supporting Different Play Formats and Grips (Required)

You must select a play format, which is categorized by controller type and grip. These selections set the available controllers and buttons, and their functionality.

When you select single Joy-Con grip as the play format (which can apply to either the right or left controller), you must also specify a grip (either solo remote grip or solo horizontal grip).

Figure 3-1 Flowchart for Supporting Different Play Formats and Grips

Applications must first set the number of players using controllers.

For applications that support both of the following play modes, specify the number of Joy-Con controllers for each player.

  • Single Joy-Con grip play, Joy-Con (R) play, or Joy-Con (L) play
  • Dual-controller grip play (dual controller play, or Pro Controller operation)

Controller indexes are assigned based on the settings content when controllers are connected to the console.

Note

For example, with a game that can be played by up to four players, if there are only two sets each of Joy-Con (L) and Joy-Con (R) controllers, up to two players can play, each holding two controllers. To play with four players, each player will have to play with one controller. For this reason, rather than determining the number of Joy-Con controllers to set in advance, we recommend allowing the user to specify the number of Joy-Con controllers.

This kind of controller assignment is easy when using the controller support applet. For more information, see 3.6 Controller Support Applet.

Requirements for Applications Supporting Tabletop Mode

If the Joy-Con controllers are connected to the console and a wireless controller is also connected, the application cannot determine which device the user wants to use as a controller. For example, this case occurs when the Joy-Con controllers are attached to the console when playing with the Pro Controller in tabletop mode. Use any of the following procedures to handle this situation.

  • Using one of the following methods, ask the user which controller they want to use.
    • Use the controller support applet in single-player special mode. For more information, see 3.6 Controller Support Applet.
    • Unique handling by the application without using the controller support applet.
  • Enable operation from both the Joy-Con controllers connected to the console and the wireless controller.
Note
  • When operation from both the Joy-Con controllers connected to the console and the wireless controller is enabled, vibrations sent to an unused controller may be unsettling to the user. In addition, when using the 6-axis sensor for input, because there is also input from the controller that is not being used, you cannot enable input from both controllers. In this case, we recommend asking the user which controller they want to use.
  • A policy of treating tabletop mode as only the state where the Joy-Con are detached from the console is prohibited by Guideline 0160: Supporting Wireless Controllers Regardless of Whether the Joy-Con Controllers Are Attached to the System. The Switch Lite behavior is similar to a Switch with the Joy-Con attached, so this policy would make Switch Lite not playable in tabletop mode.

Specifying a Grip for One Joy-Con

You can set any of the following grips when the application supports either Joy-Con (R) play or Joy-Con (L) play, or both.

  • Solo remote grip
  • Solo horizontal grip

The following advantages for the user result from setting the grip correctly in the application.

  • Play will continue with that grip when calling the system features. For more information, see 4.1 Supporting System Features.
Info

When holding the Joy-Con (R) vertically, the player LEDs light up in order from the top, but when holding the Joy-Con (R) horizontally, the player LEDs light up in order from the left. For more information, see 3.2 Assigning Controller Indexes (Required).


Note
  • You cannot mix settings for solo remote grip and solo horizontal grip.
  • The default value for the hid library is solo remote grip. There are also restrictions on using the controller support applet. For more information, see 3.6 Controller Support Applet.

Limitations When Supporting Pro Controller Play

The following Joy-Con grips are available for applications supporting Pro Controller play.

  • Dual-controller grip
  • Joy-Con attached to the classic-grip accessory

Care is needed when considering application specifications because these grips have the following differences compared to the Pro Controller.

Table 3-2 Differences From the Pro Controller
Option Differences
Connection Status

The number of controllers that can be connected changes.

When using Joy-Con in the Pro Controller play format, the right and left Joy-Con controllers are treated as one controller.

If one of the two Joy-Con controllers disconnects because of a dead battery or for any other reason, the entire controller is viewed as disconnected. However, the HOME Button and the Capture Button are enabled.
+Control Pad

The +Control Pad is available with the Pro Controller. On the Joy-Con, however, directional buttons that split the four directions into separate buttons are used because there is no +Control Pad.

The +Control Pad and directional buttons have the following differences.

  • The up and down buttons and left and right buttons on the +Control Pad, cannot be pressed simultaneously.

  • Because the four buttons are merged in the +Control Pad, unlike the directional buttons on the Joy-Con, there may be an occasion when up or down input is registered unintentionally when the user quickly switches between left and right input.
Control Sticks

The range of motion of the control sticks on the Joy-Con is narrower than that of the Pro Controller.

The maximum and minimum values for the control sticks are the same, but the resolution for the control stick values is different.
Accelerometer
Gyroscope

An accelerometer and gyroscope are built into the Pro Controller.
When using the Joy-Con dual-controller grip or Joy-Con attached to the classic-grip accessory, the sensor for the right controller is used.
HD Rumble

There is a vibration motor inside the left and right grips of the Pro Controller, for a total of two vibration motors.

When the Joy-Con grip is attached, it has the same play feel as the Pro Controller.

When holding two Joy-Con controllers, the sensation is improved because vibration is divided between left and right, to the controllers held in the left and right hands.
