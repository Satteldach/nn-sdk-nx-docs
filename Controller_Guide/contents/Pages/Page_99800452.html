2.3 Wireless Communication Restrictions

The Joy-Con and the Pro Controller can both use Bluetooth to connect wirelessly. The number of each type of controller that can connect and the available functionality are limited in a wireless communication environment.

Available Functionality and Maximum Number of Wireless Controllers That Can Be Connected

With the Switch, you can connect up to eight wireless controllers to the console. That number varies, however, depending upon what you are doing with the controllers.

Note
  • The NFC reader and writer and IR Motion Camera cannot be used simultaneously for the same Joy-Con (R).
  • The Pro Controller can use wired communication in System Version 3.0.0 and later. However, NFC cannot be used during wired communication.
  • The maximum number of controllers that can be connected is eight, even when including wired Pro Controllers.

Maximum Number of Controllers During Local Communication

There is a risk of signal interference, and a loss in communication, while using local communication.

The number of controllers that can be reliably connected is as follows. The number differs based on the number of Switch consoles being used.

  • Two to Four Switch Consoles
    Four or fewer wireless controllers can be connected per system (confirmed for two users).
  • Five to Eight Switch Consoles
    Two or fewer wireless controllers can be connected per system (confirmed for one user).

Maximum Number of Controllers When Connected to Bluetooth Audio

Up to two wireless controllers can be connected while using Bluetooth audio.

There is no particular additional support required of application developers for Bluetooth audio. This restriction on the number of connected controllers is described in the System Settings, where Bluetooth audio is set up. In addition, a similar description is presented in an overlay notification if the user tries to connect three or more controllers.


Info
  • Support for Bluetooth audio was added in system version 13.0.0. For more information, see Nintendo Switch System Features Guide > System Application > System Settings > Bluetooth Audio.
  • The use of NFC and the IR Motion Camera are not affected.
  • The system cannot connect to Bluetooth audio during local communication.
