1 Introduction

Purpose and Content

This document describes how to create new effects using the HD rumble feature. Refer to this document to learn more about what makes the HD rumble feature unique, how you can use it in your planning process, and how to approach the production process.

Intended Audience

This document is intended for planners and developers of applications that use the HD rumble feature.

Structure of This Document

2 Creating New Effects With Vibrations describes what makes the HD rumble feature unique and how that can be used to create new effects.

3 Use Cases for Vibration describes three potential uses for the HD rumble feature.

4 Vibration Content Production Process describes the process for developers to use when producing content using the HD rumble feature.

5 Appendix provides supplemental information about the HD rumble feature.

Related Documents

For more information about using the HD rumble feature, see the pages for the vibration feature at NintendoSDK Documents > Features > Input Device > hid Library > Manual > Features > Vibration. The samples and tools required for using the vibration feature are bundled with the NintendoSDK NX Add-On. We recommend that you look at the samples and tools to help you better understand the vibration features.
