3 Use Cases for Vibration

This section describes use cases for the HD rumble feature. The linear resonant actuator can be used in the same way as a conventional vibration motor, but it can also be used in ways that have never been seen before. The various use cases exist along a spectrum from more basic uses that are similar to existing uses, to more novel uses, as follows.

    • Simple Uses
    • Uses in Combination With Video and Audio
    • Uses That Emphasize Vibration as a Standalone Effect

This page describes how to use the feature in each use case.

Simple Uses

The first use case is the simplest one: using the linear resonant actuator as a simple vibration generator.

This use is closest to the way the eccentric rotating mass has been used. Also, the scenarios in which vibrations are used this way are the same. For example, in dramatic scenes like where there are explosions. The linear resonant actuator is the replacement for the eccentric rotating mass, and with its faster responsiveness, it is backward-compatible for vibrations. The eccentric rotating mass can only be controlled with simple starts and stops, so to use the linear resonant actuator in this manner, you would control the vibrations with numerical values, for example by setting the strength of vibration (the amplitude) to values like 1.0 or 0.5, and the fineness of vibration (the frequency) to values like 160 Hz or 320 Hz.

Uses in Combination With Video and Audio

The following use case plays off the strength of the new vibration device a little more: it links vibration to video and audio.

Vibration was previously used primarily in scenes to surprise the user, and in scenes that required conveying strong impact. The linear resonant actuator can be used for scenes that require more subtle effects that were originally not suitable for vibration. For example, you can use vibration synchronized with detailed actions such as walking, jumping, or throwing things to clarify the character's actions. You can change how long the vibration lingers to differentiate more clearly between small jumps and large jumps. You can also strengthen the feel of riding in a vehicle by synchronizing the amplitude and frequency of the vibrations with the number of rotations in the engine of the vehicle.

To realize these kinds of detailed vibrations, you create the vibration data in advance. Because you play vibration data that has been created in advance, rather than generating the data in real time, you can think of the vibration data as being handled in a way similar to audio data and image data.

The NintendoSDK NX Add-On includes a Vibration Demo collection (VibrationDemo) of sample vibrations. You can use the Vibration Demo collection to experience how the operations and feel of the game change by adding vibration in various situations in the application. Try out this demo if you want to experience how to effectively use the HD rumble effects.

Uses That Emphasize Vibration as a Standalone Effect

The final set of examples shines a spotlight on uses that are unique to the vibration feature.

It includes the ability to use vibration itself as a game resource. Because the linear resonant actuator can produce various vibrations, the differences in them can be used as elements of gameplay. For example, you can have players appraise items they cannot see, with only the vibrations as a clue, or use vibrations to determine the distance and direction to an enemy off the screen, or even the enemy type.
