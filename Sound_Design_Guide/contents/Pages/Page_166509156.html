3 Tips

This page introduces tips for sound development.

Switch Sound Mode Settings

The Switch system settings provide the following sound mode settings for each audio output device.

System Setting Output Device Modes
TV Settings > TV Sound HDMI Automatic / Surround Sound / Stereo / Mono
System > Sound System Speakers / Headphones / USB Audio Output Device / Bluetooth Audio Output Device Stereo/Mono

Note: When TV Sound is set to Automatic, the system will operate in Surround Sound mode if the output device supports surround sound, and Stereo mode if not.

Users can change this setting at their discretion through the Switch system settings, even when the application is starting. However, because the Switch has a feature to downmix surround audio output to two channels according to the selected sound mode setting and the actual number of channels of the output device, you do not need to worry about the possibility of audio from the center, rear left, or rear right channels of surround mode not being output or sounds missing in stereo/mono mode on the application side.


Based on these considerations, the sound developer for the application can design sound output as follows.

  • Design sound for surround mode.
    • Regardless of the system's sound mode setting, the application designs sound with the assumption of outputting audio from all channels.
    • The final output corresponding to the system's sound mode settings is left up to the downmix feature of the Switch.
      • You can use the audio renderer provided by the NintendoSDK to set the coefficient used in downmix processing calculations to an application-specific value. For more information, see the audio library manual for the NintendoSDK.
  • Design sound for stereo.
    • Regardless of the system's sound mode setting, the application designs sound with the assumption of outputting audio from only the front channels.
    • Narrowing the mix processing of voices to only two channels is expected to raise processing efficiency, including processing to play a larger number of sounds.
    • This design is effective for applications that do not require surround output, such as 2D scrolling games.

Note that if you are considering specifications to switch sound mode using original settings configured within the application, you cannot change the sound mode setting on the Switch side from the application. Even if you switch the original mode setting on the application side, audio is ultimately output to channels dependent on the sound mode setting selected on the Switch system side, so the settings in the application may be disabled in some cases.

Measuring Loudness Values

Loudness values for Switch can be measured using either Spy or SystemAudioMonitor, included in the NintendoSDK.
The differences between the two tools are as follows.

  • Spy
    • Measurements only occur for audio played back by AudioRenderer.
    • The application has to incorporate Spy.
    • Values are displayed in a graph format.
    • Output device volume settings for the television are always incorporated.
  • SystemAudioMonitor
    • Measurements occur not only for audio played back by AudioRenderer but also by AudioOut.
    • Nothing needs to be incorporated into the application.
    • Raw values are displayed.
    • Output device volume settings are incorporated, corresponding to the output device at the time of measurement.

Measuring Loudness Values with Spy

The Spy features included with the NintendoSDK, can be used to measure loudness values and True Peak values of a currently running application.
For more information about how to use Spy, see the NintendoSDK documentation.

In Spy.exe, the Audio Loudness Meter Panel displays the average loudness and True Peak values for an application while it is running.

Immediately after connecting to a target, Spy.exe automatically begins taking measurements.
For more information about measurement segments when taking measurements, see 2. Support Recommendations.
The following diagram shows a sample measurement taken using the audio loudness meter in Spy.exe.

Figure 3.1 Audio Loudness Meter Panel in Spy.exe


The value for Integrated(LKFS), marked as A in Figure 3.1, is the average loudness measured between the start of measuring and the present.
This measurement value will appear green when it is within the recommended range of the average loudness target value (-24 LKFS to -28 LKFS).
When this measurement value turns yellow, it indicates that it is within the tolerance range of the average loudness measurement value (-22 LKFS to -28 LKFS).
When this measurement value turns red, it indicates that it is outside the tolerance range of the average loudness measurement value.

The peak value measurement can be found next to B in Figure 3.1.
When True Peak is on, a calculated True Peak value is displayed here.
This measurement value will appear blue when it is within the recommended range for True Peak.
When this measurement value turns red, it indicates that it is outside of the recommend range.

Info

The function that sets the volume of the output device for the TV (nn::audio::SetAudioOutputDeviceVolume) can affect the measurement values shown in the Audio Loudness Panel in Spy.
You may want to consider letting these values be applied by the output device volume settings for the TV, even when the console speakers, headphones, or other output devices are active.

Measuring Loudness Values With SystemAudioMonitor

The SystemAudioMonitor features included with the NintendoSDK can be used to measure loudness values and true peak values of a currently running application.
For more information about using SystemAudioMonitor, see NintendoSDK Documents.

Info

SystemAudioMonitor is available starting with NintendoSDK NX Add-On 5.1.0.

In the upper portion of SystemAudioMonitor.exe, the average loudness and true peak values appear for the running application.

Immediately after connecting to a target, SystemAudioMonitor.exe automatically begins taking measurements.
For more information about measurement segments when taking measurements, see 2. Support Recommendations.
The following diagram shows a sample measurement taken using SystemAudioMonitor.exe.

Figure 3.2. SystemAudioMonitor.exe


The value for INT, marked as A in Figure 3.2, is the average loudness measured between the start of measuring and the present.
The peak value can be measured at B in Figure 3.2.

Info

The measurement values for SystemAudioMonitor are updated in accordance with the device currently playing output with the configured output device volume settings, using the output device volume settings function (nn::audio::SetAudioOutputDeviceVolume).
