2 Support Recommendations

This page describes support recommendations for sound development.

Volume Adjustment for Each Audio Output Device

There are five device types that output sound from the Switch: audio devices connected via HDMI, the console speakers, headphones, USB audio output devices, and Bluetooth audio output devices.

When HDMI output is connected to a TV and equipment such as an audio amplifier, users may experience discomfort if the volume is different from TV broadcasts and may need to adjust the TV's volume for each item of content that is played. To avoid this situation and improve usability, you must use a volume that conforms to loudness standards.

The volume level must also be high enough to be heard in environments with a lot of ambient noise, such as when playing speakers outside and when listening on headphones while on a train.

Because the environment used is assumed to vary depending on the device that outputs the audio for Switch, we recommend configuring volume settings appropriate to each output device.

Volume Adjustment When Connected via HDMI

Consider the average loudness target value and average loudness target value using the following methods, and configure the volume output level of sound used by the application to fall within the recommended range and allowable range for each method.

Average Loudness Target Value

When designing the volume levels of an application, we recommend configuring the average loudness target value (target loudness value) and adjusting the volume.

For the basic target value, use -24 LKFS. (This value conforms to the target loudness value in operating guidelines for the broadcasting industry.)

Some applications, however, may have quiet scenes and intense scenes where the difference in volume easily becomes large, or may require expression that uses a wide dynamic range. It is fine to set the target loudness value on the low end and then adjust the volume according to the application's attributes. In this case, set the recommended range of the target value with a lower limit down to -28 LKFS.

Measuring Average Loudness

Measurement Method

Measure the following channels using a loudness meter that conforms to a general algorithm for measuring loudness (such as ITU-R BS.1770-2).

Titles Supporting Surround All channels except the LFE channel
Other Two channels (L and R)

Measurement Segment

When measuring average loudness, measure using gameplay samples from many different scenes in the game. If possible, including a small climax scene such as a boss battle in the measurement segment helps to provide a more effective measurement result.

Samples that are very inconsistent in average loudness are deemed inappropriate as representative samples for measuring average loudness for the application. In such cases, set the measurement segment using scenes that a general user experiences as samples.

A guideline for measurement length is about 30 minutes to 2 hours.

Allowable Measurement Result Range

Depending on the application, a certain level of measurement error in the measurement result may occur due to the play content during measuring and conditions such as the segment settings.

Based on these attributes, set the allowable range of measurement error for the average loudness target value to +2 LK.

Measuring Peak Value

To avoid the occurrence of distortion and noise due to overloading after converting the digital signal output from HDMI to an analog signal, adjust the volume for the output level of all channels to within -1 dBTP/-3 dBFS or lower.

Allowable Range of Peak Value

-1 dBTP/-3 dBFS or lower

If the average loudness value falls outside the recommended range, make a determination after fully considering the application's attributes.

In general, loud volume that stands out is apt to cause users discomfort. In cases where the average loudness exceeds -22 LFKS, carefully consider the volume including the necessity of the expression.

Volume Adjustment During Speaker Output

Generally speaking, a guideline for volume balance during output from the speakers is setting the volume level approximately +6 dB louder than the volume level during HDMI output.

However, simply increasing the output audio level may result in audio cutoff and noise occurring due to the peaks getting clipped.

Adjustment of Volume When Outputting Sound Externally

Headphones, USB audio output devices, and Bluetooth audio output devices are treated collectively as external audio output.
Similar to output from the speakers, a guideline for volume balance during output from an audio output device is setting the volume approximately +6dB louder than the volume level during HDMI output.

However, simply increasing the output audio level may result in audio cutoff and noise occurring due to the peaks getting clipped.

Examples of Adjustments Using Switch System Features

The NintendoSDK provides the nn::audio::SetAudioDeviceOutputVolume function as one way to adjust the output volume of each device.
Switch system features use this function to adjust the output volume level for each device as follows.

Table 2-2 Loudness Target Value and nn::audio::SetAudioDeviceOutputVolume Setting Value for Each Output Device
Audio Output Device Argument (pDeviceName) (See Info) Argument (volume) Loudness Target Value
HDMI AudioTvOutput 0.5 -24 LKFS
System speaker AudioBuiltInSpeakerOutput 1.0 -18 LKFS
External audio output AudioExternalOutput 1.0 -18 LKFS

For more information about nn::audio::SetAudioDeviceOutputVolume, see NintendoSDK Documents.

Info

Note: The parameter values in this table, except for AudioExternalOutput, will be available in NintendoSDK NX Add-On 13.1.x and later.

In SDKs before 13.1.x, use AudioStereoJackOutput(headphone) and AudioUsbDeviceOutput(USB audio output device) instead of AudioExternalOutput.
Additionally, in SDKs prior to NX Add-On 13.1.x, if a value is not set for nn::audio::SetAudioDeviceOutputVolume for the USB audio output device, the value set is always the same as for the headphones.
