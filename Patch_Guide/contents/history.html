Revision History
Version Update Date Category Revisions
5.0

2021-10-01

 Additions
  • 2.6 Handling for Initial Applications to Reduce Unnecessary Regions
    Added the method of distributing most of the data as a patch rather than the initial application as a method to reduce the number of unreferenced regions within the initial application.
  • 2.7 Application Compaction
    Added a description of application compaction.
  • 3.3 Patch Distribution
    Added that the developer needs to configure the settings on NCMS for distributing the patch after it has passed Lotcheck.
    Noted that the timing for patch distribution cannot be separated by region.
    Noted that you cannot specify certain users or Switch consoles as the distribution targets for the patch.
    Added settings to configure on NCMS when distributing the patch.
    Noted that there is a setting you can configure to prevent information leaks for patches distributed during pre-order.
Changes
  • General
    Revised wording that could lead to misunderstandings. Fixed inconsistencies in terminology.
  • 1 Introduction
    Changed the recommendation about when to read this document to be starting from when you are planning and developing the application.
    Deleted "partial file patch" and "most recent patch" from Terminology.
    Deleted Independent Server Setup Manual from Related Documents.
  • 2.1 Capabilities of Patches
    Added Scope of Patching to the sections on the page.
    Added that you can update almost all of the data by applying a patch.
    Added information about regions that cannot be reduced in size.
    Added an Important Information note that downgrading NintendoSDK versions through a patch is prohibited.
  • 2.1.1 Adding Paid Features
    Moved the page location from a child page under Switch Patch Features to this page.
    Added a reference to the Nintendo Switch E-Commerce Guide.
    Deleted the Adding Features Using Only Downloadable Content section and the Adding Features Using a Patch and Downloadable Content Together section.
    Added Adding Features Combining a Patch for Supporting Multiplayer and DLC.
  • 2.2 How Patches Work
    Changed the page name from Patch Specifications.
    Added that you can create patches by extracting only the difference in data before and after the application is revised.
    Added a reference section (about the memory size required for patching).
    Added an important information section (important information about patch sizes and reference to NintendoSDK Documents).
  • 2.3 Update Processing via Patches
    Changed the page title from Updating Patches.
    Added Downloading and Installing Patches, Updating With Incremental Data, Patches Distributed Through Local Communication, and Minor Fixes for Which the System Does Not Get a Patch.
  • 2.3.1 Making Patches Mandatory for Applications That Use Network Services
    Changed the page title from Making Patches Mandatory.
    Deleted the Update Within 24 Hours section and the Immediate Update section.
    Added that the application release versions for all users may not match.
    Added that to prevent users with earlier release versions of the application from using network services, you must make patching mandatory through Nintendo's authentication server.
  • 2.4 Patch Management and Compatibility
    Added 4 Important Information about backward compatibility.

  • 2.5 On-Card Patch
    Added a reference to the NintendoSDK Documents about using on-card patches.
    Added a reference section indicating that you can use application compaction to reduce the patch size of on-card patches.
    Added an important information section, and added the following two points.

    • If a patch with a later release version than the on-card patch is released, the application will not be updated incrementally.

    • When the operating frequency set for the initial application differs from the operating frequency set for the on-card patch as described below, the timing when data is loaded may change greatly.

  • 3.1 Creating and Debugging Patches
    Changed the page title from Creating and Debugging Patches.

  • 3.2 Patch Submission
    Changed the page title from Patch Registration.
    Added a reference section and moved the OMAS descriptions there.
    Added an important information section and moved the important information about using patches to add online features there.
  • 4 Important Information
    Changed the page title from Important Considerations for Patching.
    Added the Changing the Rating section and the Guidelines section.
    Deleted the child page and consolidated some of the information on the main page.
Deletions
  • Development Environment
  • Scope of Patching
  • Compatibility Before and After Applying the Patch
  • Changing the Rating
  • Reducing Patch Size
  • On-Card Patch Operating Frequency
