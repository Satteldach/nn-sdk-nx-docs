2.3 Update Processing via Patches

Downloading and Installing Patches

The system performs the full sequence of processes for installing the patch. It is not possible to get patches from the application.

When a patch is released, Nintendo's servers notify the Switch console. A Switch console that has received a notification proceeds to get information about the patches and to download any necessary patch.
In addition, if a user newly downloads the application, the patch is also downloaded at the same time.

When downloading a patch, there must be enough space in either system memory or a microSD card to save the data. In addition, the size of the patch being downloaded differs depending on which if any patches the user has already obtained for the application. For more information, see NintendoSDK Documents > Features > Patches > FAQ.

If the patch has finished downloading, it will be installed when the application is started.

Note

Even when you have already distributed a patch, there are cases where users may start the application without applying the patch.
For example, even after a patch has been downloaded, if the user removes the microSD card before starting the application, the application would be started without the patch applied.

For that reason, Nintendo provides a feature for requiring the patch for applications that use an independent server or NEX/NPLN game server. For more information, see 2.3.1 Making Patches Mandatory for Applications That Use Network Services.

Updating With Incremental Data

When there is already a patch on the Switch, the data downloaded to update to the latest patch will not be the entirety of the new patch, but rather the content incremented from the patch that was already obtained. However, incremental data may not be used to update in the following kinds of cases.

  • The Disable Download flag was set in NCMS for the immediately preceding patch.
    For more information, see 3.3 Patch Distribution.
  • When updating the on-card patch.
    For more information, see 2.5 On-Card Patch.

For more information about incremental data, see NintendoSDK Documents > Features > Patches > FAQ > How Do I Find the Size of a Data Download When Getting a Patch? > When Getting the Latest Patch of a Patch That Has Already Been Received.

Patches Distributed Through Local Communication

Patches can be distributed using local communication between Switch consoles running system version 4.0.0 and later. For an overview of this feature, see the Nintendo Switch Overview > Communication Features > Local Patch Distribution.

Minor Fixes for Which the System Does Not Get a Patch

For minor fixes that do not require notifying the user, you can configure settings to not have the Switch system obtain the patch when it receives a notification. For more information about this setting, see 3.3 Patch Distribution > Settings > Update Notification Flag.
If the Switch system does not get the patch automatically, the user can use one of the following methods to obtain the patch.

  • Re-download the application
  • Run Software Update from the HOME Menu
