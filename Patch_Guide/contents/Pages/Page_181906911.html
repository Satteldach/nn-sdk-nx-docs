1 Introduction

Objectives and Content

This document describes the patch features provided in Nintendo Switch™ (henceforth Switch), in greater detail than in the Nintendo Switch Overview.

Intended Audience

This document is intended for planners and developers of Switch applications.

When to Read This Document

Read this documentation when you are planning and developing Switch applications. Before reading this documentation, see the Nintendo Switch Overview.

Related Documents

Also see the following documentation.

Documents Overview
Nintendo Switch Overview Provides an overview of patching features in Features > Application Features. Read this overview before reading this document.

Terminology

This document uses the following terminology. For a list of other terms, see Nintendo Switch Terminology.

Term Description
Initial application The version of the application that is initially released, with release version 0, and its master ROM (NSP file).
Revised application An application created with revisions to the initial application, and the master ROM (NSP file) for that application.
On-card patch

A feature that writes patch data along with the initial application in the Switch game card, and the patch used for this process.
