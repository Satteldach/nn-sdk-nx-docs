2.1 Capabilities of Patches

A patch is data for adding functionality or fixing discovered bugs after an application's release.

For each title, only the latest patch can be distributed. A shared patch is required if there will be distribution of both a card-based application and a downloadable application.

In addition, there is a feature for writing the patch to the Switch game card so that game cards that contain the application with the bugs fixed can be manufactured. For more information, see 2.5 On-Card Patch.

There is no way to charge for patches. For more information about adding paid features, see 2.1.1 Adding Paid Features.

Scope of Patching

You can update almost all of the data by applying a patch. However, the size of the following data cannot be reduced.

  • Data save memory of the user's save data (user account save data)
  • Journaling region for the user save data
  • Data delivery cache storage

If the NX Add-On version of the SDK used to create the patch is 3.1.0 or later, you can use the patch to expand the size of the save data save area, journaling area, and data delivery cache storage. The NX Add-On version that was used to create the initial application is not relevant.

For more information about expanding the size of each area, see NintendoSDK Documents > Features > Basic Features > fs Library.

Info

There is no feature for applying patches to DLC. For more information about updating downloadable content, see the Nintendo Switch E-Commerce Guide.

Note

Downgrading the NintendoSDK version via a patch is prohibited.
