2.5 On-Card Patch

A feature for including patches on a game card is provided as a method to produce game cards that contain the revised version of the application. This feature, and the patch itself, is an on-card patch. For more information about using on-card patches, see NintendoSDK Documents > Features > Patches > Building and Running a Patch.

When using on-card patches, you need a game card that has an application storage area sufficient to store the application and the patch. For more information about the size of the application storage area, see NintendoSDK Documents > Features > NX Development Card.

Info

You can use application compaction to reduce the amount of space required by the application.
For more information, see 2.7 Application Compaction.

Note
  • When an on-card patch is first updated to a newer release version, the entire patch is downloaded and applied. Subsequent updates are performed using incremental data.
  • The downloaded patch is saved to system memory or a microSD card.
  • When using an on-card patch and the operating frequency set for the initial application differs from the operating frequency set for the on-card patch as described below, the timing when data is loaded might change greatly. If the data load timing changes, the behavior might change even if there are no changes to the source code. For more information about the operating frequencies of Switch game cards, see NintendoSDK Documents > Features > NX Development Card.
    • If the initial application requires an 8 GB card, you may only set 25 MHz as the operating frequency.
    • If the card size exceeds 8 GB due to the on-patch card, you may set 25 MHz or 50 MHz as the operating frequency.
