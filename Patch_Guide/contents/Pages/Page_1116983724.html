3.3 Patch Distribution

Configure the distribution settings on NCMS after the patch has passed Lotcheck.

Info

Nintendo Content Management System (NCMS) is a web tool for registering products to sell on Nintendo eShop. You can access it from the link in the Nintendo Developer Portal.

For more information about using NCMS, see the manual in NCMS.

Distribution Settings

In NCMS, on the Distribution Data Settings page, set the distribution time and click Distribute to Users to distribute the patch at the specified time.
However, if any of the following conditions apply, the settings must also be verified and approved by Nintendo. In NCMS, on the Distribution Data Settings page, set the distribution time and click Submit.

  • Downloadable content or service items will be distributed at the same time as the patch.
  • A patch corresponding to a compacted application will be distributed.
  • The patch has a Disable Download flag.

Settings

This section describes the items that must be configured when setting the distribution of a patch on NCMS.

Block Earlier Releases From Connecting to NEX/NPLN Server

Selecting this option blocks earlier releases, when the patch is released, from connecting to the NEX/NPLN server. For more information, see the following documentation.

  • NEX
    Nintendo Switch NEX Guide > Tips and Tricks > Patches and Compatibility
  • NPLN
    In the NPLN Documentation included in the NPLN package, NPLN Guide > Patch Distribution and Compatibility

This item is automatically selected based on the content of the OMAS application.

If this item is selected, click Distribute to Users in NCMS at least 2 hours before the scheduled patch distribution time.

If you need to reconfigure the distribution settings again after selecting Distribute to Users, such as due to needing to change the distribution time, contact Nintendo via the NCMS forum.
Even if you change the distribution time, the initial distribution time would still be the time when the game servers switch compatibilities, and this setting needs to be manually changed by Nintendo.

Update Notification Flag

If you clear the check box for this item, the system does not get the patch automatically and the patch update notification does not appear when the application starts.
Clear this check box if you do not want to notify users of updates, such as when implementing trivial fixes. For more information, see 2.3 Update Processing via Patches.

Force Update Flag (Block Earlier Releases From Connecting to the Authentication Server)

Select this flag to force a patch update when network services are used in an application that uses network services provided by NEX/NPLN or an independent server. This feature is enabled at the time the patch is distributed.
However, users may continue to use network services without patching for up to 24 hours after patch distribution. For more information, see Nintendo Switch Online Play Guide > Compatibility With Earlier Versions of an Application.

Disable Download Flag

Set this flag to stop distribution of the patch. Use this feature in situations like when a serious bug is discovered in the application after the patch has been applied. Contact Nintendo via the NCMS forum if you set this flag.

Note

When you set the Disable Download flag, incremental patch updates between release versions are no longer possible. For example, if you set the Disable Download flag for the patch for release version 4, you cannot incrementally update from release version 3 to release version 5. The user must download the entirety of the release version 5 patch. They can update with incremental data from release version 5 to release version 6.

Distribution Targets and Timing

You cannot specify certain users or certain Switch consoles as the distribution targets for the patch. In addition, you cannot distribute patches at different times in different countries or regions.

Info

Patches can be distributed even in countries where there is no established Nintendo eShop.

Important Information for Distributing Patches for Applications That Support Pre-Orders

When selling an application that supports pre-orders, the user can download the patch prior to the distribution date (play start date). However, the following problems might occur if you distribute the patch. For more information about pre-orders, see Nintendo Switch E-Commerce Guide > Sales Using Nintendo eShop > Nintendo eShop Sales Options (Discounts, Buyer Benefits, Download Codes, Pre-Orders, Season Passes).

  • A malicious user can dig into the patch and leak information.
  • Players can apply the patch to a game card obtained prior to the release date, and play the game.

To prevent these issues, we provide features to distribute the patch securely and disable playing applications that have been patched until the release date. To use these features, contact Nintendo.

Handling Gameplay With Patched Applications Even Before the Release Date

Even if you use the feature that prevents patched applications from being played until the release date, it is possible for users to play patched application early if they start a version of the application obtained through a dedicated download code. For example, you can use this feature when requesting game previews from media.
However, applications downloaded through dedicated download codes are subject to the following restrictions.

  • If you restart Switch and it is not connected to the internet when starting the application, you cannot play the application with the patch applied.
  • You cannot use local communication to distribute the patch to another Switch.
