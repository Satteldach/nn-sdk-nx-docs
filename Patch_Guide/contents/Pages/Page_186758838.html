2.2 How Patches Work

You can create patches by extracting only the difference in data before and after the application is revised.

If only a part of a file is different before and after the revision, you can also include only a part of that file, rather than the whole file, as the revision content in the patch. However, there are several restrictions when creating a patch that only contains the appropriate revised parts. In addition, some of the restrictions must be supported when the initial version of the application is created.
For more information about the restrictions, see NintendoSDK Documents > Features > Patches. In particular, see Features > Patches > Optimization Information for methods to reduce patch size.

Info

When creating a patch, the more the initial application and revised application match on a binary level, the smaller the size of the patch.

Note

Large patches place more load on Nintendo's servers and take longer for the application to download.
For more information about checking the required patch size, see NintendoSDK Documents > Features > Patches > analyze-patch Command.
