3.2 Patch Submission

To submit a patch, you must first create a patch release in Nintendo Developer Portal. For more information, see the Nintendo Switch Master ROM Submission Procedures.

When you register a patch release in Nintendo Developer Portal, a release information page is created in OMAS.
If online features are included, enter the required information in the OMAS Release Information page and submit a request for those features. If online features are not included, this request is not required.
The request must be submitted even if there are no changes to the use of the online features in that patch.

Info

Online Title Management System (OMAS) is a web tool for requesting network features when developing products that support network services. You can access it from the link in the Nintendo Developer Portal.

For more information about using OMAS, see the manual that you can access from the OMAS menu.

Note

To add online features with a patch, request the applicable features on OMAS. A development environment for the network features will be provided after this request is approved.
Development environments that are already in use may continue to be used. If there are changes to the use of the online features, describe the changes when submitting your request.

After the request is approved on OMAS, you can submit the patch in the Nintendo Developer Portal.
