3.1 Creating and Debugging Patches

The following flow is used to create and debug patches.

  1. Create and debug the revised application.
  2. Create the patch in AuthoringTool.
  3. Debug after applying the patch.

For more information, see NintendoSDK Documents > Features > Patches. The following table shows the specific content to check for and their corresponding pages.

Description Page
Creating the revised application and patch Features > Patches > Building and Running a Patch
Reasons for needing to debug with the patch applied Features > Patches > Procedures for Creating Patches
Performance of the application with the patch applied Features > Patches > Performance When Applying Patches
Note

Retain the following files and data even after creating the patch. They are required for creating patches and revising in AuthoringEditor.

  • NSP file of the initial application
  • NSP file of the latest released patch
  • Program and source data for the revised application
