2.3.1 Making Patches Mandatory for Applications That Use Network Services

As described in 2.3 Update Processing via Patches, Switch patches are processed completely by the system. However, there are cases where the patch has not finished downloading, or when automatic updates are disabled due to the user turning off Auto-Update Software in the system settings. For this reason, the release version of the application is not ensured to be identical for all users.

When using an independent server or NEX/NPLN game server, there is a feature to prevent unpatched applications from connecting to the server by making patches mandatory. For more information, see Nintendo Switch Online Play Guide > Compatibility With Earlier Versions of an Application.

For more information about the settings required for enabling this feature, see 3.3 Patch Distribution > Force Update Flag (Block Earlier Releases From Connecting to the Authentication Server).
