2.4 Patch Management and Compatibility

When an application is run for the first time on Switch, its release version is recorded in system memory. This release version is called the required version.
When the application starts, the system compares it with the required version stored in memory. If the release version of the application being started is earlier, the system prompts the user to download and install a patch.

Although patches can be deleted, for example by removing the microSD card, the required version cannot be reset unless the console is initialized.
In addition, the release version that is saved is common to both the card version and the download version of the software, so forward compatibility (making it possible for earlier release versions to use data created in the new release version) does not need to be considered. However, you do need to consider backward compatibility, or the situation where data created in an earlier release version is used in a later version. For more information, see Nintendo Switch Guidelines > 0053: Prohibition of Applying Patches That Make Earlier Save Data Unusable.

Info

On development hardware, you can run a DevMenuCommand to rest the required version.
For more information, see NintendoSDK Documents > Features > Controlling the Development Hardware > DevMenu > Managing Applications.
