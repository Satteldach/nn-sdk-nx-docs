4 Important Information

This page describes important information for patches.

Changing the Rating

Note that if the rating is changed, the parental controls might prevent the application from running.
If you have a rating change request from the rating organization, or if you need to add a rating due to the addition of a country or region to which you want to distribute, contact Nintendo to change the rating.

Info

If the patch will change the rating for the application, you must use AuthoringEditor to edit the rating information for the revised application of the previously released patch (or the initial application in the case of the first patch) and create the new patch.
You cannot change the rating for a patch (NSP file) that has already been created.

Guidelines

In the Nintendo Switch Guidelines, there are guidelines, such as maximum patch size, for patches. Comply with each guideline.
