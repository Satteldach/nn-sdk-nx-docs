2.1.1 Adding Paid Features

As described in the 2.1 Capabilities of Patches section, you cannot distribute paid patches.
To add features at a cost, use DLC, consumable service items, or subscription service items. For more information about these items, see the Nintendo Switch E-Commerce Guide.

As a reference, this page describes the functionality for combining both a patch that supports multiplayer and DLC.

Adding Features Combining a Patch for Supporting Multiplayer and DLC

To ensure that users who purchase the DLC can play with those who have not played it in multiplayer mode, you can separate the data for the DLC and the patch. For example, in competitive fighting games, you can distribute a patch containing additional character data (such as 3D modeling data and texture data), and then add the data for selecting the additional characters (the program for adding character selection options, character thumbnail images, and so on) with the paid downloadable content. As a result, you can support cases like the following depending on how the application is controlled.

  • All users can join multiplayer games containing the additional characters, but only those users who have purchased the downloadable content can select those additional characters.
  • Only users who have purchased the downloadable content can use the additional characters in multiplayer games, but all users can reference the replay data.

Although any data may be included in either the patch or the downloadable content, the structure of having the downloadable content contain only flag data is weak in terms of security, so consider multi-layer data protection such as incorporating the additional character selection screen in the downloadable content side.
