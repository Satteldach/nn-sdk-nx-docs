4.3 Explanation of the Leg Strap Usage Screen

If your application uses the leg strap, instruct users how to put it on according to the following description.

Leg Strap Usage Screens Provided by Nintendo

Nintendo provides the following screens that show how to use the leg strap.
Worn on the right leg: Worn on the left leg:

Additional notes about the standardized text:

  • Step 2
    • If your application does not specify which leg to attach the leg strap to, change "right leg" or "left leg" to "dominant leg."
  • Step 3

    • If the design of your application involves pressing a button to progress to the next screen, change this to the following text.

      Position the leg strap at the center of your thigh.

Display Timing

Display at least once per application startup, showing it at an appropriate time before the user actually operates the leg strap in the application.

It is not enough to display this only the very first time the application is started and then never display it again when the application is run.

The user must see this information. It is not enough to display this only inside a settings dialog box or menu that the user must deliberately select in order to see.

Duration of Display

Continue displaying this until it can be confirmed with the Joy-Con (L) accelerometer or some such means that the leg strap is attached properly and the user is standing still.

It is all right for the user to proceed immediately to the next screen by pressing a button.

Supported Languages

Nintendo provides the Leg Strap Usage screen in the following languages. Use the languages that are needed to match your application's specifications.

  • Asian languages
    • Japanese, Traditional Chinese, Simplified Chinese, and Korean
  • Western languages
    • US English, UK English, German, French, Spanish, Italian, Dutch, European Portuguese, Brazilian Portuguese, and Russian

The cautionary text screen in each language is attached to this document. For more information, see 6 File List.

Creating Your Own Leg Strap Usage Screen

We recommend using the Leg Strap Usage screens provided by Nintendo, but you can also create your own customized screen as part of your application's explanation of the use of the leg strap.

If you create a customized screen, make sure that you include the information included in Nintendo's Leg Strap Usage screen.

Illustrations

We recommend using the illustrations provided by Nintendo, but you can also create and use your own illustrations as long as they include equivalent content.

It is also acceptable to explain usage with a screen that uses a product photo or with a video clip.

Text

We recommend including the following standardized text set by Nintendo. You can reword the text as long as the meaning is preserved.

  1. Insert the Joy-Con (L) into the pocket on the leg strap.
  2. Pass the strap through the hole, and wrap it around your right leg.
  3. Position the leg strap at the center of your thigh, then stand still for a moment.
