1 Introduction

Purpose and Content

This document describes the following concepts.

  • Image techniques that take photosensitivity into account
  • Measures to promote a fun and safe experience in applications played by moving the system or controllers, including the Joy-Con™ controllers. These measures can be implemented in various ways, including the application's controls and rules.
  • Measures to promote a fun and safe experience in applications that use vibration. These measures can be implemented in various ways, including the application's controls and rules.

Audience

This document is intended to be read by planners and developers of Nintendo Switch™ applications.

When to Read This Document

Read this document when planning an application.

Structure of This Document

2 Taking Photosensitivity Into Account covers visual techniques that take photosensitivity into account.

3 Motion Controls Using the Joy-Con and the Console covers the standards for using the Joy-Con strap and presents examples of application designs that take safety into account.

4 Motion Controls Using the Leg Strap presents examples of application designs that take safety into account.

5 Vibration Feature presents examples of application designs that take safety into account when using the vibration feature.

Note for Developers Planning Applications That Support the Leg Strap

If you plan to use the leg strap in your application, note that Nintendo must approve applications that support the leg strap to confirm that the accessory is being used appropriately.

Based on the results of that check, Nintendo may recommend or require you to implement handling that is not described in this guide.


Contact Nintendo if you want to support the leg strap accessory.

Because it takes time to perform these checks, contact Nintendo as early in development of your application as possible.
