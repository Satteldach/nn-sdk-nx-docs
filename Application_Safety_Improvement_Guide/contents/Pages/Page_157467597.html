3.4 Joy-Con Strap Usage Screen Explanation

If instructing the user to attach the Joy-Con strap is either required or recommended for your application, follow the requirements below when you prompt the user to use the strap.

Joy-Con Strap Usage Screen Provided by Nintendo

Nintendo provides the following Joy-Con Strap Usage screens.

  • App-embedded version


    • Display the following Joy-Con Strap Usage screen for applications that intentionally require players to take their hands off the Joy-Con controllers with the Joy-Con straps attached during play.

  • Controller support applet version (the applet provides a function that the application calls to display the screen)


  • For more information about implementing the Joy-Con Strap Usage screen (controller support applet version), see the following documentation.
    • NintendoSDK Documents
      • NintendoSDK API Reference
        • void nn::hid::ShowControllerStrapGuide ( )

Display Timing

Display every time the application runs, showing it at a time when it is appropriate to inform the user (for example, immediately after the application starts or immediately before the application enters a mode where motion controls are possible).

It is not enough to display this only the very first time the application is started and then never display it again when the application is run.

The user must be shown this explanation. It is not sufficient to display this screen only inside a settings dialog box or other menu that the user must deliberately select to see the screen.

Duration of Display

There is no specific requirement for how long to display this screen, provided it is shown long enough for the user to read and understand its content.

We recommend displaying the screen for five seconds, but it is acceptable to allow the user to proceed with a button press.

Supported Languages

The Joy-Con Strap Usage screen is provided in the following languages. Use the languages that are needed to match your application's specifications.

  • Asian languages
    • Japanese, Traditional Chinese, Simplified Chinese, and Korean
  • Western languages
    • English, German, French, Spanish, Italian, Dutch, European Portuguese, Brazilian Portuguese, and Russian

The cautionary text screen in each language is attached to this document. For more information, see 6 File List.

Creating Your Own Joy-Con Strap Usage Screen

We recommend using the Joy-Con Strap Usage screen provided by Nintendo, but you can also create your own customized strap usage screen as part of the operating instructions for your application.

If you create a customized screen, make sure that you include the information included in Nintendo's Joy-Con Strap Usage screen.

Illustrations

We recommend using the following illustrations, but you can also create and use your own illustrations as long as they include equivalent content.

It is also acceptable to use a product photo.

Note: This illustration depicts the right Joy-Con controller.


If your application's design makes it more appropriate to display an illustration depicting the use of both controllers, we recommend using the provided illustration that shows both the right Joy-Con and the left Joy-Con being held in the user's hands. However, you are free to create and use your own artwork as long as it includes equivalent content.

Text

You must include both of the following standardized texts set by Nintendo. However, you can reword the text as long as the meaning is preserved.

  • Standardized text about using the strap

    When you play with a Joy-Con controller,
    attach the strap as shown.

    Hold the Joy-Con controller securely and do not let go of it.

    • Include the text for applications that intentionally require players to take their hands off the Joy-Con controllers with the Joy-Con straps attached during play.

      When you play with a Joy-Con controller,
      attach the strap as shown.

      Hold the Joy-Con controller securely and
      do not let go of it unless otherwise instructed.

  • Standardized text for cautioning users about their surroundings

    Be aware of your surroundings.
    Allow adequate room around you during game play.

The standardized text in each language is attached to this document. For more information, see 6 File List.
