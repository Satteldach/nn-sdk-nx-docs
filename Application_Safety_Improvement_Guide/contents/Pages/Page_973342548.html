3.2 Caution About Surroundings

Applications That Are Played by Moving the Joy-Con Controllers

Applications that require use of the Joy-Con Strap must include a caution to users about avoiding bumping into people or objects during play. When cautioning users, use text similar to the following example.

Note: For more about applications for which Joy-Con Strap usage is required, see 3.1 Joy-Con Strap Usage Standards.

Applications Played by Moving the System and Controllers

The decision about whether you need to caution users about their surroundings depends on the specifications of each application. The person in charge of development is responsible for determining whether cautions on surroundings are necessary.

Text

We recommend including the following standardized text set by Nintendo. You can reword the text as long as the meaning is preserved.

Be aware of your surroundings.
Allow adequate room around you during game play.

Cautionary text in each language is attached to this document. For more information, see 6 File List.

Display Timing

Display every time the application runs, showing it at a time when it is appropriate to inform the user (for example, immediately after the application starts or immediately before the application enters a mode where motion controls are possible).

It is not enough to display this only the very first time the application is started and then never display it again when the application is run.

The user must be shown this explanation. It is not enough to display this only inside a settings dialog box or menu that the user must deliberately select in order to see.

Duration of Display

There is no specific requirement for how long to display this screen, provided it is shown long enough for the user to read and understand its content.

We recommend displaying the screen for 5 seconds, but it is acceptable to allow the user to proceed with a button press.
