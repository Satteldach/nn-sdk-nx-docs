4.1 Caution About Surroundings

Applications that use the leg strap must caution users about being careful not to bump into people and objects during play. Caution users based on the following descriptions.

Screens Provided by Nintendo Cautioning Users About Their Surroundings

Nintendo provides the following attention screens that caution users about their surroundings.

  • For applications that use the leg strap in combination with the Joy-Con (R):
    Screen cautioning users about their surroundings Screen cautioning users about their surroundings and prompting users to be considerate of their neighbors
    Note: Only in Asian languages.

  • For applications that use only the leg strap:
    Screen cautioning users about their surroundings Screen cautioning users about their surroundings and prompting users to be considerate of their neighbors
    Note: Only in Asian languages.

Display Timing

Display at least once per application startup, showing it at an appropriate time before the user actually operates the leg strap in the application.

It is not enough to display this only the very first time the application is started and then never display it again when the application is run.

The user must see this information. It is not enough to display this only inside a settings dialog box or menu that the user must deliberately select in order to see.

Duration of Display

There is no specific requirement for how long to display this screen, provided it is shown long enough for the user to read and understand its content.

We recommend displaying the screen for 5 seconds, but it is acceptable to allow the user to proceed with a button press.

Supported Languages

Nintendo provides screens in the following languages to caution users about their surroundings. Use the languages that are needed to match your application's specifications.

  • Asian languages
    • Japanese, Traditional Chinese, Simplified Chinese, and Korean
  • Western languages
    • English, German, French, Spanish, Italian, Dutch, Portuguese, Brazilian Portuguese, and Russian

The cautionary text screen in each language is attached to this document. For more information, see 6 File List.

Creating Your Own Cautionary Text Screen

We recommend using the cautionary screen provided by Nintendo, but you can also create your own screen that cautions users about their surroundings as part of the operating instructions for your application.

If you create a customized screen, make sure that you include the information included in Nintendo's cautionary text screen.

Text (Caution About Surroundings)

Include the following boilerplate text set by Nintendo. You can reword the text as long as the meaning is preserved.

Make sure you have enough space around you.

The cautionary text screen in each language is attached to this document. For more information, see 6 File List.

Text (Message Encouraging Users to be Considerate of Their Neighbors)

For the Asia region only, we recommend taking the country or region's housing situation into consideration and including the following standardized text set by Nintendo. You can reword the text as long as the meaning is preserved.

近隣の迷惑にならないよう 時間帯や振動・音などに注意してください
