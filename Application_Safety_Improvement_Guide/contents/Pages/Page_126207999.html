Every application falls under one of the following three categories. The table presents the different usage standards that can apply to applications, and shows whether users need to use a Joy-Con strap when playing your application, based on the application category.
I. Applications that could lead users to move Joy-Con controllers in rapid, wide, or forceful motions
II. Applications that do not fall under either I or III
III. Applications where the user holds a Joy-Con horizontally in both hands (solo horizontal grip)

Backgrounder

Applications That Require the Joy-Con Strap

The following examples describe applications that require using the Joy-Con wrist strap.

  • Sports games that involve motions of the Joy-Con controller that replicate actions like throwing a ball
  • Sports games and action games that involve rapid or large swinging motions of the Joy-Con controller to replicate actions like swinging a bat or a sword
  • Sports games and action games that involve swinging or throwing motions of the Joy-Con controller to replicate actions like cracking a whip or throwing a Frisbee or boomerang
  • Games that require players compete to win or score points where users are likely to swing the controllers with large or vigorous motions in the heat of the moment

Applications That Do Not Require the Joy-Con Strap

The following examples describe applications that do not require using the Joy-Con wrist attachment.

  • Traditional RPG-type games, simulation-type games, and action games where a Joy-Con controller is held horizontally in both hands

Use of the Joy-Con Strap Usage Screen

We recommend using the Joy-Con Strap Usage screen provided by Nintendo (app-embedded version or controller support applet version), but you are also allowed to create your own Joy-Con strap usage explanation screen and incorporate it somewhere in your application's overall explanation of how to play.

If you create your own explanation screen, include both text-based instructions for using the Joy-Con strap and illustrations of using the strap. Your explanation screen must cover all the information provided on Nintendo's Joy-Con Strap Usage screen.

For more information about creating your own screen, and about using the Joy-Con Strap Usage screen, see 3.4 Joy-Con Strap Usage Screen Explanation.

When to Present Instructions for Using the Joy-Con Strap

Your application must display the Joy-Con Strap Usage screen at a time when it is appropriate to caution the user to use the strap (for example, immediately after application startup or immediately before your application enters a mode where motion controls are enabled).

You must display the Joy-Con Strap Usage screen at least once each time the application starts. It is not sufficient to present this explanation just once the very first time the application starts, and to not present it every other time the application starts.

The user must be shown this explanation. It is not sufficient to display this screen only inside a settings dialog box or other menu that the user must deliberately select to see the screen.
