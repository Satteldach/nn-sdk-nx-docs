4 Internal Processing

This section describes the internal processing of features provided by the IR Motion Camera library.

Image Processing Overview

Because the background tends not to be visible in the IR image captured by the IR Motion Camera, the image processing performed is simpler and of higher accuracy than on a normal camera.
The following figure presents an example of image processing. It depicts the calculation of the center of luminosity for the image.

Some image processing, as shown in the figure, is performed either by the hardware engine inside the IR Motion Camera or by the MCU in the Joy-Con (R).
It is also technically possible to send the IR images to the console for processing.
However, because Bluetooth is used for communication between the console and the Joy-Con, this transfer of raw IR images results in a very slow frame rate.
Consequently, raw IR image processing on the console is only planned for some applications.
It is possible to capture compressed 40 x 30 images in real time by using hand analysis mode.
However, these compressed images contain a lot of noise and are not suitable for image processing on the console.


The following section describes the internal processing of features provided by the IR Motion Camera library.
Contact Nintendo support when planning games where your image processing will not work even when using the following options, because it is possible that it will work as soon as Joy-Con MCU is supported.

Moment Mode (Image Processing With the Hardware Engine)

As shown in the following figure, an image with a resolution of 320 × 240 is divided into 48 40-by-40 blocks in an 8-by-6 grid.

The following values are calculated for each block in the grid.

  • Average luminosity value
  • Luminosity center coordinates

In other words, 48 sets of data that include the average luminosity value and the luminosity center coordinates are exported.
Combine the data from each of the 48 grid blocks to find the whole image's luminosity center coordinates.

Hand Analysis Mode (Image Processing With the MCU)

IR images are sent to the MCU in the Joy-Con (R).
The MCU performs image processing to recognize hand-related information.
Information such as the number of fingers, the center position of the palm, and an outline of the hand is exported as data.

Because this mode requires the hand to fall accurately within the IR Motion Camera's angle of view, you must adjust the hand's position.
For example, having a guide that shows the hand outline (as in the following image) makes hand positioning easier.

You can capture compressed 40 × 30 images similar to the following in real time, at the same time as hand data. These images can be used in the guide and for positioning.

Clustering Mode (Image Processing With the Hardware Engine)

As shown in the following figure, objects greater than a specific brightness (luminosity) value and size are detected and clustered.

Data is exported that includes the average brightness value and the brightness focus coordinates for those clusters. (Some forms are not recognizable as clusters.)
Up to sixteen clusters can be detected.
You are free to set your desired parameters for the brightness value and size for detecting clusters.

Adaptive Clustering Mode (Image Processing With the Microcontroller)

Adaptive clustering mode detects clusters while changing the camera settings, such as exposure time and LED intensity, for each frame so that the markers pictured by the IR Motion Camera can be easily detected.
Think of it as a clustering mode with an auto-exposure compensation feature, specialized for detecting markers.
Also, even though there is less information for detectable objects compared to clustering mode, the number of clusters that can be detected is increased to 32.
We recommend selecting the mode that is more suitable for your use case.

Pointing Mode (Image Processing With the Hardware Engine)

Pointing mode is a mode for pointing using the IR Motion Camera. It works by detecting a dedicated retroreflector bar placed near the screen.

Determine the size of the retroreflectors in this figure, the distances between them, and recognize the retroreflector bar.
Later, the central point between the three points of the retroreflectors is set as the pointing coordinates.

IR LED Mode

IR LED mode is for using the IR Motion Camera not as a sensor (camera), but as an LED that can control IR illumination.

It is primarily intended to be used for playing with multiple Joy-Con controllers, one of which emits light in this mode, and the other of which is used for taking photos with the IR Motion Camera.
However, because it takes time to switch the LED on or off, it is not suitable for data communication via high-speed signal switching.

Pulse Rate Measurement Mode

The pulse rate measurement mode is a mode where the IR Motion Camera emits an infrared signal to the tip of the user's finger, and the changes in the light reflected by the hemoglobin in the blood are measured to measure the user's approximate pulse rate.
As pictured in the following figures, if you press the ball of your thumb lightly against the IR Motion Camera and hold still for a while, there will be slight changes in brightness between the images depending on the amount of light that is reflected.
You can use this information to get an approximate pulse rate.

Also note that this feature is for obtaining the user's approximate pulse rate during a certain period of time, not for obtaining real-time changes in the pulse rate.
In addition to the approximate pulse rate, information such as measurement progress, reliability, and the cause of errors can be obtained from the library. We recommend using this information in the UI or elsewhere to guide the user so that they can perform measurements appropriately.

Note

Nintendo Switch is not a medical device.
The pulse rate obtained in pulse rate measurement mode is only an estimate. Do not use it for medical diagnosis, treatment, or prevention.
Consider these limitations when using this feature.

Note

We have not tested pulse rate measurement using any part of the body other than the surface of the thumb, and pulse rate measurement with other body parts is not supported.

Depending on how this feature is used, you might need to display cautionary text to users in order to draw their attention to this important information.
For more information, see 3 What the IR Motion Camera Can Do and the SDK documentation.

Image Transfer Mode

Primarily for debugging purposes, a mode is being prepared that can send 8-bit grayscale IR image data to the console in the following sizes: 320 × 240, 160 × 120, or 80 × 60.
Transferring a 320 × 240 raw image to the system can take under four seconds in ideal conditions where things like Bluetooth packet drops are not occurring.
Transferring an 80 × 60 raw image to the system can take under 0.25 seconds under ideal conditions where things like Bluetooth packet drops are not occurring.
There is a trade-off in data volume for transfer time.
