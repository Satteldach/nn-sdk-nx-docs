3 What the IR Motion Camera Can Do

Features Provided by the Library

The following features are provided by the IR Motion Camera library.
Details of each feature will be documented later.

Feature Overview
Moment Mode Performs a moment calculation on the image captured by the IR Camera as part of the image processing, and displays the result.
Hand Analysis Mode

Outputs information about the image of a hand captured by the IR Camera, including information about the external shape, outline, and surface area.
A compressed 40 × 30 image is displayed at the same time as the hand data.
Clustering Mode Detects clusters of objects captured by the IR Camera.
Adaptive Clustering Mode Detects clusters while changing the camera settings such as exposure time and LED intensity for each frame according to the capture target.
Compared with clustering mode, detailed settings cannot be configured, but precise data can be obtained.
Pointing Mode Detects the reflective bar, with the three retroreflector points aligned, and displays the center of those points as the pointing coordinates.
Image Transfer Mode Transfers images captured by the IR Camera at a low frame rate.
IR LED Mode Handles the IR Motion Camera not as an IR camera, but as an LED that can control IR illumination, and controls the camera.
Pulse Rate Measurement Mode Measures the player's approximate pulse rate when they cover the IR Motion Camera with their thumb.

Sample Uses

The features provided by the IR Motion Camera library have many supported use cases.
This section reviews some practical examples.

Using Fast Hand Movement as Input

With moment mode, you can find the coordinates for the center of luminosity for an entire image.

Although the image processing is simple, changes to luminosity coordinates can be used for various purposes.

Using Hand Shape as Input

In hand analysis mode, you can recognize information about the shape of the hand and use it as input. For example, you can count the number of fingers to play rock-paper-scissors.

Using With Attachments

By using the clustering mode that can recognize objects of specified brightness and size, you can detect movements of specific objects that reflect IR light and use them in game software.
For example, with Nintendo Labo you can use the Toy-Con attachments to watch the movement of retroreflectors within the Toy-Con and apply them in the game.
The following example demonstrates the punch mechanism of the Toy-Con Robot.

The retroreflector, circled in red, is recognized as an object marker.

Viewing the object move up and down in the game enables actions such as punching and walking.

Recognizing External IR Light

In principle, the IR Motion Camera emits IR light and captures that light when it is reflected. However, you can also detect external IR light with a wavelength of 850 nm.
For example, by enabling or disabling external IR light that the IR Motion Camera recognizes, you can send information from the device that emits the IR light to the Joy-Con.
In addition, the Joy-Con (R) itself can emit IR light when using the IR LED mode, which can be detected by the IR Motion Camera on another Joy-Con (R).

Properties such as the recommended brightness of the external IR light depend on the plans for the game such as the assumed play environment, the distance between the IR light and IR Motion Camera, and the degree of surrounding noise. Adjust these properties based on your needs.

Note: Depending on the wavelength band and IR Motion Camera hardware specifications in use, it may not be possible to support IrDA.

Measuring Pulse Rate

As pictured in the following figures, if you press the ball of your thumb lightly against the IR Motion Camera and hold still for a while, the IR Motion Camera emits an infrared signal toward the tip of your thumb, and this signal reflects off of the hemoglobin in the blood and returns this information to the camera.

Depending on the changes in the amount of light that is returned, the images obtained by the IR Motion Camera also change slightly in brightness, and this information can be used to obtain an approximate pulse rate.

To obtain an approximate pulse rate, you must measure the pulse while the user is being still for anywhere from several seconds to around 10 seconds.
We do not recommend measuring the pulse rate while making the user perform some other action.
We recommend giving the user thorough guidance about the appropriate measurement method, such as by using the pulse rate measurement information obtained from the library.

Also note that this feature is only for obtaining the user's approximate pulse rate during a certain period of time, and is not suitable for uses such as detecting real-time changes in pulse rate.

Note

Nintendo Switch is not a medical device.
The pulse rate obtained in pulse rate measurement mode is only an estimate. Do not use it for medical diagnosis, treatment, or prevention.
Consider these limitations when using this feature.

Note

We have not tested pulse rate measurement using any part of the body other than the surface of the thumb, and pulse rate measurement with other body parts is not supported.

Displaying Cautionary Text

If you are using this feature and showing users the progress or results of pulse rate measurement or an evaluation of the measurement results, you must convey the important information described in the preceding Note blocks to users.
When you do this, display cautionary text in the application that clearly conveys to users the fact that measurements obtained using this feature are only estimates and are not for medical diagnosis, treatment, or prevention.
The following is an example. You can reword the text as long as the meaning is preserved.

The pulse rate measurements and functions are estimates only. They are not to be used for medical diagnoses, treatment, or prevention.

To ensure that users read the cautionary text, display it in a scene that users are certain to view when performing measurements, rather than within a settings dialog box or a menu.

In addition, although there is no specific requirement for how long to display the cautionary text, it must be displayed long enough for users to read and comprehend it.
We recommend displaying the text for about five seconds, but a specification where the user does something like press a confirmation button to move forward is acceptable.

Displaying Guidance About How to Use the Feature

In order to use the pulse rate measurement feature, the user must hold the controller in a particular way.
If they do not hold the controller correctly, it can result in the measurement failing, requiring another attempt, or in the measurement taking a long time. This can degrade the user experience.

In order to encourage correct use of the pulse rate measurement feature, we recommend displaying guidance about how to use it within the application.
When displaying guidance about how to use the feature, display it after the cautionary text described earlier.

Displaying IR Images

You can check IR images by using image transfer mode, although this check does not occur in real time.
It is possible to check the compressed 40 × 30 images in real time by using hand analysis mode.
