Nintendo Switch Online

This chapter covers requirements related to Nintendo Switch Online.

Info:
  • You must set the country setting of Nintendo Accounts that you use to test the guidelines in this chapter to a country that provides the Nintendo Switch Online service. For a list of countries that provide the service, see the following.
    • Nintendo Switch Independent Server Setup Manual
      • Appendix > Countries of Residence Allowed for Nintendo Accounts
  • Nintendo does not provide the Nintendo Switch Online service in China. However, you must still select No features require membership as the Nintendo Switch Online policy for applications for China. For details, see the Nintendo Switch Online Play Guide.


Nintendo Switch Online: General

This subchapter covers general requirements for Nintendo Switch Online.

0163: Implementing handling for features that require a Nintendo Switch Online membership (When some features require membership)
If an error occurs because the user is not a member of Nintendo Switch Online, you must call the specified function to display the sign-up sequence.
Software to Be Tested

Applications whose Nintendo Switch Online Policy in OMAS is "Some features require membership"

Info:
  • For more information about the application policy categories, see the Nintendo Switch Online Play Guide.
  • For applications whose policy is "All features require membership," see 0170: Implementing handling for features that require a Nintendo Switch Online membership (When all features require membership).
Backgrounder

If your application offers features that require the user to join Nintendo Switch Online, then you must display the system feature UI for the membership sign-up sequence when a user who is not a member tries to access those features. Your application must handle this differently depending on whether you use independent servers or middleware to implement the features, as shown below.

  • When using independent servers:
    Your application must handle the situation as described in "Nintendo Switch Online > Application-Level Support > Using Independent Servers" in the Nintendo Switch Online Play Guide.
  • When using middleware:
    If your application uses middleware such as NEX or Pia to provide network services, you must implement whatever error handling is required by each middleware.
    For details, see "Nintendo Switch Online Support > Application-Level Support > NEX Error Handling When the Application Policy Is Some Features Require Membership" in the Nintendo Switch Online Play Guide.

If your application uses both independent servers and middleware, you must implement both kinds of handling.

Info:

If DevMenu > Accounts > Firmware settings > Enable Nintendo Account license verification is not selected, the NSA ID token contains no Nintendo Switch Online membership information. To test this guideline, you must select to Enable Nintendo Account license verification.
References

For details on how to implement this handling in applications whose Nintendo Switch Online policy is "Some features require membership," see the following documents.


  • Nintendo Switch Online Play Guide
    • Nintendo Switch Online Support > Application-Level Support
    • Nintendo Switch Online Support > Use in a Development Environment > Nintendo Switch Online Membership Manager
  • Nintendo Switch Independent Server Setup Manual
    • Connecting to an Independent Server > Nintendo Switch Online Support
Test Method
  1. In DevMenu, go to Shop > Valid Shop and change this setting to Test Shop.
  2. On Nintendo Switch Online Membership Manager, identify the Nintendo Accounts that are linked to user accounts on the Switch devkit, and for each one select Expire to set its Service availability to Unavailable. (Do this for as many Nintendo Accounts as necessary for the test.)
  3. Hold down the POWER Button on the Switch devkit, then on the Power Menu select to restart the devkit.
  4. Start the application and proceed to a scene where you can use a feature that requires a Nintendo Switch Online membership.
  5. Attempt to use that feature.
  6. Cancel out of the system-side UI.
  7. Proceed to a scene where you can use a feature that requires a Nintendo Switch Online membership, and once more attempt to use that feature.
  8. In the system-side UI, jump to Nintendo eShop (ec test applet).
  9. On Nintendo Switch Online Membership Manager, identify the Nintendo Accounts that are linked to user accounts currently being used by the application, and for each one select Grant to set its Service availability to Available.
  10. In the ec test applet, press the A Button and close the ec test applet.
  11. If the application continues with the scene from step 7, then proceed with that scene and attempt to use the feature you are testing. If the application returned you to a scene earlier than the scene from step 7, proceed once again to the scene from step 7, then attempt to use the feature you are testing.
  12. If the application has multiple features that require a Nintendo Switch Online membership, repeat steps 2 through 11 for every such feature.
Pass/Fail Determination
Passes if all of the following conditions are met.
  • In steps 5 and 7, the system-side UI is displayed to explain that a Nintendo Switch Online membership is required.
  • In step 6, the feature being tested cannot be used.
  • In step 11, the feature being tested can be used.

0170: Implementing handling for features that require a Nintendo Switch Online membership (When all features require membership)

If errors occur in your application when the user is not a member of Nintendo Switch Online, your application must handle the error by complying with "Implementing handling when your application is unable to use a network service account."
Software to Be Tested

Applications whose Nintendo Switch Online Policy in OMAS is "All features require membership"

Info:
  • For more information about the application policy categories, see the Nintendo Switch Online Play Guide.
  • For applications whose policy is "Some features require membership," see 0163: Implementing handling for features that require a Nintendo Switch Online membership (When some features require membership).
Exceptions
  • When there is no disadvantage to the user even if the error is not displayed, such as in the following examples:
    • During (background) processes that do not involve active user interaction, where the error causes no problems that affect the user's ability to progress further in your application
Backgrounder

When a user who is not a member of Nintendo Switch Online plays an application whose policy is "All features require membership," calling functions that allocate a cache for the NSA ID token returns the error nn::account::ResultNetworkServiceAccountUnavailable.

This applies to the following functions.

  • nn::account::EnsureNetworkServiceAccountIdTokenCacheAsync()
  • nn::nex::NgsFacade::Login()
  • Any of the following nn::nex::SmartDeviceVoiceChatClient functions:
    • GetAvailability()
    • JoinRoom()
    • ChangeVoiceChatChannel()
  • Any of the following nn::ens::SmartDeviceVoiceChatClient functions:
    • TestAvailability()
    • JoinRoom()
    • ChangeVoiceChatChannel()
  • NPLN functions that trigger communication processing

If this error is returned, you must handle it as described in 0121: Implementing handling when your application is unable to use a network service account.

Info:
  • For more information on how to change the Nintendo Switch Online membership status in your development environment, see the Nintendo Switch Online Play Guide.
  • Even if the user is not subscribed to Nintendo Switch Online, the nn::account::ResultNetworkServiceAccountUnavailable error does not occur unless DevMenu > Accounts > Firmware settings > Enable Nintendo Account license verification is selected. To test this guideline, you must select to Enable Nintendo Account license verification.
  • The nn::nex::NgsFacade::Login() function is an overloaded function, meaning that it has multiple variations. The only variation that is subject to this guideline is the variation (provided up until NEX library version 4.4.0) that takes nn::account::UserHandle as an argument.

Test Method
  1. In DevMenu, go to Shop > Valid Shop and change this setting to Test Shop.
  2. On Nintendo Switch Online Membership Manager, identify the Nintendo Accounts that are linked to user accounts on the Switch devkit, and for each one select Expire to set its Service availability to Unavailable. (Do this for as many Nintendo Accounts as necessary for the test.)
  3. Hold down the POWER Button on the Switch devkit, then on the Power Menu select to restart the devkit.
  4. Start the application and proceed to a scene where you can use a feature that requires a Nintendo Switch Online membership.
  5. Attempt to use that feature.
  6. Cancel out of the system-side UI.
  7. Proceed to a scene where you can use a feature that requires a Nintendo Switch Online membership, and once more attempt to use that feature.
  8. In the system-side UI, jump to Nintendo eShop (ec test applet).
  9. On Nintendo Switch Online Membership Manager, identify the Nintendo Accounts that are linked to user accounts currently being used by the application, and for each one select Grant to set its Service availability to Available.
  10. In the ec test applet, press the A Button and close the ec test applet.
  11. If the application has multiple features that require a Nintendo Switch Online membership, repeat steps 2 through 10 for every such feature.
Pass/Fail Determination
Passes if all of the following conditions are met.
  • In steps 5 and 7, the system-side UI is displayed to explain that a Nintendo Switch Online membership is required.
  • In step 6, the feature being tested cannot be used.
  • In step 10, the application calls the function that previously returned the nn::account::ResultNetworkServiceAccountUnavailable error, and continues the scene while allowing the player to use the feature being tested.
  • In steps 5 through 10, no features of the application use the error viewer applet or other methods to display errors in the 2124-0200 to 2124-0269 range.

0210: Free-to-play applications that use NPLN must require a Nintendo Switch Online membership
Free-to-play applications that use NPLN must require a Nintendo Switch Online membership for all NPLN features.
Software to Be Tested
Free-to-play applications that use NPLN
Backgrounder

If your free-to-play application uses NPLN, your application must require a Nintendo Switch Online membership for all NPLN features.

If your application's Nintendo Switch Online Policy in OMAS is set to "All features require membership," it ensures that all NPLN features require a Nintendo Switch Online membership.

If your application's Nintendo Switch Online Policy in OMAS is set to "Some features require membership," you must open the NPLN Dashboard web tool, go to Auth > Config, and check that all of the NPLN features are included in the list of services that require a Nintendo Switch Online membership. See the NPLN Manual for more information about the settings to configure so that all NPLN features require Nintendo Switch Online membership.

Info:

Demos are treated as separate from free-to-play applications and are not subject to this guideline. Note that if you have a demo, you must set it to the same Policy as the full retail version of your application.
References
  • NPLN Manual
    • NPLN Dashboard Manual > Changing and Applying Tenant Settings (Config) > Configuring Authorization Rules When Some Features Require Nintendo Switch Online Membership
  • Nintendo Switch Online Play Guide
    • Nintendo Switch Online Support > Member-Only and Complimentary Features
Test Method
Info:

Perform the following to check whether an application is free-to-play.

  • On OMAS, access the application's Title Information page. Under the Application Overview section, confirm that the entry for the Free-To-Play? field is Yes.
  1. On OMAS, access the application's Title Information page. Under the Nintendo Switch Online Policy section, check the Application Policy.
  2. If the Policy you checked in step 1 is set to "Some features require membership," check the following on NPLN Dashboard:
    • Auth > Config
Pass/Fail Determination
Passes if at least one of the following conditions is met.
  • In step 1, Nintendo Switch Online Policy > Application Policy is set to "All features require membership."
  • In step 2, Auth > Config > Services that require an NSO membership is set to "All services".
  • In step 2, Auth > Config > Services that do not require an NSO membership is set to "Auth" only.
