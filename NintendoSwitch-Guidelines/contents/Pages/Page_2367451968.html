Safety

This chapter covers requirements for application design and development to promote a fun and safe experience for users. Developers of all applications must read this chapter.

Applications that are played using Joy-Con

This subchapter covers requirements that apply to applications played using Joy-Con controllers.

It is possible to create a Switch application that can be played by moving the Joy-Con controllers, using the accelerometers and gyroscopes built into the Joy-Con controllers to detect movement.

On the other hand, it is possible that users may perform unintentional operations in such applications. To avoid users accidentally performing unintended operations, follow the guidelines from this subchapter when designing applications.

0098: Prohibited motions of Joy-Con controllers
Do not require or prompt users to perform any of the prohibited motions listed in the Backgrounder.
Software to Be Tested

Applications that are played by moving the Joy-Con controllers
Backgrounder

The following motions are potentially unsafe. Applications therefore must not require or prompt users to perform any of these motions within the application.

Prohibited motion Why is this prohibited? Illustration

Operations where the user releases all buttons while shaking or waving a Joy-Con, and is then no longer touching any buttons

If the user takes all their fingers off the buttons, the user may accidentally throw the Joy-Con.

Any motion which includes competing to attach or detach the Joy-Con controllers quickly It is prohibited to use attaching/detaching the Joy-Con controllers as input.
References
  • Nintendo Switch Application Safety Improvement Guide
Test Method
Use the Joy-Con controllers to play through all modes of the application from beginning to end.
Pass/Fail Determination
Passes if the application does not require or prompt users to perform any of the prohibited motions listed in the Backgrounder.

  • Your application does not use a Joy-Con strap usage screen provided by Nintendo, but does display a screen of your own design that includes both the explanation about using the strap and the explanation cautioning users about their surroundings

You must handle this display in a way that complies with the following guideline.

  • 0100: Explaining how to attach the Joy-Con strap

You must get approval from Nintendo in advance if you want to have users perform any motions or operations similar to those shown below. It is prohibited to create applications that require or prompt users to perform the following motions or operations without getting approval from Nintendo in advance.

Motions that must get approval in advance Reason why you must get approval in advance Illustration

Operations where the user makes large swinging motions of the Joy-Con controllers

Making large swinging motions with a Joy-Con may cause the Joy-Con or the user's hand or arm to hit nearby people or objects.

Hitting or striking the Joy-Con controllers

 This could damage the Joy-Con controllers or hurt the user depending on how they are hit.

  • When getting approval from Nintendo in advance, include the following information.
    • An overview of your game. (Including its number of players.)

    • Rating information
      • If you have not yet received all ratings, provide the ratings you expect to receive.
    • An overview of the motion you want to have users perform.
    • Any investigations or discussions you have had regarding considerations of the safety of this motion.
    • ROM data that Nintendo can use to check the issue that you want Nintendo to approve in advance.

0100: Explaining how to attach the Joy-Con strap
If your application could lead users to move Joy-Con controllers in rapid, wide, or forceful motions, your application must prompt the user to attach and use the Joy-Con strap.
Software to Be Tested

Applications that could lead users to move Joy-Con controllers in rapid, wide, or forceful motions

For more information about applications for which Joy-Con strap usage is required, see the Application Safety Improvement Guide > Motion Controls Using the Joy-Con and the Console > Joy-Con Strap Usage Standards and refer to "Category I" in the table.

Note: Here, the phrase "Joy-Con strap" includes both the regular Joy-Con strap and the Joy-Con AA Battery Pack.
Backgrounder

If your application could lead users to move Joy-Con controllers in rapid, wide, or forceful motions, then Joy-Con strap usage is required and therefore your application must prompt the user to attach and use the Joy-Con strap.
Nintendo recommends using one of the Strap Usage screens provided by Nintendo when prompting the user, but you are also allowed to create your own explanation screen and incorporate it somewhere in your application's overall explanation of how to play, as long as your screen provides the same explanation.

Strap Usage screen provided by Nintendo
  • Application-embedded version


  • Controller support applet version (provides a function that displays this screen when called by the application)
  • Display timing
    • At least once per application startup, you must display the Strap Usage screen or the explanation at a time when it is appropriate to caution the user to use the strap (for example, immediately after application startup or immediately before your application enters a mode where motion controls are possible).
  • Display language
    • Display it either in the language currently set in your application or in the language currently set in system settings.
    • If your application uses the controller support applet version of the Strap Usage screen, the screen will automatically be displayed in an appropriate language.
Strap Usage screen unique to your application

If you create your own screen, it must meet the following conditions.

  • Illustration

    • You must include an illustration of a Joy-Con controller being held in a user's hand, with the Joy-Con strap attached and the strap lock tightened on the user's wrist. (Your illustration must also include the circled numbers.)

      This illustration depicts the right Joy-Con controller.

      The circled numbers ① through ③ in the illustration do not have corresponding explanations in the standardized text, but you must not remove these circled numbers from the illustration.

  • Standardized text

    • You must include both of the following standardized texts set by Nintendo. You can reword the text as long as the meaning is preserved.

      • Standardized text about using the strap

        When you play with a Joy-Con controller,
        attach the strap as shown.
        Hold the Joy-Con controller securely and do not let go of it.

      • Standardized text for cautioning users about their surroundings

        Be aware of your surroundings.
        Allow adequate room around you during game play.

  • Display timing

    • At least once per application startup, you must display the illustration, the standardized text about using the strap, and the standardized text for cautioning users about their surroundings at a time when it is appropriate to caution the user to use the strap (for example, immediately after application startup or immediately before your application enters a mode where motion controls are possible).
    • It is also possible to use separate screens to give the explanation about using the strap and the explanation cautioning users about their surroundings.

  • Display language

    • Display it either in the language currently set in your application or in the language currently set in system settings.

Applications with a specification that intentionally asks the user to let go of a Joy-Con controller while the user is wearing the wrist strap during gameplay

          2. Pass the strap through the hole, and wrap it around your right leg.
          3. Position the leg strap at the center of your thigh, then stand still for a moment.

        • You must create illustrations that correspond to the standardized texts 1 through 3.
