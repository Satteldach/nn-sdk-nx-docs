Demos

This chapter covers requirements for application design and development and applies to demo versions of applications. In addition to applications distributed for promotional purposes at no charge to the user, the "demos" referred to by this chapter also include test versions of your application distributed to users as alpha or beta versions.

Demos: General

This subchapter covers requirements that apply to all demos on Switch.

0125: Limit on demo size

The size of a demo must be no larger than the following threshold value.

2 GiB
Software to Be Tested
All demos
Backgrounder

Demo versions of applications are limited to being no more than the stipulated size. Contact Nintendo if your specifications make it impossible to meet this size limit.
Test Method
Load your NSP file in AuthoringEditor, then go to Basic > Size information and check the value displayed in the Application install size field.
Pass/Fail Determination

Passes if the value displayed in AuthoringEditor in the Basic > Size information > Application install size field after loading the NSP file is no larger than the threshold value.

0126: Clearly distinguishing that your demo is not the full retail version
Users must be able to tell your demo apart from the full retail version of your application by looking at your demo's title name.
Software to Be Tested
All demos
Exceptions
Demos that are exclusively for RIDs (Retail Interactive Displays)
Backgrounder

The Data Management screen does not automatically put any markers on demos to let users tell demos apart from full retail versions. If users can't tell the difference between your demo and your full retail application by looking at their title names, they might accidentally delete the full retail version when they intended to delete the demo. To prevent this, you must set a title name for your demo that allows users to tell it apart from the full retail version.

If you have no preferred notation, simply add "Demo" at the end of your demo's title name.

If your demo is for China, you must add "体验版" or similar Simplified Chinese notation to your demo's title name.

Nintendo also recommends making the icons for your demo and full retail version different in some way, as this visual difference may also help users to tell them apart.
Test Method
  1. In Authoring Editor, open the NSP file for the demo and the NSP file for the full retail version.
  2. In each file, go to Basic > Title to display the title name.
  3. Compare the title name of the demo to the title name of the full retail version.
Pass/Fail Determination
For applications that are not for China:

Passes if the title name of the demo is distinguishable from that of the full retail version in every language the application supports.

For applications for China:

Passes if the title name of the demo contains "体验版" or similar Simplified Chinese notation, making it distinguishable from the full retail version.
