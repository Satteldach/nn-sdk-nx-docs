5.10 Toy-Con Pedal

Describe how to use the Toy-Con Pedal

The user cannot use the Toy-Con Pedal properly if they do not know how to operate it.

We recommend describing how to use the Toy-Con Pedal in advance and allowing the user to access this description as necessary.

Adjust the sensitivity of the controls so the application responds without excessive user motions

Sensors of the same kind can have individual differences, and each user has a different range of motion.

To avoid damage to the Toy-Con Pedal, set the thresholds for recognizing Toy-Con Pedal controls with enough margin so users can accomplish the intended actions in the game without the need for rapid or forceful motions.
