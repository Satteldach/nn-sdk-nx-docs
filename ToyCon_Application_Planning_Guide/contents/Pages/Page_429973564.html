5.11 Toy-Con Spray Can

Any application that supports Toy-Con Spray Can must include measures to promote a fun and safe experience. These measures can be implemented in various ways, including the application's controls, instructions, and notices. The following are some examples.

Describe how to use the Toy-Con Spray Can

Users cannot use the Toy-Con Spray Can properly if they do not know how to operate it

We recommend describing how to use the Toy-Con Spray Can in advance and allowing the user to access this description as necessary.

Adjust the sensitivity of the controls so the application responds without excessive user motions

Individual sensors of the same kind can have factory differences, and different users have different range of motion.

To avoid damage to the Toy-Con Spray Can, set the thresholds for recognizing Toy-Con Spray Can controls to value ranges wide enough that users can accomplish the intended actions in the game without needing to use rapid motions.

Display messages or images urging users to hold the Toy-Con with both hands while playing

If the user holds the Toy-Con Spray Can with one hand, or lets go of the Toy-Con Spray Can while playing, it may collide with nearby people or things.

If you instruct the user to play while holding the Toy-Con Spray Can with both hands, you can reduce the likelihood of them letting go of the Toy-Con Spray Can, and of collisions with people or things around them.
