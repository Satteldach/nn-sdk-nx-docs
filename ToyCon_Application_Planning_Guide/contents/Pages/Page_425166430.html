5.6 Toy-Con Robot

Any application that supports Toy-Con Robot must include measures to promote a fun and safe experience. These measures can be implemented in various ways, including the application's controls, instructions, and notices. The following are some examples.

Describe how to use the Toy-Con Robot

Users cannot use the Toy-Con Robot properly if they do not know how to put it on or operate it.

To prevent unsafe uses, before game development, review the operational specifications and use cases for the Toy-Con Robot.

We recommend describing how to put on and use the Toy-Con Robot, displaying a warning message, and allowing the user to access this description as necessary.

Putting on the Toy-Con Robot

Nintendo-Provided Images of How to Put On the Toy-Con Robot

Nintendo will provide images that show how to put on the Toy-Con Robot.

We recommend using the images provided by Nintendo that show how to put on the Toy-Con Robot.


Image of Putting on the Toy-Con Robot



You can also prepare a proprietary screen to include as part of your overview of application operations.

If you are preparing a proprietary screen, include the following standardized text, specified by Nintendo, along with the screen.

  • Place the visor on your head.
  • Place the main body on your back, and then firmly tighten the shoulder straps.
  • Place the robot shoes on your feet, and then stand up. Ensure that the string length does not become too short when you move your feet up and down.
  • Grip the robot arms. Ensure that the string length does not become too short when you extend your arms.

Display Timing

Display this screen one time, when the game first starts, and before gameplay begins.

Consider specifications that allow users who start the game later, to check how to put on the Toy-Con Robot. The display location and display method are not specified by Nintendo.

Display Duration

As long as the screen is displayed long enough for the user to read and understand its content, there is no specific requirement for how long to display the screen.

It is also not a problem to allow the user to proceed by pressing a button.

Supported Languages

Use the languages that are needed to match your application's specifications.

Nintendo provides versions in the following languages: Japanese, English, German, French, Spanish, Italian, Dutch, Portuguese, Russian, Traditional Chinese, Simplified Chinese, and Korean (Hangul).

Use the languages that are needed to match your application's specifications.

Adjust the sensitivity of the controls so the application responds without excessive user motions

Sensors of the same kind can have individual differences, and each user has a different range of motion.

To avoid damage to the Toy-Con Robot, set the thresholds for recognizing Toy-Con Robot controls to value ranges wide enough that users can accomplish the intended in-game actions without needing to use rapid motions.

Display messages or images urging users to be careful of people and things around them

Users may become absorbed in a game after repeated play and become less aware of their surroundings. It is important to remind users to stay aware.

Text

Include the following standardized text set by Nintendo. You can reword the text as long as the meaning is preserved.

Allow adequate room around you during gameplay.

Example Display

Display Timing

Display this screen before gameplay begins. You must display the screen cautioning the user about their surroundings at least once every time the application starts. It is not sufficient to display this description just once the very first time the application is started.

It is required that the user can see this description. It is not sufficient to display this screen only inside a settings dialog box or other menu that the user must deliberately select to see the screen.

Display Duration

As long as the screen is displayed long enough for the user to read and understand its content, there is no specific requirement for how long to display the screen.

We recommend displaying the screen for five seconds, but it is not a problem to allow the user to proceed with a button press.

Supported Languages

Use the languages that are needed to match your application's specifications.

Nintendo provides versions in the following languages: Japanese, English, German, French, Spanish, Italian, Dutch, Portuguese, Russian, Traditional Chinese, Simplified Chinese, and Korean (Hangul).

Use the languages that are needed to match your application's specifications.
