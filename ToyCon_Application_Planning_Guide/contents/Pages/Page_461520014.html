Toy-Con common excel Toy-Con_Cautions_VER.xlsx

An Excel file with a collection of text messages required for the various Toy-Con accessories.

Divided into separate worksheets.

  • text_1: The text for the attention screen about being aware of surroundings for the Toy-Con Fishing Rod.
  • text_2: The text for the strap-usage screen for the Toy-Con Piano.
  • text_3: The text for the screen about wearing the Toy-Con Robot.
  • text_4: The text for the attention screen for the Toy-Con VR Goggles.
  • text_5: The text for the break message for the Toy-Con VR Goggles.
  • text_6: -
  • text_7: The text that describes how to calibrate the six-axis sensor.

When you open the Toy-Con folder, there is a folder for each Toy-Con.

  • The XXX portion of the filename is the supported language.
    • ja: Japanese / en: English / de: German / fr: French / es: Spanish / it: Italian / nl: Dutch / po: Portuguese / ru: Russian / ko: Korean / cn: Simplified Chinese / tw: Traditional Chinese
  • The YYY portion of the filename is the resolution (720p/1080p/4K).
  • The VER portion of the filename is the version.
  • AI files are in the RGB format.
  • Adobe Illustrator CS6 or later is required to open AI files.
