5.7 Toy-Con Car

Any application that supports Toy-Con Car must include measures to promote a fun and safe experience. These measures can be implemented in various ways, including the application's controls, instructions, and notices. The following are some examples.

Describe how to use the Toy-Con Car

Users cannot use the Toy-Con Car properly if they do not know how to use it.

We recommend describing how to use the Toy-Con Car in advance and allowing the user to access this description again as necessary.

Adjust the sensitivity of the controls so the application responds without excessive user motions

Sensors of the same kind can have individual differences, and each user has a different range of motion.

To avoid damage to the Toy-Con Car, set the thresholds for recognizing Toy-Con Car controls to value ranges wide enough that users can accomplish the intended in-game actions without needing to use rapid motions.

Display messages or images urging users to sit while playing

If the user plays while standing, the Nintendo Switch system may fall out of the Toy-Con Car while playing.

If you instruct the user to stay seated while playing, you can reduce the likelihood of the system falling out.
