5.5 Toy-Con Piano

Any application that supports Toy-Con Piano must include measures to promote a fun and safe experience. These measures can be implemented in various ways, including the application's controls, instructions, and notices. The following are some examples.

Describe how to use the Toy-Con Piano

Users cannot use the Toy-Con Piano properly if they do not know how to use it.

We recommend describing how to use the Toy-Con Piano in advance and allowing the user to access this description again as necessary.

Adjust the sensitivity of the controls so that the user does not have to forcefully press down the keys

Sensors of the same kind can have individual differences, and each user has a different range of motion.

To avoid damage to the Toy-Con Piano, set the thresholds for recognizing Toy-Con Piano controls to value ranges wide enough that users can play the intended note without needing to use forceful motions.

Display messages or images urging users to wear the Joy-Con strap

To reduce the likelihood of the user accidentally letting go of the Joy-Con while playing your application, you must display the Joy-Con Strap Usage screen in accordance with the following requirements.

Text

Include the following standardized text (provided by Nintendo) with applications that use Toy-Con Piano (Baton). You can reword the text as long as the meaning is preserved.

When you play with the Baton, attach the strap as shown. Hold the Baton securely and do not let go of it.

Example Display

Display Timing

Display the Strap Usage screen or the description at a time when it is appropriate to caution the user to use the strap (for example, immediately after application startup or immediately before your application enters a mode where motion controls are possible).

You must display the Joy-Con Strap Usage screen at least once every time the application starts. It is not sufficient to display this description just once the very first time the application is started, without repeating it every other time the application is started.

It is required that the user can see this description. It is not sufficient to display this screen only inside a settings dialog box or other menu that the user must deliberately select to see the screen.

Display Duration

As long as the screen is displayed long enough for the user to read and understand its content, there is no specific requirement for how long to display the screen.

We recommend displaying the screen for five seconds, but it is not a problem to allow the user to proceed with a button press.

Supported Languages

Nintendo provides versions in the following languages: Japanese, English, German, French, Spanish, Italian, Dutch, Portuguese, Russian, Traditional Chinese, Simplified Chinese, and Korean (Hangul).

Use the languages that are needed to match your application's specifications.

Display messages or images urging users to be careful of people and things around them

Users may become absorbed in a game after repeated play and become less aware of their surroundings. It is important to remind users to stay aware.

Text

Include the following standardized text set by Nintendo. You can reword the text as long as the meaning is preserved.

Allow adequate room around you during gameplay.

Example Display

Display Timing

Display this screen before gameplay begins. You must display the screen cautioning the user about their surroundings at least once every time the application starts. It is not sufficient to display this description just once the very first time the application is started.
