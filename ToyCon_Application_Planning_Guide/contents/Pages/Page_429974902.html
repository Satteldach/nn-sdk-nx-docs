5.12 Toy-Con VR Goggles

Any application that includes VR mode must include measures to promote a fun and safe experience. These measures can be implemented in various ways, including the application's controls, instructions, and notices.

Complying With Parental Controls

The age rating for VR mode is 7 and older, so instruct users to restrict the use of VR mode by children 6 and younger.

The VR Mode (3D Visuals) restriction in the parental controls enables prohibiting VR mode for children 6 or younger. Applications that support VR mode must enable restriction of VR mode by the parental controls.

Using Video That Avoids Motion Sickness

You must implement measures so that the application can be played for a long time without incurring motion sickness. The following are some examples.

Reprojection

The delay between when the user's head moves (the gyroscope value) and when that movement is applied on the screen can cause motion sickness. We recommend using reprojection to resolve this delay and mitigate motion sickness. For more information about implementation, contact Nintendo.

Setting the Frame Rate as High as Possible

A large screen refresh interval makes it harder to track head movement and can cause motion sickness.

Matching the Camera Movement With the User's Head Movement

If the camera movement does not match the user's head movement, the user's sensations will not be consistent and may cause motion sickness. Consider the following methods to create camera behavior that would be less likely to cause motion sickness.

  • Do not move the camera viewpoint in ways unrelated to user operations.
  • Limit the speed of camera zooming.

Avoiding Incorrect Stereoscopic Display

By implementing VR mode, it is possible to intentionally display the following types of images. However, these images might not achieve a correct stereoscopic 3D effect, or might cause the user to feel uncomfortable even if they achieve a stereoscopic effect.

To avoid displaying incorrect stereoscopic images in applications that implement VR mode, avoid displaying images like the following as much as possible.

  • States where the relative front/back positions of objects conflict
    When two objects overlap in a standard 3D display, the object in front is displayed while the object in the back appears to be hidden. Images where this positional relationship contradicts itself and the object in front is hidden by the object in the back will cause discomfort to users.

For more information, see the following section in the Nintendo Switch Guidelines.

  • VR
    • 0201: Prohibition of incorrect stereoscopic display

Parallax Restrictions

When implementing VR mode, you can apply parallax to the left and right sides of the screen to create a sense of depth or protrusion, but excessive parallax will cause discomfort to users. For this reason, we recommend keeping the left/right image parallax within the following range.

Depth Direction Parallax

Depth

Within 10.0 mm (52 pixels)

Protrusion

Within 5.0 mm (26 pixels)

The mm described in this section are the standard values in VR mode. This is when the pixels for both the left eye and right eye are treated as a single pixel (0.192 mm x 0.192 mm).

Parallax exceeding the recommended range is fine under the following circumstances.

  • If the duration where it exceeds the recommended range is one second or less.
    For short durations, such as when a temporary sequence is played for one second or less, parallax exceeding the recommended range is acceptable because the human eye cannot adjust fast enough to follow the parallax. If visual adjustment is not fast enough, it is difficult for the user to feel discomfort even if the parallax exceeds the recommended range.

Considering Lens Distortion When Image Processing　

With the Toy-Con VR Goggles, the user looks at the screen through lenses so the screen is in focus even at extremely close range. At such times, the images on the screen can become distorted like the view through a fish-eye lens. We recommend using a process to cancel out this distortion by displaying images that have been distorted in the opposite way so they appear undistorted when viewed through the lenses. For more information about implementation, contact Nintendo.

Correcting For Chromatic Aberration

When the screen is viewed through the Toy-Con VR Goggles, chromatic aberration occurs because the refractive index of the lens is different for the different RGB color components. The RGB misalignment worsens from the center of the lens outward. As a countermeasure, we recommend chromatic aberration correction, creating the images for display on the screen with the RGB components shifted in the opposite direction to mitigate the chromatic aberrations experienced through the lenses For more information about implementation, contact Nintendo.

Displaying an Attention Screen for Toy-Con VR Goggles

To guide users about how to use the Toy-Con VR Goggles and draw their attention to important information, show an attention screen based on the following description.

Attention Screen Provided by Nintendo

Nintendo provides the following attention screen.

Display Timing

Show the attention screen every time the application is started.

You must show the screen before the user actually operates the Toy-Con VR Goggles (before entering VR Mode).

You must display the attention screen at least once before the user actually operates the Toy-Con VR Goggles. It is not sufficient to display this description just once the very first time the application is started, and never display it again when starting the application.

It is required that the user can see this description. It is not sufficient to display this screen only inside a settings dialog box or other menu that the user must deliberately select to see the screen.

Display Duration

If the screen is displayed long enough for the user to read and understand its content, there is no specific requirement for how long to display the screen.

We recommend displaying the screen for five seconds, but it is not a problem to allow the user to proceed immediately with a button press.

Prompting Users to Take Appropriate Breaks

When playing the game in VR mode, the user may experience symptoms similar to motion sickness depending on their conditions. It is also possible that they may feel tired or ill after playing the game for a long time.

It is important to set one instance of play to last a short period of time and create appropriate pauses as the game proceeds to ensure that users take proper breaks.

You can also measure users' play time to display messages prompting them to take a break.

Displaying Messages Prompting Users to Take a Break

Periodically show messages prompting users to take a break while playing in VR mode.

Text

Include the following standardized text to prompt users to take a break. You can reword the text as long as the meaning is preserved.

Do you want to take a break?

Note: Text in each language is attached to this document. For more information, see File List.

Display Timing

Periodically display this message after the user starts playing the game in VR mode.

You must display this message within 30 minutes of starting the game in VR mode, and then periodically every 30 minutes or less thereafter.

Determine the timing for showing this message prompting users to take a break based on how strictly the application follows the recommended procedures described earlier on this page in Using Video That Avoids Motion Sickness. For applications that do not strictly follow these procedures, we recommend displaying the message at shorter intervals.

Calibrating the System's Six-Axis Sensor

Over the course of extended gameplay, the six-axis sensor drifts and errors accumulate in the values obtained from the sensor.

For more information, see NintendoSDK VRGogglesKit (NintendoSDK SevenKit) > Features > hid Library > SevenSixAxisSensor > Important Information > Calibration. This documentation will be provided after your plan is approved.

Implementing a Feature to Reset the Base Position

Calibration using the accelerometer does not work for the yaw axis (the axis of rotation around the center of gravity) of the system's six-axis sensor. As a result, the orientation as calculated by the sensor will gradually drift compared to the real-world orientation after the game has been played for a certain amount of time.
If this drift is a problem, implement a feature to reset the base position (see the note).

Note: The base position is a value that serves as the reference for associating the actual orientation of the controller with the internal orientation.

No Disadvantages Given to the User When Resuming a Game after Sleep Mode or Transitions from the HOME Menu

For health and safety, it is essential to design rest breaks into gameplay in VR mode. The user must be able to resume the game without any disadvantages if they suspend it by entering sleep mode, transitioning to the HOME Menu, pausing the game, or another method. This enables the user to take a break at any time according to their physical needs.

This requirement is meant to avoid situations where users feel ill but continue to play in VR mode because they are worried about disadvantages if they stop.

Specifically, the following types of consideration are required.

  • The player can resume from the suspended scene.
  • Scores and other aspects are not reset.

Notifying the System When Starting and Ending Stereoscopic Display

To avoid discomfort to users playing in VR mode, applications that implement VR mode should do the following.

  • Call the nn::pl::BeginVrMode() function when starting stereoscopic screen output.
  • Call the nn::pl::EndVrMode() function when ending stereoscopic screen output.

If these functions are called correctly, the system is able to keep track of times when the application is displaying stereoscopic screens and the user might be wearing the Toy-Con VR Goggles. When the user presses the HOME Button in this state, the VR curtain is displayed. For more information, see HOME Menu and Library Applets.

HOME Menu and Library Applets

The HOME Menu and the various library applets do not support VR mode 3D display.

For this reason, if you transition to these screens during VR mode, a message (a VR curtain) like the following is automatically displayed to instruct the user to remove the Toy-Con VR Goggles, after which VR mode is ended and the transition takes place.

Note

This specification might change in a future update.

When Transitioning to the HOME Menu

If the user presses the HOME Button again while this screen is displaying, the transition to the HOME Menu is canceled and the user can return to the game still in VR mode.

When Starting a Library Applet

It is not possible to return to the game still in VR mode. The user must remove the goggles and end VR mode.

Overlay Notifications

During VR mode, overlay notifications are displayed in the upper center of the screen.

Quick Settings

During VR mode, Quick Settings are displayed in the lower center of the screen.

Unlike with the normal Quick Settings, the only setting that can be changed is the screen brightness.

This change applies to the brightness of the screen during VR mode. Changing this setting does not alter the ordinary screen brightness.
