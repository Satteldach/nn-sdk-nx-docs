1 Introduction

Purpose and Content

This document describes concepts you must consider when planning applications that support Toy-Con accessories.

Audience

This document is intended to be read by planners and developers of Nintendo Switch™ applications that support Toy-Con.

When to Read This Document

Read this document when planning an application that supports Toy-Con.

Structure of This Document

2 What Is Toy-Con? gives an overview of Toy-Con.

4 Ratings describes the ratings standards for applications that support Toy-Con.

5 Toy-Con Application Safety provides notes about taking safety into account, with an emphasis on Toy-Con durability and the experience of playing applications that use Toy-Con.

Related Documents

For more information about application safety, see Nintendo Switch Guidelines and Application Safety Improvement Guide.

Note for Developers Planning Applications That Support Toy-Con Accessories

Due to the nature of Toy-Con accessories, Nintendo checks applications that support Toy-Con for safety issues.

Based on the results of that check, we may recommend or require you to implement handling that is not described in this Guide.


If you want to support Toy-Con accessories, contact Nintendo through your publisher using the following email addresses, and provide an overview of how you plan to use Toy-Con accessories in your application.

Because it takes time to perform these checks, contact Nintendo as early in development of your application as possible.

  • For titles for the Japanese, Hong Kong, Taiwan, or Korean markets, contact ml-labo_contact@nintendo.co.jp.
  • For titles for the Americas or Europe markets, contact thirdpartypublisher@noa.nintendo.com.

Note that at present, Nintendo is not accepting proposals for additions to the Toy-Con accessory lineup.

Additionally, Nintendo does not provide additional information or Toy-Con accessories beyond those listed on the official Nintendo website. Please note this fact.

Toy-Con Library

Nintendo provides dedicated libraries for the following Toy-Con accessories.

They enable implementation of various Toy-Con operations that match the overall feel of Nintendo Labo.

After your proposal is approved, the library package is provided to you.

  • Toy-Con Piano
  • Toy-Con Car
  • Toy-Con Plane
  • Toy-Con Submarine
  • Toy-Con Pedal
  • Toy-Con VR Goggles
