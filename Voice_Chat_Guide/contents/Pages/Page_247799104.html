2.1 About Matchmaking Voice Chat

Overview

Matchmaking Voice Chat is a feature of the Switch Online app. With this feature, players participating in network matches in Switch applications can use voice chat on their smart devices.
Matchmaking Voice Chat is displayed as Voice Chat in the Switch Online app.
For a Switch application to use the Matchmaking Voice Chat feature, the application must be implemented in a special way, and application-specific information must be registered to the Voice Chat server, which is the server that provides the Matchmaking Voice Chat functionality.

Supporting Parental Controls

Matchmaking Voice Chat is not subject to the parental control restrictions in communicating with others.
Avoid implementations where an application obtains the parental control settings and determines whether to enable or disable Matchmaking Voice Chat.

Client Libraries

Matchmaking Voice Chat can be used for matchmaking using Nintendo's game server (the server that NEX or NPLN provides) and for independent matchmaking using an independent server.
Libraries from the NEX library (the nn::nex::SmartDeviceVoiceChatClient class) and the SmartDeviceVoiceChat library provided as part of NintendoSDK are provided as client libraries.
Matchmaking that uses NPLN or an independent server has the advantage of using the SmartDeviceVoiceChat library to make it unnecessary to link to the NEX library.

Info

NPLN is a mechanism for adding online functionality, and is the successor to NEX. For more information about NPLN, see the NPLN Manual.

NEX Library

The NEX library is an expanded communication library for the NintendoSDK. It includes features such as matchmaking, ranking, and data stores.
The Matchmaking Voice Chat feature is provided as a part of the NEX library in NEX 4.6.0 and later.
For more information about NEX, see the Nintendo Switch NEX Guide and NX NEX Manual.

SmartDeviceVoiceChat Library

SmartDeviceVoiceChat is a library for using the Matchmaking Voice Chat feature. The features it provides are identical to those of the NEX library's Matchmaking Voice Chat feature.
Using the SmartDeviceVoiceChat library when implementing matchmaking and other online functionality through NPLN or an independent server makes it no longer necessary to link to the NEX library.
It is provided as a private package (SmartDeviceVoiceChatKit) starting in NintendoSDK 12.3.6, and is included in the standard NintendoSDK package starting in NintendoSDK 16.2.0.
If you need a private package, contact your Nintendo support representative.

Glossary

The following section explains terms related to Matchmaking Voice Chat.

Matchmaking Voice Chat Terminology

Glossary
Nintendo Switch Online App

The smart device application that provides services linked to Switch games. It is referred to as the Switch Online app in this document.

Matchmaking Voice Chat

Matchmaking Voice Chat is a feature that performs matchmaking for online matches in Switch applications and enables the gathered users to voice chat.

Notifications are sent to smart devices when the online match in the Switch application begins. Voice chat then begins for users who have the smart device application running.

Matchmaking Voice Chat is displayed as Voice Chat in the Switch Online app.
Voice Chat Server

The server that provides the Matchmaking Voice Chat functionality.
Title Group

Matchmaking Voice Chat is handled in units of title groups.
Multiple application IDs can be linked to a single title group.
Voicing chat can take place among applications that belong to the same title group.
Room

A place created on the Voice Chat server where users can gather together.
Members participating in a room can voice chat with each other.
Game Mode

The game mode indicates the kind of online play during which voice chat occurs.
For example, if an application has voice chat for both individual matches and tag matches online and voice chat occurs in both, they can be set as separate game modes.
Channel

By setting separate channels, the users participating in the same room can be divided into separate groups for communication.
For example, if the members in a room are divided into the A team and the B team for battle, you can prepare one channel for the A team and a separate channel for the B team.
In this way, the team members using the same channel can communicate with each other, but the members of the other team using the other channel cannot.

Management Tool Terminology

Nintendo Developer Portal

This website is specifically intended for game developers working on the Nintendo platforms.
You can review development manuals and add the applications or products you are working on.
If your product will use the voice chat feature, open MY PRODUCTS, select the product, select Releases > Features > Program Specifications > Supports voice chat, and then register the necessary information.

OMAS

OMAS (Online Title Management System) is a Web management tool used to submit applications for the network features that your application will use. OMAS can be accessed from the Nintendo Developer Portal link.
Make an OMAS request to use network features for setting up and configuring a server and to enable network feature development.

If you plan to use Matchmaking Voice Chat, you must request its use in each title on OMAS.
If you plan to implement the voice chat feature without using Matchmaking Voice Chat, you do not need to make a request to use the feature on OMAS.
