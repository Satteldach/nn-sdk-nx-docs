2.2 Conditions for Joining the Same Room

When Using NEX or NPLN

The matchmaking mechanism in NEX and NPLN only allows matching between users connected to the same game server. For this reason, Matchmaking Voice Chat cannot take place between applications connected to different game servers.

As a rule, one NEX game server is assigned for the same title (the applications that all have the same top four digits in their initial codes). If you want to use the same NEX game server for multiple titles, contact Nintendo. In principle, dividing a title among multiple NEX game servers is not supported.

When using an NPLN game server (tenant), an application developer can freely add or change applications that can connect to the game server. For more information, see the NPLN Manual.

Conditions for Joining a Room

All of the following conditions must be satisfied for users to join together in the same room for voice chatting with the Matchmaking Voice Chat feature.

  1. The users joining the same room are all using titles that belong to the same title group.
  2. The users joining the same room are all using voice chat with the same session ID specified in the title.
Info

Users can join the same room as long as they have the same session ID, even if the game modes differ. However, if you set it to a different game mode according to the type of matchmaking, it becomes easier for Nintendo to investigate when some kind of problem has occurred. Basically, make sure that you set the game mode when using NEX.


Using Titles That Belong to the Same Title Group

Users who are using titles that belong to different title groups cannot join the same room.
The Voice Chat server manages applications in units of title groups.

For more information about the conditions for titles to belong to the same title group, see 2.3.1 Development Environment Server Settings for Matchmaking Voice Chat.

Specifying the Same Session ID

Matchmaking Voice Chat rooms are prepared based on the session ID specified by the application. Users with the same specified session ID can join the same room.

If you are using the NEX matchmaking feature, specify the gathering ID for the session ID. If you are using the NPLN matchmaking feature, specify the game session ID.

If you are preparing a custom matchmaking setup on an independent server, specify an ID that will be shared by all users who join the same room.
