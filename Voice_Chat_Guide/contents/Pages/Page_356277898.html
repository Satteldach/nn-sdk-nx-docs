2.3 Beginning Development

To develop applications that use Matchmaking Voice Chat, you must submit the following request forms.

Request Item Description
OMAS request to use Matchmaking Voice Chat

Fill in the required information for Matchmaking Voice Chat in OMAS before submitting your request.

The Matchmaking Voice Chat server settings are configured based on the information in your OMAS request.
Whereas the OMAS request for Matchmaking Voice Chat is submitted individually for each title (product), the request for the Matchmaking Voice Chat server settings is submitted for the whole title group. For this reason, registering settings to the Matchmaking Voice Chat server involves a special operation. Make sure to review 2.3.1 Development Environment Server Settings for Matchmaking Voice Chat.

Matchmaking Voice Chat becomes available in the development environment when the Matchmaking Voice Chat server settings phase is approved. The server settings take several business days.

Getting the Switch Online App for Development

 For more information, see 2.3.2 Getting the Switch Online App for Development.
Info
  • Effective from the January 2021 update of OMAS, the OMAS request for Matchmaking Voice Chat does not require the registration of a game mode ID.
  • Effective from the May 2019 update of OMAS, the development environment server settings for Matchmaking Voice Chat are configured based on the OMAS request. For more information, see 2.3.1 Development Environment Server Settings for Matchmaking Voice Chat.
  • To use voice chat in the development environment, you no longer need to remove access restrictions on individual network service account IDs.
