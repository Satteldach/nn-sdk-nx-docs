2.3.1 Development Environment Server Settings for Matchmaking Voice Chat

To use Matchmaking Voice Chat in the development environment (the dd1 environment), the application information (the application ID) must be registered on the Matchmaking Voice Chat server.
Registration requests are made in OMAS (after May 2019).

Matchmaking Voice Chat Requests in OMAS

For applications that will support Matchmaking Voice Chat, fill in the required information in the request to use Matchmaking Voice Chat on OMAS and submit the request.

Submit a separate request for each application. If there are applications with the same name but different application IDs, submit a request for each of them.

Matchmaking Voice Chat becomes available in the development environment when the Matchmaking Voice Chat server settings phase is approved.

Relationship Between the OMAS Request and Matchmaking Voice Chat Server Settings

If you submit a request on OMAS for an application that supports Matchmaking Voice Chat, the Matchmaking Voice Chat server settings are changed according to the information in the request. The changes are implemented when the OMAS Matchmaking Voice Chat Server Settings phase is approved.

Matchmaking Voice Chat server settings are configured individually for each title group. (For more information about title groups, see 2.1 About Matchmaking Voice Chat.) However, because requests in OMAS cannot handle title groups, title groups are configured automatically according to the rules described in the next section.

OMAS Requests and Title Group Handling

As described in 2.2 Conditions for Joining the Same Room, applications with different application IDs must belong to the same title group for Matchmaking Voice Chat to work.

Title group settings are registered using the rule that Applications with the same first four digits in the initial code are configured in the same title group, based on the OMAS request.

For example, if you have three applications with the same first four digits, such as ABCDA, ABCDB, and ABCDC, they are set to the same title group. However, a separate Matchmaking Voice Chat request must be submitted for each application.

Contact Nintendo if you want to separate a title group despite the applications having the same first four digits if the initial code, or if you want to put applications that have different first four digits in the initial code in the same title group.

Info

The Matchmaking Voice Chat request settings on OMAS are not synchronized among applications that belong to the same title group.

Handling Applications Whose Matchmaking Voice Chat Requests Were Previously Submitted Using an Excel File

Before the May 2019 OMAS update, requests were submitted in the form of Excel files. If a request in the form of an Excel file has already been submitted for an application, you do not need to resubmit the request in OMAS.

The settings for the title group remains configured based on the information in the previously submitted Excel file. The content in the OMAS request does not automatically change to the content submitted in the Excel file.
