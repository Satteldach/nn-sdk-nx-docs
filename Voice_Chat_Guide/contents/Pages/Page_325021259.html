2.1.3 Supporting Matchmaking Voice Chat

This section describes the processes required for an application to support Matchmaking Voice Chat.

Minimum Requirements

Comply with the items related to Matchmaking Voice Chat in the Nintendo Switch Guidelines.
When checking the guideline item 0182: Supporting matchmaking when Matchmaking Voice Chat is not available, see Nintendo Switch Network Error Simulation Manual > Generating Matchmaking Voice Chat Errors.

Info

As of version 20.0 of the Nintendo Switch Guidelines, the item "0182: Supporting matchmaking when Matchmaking Voice Chat is not available" applies to applications that use NEX voice chat functions. However, even when using the SmartDeviceVoiceChat library included in NintendoSDK, you must similarly comply with this guideline item.

In addition, requirements are different depending on whether the application is using NEX, using NPLN, or using independent matchmaking with an independent server. Handle based on the following information.

When Using NEX

When the Matchmaking Voice Chat feature is added to an application that uses the NEX matchmaking features, the minimum requirement is to call the functions for starting and ending voice chat at the beginning and end of the online matches. Specify the gathering ID (session ID) and game mode as the parameters for the function for starting voice chat.

The gathering ID is required in order to join the same voice chat room. For more information, see 2.2 Conditions for Joining the Same Room.

Although the game mode setting does not affect Matchmaking Voice Chat, please set the game mode differently according to the type of matchmaking so it is easier for Nintendo to investigate when a problem related to Matchmaking Voice Chat has occurred.

When Using NPLN

When adding the Matchmaking Voice Chat feature to an application that uses NPLN, specify the game session ID that is generated by NPLN's Matchmaking service as the session ID parameter for the function for starting voice chat.

You do not need to explicitly set a game mode parameter. The value set for game mode has no effect on the behavior of Matchmaking Voice Chat. However, if you set it to a different game mode according to the type of matchmaking, it becomes easier for Nintendo to investigate when some kind of problem has occurred.

When Using Custom Matchmaking With an Independent Server

If you are designing a custom matchmaking system to use with an independent server, in addition to calling the functions to start and end voice chat, you must prepare an ID that is unique for each gathering of users performed via matchmaking. Voice chat is available between users who share this same ID.

You do not need to explicitly set a game mode parameter. The value set for game mode has no effect on the behavior of Matchmaking Voice Chat. However, if you set it to a different game mode according to the type of matchmaking, it becomes easier for Nintendo to investigate when some kind of problem has occurred.

Optional Features

Matchmaking Voice Chat provides the following optional features. Using these features is not mandatory.

Feature for Determining Whether Matchmaking Voice Chat Is Available

As described in 2.1.1 Advance Preparations for Using Matchmaking Voice Chat, you must use your Nintendo Account to sign in to the Switch Online app.
A function is provided for Switch applications to determine whether the user can use Matchmaking Voice Chat.

Switch Online App Download Guide Feature

This feature displays a webpage in the web applet for downloading the Switch Online app.
Use this feature to direct users who cannot use Matchmaking Voice Chat to download the Switch Online app.
