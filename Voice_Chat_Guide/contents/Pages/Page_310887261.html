2.1.1 Advance Preparations for Using Matchmaking Voice Chat

The following settings are required for users to use Matchmaking Voice Chat.

  1. Switch Online Membership
  2. Signing In to the Switch Online App

Switch Online Membership

A Switch Online membership is required for using Matchmaking Voice Chat.

A Nintendo Switch Online membership is also needed when using Matchmaking Voice Chat in a development environment. For more information about getting a Switch Online membership in the development environment, see Nintendo Switch Online > Use in a Development Environment in the Nintendo Switch Online Play Guide.

Signing In to the Switch Online App

To use Matchmaking Voice Chat, you must configure the following settings for the user's Nintendo Account in advance. These settings must be configured for all users using Matchmaking Voice Chat.

  1. Link the Nintendo Account to a Switch user account.
  2. Sign in to the Switch Online app using the target Nintendo Account.

If the Nintendo Account is not linked to a Switch, a screen like the following is displayed, and the user cannot use the Switch Online app.

In addition, Nintendo Accounts that are not signed in to the Switch Online app cannot use the Matchmaking Voice Chat features.

Displaying a guide for downloading the Switch Online app in a Switch application is available as an optional feature. For more information, see 2.1.3 Supporting Matchmaking Voice Chat.
