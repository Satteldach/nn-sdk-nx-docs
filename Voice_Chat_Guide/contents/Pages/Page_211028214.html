1 Introduction

Purpose and Content

You can use one of the following methods for implementing voice chat in Nintendo Switch™ (Switch) applications.

  1. Use the voice chat feature (Matchmaking Voice Chat) that uses the Nintendo Switch Online app (Switch Online app) for smart devices.
  2. Use the audio input from a device attached to the Switch audio jack to transmit voice data in the Switch application.

This document includes the following information.

  • The first method includes information needed when planning, developing, and releasing applications that use Matchmaking Voice Chat.
    • See 2 Matchmaking Voice Chat.
  • The second method lists the content needed when using voice chat to transmit audio data in Switch applications.
    • See 3 Voice Chat for Transmitting Audio Data in Switch Applications.
Info
  • Implementing the functionality to transmit voice data in Switch applications is outside the scope of this document. For more information, see the related software development kits and middleware manuals.
  • Matchmaking Voice Chat is displayed as Voice Chat in the Switch Online app.

Intended Audience

This document is intended for project owners and developers of applications that use voice chat.

When to Read This Document

Read this documentation when you are planning or developing applications that use voice chat.

Related Documents

For more information about Nintendo Switch Online, see the Nintendo Switch Online Play Guide.

The API for implementing the Matchmaking Voice Chat feature in applications will be included in NEX 4.6.0 and later. For more information about the NEX library API, see the NX NEX Manual.
