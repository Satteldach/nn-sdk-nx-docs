2.4 Handling at Release

No specific steps are required for releasing an application that supports Matchmaking Voice Chat.

The same settings that were configured in the development environment are applied in the production environment. For more information about configuring settings in the development environment, see 2.3.1 Development Environment Server Settings for Matchmaking Voice Chat.

Info

Previously, you needed to submit a request file before the release, but that step is no longer necessary.
