3 Voice Chat for Transmitting Audio Data in Switch Applications

Overview

This section describes the support required to use the audio input from a device connected to the Switch for voice chat, as opposed to using Matchmaking Voice Chat.

Registering to Use Voice Chat Functionality

In Nintendo Developer Portal > MY PRODUCTS, select the product, select Releases > Features > Program Specifications > Supports voice chat, and then register the necessary information.

Testing Devices That Allow Microphone Input

Test at least two types of microphone input devices available to the user, testing them in every play mode supported by the application.

Customer Support for Devices That Allow Microphone Input

Nintendo cannot respond to inquiries from users about devices that allow microphone input for the application. Publishers must appropriately support inquiries from users.

Relevant Guidelines

Comply with the following guidelines.

  • 0069: Complying with parental controls
  • 0139: Implementing in a way that does not depend on specific characteristics of any supported microphone
  • 0162: Prohibition of implementing features that save microphone input audio
Info

If you plan to release your application in the United States, and your application implements certain communication features, your application must comply with the Twenty-First Century Communications and Video Accessibility Act (CVAA). The CVAA is a United States law that obligates developers to enhance accessibility for people with disabilities. If you have questions about how to comply with the CVAA in your application, please consult your own legal department or external legal counsel.
