7.1.1 Installing From a PC

Connect the EDEV to a PC and use DevMenuCommand to install the application on the EDEV.

  1. Connect the EDEV to a PC.
    For more information about connecting the EDEV to a PC, see 6.1 Connecting the EDEV and PC.

  2. On the PC, from the Start menu, select Nintendo Target Manager or Nintendo Target Manager 2.

    Target Manager starts.

  3. Right-click the target pane and select Add Target from the shortcut menu.

  4. Select the EDEV to connect and click OK or Add.
    Check the serial number of the EDEV to connect and select it.

    The selected EDEV is added in the Target pane.

  5. Right-click the added EDEV and select Connect to Target from the shortcut menu.

    If connection succeeds, the status changes to Connected.

  6. Display the NintendoSDK installation directory in Explorer.

  7. In the address bar, type cmd and press ENTER.

    The Command Prompt window appears.


  8. At the command prompt, enter the following command to install the NSP file.
    For %NspFile%, enter the absolute path for the NSP file to install.
    When using an SDK version earlier than NX Add-On 1.0.0, change DevMenuCommand.nsp to DevMenuCommand.nca when entering the command.

    .\Tools\CommandLineTools\RunOnTarget.exe .\TargetTools\NX-NXFP2-a64\DevMenuCommand\Release\DevMenuCommand.nsp -- application install %NspFile%

    Installation completes, and SUCCESS is displayed at the command prompt.

    Info

    For more information about DevMenuCommand, see NintendoSDK Documents > Features > Controlling the Development Hardware > DevMenuCommand.
