4.4 Important Information During Wireless Communication

Make sure that you review the following important information before using wireless communication with the EDEV.

WLAN Access Point Channels

Wireless communication does not work when the WLAN access point is selecting channels in the following ranges.

  • Channels 100 to 140
  • Channels 149 to 165 (the band primarily used by North American specification WLAN access points)

Make sure that the listed channels are not being selected when the WLAN access point channel settings are being configured automatically.

The WLAN access point specifications can result in automatic channel switching.

Distance During Use

Wireless performance can degrade as a result of interference and stronger input if the distance between Nintendo Switch development hardware units or between Switch consoles and the WLAN access point is too close.
If that is the case, separate the devices by at least one meter.
