8.3 Updating the EDEV Firmware

A tool for updating the EDEV console was added in NX Add-On 4.3.0 and later. (The PC tool, however, was added in NX Add-On 4.4.1.)
Using this update tool maintains all applications installed on the device and all of the settings. It can be used by itself to update the firmware.

For more information about this update tool, see NintendoSDK Documents > Guide to Setting Up the Environment > More Information > Updating With System Update.
