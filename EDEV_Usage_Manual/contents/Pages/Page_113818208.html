9.3 EDEV Touch Panel Is Not Responding

The EDEV touch panel, like the touch panel of the Switch retail unit, does not respond to the following actions.

  • Fingertip input
  • Input using a fine-tipped, electrically conductive (such as metal) stylus

The touch panel cannot be used when the EDEV is in TV mode. Switch the EDEV to handheld mode.

For more information about switching to handheld mode, see 8.4 Switching Between Handheld and TV Modes.
