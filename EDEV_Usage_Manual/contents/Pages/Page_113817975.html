Before you use the EDEV, check that your bundle contains all of the following items.

  • EDEV main unit (HAT-002) or EDEV-D main unit (HAT-002(-01))
  • Joy-Con™ (L) (HAC-015), Joy-Con™ (R) (HAC-016) (Joy-Con (L), Joy-Con (R))


  • Nintendo Switch dock (HAC-007)
    Use the dock by inserting the EDEV as follows.



  • Relay Box (HAT-004) or Relay Box-D (HAT-004)
    Used to connect the EDEV to a PC or a power source.
    Relay Box and Relay Box-D can be distinguished by housing color and labeling.


    		 Housing Color Label
    Relay Box Gray RelayBox
    Relay Box-D Red RelayBox-D

    Note

    The EDEV Kit contains an EDEV unit and Relay Box, while the EDEV-D Kit contains an EDEV-D unit and Relay Box-D.
    To avoid malfunction, use only the packaged components.

  • AC adapter (HAC-002)
    Used to supply power to the Nintendo Switch dock, or to charge the EDEV or the Joy-Con.
  • Joy-Con charging grip (HAC-012)
  • Joy-Con strap (HAC-014)
  • Stand
  • HDMI Cable
  • USB charging cable
  • USB Micro-B to Micro-A cable
    Used to connect the relay box to a PC.
  • Bundled items list
Info

In addition, a display with HDMI input is also required when using TV mode.

The maximum resolution for the Switch (during TV mode) is 1080p.
