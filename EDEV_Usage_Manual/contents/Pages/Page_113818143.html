5.6 Pairing the Joy-Con

To use a Joy-Con that has never been connected to the EDEV, you must register that controller in the EDEV, which is the process of pairing.

The EDEV can register the information for as many as 10 controllers, which is the same as the Switch retail unit.

Before using the Joy-Con, perform the following procedure to pair the Joy-Con.

  1. Turn the EDEV on.
    For more information about turning the EDEV on, see 5.2 Turning the EDEV On and Off.

  2. Confirm that DevMenu is displayed in the EDEV screen or that an application is running.

  3. Attach the Joy-Con to the EDEV console.
    Attach Joy-Con (R) to the right rail and Joy-Con (L) to the left rail.

    The Joy-Con pairing completes within one second.

  4. Check whether you can operate the Joy-Con.

    When pairing is complete, you can operate the Joy-Con attached to the EDEV console.

  5. Remove the Joy-Con from the EDEV console.

  6. Check the Joy-Con player LED.

    If pairing is complete, the player LED lights up corresponding to the assigned controller number.

    Info

    For more information about player LED lighting patterns, see the Nintendo Switch Controller Guide.
    If the Joy-Con still do not respond after completing this procedure, see 9.7 Unresponsive Joy-Con.
