8.1 Restarting the EDEV

If you need to restart the EDEV during application development or at other times, perform the following operations.

Restarting From DevMenu
  1. In the upper-right corner of the screen, select the power icon.
  2. Select Reboot.


Restarting When the EDEV Is Connected to a PC

For more information about connecting the EDEV to a PC, see 6.1 Connecting the EDEV and PC.

  1. On the PC, from the Start menu, select Nintendo Target Manager or Nintendo Target Manager 2.

    Target Manager starts.
  2. Nintendo Target Manager:
    • Right-click the SDEV you want to restart and select Soft Reset from the menu.
  3. Nintendo Target Manager 2:
    • Right-click the SDEV you want to restart and select Power > Restart from the menu.
