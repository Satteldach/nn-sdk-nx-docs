9.12 Cannot Connect to EDEV From Target Manager

If you cannot connect to the target EDEV from Target Manager (Nintendo Target Manager or Nintendo Target Manager 2), it might be because the communication protocol generation (htc-generation) is not configured correctly.

If you are using Nintendo Target Manager, you must set htc-gen1 in both the host PC settings and the EDEV settings.
If you are using Nintendo Target Manager 2, you must set htc-gen2 in both the host PC settings and the target settings.

To check and change the communication protocol generation setting, use the HtcGenerationManager tool. (For more information, see NintendoSDK Documents > Guide to Setting Up the Environment > NX > Using Target Manager 2 > Starting HtcGenerationManager.)
