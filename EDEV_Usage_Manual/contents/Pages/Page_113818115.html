4.2 Components

The various components of the EDEV, the Nintendo Switch dock, and the Joy-Con are named the same as they are in the retail unit. See the Nintendo Switch Overview.

This section describes the names of the various parts of the relay box.

Relay Box
Top View

Number Name Description
1 TV output LED

Illuminates when the relay box is correctly connected to a TV.
In addition, this LED flashes when the relay box detects an error.

It lights up briefly when the relay box receives power from the AC adapter, and when it is connected to the EDEV.
2 Console connector

Connects to the USB Type-C™ connector on the bottom of the EDEV.

The plug can be connected in either orientation.
Front

Number Name Description
3

HDMI connector

Used to connect an HDMI cable.

Connect the cable to a TV to send audio and video output from the EDEV to the TV in TV mode.
4 USB port (supports USB 3.0 Micro-B) Connects the relay box to a PC via a USB Micro-B to Micro-A cable.
5 AC adapter port

Used to connect the bundled AC adapter.

The plug can be connected in either orientation.
