9.9 Cannot Detect USB Devices

If the USB device cannot be detected, check the settings and connection according to the type of USB device connection.

Info

If a USB-Ethernet adapter is connected for internet communication, consider using wireless communication.

If the USB Device Is Connected Via the Nintendo Switch Dock

If the USB device is connected to the Nintendo Switch dock, check the following.

  • Is the USB device properly connected to the Nintendo Switch dock?
  • Is the EDEV properly attached to the Nintendo Switch dock?

For more information about connecting USB devices, see 6.2 Connecting the EDEV and USB Devices.

If you do not find any problems while checking these things, perform the following operations.

  1. Unplug the AC adapter that is connected to the Nintendo Switch dock from the power outlet.
  2. Unplug the USB device from the Nintendo Switch dock.
  3. Remove the EDEV from the Nintendo Switch dock.
  4. Restart the EDEV.
    For more information about restarting the EDEV, see 8.1 Restarting the EDEV.
  5. Plug the AC adapter that is connected to the Nintendo Switch dock into the power outlet.
  6. Attach the EDEV to the Nintendo Switch dock.
  7. Connect the USB device.

If the USB device still cannot be detected after completing these operations, confirm that power is being supplied to the USB port by connecting another USB device to the Nintendo Switch dock that lights up when power is supplied.
If power is not being supplied to the USB port, the EDEV might be damaged. For more information about requesting a repair, see 10 Repair Contact.

If the USB Device Is Directly Connected to the EDEV Console

Check that the USB device is properly connected to the EDEV.
For more information about connecting USB devices, see 6.2 Connecting the EDEV and USB Devices.

If there were no problems with the connection, restart the EDEV.
For more information about restarting the EDEV, see 8.1 Restarting the EDEV.

If the USB device still cannot be detected after completing these operations, confirm that power is being supplied to the USB port by connecting another USB device to the EDEV console that lights up when power is supplied.
If power is not being supplied to the USB port, the EDEV might be damaged. For more information about requesting a repair, see 10 Repair Contact.
