16.0

2021-06-21

 Changes
  • Roles and Usage Requests
    In Roles, under both Role Types and Quick Reference Chart for Role Types, added that users with the Reviewer role or higher can perform the operation to end delivery of data that is being delivered.
  • Data Delivery
    Added a table and the following content to Updating Data > Stopping Delivery of Delivered Binaries.
    • The Expire operation to end delivery can now be performed by users with the role of Reviewer or higher.
    • When the new binary is approved, the delivery end date and time of the delivered binary is set automatically.
    • In the future, there will be a change to the roles that are permitted to change the delivery end date and time for a binary whose status is Publishing.
  • Test Delivery of News Items
    In Test Delivery of News Items, under Step 1: System Settings, noted that the use of a retail unit is required.
    In Troubleshooting for Test Delivery of News Items > Checklist > Q07, changed the procedure from checking whether a passcode has been entered to checking the current system settings.
  • Configuring the System for Test Delivery
    In Introduction, added a note in the Note block about the occurrence of 2141-0005 errors.
    Added Checking the System's Settings.
  • BCAT WebAPI
    In Authentication > V1 Authentication > Setting Up an Access Token, deleted the Info block describing how to get an NDID access token.
  • FAQ
    In the answer for News Delivery FAQ > N-5, added an Info block noting that the problem is often that the system has not been configured for test delivery.
