5.2 Test Delivery of Data

Test Delivery of Data

This section describes the procedure for test delivery of data for applications that support BCAT data delivery to Switch consoles.

Step 1: System Settings

Refer to 5.3 Configuring the System for Test Delivery and configure the Switch system settings.

Step 2: Adding Delivery Targets

Refer to 5.4 Adding Test Delivery Targets and add the following information to the BCAT Management Tool.

  • The Nintendo Account or the account for China
  • The Switch system serial number
Info

The specified information for the Nintendo Account or the account for China is used to notify the Switch system about the start of file delivery and to trigger background synchronization.

If the application has immediate synchronization, an account other than the Nintendo Account or the account for China added in this step can also receive the test delivery data. In that case, there is no need to add a Nintendo Account or an account for China.

Step 3: Adding Data

See 4 Data Delivery and add data to the BCAT Management Tool.

In test delivery, files that are not currently being delivered can be set for delivery. As a result, for example, pre-delivery review is not necessary.

Step 4: Registering IP Addresses

See 2.8 Restricting IP Addresses and register the Switch system’s global IP address in the BCAT Management Tool.

Step 5: Delivery

Perform the following operations.

  1. In the BCAT Management Tool menu, select Test Delivery > Manage Test Delivery.
  2. Select Create Test Delivery List.
  3. Follow the instructions on the screen and select a file for test delivery.
  4. Follow the instructions on the screen and select a delivery target (a Nintendo Account or an account for China, and a Switch system serial number).
  5. Operate the Switch console that will be the delivery target and connect it to the internet. Turn on the power, wake up the console, and unlock the screen.
  6. Return to the BCAT Management Tool, and select Save and Deliver to start test delivery.

Stopping Test Delivery of Data

This section describes the steps for stopping test delivery of data.

  1. Refer to 5.3 Configuring the System for Test Delivery and delete the test delivery settings from the Switch console.
  2. In the BCAT Management Tool menu, select Test Delivery > Manage Test Delivery.
  3. Click the Delete button for the list that used test delivery.
