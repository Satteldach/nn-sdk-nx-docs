5.3 Configuring the System for Test Delivery

Introduction

This page describes the procedure for configuring the system for test delivery.
Prepare the following items in advance.

  • System
    • If testing the delivery of data, a development hardware device or a retail unit.
    • If testing the delivery of News items, a retail unit.
  • Internet connection environment
Note
  • The system configured for test delivery receives test deliveries for both News and data.
    The system cannot receive test delivery of only one or the other.
  • If a 2141-0005 error occurs on a system that has been configured for test delivery, try re-entering the passcode using the procedure described in Configuring the System for Test Delivery, or restore the normal system settings using the procedure described in Deleting the Configuration for System Test Delivery.

Configuring the System for Test Delivery

Step 1: Entering Hidden Commands

Use the following procedure to enter a hidden command.

Adjust the system volume before proceeding to make sure that you do not miss the brief sound effect played in step 4.


  1. On the HOME Menu, in System Settings, select Internet Settings.
  2. Display the network list screen.
  3. Press the + Button.
  4. While pressing the + Button, hold down the L Stick for 3 seconds.
    When the command has been successfully entered, a short, soft popping sound is played.


Info
  • To return to the previous screen when no sound effect was played, press the B Button one time to display the network list screen again. Then try to enter the hidden command again.
  • Hidden commands can also be entered by simultaneously holding down either the + or - Button and holding down either the L or R Stick.

Step 2: Connecting to the Network

From the network list screen, select a network to connect to and then connect to the network by entering the password, as you would for ordinary internet settings.

When a Hidden Command Is Successfully Entered

The following dialog box closes automatically and the screen to enter the passcode appears when the connection goes through.

Proceed to step 3.

When a Hidden Command Is Not Successfully Entered

Entering a hidden command has failed when the preceding dialog box does not automatically close even if the connection has ended, and the display of the dialog box changes as follows.

Return to step 1, and enter the hidden command again.

Step 3: Entering Passcodes

Enter a passcode corresponding to the system type and platform region on the following screen.

The system gets settings from the server that correspond to the passcode, and saves them to the system.

Info

The platform region is the region where the system is used, set for the system itself. The two options that are currently available for the platform region are Global and China. For more information, see NintendoSDK Documents.
In the production environment, Nintendo Switch consoles sold for China are configured with China as the platform region, and Nintendo Switch systems sold for other regions are set to Global.

When Passcode Input Is Successful

The following type of dialog box indicating success appears when configuration was successful. Follow the instructions in the dialog box and turn off the system.

When Passcode Input Fails

The following type of dialog box indicating failure appears when configuration failed. The following are the primary reasons for configuration failures.

  • The passcode was not entered correctly.
  • Communications are restricted by a network administrator.
  • If the system is being managed by Nintendo: Due to special circumstances, the development hardware is connected to a server environment other than the dd1 development environment, or the retail unit is connected to a server environment other than the lp1 production environment.
    • If this happens, reinitialize the system before proceeding.

Info

You can investigate the cause of the problem by searching for 2141-yyyy in the Error Code List documentation.

Contact Nintendo if you cannot resolve the problem.

Deleting the Configuration for System Test Delivery

This section describes the procedures for deleting a configuration for test delivery from the system.

  1. Open the screen for entering the passcode using the procedure described previously.
  2. Enter delete as the passcode.
  3. A dialog box indicating that the configuration was deleted appears. Follow the instructions in the dialog box and turn off the system.
Info

Test delivery configurations can also be deleted by initializing the system.

However, using Initialize Console Without Deleting in recovery mode does not delete this information.

Checking the System's Settings

You can determine whether a system has been configured for test delivery by checking the passcode entry screen.

To display the passcode entry screen, enter the hidden command described previously.

If the system has been set for test delivery, the system's current settings are displayed using dimmed text in the preview field, as shown below.

If the preview field does not show dimmed text, the system is set with the default settings. When that is the case, the system is not configured for test delivery.
