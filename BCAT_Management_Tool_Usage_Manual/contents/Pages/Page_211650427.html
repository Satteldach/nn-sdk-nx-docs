Setup FAQ

ID Question Answer Reference
I-1 I don't know the URL of the BCAT Management Tool.
  • For more information, see 2.1 Logging In to the BCAT Management Tool.
  • Use separate URLs depending on the purpose.


I-2 I can't log in to the BCAT Management Tool.
  • Use the NDID to log in to the BCAT Management Tool.
  • If you do not have an NDID, send a NDID issue request to the administrator in your organization.
  • For more information about finding out who your company administrator is, see Contact Your Company Admin.
  • Nintendo Developer Portal > ADMIN > User Management
    • The organization's administrator can issue NDIDs on these pages.

News Delivery FAQ

ID Question Answer Reference
N-1

I can't locate the channel I'm looking for in the News Delivery menu.
  • The channels displayed in News Delivery in the BCAT Management Tool are managed in NCMS. Check the content of the information you have submitted in NCMS.
  • Confirm that an appropriate role has been assigned to the NDID used to log in to the BCAT Management Tool.
  • The News Delivery menu is not displayed because the BCAT Management Tool cannot deliver News to the development environment (dd1 environment).
  • 2.2 Roles and Usage Requests
  • NCMS
N-2 I can't find the product that I want to add to Related Products.
  • Only products that include all delivery countries specified for the News item as release countries can be added to Related Products. Check the target countries where the News item will be delivered.
  • Check the delivery settings of the product in NCMS.
  • 3.2 Related Products
N-3

I can't enter a URL for the Video URL when creating a News item.

For example, the error "The specified domain is not responding" is displayed. Alternatively, I cannot play that video on the Switch.

  • Videos that you want to include in News must be submitted and approved on NCMS.

  • NCMS will generate a dedicated URL after the video has been approved. Enter this URL in the BCAT Management Tool.
  • NCMS
N-4 I cannot request a pre-delivery review after creating the News item.
  • A user with the Manager role has disabled pre-delivery review for that channel.
  • Channel Details
N-5 Failed to receive test delivery.
  • See Troubleshooting for Test Delivery of News Items in 5.1 Test Delivery of News Items.
Info

In the troubleshooting described on that page, the problem is often that the system has not been configured for test delivery.
You can check whether the system has been configured for test delivery using the procedure described in 5.3 Configuring the System for Test Delivery.
N-6 Cannot receive email notifications.
  • See the 2.5 Email Notifications section and check the Mail Settings menu.
  • Check the spam folder of the Mailbox on your PC.
  • Consult with the administrator for your email address.


N-7 Production delivery fails.
  • Delivery Target Country Is Not China
    • Verify the country the News is being delivered to, and the country of residence associated with the Nintendo Account linked to the Switch console.
  • Delivery Target Country Is China
    • Verify that a user account linked with an account for China exists on the Switch system.
  • See 3 News Delivery > If the News Cannot Be Received After the Delivery Start Date and Time Has Arrived.

Data Delivery FAQ

ID Question Answer Reference
D-1 I cannot find the target application in the Data Delivery menu.
  • The applications displayed in Data Delivery in the BCAT Management Tool are managed in OMAS. Verify that you have applied to use BCAT data delivery in OMAS.
  • Check that the target application can be viewed in OMAS with the NDID you entered to log in to the BCAT Management Tool.
  • If you can view the target application in OMAS, in the My Profile menu, click Request Permissions Synchronization With OMAS to refresh the permissions cache.. For more information about the cache, see 2.2 Roles and Usage Requests.
  • OMAS
  • 2.1 Logging In to the BCAT Management Tool
D-2

I can't find the interface for adding data even though the target application is displayed in the Data Delivery menu.
  • The application request information in OMAS may not be shown in the BCAT Management Tool.
  • From the BCAT Management Tool menu, select Manage BCAT Usage Requests and then click Get and Apply BCAT Usage Request to apply the information.
  • A user must have the Manager role in the BCAT Management Tool to perform these operations.
  • OMAS
  • 2.2 Roles and Usage Requests
D-3

"Could not find valid BCAT usage request" is displayed when I select Manage BCAT Usage Requests.
  • The request information can only be applied when the status of the application request information in OMAS is In Development or later.
  • The application request information status may be rolled back due to updating the request or other issues. For more information, see the OMAS Help.
D-4 I can't rename a directory.
  • Directories cannot be changed.
  • Delete the directory, and then create a new directory.
  • Directories can only be deleted if there are no files being delivered in the directory.
D-5

When performing immediate synchronization from the application, error code 2122-2403 (ResultServerError403) occurred and communication failed.
  • See 2.8 Restricting IP Addresses, and register and permit access to the global IP address of the internet connection for the Switch in the BCAT Management Tool.
  • If you are testing delivery, see 5.2 Test Delivery of Data to make sure you have specified the serial number of the Switch console on the delivery list.
  • Contact the internet connection administrator.
