3.4 Channel Details

Channel Details

In addition to the settings for each news item, settings for each channel are also handled in the BCAT Management Tool.
Settings for each channel can be performed in the News Channel Details menu. The Manager role is required for operating that menu.

Special Item Descriptions

Setting Description
Run a Pre-Delivery Review

The value that controls running the pre-delivery review.

  • true
    • Run pre-delivery review.
    • Specify this value for a double-check by users with both the Editor and Reviewer roles.
  • false
    • Do not run pre-delivery review.
    • Only specify this value if entrusting the work to users with the Editor role.
