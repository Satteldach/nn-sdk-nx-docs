3 News Delivery

News Delivery

This section describes how to create and deliver News.

Note

If you complete the procedure described later in Creating News Items in the production environment (the lp1 server environment), News is delivered to all target Switch systems in that production environment.
We strongly recommend that you take the following steps to ensure that News is not delivered with erroneous content or at the wrong time.

  1. Create the News in the production environment.
  2. Test deliver the News in the production environment and check the content of the News using the production hardware.
  3. Deliver the News in the production environment.
Info

You cannot create and deliver News or conduct test delivery in the development environment (dd1 server environment).

Delivering News

Step 1: Selecting the Channel

  1. From the BCAT Management Tool menu, select News Delivery. The list of channels is displayed.
  2. Select the channel for operations.

Step 2: Creating Directories

  1. Select the channel for operations. The list of directories is displayed.
  2. If no directories exist, select Create New Directory to create a directory.
Info

The directory name does not affect News delivery results. Create multiple directories for each News type to manage the News items as needed.

Step 3: Creating News Items

  1. Select the directory.
  2. Select Create New to begin creating a News item.
  3. Specify the content for the item, using the following references.
    • Nintendo Switch News Delivery Guide > News Delivery Flow > Creating News (Japanese, English)
    • Nintendo Switch News Delivery Guide > BCAT Management Tool: Setting Items and Setting Rules (Japanese, English)
  4. Click the Add button to finish creating the News item.


News Entry Form

Information to Enter for Each News Item

Some information for News items only needs to be entered one time for each News item.

You must pay particular attention to the following items.

Setting Description
Delivery Start Date and Time

Specify the date and time to start delivery of the News item from the BCAT server.

News items that have completed the pre-delivery review in addition to either the Nintendo review or the Tencent review are automatically delivered after this date and time.

Info

There is a lag of approximately 10 minutes between the start of delivery and the time when the News can actually be displayed on the Switch system.

Delivery End Date and Time

Specify date and time to end delivery of the News from the BCAT server.

The News will no longer be delivered from the server after this date and time.

Switch devices that have already received the News are not affected when this date and time arrives. If necessary, specify a value for Delivered News Display Term (described later).

The default end date is 30 days after the start of delivery.

Manually change this value if you want to end delivery any time other than 30 days after the start.
Delivered News Display Term

Set a date and time to stop displaying the News item on the user's Switch system.

Specify a News display term when you must restrict the display period for reasons such as copyright.

If no value is specified, the News can continue to be displayed as long as the user has saved the News to the Switch system.

To delete (hide) a News item that was delivered by mistake, change this value to a past date and time and redeliver the News item.

Note

News that has passed the Display Expiration of the Delivered News cannot be overwritten.

For example, after you change the display period to a past date to temporarily hide News that was delivered by mistake, you can no longer revise and deliver (display) this News item. In this case, create a new News item.
Alternate Language

Specify an alternate language to download if the News item does not have the language that the Nintendo Switch system requires.

Do not change this default value without a good reason. If you cannot avoid changing it, specify just one of the other language choices.

Info

The Switch system only downloads News items from the server that match both the country of the Nintendo Account (associated with the user account) and the system language settings.

If the News item written in the language set in the system language settings does not exist on the BACT server, the News is not downloaded even if the country of the Nintendo Account matches.

However, if an alternate language is specified for News items, News items written in this alternate language are downloaded in place of the language that matches the system language settings.

Information to Enter for Each Language

Some information for the News item must be entered for each language.

You must pay particular attention to the following items.

Setting Description

Video URL

This video is displayed in a large size at the top of the News item.

Specify the URL of a video uploaded as an eShop Video in NCMS.

Videos must be approved by Nintendo in NCMS, and have statuses set to Process Completed.

Note

After the Delivery End Date and Time set in NCMS has passed for a video, it can no longer be played from the News item.

If you plan to post a video set with a Delivery End Date and Time to a News item, we recommend that you set the value of Delivered News Display Term for the News item so it occurs before this Delivery End Date and Time.
Main Image

Upload and specify the image to display in the body of the News.

For more information about the image format, see the Nintendo Switch News Delivery Guide.

If a video URL has been specified, the main image will be used as a thumbnail for the video. If you specify a main video but do not specify a main image, the image registered in NCMS is used as the thumbnail.

Info

You can specify up to two main videos or main images.

Main images that are treated as thumbnails for main videos, however, are not considered part of this limit.

For example, you can add the following four items at maximum: two main videos and two thumbnail images for each video.
Body

You can enter up to 5,000 characters.

To display a portion of the text in bold on the Switch system, surround that portion with the tags <strong> and </strong>.

The tags are counted in the character count. No other tags can be used.

Step 4: Verifying News Items

  1. Select Preview and verify the emulation results on the Switch system.
  2. Select Edit and revise information as needed.
Note

The emulation results in the preview have a different appearance from their appearance on the actual Switch system.

Make sure that you perform test delivery before actual News delivery and verify the actual appearance of the News item on the Switch system.

Step 5: News Delivery Request

  1. Select Request Pre-Delivery Review.
  2. The News becomes available for delivery after a user in the Reviewer or Manager role approves the review.
  3. The News is automatically delivered at the delivery start date and time.
Note

If the News is subject to 2.4 Nintendo Review - Tencent Review, it is not delivered until the review is approved by a reviewer at Nintendo.

Updating News

For more information, see the Nintendo Switch News Delivery Guide > Workflow for News Delivery > Revisions After Delivery (Japanese, English).

Deleting News

Deleting Undelivered News

You can delete undelivered News using the BCAT Management Tool.

Select the target News in the BCAT Management Tool and follow the instructions on the screen to delete it.

Deleting Delivered News

News that has already been delivered cannot be deleted in the BCAT Management Tool.

To revise News that has already been delivered, deliver the News item again according to the preceding Updating News section.

To delete delivered News items from the Switch system, revise the date in Delivered News Display Term to a past date and deliver the News item again.

If the News Cannot Be Received After the Delivery Start Date and Time Has Arrived

If the News cannot be received by the delivery start date and time, try the following procedure.

  1. Wait ten minutes after the delivery start date and time.
  2. Confirm that the channel has been subscribed to.
  3. Close the application.
  4. If the Switch system has a wireless connection to the internet, enable airplane mode and wait 15 minutes. After that time has passed, disable airplane mode.
  5. Put the Switch system in sleep mode and then wake it up.
  6. If the Switch system is not connected to the internet, establish the connection.
  7. Wait ten minutes while connected to the internet.

Similar guidance can be found on the Nintendo website in Japan.
