5 Test Delivery

About Test Delivery

A test delivery mechanism is provided for experimentally delivering created news and data.

When using test delivery, you can deliver news and data items only to specific Switch systems and network service accounts.

Use test delivery in the following scenarios.

  • Checking the actual appearance on a Switch system in advance, ensuring that news and data items with incorrect content are not being delivered to users in the production environment
  • Debugging multiple delivery states concurrently when debugging an application that supports data delivery
    • For example, to debug a summer online event and winter online event in parallel
