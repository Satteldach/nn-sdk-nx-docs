5.1 Test Delivery of News Items

Test Delivery of News Items

This section describes the process for test delivery of News items and receiving them on the Switch system.

Step 1: System Settings

Refer to 5.3 Configuring the System for Test Delivery and configure the Switch system settings.

You must use a retail version of the Switch console, not a development hardware device.

Step 2: Adding Delivery Targets

Refer to 5.4 Adding Test Delivery Targets and add the following information to the BCAT Management Tool.

  • The (production environment) Nintendo Account or the account for China.
  • The Switch system serial number
Info

The specified Nintendo Account or the account for China will be used to download News to the Switch console.

Step 3: Adding News

Refer to 3 News Delivery, and add News to the BCAT Management Tool.

In test delivery, News that is not currently being delivered can be set for delivery. As a result, for example, pre-delivery review is not necessary.

Step 4: Registering IP Addresses

See 2.8 Restricting IP Addresses and register the Switch system’s global IP address in the BCAT Management Tool.

Step 5: Delivery

Perform the following operations.

  1. In the BCAT Management Tool menu, select Test Delivery > Manage Test Delivery.
  2. Select Create Test Delivery List.
  3. Follow the instructions on the screen and select the News for test delivery.
  4. Follow the instructions on the screen and select a delivery target (a Nintendo Account or an account for China, and a Switch system serial number).
  5. Select Save and Deliver and begin test delivery.

Step 6: Following and Receiving the Channel

  1. If power for the Switch system is off, turn it on.
  2. Wake the Switch system, unlock the screen, and display the full launcher screen.
  3. Exit any applications that are running on the Switch.
  4. Connect the Switch to the internet. If the Switch is not configured to connect to the internet automatically, you must configure the system settings.
  5. Select Follow Channel on the Switch system. For more information, see the Nintendo website in Japanese or English.
  6. Use the BCAT Management Tool to select the created test delivery list. After selecting the list, select Deliver.

Stopping Test Delivery of News Items

Perform the following steps to stop test delivery of News items.

  1. Refer to 5.3 Configuring the System for Test Delivery and delete the test delivery settings from the Switch console.
  2. In the BCAT Management Tool menu, select Test Delivery > Manage Test Delivery.
  3. Click the Delete button for the list that used test delivery.

Troubleshooting for Test Delivery of News Items

If News items are not being received in this test delivery, refer to the following checklist and check each item in order from Q01.

When contacting Nintendo, attach the results of going through this checklist to make it easier for Nintendo to answer your questions.

Checklist

  • Q01. Check the Switch system serial number. Is the serial number registered in the BCAT Management Tool?
  • Q02. Check the email address of the Nintendo Account linked to the Switch system. Is the serial number registered in the BCAT Management Tool?
  • Q03. Check the country of residence of the Nintendo Account linked to the Switch system. Is it included in the News Delivery target countries?
  • Q04. Check the test delivery list URL. The URL is in the format of https://live.bcat.mng.nintendo.net/test_distributions/★.
  • Q05. Has this serial number and this Nintendo Account (or account for China) been selected in the test delivery list?
  • Q06. Is the global IP address of the internet connection for the Switch registered in the BCAT Management Tool? For more information, see 2.8 Restricting IP Addresses.
  • Q07: Is the Switch system configured for test delivery? (To check, see 5.3 Configuring the System for Test Delivery.)
  • Q08. Was the Switch system operated and the Follow Channel operation performed?
  • Q09. With the Switch system out of sleep mode and connected to the internet, select the Deliver button in the BCAT Management Tool. Are logs retained in the access log for test delivery?
  • Q10. Check the system version of the Switch system. Ideally it is the latest version.
