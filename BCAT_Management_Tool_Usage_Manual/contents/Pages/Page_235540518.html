4.1 Application Details

Application Details

In addition to the settings for each data item, settings for each application that supports data delivery are also handled in the BCAT Management Tool.
Settings for each application are performed in the Application Details menu. The Manager role is required for operating that menu.

Special Item Descriptions

Setting Description
Data Delivery Cache Storage Size

The value last obtained from OMAS is displayed in the BCAT Management Tool.

For more information about getting values from OMAS, see Initial Setup in 4 Data Delivery .

Passphrase

The value to set in the BcatPassphrase element of the application's NMETA file is displayed.

Share this value only with application developers and debugging parties.

This value cannot be changed.

Run a Pre-Delivery Review

The value that controls running the pre-delivery review.

  • true
    • Run pre-delivery review.

    • Specify this value for a double-check by users with both the Editor and Reviewer roles.


  • false
    • Do not run pre-delivery review.
    • Only specify this value if entrusting the work to users with the Editor role.
Required Application Version

The value for restricting connections from applications that are out of date.

The default value is 0.

To deliver data only to systems with the latest application patch applied, specify the same value as the release version of that application patch.

Both immediate and background synchronization fail in applications with release versions that do not match that value. Also, if the error that occurs during immediate synchronization (for example, an nn::Result corresponding to error code 2122-0032) is passed to the error viewer applet, a message prompting update of the application is displayed.

Note

If this value is accidentally changed before the application patch is being delivered, it will confuse the application users, who will not know how to resolve the issue.

Be careful when changing this value.

Note

Even if this value is changed, the change is not immediately applied on the Switch. Changes are applied to the Switch at either of the following times.

  • When background synchronization is performed as a result of starting (or ending) delivery of the next binary after the value is changed
  • When there is immediate synchronization of the application approximately and at least ten minutes after the value is changed
Service Status

This value is for notifying Switch systems of the service status.

The default value is in_service.

  • in_service
    • Set when data delivery service for the application is being provided.
  • expired
    • Set when data delivery service for the application has ended.
    • Both immediate and background synchronization fail when settings have expired. Also, if the error that occurs during immediate synchronization (for example, nn::Result corresponding to error code 2122-0041) is passed to the error viewer applet, a message indicating that the service has expired is displayed.
Note

Even if this value is changed, the change is not immediately applied on the Switch. Changes are applied to the Switch at either of the following times.

  • When background synchronization is performed as a result of starting (or ending) delivery of the next binary after the value is changed
  • When there is immediate synchronization of the application approximately and at least ten minutes after the value is changed
