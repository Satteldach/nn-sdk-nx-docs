5.4 Adding Test Delivery Targets

Adding Test Delivery Targets

Test delivery must be focused on specific targets by adding the following information to the BCAT Management Tool.

  • The Switch system serial number
  • Nintendo Account or account for China linked to a user account on that Switch console.

The preceding information is managed independently for each News channel, and each application that supports data delivery.

Registering Serial Numbers

  1. In the BCAT Management Tool, select the News delivery channel or data delivery application for which to perform test delivery.
  2. Click the Test Delivery menu.
  3. Click Manage Test Delivery. A list of registered Switch consoles is displayed.
  4. Select Create Test Delivery List and add the serial number for the Switch system according to the instructions on the screen.
Info
  • The serial number is the value on the sticker at the bottom of the Switch system. For example, XAW03121003905 is a value in that format.
  • You can register multiple serial numbers at the same time by uploading a CSV file.
    • Use UTF-8 without BOM for character encoding in the CSV file.
    • For more information, see the tooltip in the BCAT Management Tool.

Adding Accounts as Delivery Targets

The account that you add as a delivery target varies depending on the country that is the delivery target of the News items and the data.

Delivery Target Country Kind of Account to Add
Outside of China Nintendo Account
China Account for China

Use the following procedure to add the delivery target accounts.

  1. In the BCAT Management Tool, select the News delivery channel or data delivery application for which to perform test delivery.
  2. Click the Test Delivery menu.
  3. Click Destination Account. A list of added Nintendo Accounts and accounts for China appears.
  4. Click Add account and follow the instructions to add a Nintendo Account or an account for China.
Info

Basic authentication is required to view the page for Nintendo Accounts and the page for accounts for China in the development environment (the dd1 server environment). Refer to the following information and handle accordingly.

  • Nintendo Developer Portal > Nintendo Switch > Technical Information > Information for Network Titles
