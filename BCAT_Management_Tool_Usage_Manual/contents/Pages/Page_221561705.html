2.1 Logging In to the BCAT Management Tool

Logging In to the BCAT Management Tool

To use the BCAT Management Tool, you must have a Nintendo Developer ID (NDID) and submit usage requests.

NDID

This ID is used to log in to the BCAT Management Tool.

Usage Requests

To use the BCAT Management Tool to deliver news or to deliver data, you must submit a separate usage request for each.

  • Request to deliver news to a channel.
    Submit in NCMS (Nintendo Content Management System).
  • Request to deliver data to an application.
    Submit in OMAS (Online Title Management System).

For more information about submitting a request, see 2.2 Roles and Usage Requests.

Server Environments and URLs

Multiple BCAT Management Tools are provided for each server environment. The server environments and corresponding URLs are as follows.

Server Environment Name Consoles That Can Connect Purpose URL
dd1 Development hardware

Environment for debugging data delivery.

Not used for News delivery.

By default, Switch development hardware units connect to this environment.

 https://dd1.dev.bcat.mng.nintendo.net/
sd1

Development hardware

(but only the devices belonging to Nintendo's quality control staff)

Environment for data delivery Lotcheck.

Use for adding Lotcheck data before master submission of the application that supports data delivery.

Not used for debugging delivery data.

Not used for News delivery.

 https://sd1.dev.bcat.mng.nintendo.net/
sp1

Retail unit

(but only the devices belonging to Nintendo's quality control staff)

 https://sp1.dev.bcat.mng.nintendo.net/
lp1 Retail unit

Environment for general users.

By default, retail Switch units connect to this environment.

News and data delivery can be performed.

 https://live.bcat.mng.nintendo.net/


Info

When the BCAT server is undergoing maintenance or having problems, you might not be able to access the BCAT Management Tool.
For more information about maintenance, see Network Status on the Nintendo Developer Portal.


Web Browser

When using the BCAT Management Tool, use the latest version of Google Chrome as the web browser.

Some features might not work correctly in other web browsers, including Mozilla Firefox and Internet Explorer.

Time Zone

The time in the BCAT Management Tool is displayed according to the time zone set for each user.

To change the time zone, use the time zone list box displayed on the top of the screen after logging in.
