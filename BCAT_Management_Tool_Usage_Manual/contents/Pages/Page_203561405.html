2.3 Pre-Delivery Review

Pre-Delivery Reviews

News and data created in the BCAT Management Tool is delivered after going through a pre-delivery review process.

Pre-delivery reviews are conducted by users with the role of Reviewer or higher.

Changes in Status

The status of news and data created in the BCAT Management Tool changes over time.

The following sections describe the status associated with particular user operations.

The Editor in the diagram represents the user who creates the News item or data. The Reviewer represents the user who performs the pre-delivery review.

News Delivery

Note the following.

  • When the Editor creates a News item, its status changes to Editing.
  • When the Editor requests a pre-delivery review, the status changes to Pre-Delivery Review Requested.
  • When the Reviewer approves the pre-delivery review, the status changes to Delivery Approved.
  • News items with the Delivery Approved status will automatically be delivered at the delivery start date and time.

Delivering Data

The points to note are the same as for delivering news.

Omitting Pre-Delivery Review

The pre-delivery review can be omitted for some changes to settings.

For News delivery, see 3.4 Channel Details.

For data delivery, see 4.1 Application Details.
