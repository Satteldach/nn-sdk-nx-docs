3.1 Link

Links

A News item can include a link to a specific page in Nintendo eShop or a link that starts an application. This feature is called Links.

Each News item can contain a maximum of one link.

Links That Can Be Posted

The following two types of links can be posted in News.

For more information, see BCAT Management Tool Setting Items and Rules in the Nintendo Switch News Delivery Guide.

SHOP

These are links to specific pages in Nintendo eShop.

After selecting SHOP as the link type, specify the link button text and the page to link.

Info

Conditions that can be specified as a page to link are the same as those for 3.2 Related Products.

GAME

This is a link to an application. The specified application starts if the link is selected on the News display screen.

After selecting GAME as the link type, specify the link button text and the page to link.

Info

When a link on the News display screen is selected, information based on the situation is provided to the user if the linked application does not exist on the Switch console.

For example, the Nintendo eShop page for the linked application appears.

Startup Parameters

After selecting GAME as the link type, you can attach binary files to the News item. The maximum size for binary files is 16 KiB.

Binary files are passed to the application as startup parameters. Using startup parameters makes it possible to change application behavior, such as by starting from a specific sequence.

For more information about the following areas, see the oe library manual in NintendoSDK Documents.

  • Getting Startup Parameters From an Application (Using nn::oe::TryPopLaunchParameter())
  • Debugging Applications That Get Startup Parameters (Using DevMenu to read in an NXARGS file)
Info

Although the maximum size of binary files that can be received by Switch systems with System Version 4.x.x or earlier was 4 KiB, no special handling is required by the application or the BCAT Management Tool. When an out-of-date Switch system receives a binary file exceeding 4 KiB, the user is prompted to update the system before opening the News.

Differences From Related Products

3.2 Related Products is a feature similar to SHOP-type links.

Although there is the advantage of being able to post up to 10 items using the Related Products feature, there are restrictions on which pages can be linked.

The Links feature and the Related Products feature both jump to the same page with details about the software.
