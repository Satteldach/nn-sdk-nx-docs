2.2 Roles and Usage Requests

Roles

In the BCAT Management Tool, content and operations that are available to users are managed using the concept of roles.

Roles are assigned to users (NDIDs) for each News channel, and each application that supports data delivery.

Role Types

Four types of roles are provided in the BCAT Management Tool.

    • Viewer (the lowest permission level)
      Users with this role can view channels or applications and perform test delivery.
    • Editor
      In addition to the Viewer-role permissions, this role also allows users to create News items or data and request pre-delivery reviews.
    • Reviewer
      In addition to the Editor-role permissions, this role also allows users to approve pre-delivery reviews and to end the delivery of data being delivered.
    • Manager (the highest permission level)
      In addition to the Reviewer-role permissions, this role allows users to manage the roles of other users.

Usage Requests

Users with the Manager role can assign any role to another user.

The following section describes how to make a request to use each delivery of News or data, and how to be granted the Manager role.

News Delivery

  1. The requester (A in the diagram) applies for a channel for News delivery using NCMS, and waits for approval from Nintendo.
    For more information about making a request, see the Nintendo Switch News Delivery Guide.
  2. The requester logs in to the BCAT Management Tool.
    The Manager role is automatically granted to the NDID of the requester.
  3. The requester opens the News Delivery menu, selects the channel to set, and then selects Role Management > Add User.
  4. The requester grants the roles in the BCAT Management Tool to the NDIDs of the users (B and C in the diagram) of the affiliated company (NDID terminology).

Requesting News Delivery and Assigning Roles

Info

If, due to special circumstances, you want to grant a role to a user who is not associated with the requester's company, contact Nintendo.

Automatically Granting Roles

Viewer permissions for the created channel are automatically granted to NDIDs associated with the publisher company.

The publisher company for the channel refers to the software publisher of the title associated with the channel.

Info

You cannot rescind the Viewer permission of NDIDs that belong to the publisher company.

Delivering Data

  1. The requester (A in the diagram) submits an application in OMAS to use BCAT data delivery, and awaits approval from Nintendo.
  2. The requester logs in to the BCAT Management Tool.
    The Manager role is automatically granted to the NDID of the requester.
  3. The requester opens the Data Delivery menu, selects the target application, and then selects Manage Roles > User List.
  4. The requester grants BCAT Management Tool roles to the NDIDs of the following users (B and C in the diagram).
    • Users of the affiliated company
    • Guest developers (OMAS terminology)
    • Co-developers (OMAS terminology)

Automatically Granting Roles

  • When the user logs in to the BCAT Management Tool, permissions for viewing applications are synchronized between OMAS and the BCAT Management Tool.
  • Synchronized permissions are cached on the server for 24 hours. If the cache exists, the permissions are not synchronized even if the user logs in again to the BCAT Management Tool. If you want to synchronize roles immediately, select the Request Permissions Synchronization With OMAS button in the My Profile menu.
  • The following settings are applied automatically when synchronizing permissions between OMAS and the BCAT Management Tool.
    • Users with permissions to view specific applications in OMAS are granted the Viewer role for those applications.
    • Users with the Title Administrator role (OMAS term) for specific applications are granted the Manager role instead of the Viewer role for those applications.
    • When a user can no longer view an application in OMAS, their role for that application is deleted.

Manually Granting Roles

Managers can grant any role to users that satisfy the following two criteria.

  • A user who has logged in at least once to the BCAT Management Tool in the server environment of the target application.
  • A user who has permissions to view the target application in OMAS.
Info

You can grant roles for viewing applications in OMAS (and Nintendo Developer Portal) to any user in the MY PRODUCTS menu on the Nintendo Developer Portal.

Requesting Role Changes

Users can request changes to their own roles.
A role is changed when a Manager approves the request.
