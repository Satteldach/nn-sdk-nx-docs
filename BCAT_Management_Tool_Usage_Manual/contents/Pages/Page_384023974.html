2.7 Daily Reports

About Daily Reports

The following two types of daily reports can be viewed in the BCAT Management Tool in the development environment (lp1 server environment).

  • Reports for each News channel
  • Reports for each application that supports data delivery

Viewing Daily Reports

View daily reports from the Stats > Daily Report menu.

The Viewer role or higher is required for viewing daily reports.

Daily Report Summary Period

There is a time lag for daily reports.

The values that can be viewed for daily reports are the summary results from approximately two days ago.

Items Included in the Daily Report

The daily report contains the following items.

News Delivery

Column Name Description

News ID

See the news_id description in 2.6 Delivery Log.
Summary

A summary of the News.

This value is used to identify News in the BCAT Management Tool. It is entered when creating the News item.
Delivered device count The cumulative number of Switch systems that have downloaded the News item.
Read device count The cumulative number of Switch systems on which the News item has been viewed.
Great Rate The ratio of users who selected "Great!", from the users who selected "Great!" or "Oh." as a response to the News.

Delivering Data

Column Name Description

Datafile ID

See the description for datafile_id in 2.6 Delivery Log.

Filename

The filename of the virtual file. (For more information, see 4 Data Delivery.)
Delivered device count The cumulative number of Switch systems that have synchronized (downloaded) the binary file. (For more information, see 4 Data Delivery.)
