2.8 Restricting IP Addresses

Restricting IP Addresses

For security reasons, news and data delivery to Switch systems is restricted based on global IP addresses (internet connections) for certain delivery routes.

These access restrictions are set in terms of individual News channels and individual applications that support data delivery.

Configure access restriction settings in the IP Address Restrictions menu. The Manager role is required for operating that menu. The Viewer role or higher is required for viewing that menu.

Info

Effective from the February 2019 server update, the use of this feature to specify global IP addresses is required, whereas previously it was optional.

Specifying IP Addresses

Specify at least one global IP address. Access is permitted only from specified global IP addresses.

Info
  • Specify IPv4 global IP addresses.
  • IPv4 private IP addresses cannot be specified.
  • The CIDR method can be used. For example, specifying n.n.n.0/24. n.n.n.n/32 is the same as n.n.n.n.


Note

In addition to using the specified global IP address, you must perform the following steps to appropriately handle news and data.

  • Set test delivery in the Switch console and BCAT Management Tool during test delivery of news and data.
  • Set a passphrase to applications (NSP files) when delivering data.


Checking the Global IP Address

You can check the global IP address of the Switch console by selecting HOME Menu > System Settings > Internet > Test Connection and running a connection test.
