4.2 Checking the Size of the Data Being Delivered

The BCAT Management Tool has features for checking the use rate of data delivery cache storage during actual delivery, and the total data size during test delivery.
These features can be used to check whether additional data would exceed the size of data delivery cache storage.

Checking the Data Delivery Cache Storage Use Rate During Actual Delivery

The use rate of data delivery cache storage is displayed in the form of a line graph on the Manage Data Delivery page.

The graph shows the amount of data currently being delivered as a percentage of the total size of data delivery cache storage.

Info

The ratio is calculated via the following formula.

  • (B-C)/(A-C)
    • A: The data delivery cache storage size of the application the OMAS request was made for
    • B: The size of cache storage that is actually being used (total size of the delivery data + the management space used by the console system)
    • C: The management space used by the console system (4 MiB)

For example, if the data delivery cache storage size is 64 MiB and 10 MiB of that is actually being used, the formula would be (10-4)/(64-4), which is 0.1 or 10%.

The use rates for future dates include only the data that has already been approved for delivery.

If approved data is set to start delivery at a future date, the data delivery cache storage use rate will be increased by the size of that data on that date.

If approved data is set to end delivery at a future date, the data delivery cache storage use rate will be decreased by the size of that data on that date.

Checking the Total Test Delivery Data Size

Select Test Delivery > Manage Test Delivery and open the Edit Test Delivery List page to see the total size of all data in the list.

The remaining amount of data delivery cache storage and the total size of data delivery cache storage are also displayed here. These sizes do not include the management space used by the console system (4 MiB).
Supposing the data delivery cache storage size (including the management space used by the console system) is 64 MiB, and the total size of the delivery data is 0 MiB, they would be displayed as follows respectively.

  • Space Remaining in Data Delivery Cache Storage: 62,914,560 bytes (60 MiB)
  • Capacity of Data Delivery Cache Storage: 62,914,560 bytes (60 MiB)
