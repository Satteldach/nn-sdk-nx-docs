1 Introduction

Purpose and Content

This document describes how to use the BCAT Management Tool to deliver News and data to the Nintendo Switch™ (Switch).

Intended Audience

This documentation is intended for application planners and users of the BCAT Management Tool.
The following types of users are expected to use the BCAT Management Tool.

  • Application developers
    Users who deliver data in the development environment for implementing and debugging applications
  • Delivery operators (members responsible for operations)
    These users are responsible for delivering news and data to the production environment based on requests from the application planners.
