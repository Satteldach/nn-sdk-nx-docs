BCAT Management Tool Overview

The BCAT Management Tool is a web tool for PC web browsers for delivering news and data to Switch systems.
The BCAT Management Tool provides the following features.

News Delivery

  • Create news items
  • Request pre-delivery reviews for news items
  • Approve pre-delivery reviews for news items
  • Manage test delivery for news items
  • Manage user roles (authorizations) for each news channel

Delivering Data

  • Create data
  • Request pre-delivery review for data
  • Approve pre-delivery review for data
  • Manage test delivery for data
  • Manage user roles (authorizations) for each application that supports data delivery
Info
  • The pre-delivery review refers to the process of checking items before delivery to make sure that there are no errors. This is described in detail later.
  • Test delivery refers to the system of delivering items to specific Switch devices or network service accounts. This is described in detail later.
