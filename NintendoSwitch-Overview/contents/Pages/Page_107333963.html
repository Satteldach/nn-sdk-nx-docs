5.3.2 Controller Support Applet

This applet is designed to help implement certain controller configurations.

It provides the following functionality.

  • Deciding which controller to use (including the Joy-Con grip)
  • Connecting controllers (pairing and assigning player numbers)
  • Adding players from within the application
Figure 5-1 Mockup of the Controller Support Applet


The controller support applet can prompt users to connect controllers or change the controller grip based on instructions when you call it from the application. Using the applet can simplify the handling of the controllers and is recommended in the following situations. The applet is especially effective when there is a large number of players.

  • When starting and when waking from sleep.
  • When the controller is disconnected during play.
  • When changing the controller grip and when adding a controller.
Info:

For more information about this applet, see Nintendo Switch Controller Guide > Application Controller Support > Controller Support Applet, and Application Controller Support > Controller Support Under Specific Conditions.
