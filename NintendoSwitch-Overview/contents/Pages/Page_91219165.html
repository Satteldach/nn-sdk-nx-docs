5.1.2 HOME Menu

This menu can be opened at any time by pressing the HOME Button on the console.

Icons for the most recently played applications are presented in the middle of the screen. If you select the icon and press A (or tap it on the touch screen), the application will start.

Icons at the Top of the Screen

This section introduces the icons that are displayed at the top of the screen.

Figure 5-2 Icons at the Top of the HOME Menu Screen


Table 5-1 Descriptions of Icons at the Top of the HOME Menu Screen
Number Description
1

An icon for the User Page feature.

For more information, see 5.2 System Applications.
2

Shown when parental controls are set.

  • ON: The state when parental controls are set.
  • OFF: The state when parental controls are temporarily lifted.

You can use this icon to turn parental controls on and off.

To switch from ON to OFF, you must enter the parental controls PIN.
3

Shown when play time limits have been set with the Nintendo Switch Parental Controls™ app.

For more information, see 5.5 Setting and Checking From Mobile App.

Icons at the Bottom of the Screen

This section introduces the icons situated at the bottom of the screen.

Figure 5-3 Icons at the Bottom of the HOME Menu Screen

Table 5-2 Descriptions of Icons at the Bottom of the HOME Menu Screen
Number Description
1

The icons named Nintendo Switch Online, News, Nintendo eShop, Album, and System Settings are located here.

For more information, see 5.2 System Applications.
2

An icon named Controllers.

Use this to check the connection status of controllers and their remaining battery life, and to resync controllers.

This same feature for resyncing controllers can be performed from the System Settings.
3

Puts the system into sleep mode.

Press the HOME Button to wake the system up.


Options

Select the icon for an application and press the + Button or - Button to display the options for that application.

The options include various information about the application and an entrance to the application.
