4.4 Friends

With Nintendo Switch, you can become friends with other users, check on their online status, and join together to play online games.

Features

The Friends mechanism on Nintendo Switch has the following characteristics.

  • Friends are saved independently for each user.
  • Each user can have as many as 300 friends.
  • To use the Friends feature, the user must be linked to a Nintendo Account.
  • There is a Best Friends feature, and friends set as best friends are displayed preferentially in the Friend List. For more information about the Friend List, see 5.2.1 User Page.

Scope of Usage

Switch friends are friends only within the scope of the Switch system and, in principle, only can be used in Switch applications. They are not friends to be shared with non-Switch applications that use Nintendo Accounts.

If desired, you can choose not to use the Friends feature provided with the Switch system, and instead, make and use an application-specific friendship mechanism.

Becoming Friends

The following methods can be used to become friends. For more information, see the Nintendo Switch Online Play Guide.

  • Request based on a recommendation
    Users who are already friends in non-Switch applications can recommend each other via Nintendo Accounts as candidate friends if they are playing on Switch. Users can also use this feature to recommend friends who are friends on social media, or friends on Nintendo 3DS or Wii U (Nintendo Network ID).
  • Friend request from inside the application
    Send a friend request from inside the application (providing that the application supports calls to the system feature for making friend requests).
  • Friend request from Player History
    Make the friend request from the Player History in the application.
  • Schedule a friend request using local communication
    Use local communication and schedule friend requests to be sent to the users of nearby Switch systems. Friendships cannot be established this way when Switch systems are offline. The friendships are officially established the next time the Switch systems connect to the internet.
  • Friend request using a friend code
    Make the friend request using the code issued to each user.

Friend Presence

Friend Presence is a feature that uses the internet to convey information in real time about the online status of friends and the applications they are playing. This is designed for uses like checking from inside the application whether friends are present to join in gameplay, or to use the Friend List screen (a system feature) to see what applications friends are playing.

Friend Invitations

You can invite friends over the internet to come play together online. If the application supports this feature, the invitations can be sent from inside the application. Invitations can even be sent to friends who are offline. For more information, see the Nintendo Switch Online Play Guide.
