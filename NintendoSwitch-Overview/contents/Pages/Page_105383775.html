4.3 Nintendo Accounts

With the exception of system updates and a few other scenarios, users must be linked to Nintendo Accounts to use the Switch network features.

Nintendo Account

The chief characteristics of Nintendo Accounts are as follows. (For more information, see https://accounts.nintendo.com/.)

  • The accounts are device-spanning network accounts that can also be used from PCs and smart devices.
  • You can sign in using the accounts of external services like Google and Apple.

Linking With Nintendo Accounts

A link to a Nintendo Account can be set for each user on the Switch system. After an account has been logged-in on the Switch system, there is no need to log-in again (to reenter a password), aside from a few exceptions such as when certain errors occur.

By linking to a Nintendo Account, users can not only play online games on the Switch system, but they can also make use of external services for the following types of activities.

  • Purchasing of content (from official websites) using smart devices and PCs.
  • Importing resources like NNID eCash from earlier hardware.
  • Recommending friends made in non-Switch applications.

Limitations on Linking

The link between a user and a Nintendo Account cannot be removed by a user operation.

Multiple Switch systems can link to a single Nintendo Account (see 1 in the figure). When numerous Switch systems are linked to the same Nintendo Account, the user nickname and user icon are synchronized across the Switch systems. However, the application's save data is not automatically synchronized across systems. (It is possible to prompt synchronization by using the 7.1 Save Data Cloud feature available in the Nintendo Switch Online service. It is not possible to either link multiple users to the same Nintendo Account on the same Switch system (2 in the figure), or to link one user to multiple Nintendo Accounts (3 in the figure).
