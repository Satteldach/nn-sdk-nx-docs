6.2 Local Communication

Local Communication

Local communication is wireless communication between nearby Switch consoles. The local communication feature for the Switch console has the following characteristics.

  • A maximum of eight Switch consoles can be connected regardless of the play mode.
  • When a user is using local communication from an application, that user does not need to have a Nintendo Account.

Using multiple wireless controllers that are connected to the same Switch console in multiplayer mode is not considered local communication.

Number of Consoles Connected in Local Communication and Number of Wireless Controllers

Because communication with another Switch and communication between a Switch console and a wireless controller can interfere with each other, the number of wireless controllers that can connect to a single Switch console during local communication is restricted. For example, when eight Switch consoles are using local communication, the maximum number of wireless controllers that can be connected to a single console is two (each right and left Joy-Con controller counts as one wireless controller). For more information about the number of wireless controllers that can be connected when consoles are using local communication, see Nintendo Switch Controller Guide.

Local Patch Distribution

A feature for distributing patches between Switch consoles is provided as a system feature. Nothing needs to be implemented in the application to use this feature. This feature can be used from the following scenes.

  • From the error message (error code 2203-0113 or 2203-0114) that is displayed when the communication version specified by the application does not match the version used by the other player.
  • From Match Version with Local Users, opened by selecting Options for the application in the HOME Menu.
