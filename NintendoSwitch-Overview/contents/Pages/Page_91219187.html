5.4.1 Overlay Notifications

This feature displays information of immediate relevance on the screen when the console is turned on (including when an application is running). The notifications appear in the upper-left part of the screen.

  • Volume change
  • Screen capture
  • System (Low battery, Charging, Download completed)
  • Friend presence
  • Time remaining on the play timer (when there is little time left) or an indication that the set time has been exceeded.

For more information about the play timer feature, see 5.5 Setting and Checking From Mobile App.
