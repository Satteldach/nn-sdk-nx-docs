6.1.1 Data Delivery System (BCAT)

For features such as data delivery, Nintendo provides a system called BCAT (Background Contents Asymmetric sync delivery and Transmission).
Data delivery is a feature that downloads data to Switch consoles from servers managed by Nintendo.
The following are examples of what is possible when using this functionality.

  • Deliver additional player characters during an online campaign.
  • Deliver items that can be used within the application, based on actual goods, in association with offline, real-time events.
  • Deliver configuration files to adjust game balance.

For more information, see NintendoSDK Documents > Features > System > bcat Library and the Nintendo Switch BCAT Data Delivery Guide.
