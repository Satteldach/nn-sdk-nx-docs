4.2 Users

The save data and other resources stored in the Switch console are managed collectively for each person as a unit, called a "user."

Registering and Unregistering Users

Up to eight users can be registered in the same Switch system. When a family is sharing one Switch system, each family member can register as a separate user in the system.

At least one user is assured to be registered in the Switch system. (When the Switch system is started for the first time, at least one person must register.) New users are added either inside a Switch application or via the System Settings menu.

The System Settings menu on the Switch system can also be used to unregister users. When a user is unregistered, all of the save data and other resources that belong to that user are deleted.

User Profiles

When a user is registered to the Switch system, a nickname and an icon are set for the user profile. This information is publicly available to other persons playing with the user on the Switch system or on online. The profile information can be changed at any time.

  • The nickname is a string of up to 10 characters, including any combination of alphanumeric characters, hiragana, katakana, and symbols.
  • The icon includes an image of a game character or a Mii against a background. (See the following figure.)
