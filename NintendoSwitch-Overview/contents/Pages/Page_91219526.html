5.2.6 System Settings

This is a feature for configuring a variety of settings for the Switch console, including internet connectivity and parental controls.

The System Settings can be called even during gameplay if settings need to be configured for the application. This feature provides an environment where settings can be readily configured as needed.

However, for items such as language settings and user settings, the suspended application or the system itself may need to be restarted after the settings are changed.
