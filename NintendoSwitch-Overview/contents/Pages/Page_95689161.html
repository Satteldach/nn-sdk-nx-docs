Connecting the Joy-Con and the Console

Rails are built into the right and left sides of the Switch console. Slide the Joy-Con controllers down the rails to physically connect them together. (See Figure 3-2 Attaching the Joy-Con to the Console.) At this point, there is wired communication with the console.

Figure 3-2 Attaching the Joy-Con to the Console

The Joy-Con controllers have no contacts for recharging. They can be recharged only when attached to a Switch system that is being powered by a Nintendo Switch AC adapter. (The Joy-Con will not be charged when the Switch system is running on batteries.) The right and left Joy-Con controllers can be switched out for others to recharge them, but button input will be disabled.

When detached from the console for use as independent controllers, the Joy-Con controllers communicate with the console via Bluetooth wireless communication. A pair of Joy-Con controllers form a set, and a maximum of four sets can be connected at any one time. For more information about the connections between the console and the Joy-Con during local communication, see 6.2 Local Communication. For more information about the connections between the console and the Joy-Con in other states, see Nintendo Switch Controller Guide.
