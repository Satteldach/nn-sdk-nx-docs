2.3 Differences in the Nintendo Switch Family

Size Differences Between Switch and Switch Lite

Switch Lite is smaller than Switch. The size of the control sticks and the A, B, X, and Y Buttons are the same.
For detailed size information, see 11 Appendix: Hardware Comparisons.

Switch Lite cannot be placed in the Nintendo Switch dock.

Figure 2-1 Switch and Switch Lite Size Comparison

Switch Lite Hardware Specification Differences

The Switch Lite hardware differs from the Switch hardware in the following ways.

  • The Joy-Con controllers cannot be removed.
  • There is no HD rumble feature.
  • There is no IR Motion Camera.
  • There is one accelerometer and one gyroscope.
  • The screen is smaller.
  • The +Control Pad replaces four separate directional buttons.
  • USB devices cannot be used with the standard Switch Lite set.

You must consider these differences when developing applications. There are also the following differences.

  • There is no stand to use with tabletop mode.
  • The system is not capable of charging accessories such as Joy-Con controllers and Nintendo Switch Pro Controllers.

For more information, see Nintendo Switch Controller Guide, Nintendo Switch HD Rumble Guide, Nintendo Switch IR Motion Camera Guide, and Nintendo Switch Play Mode Guide.

Application Behavior on the OLED Model

Play is fundamentally the same as on the original model, but applications that depend on a certain console and screen size may have some limitations.
For example, limitations apply to the following applications.

  • Applications that connect the screens of multiple Switch consoles in order to play
  • Applications played by attaching the Switch console to a dedicated controller

References to Switch in the Application

When referring to Nintendo Switch in your application, display an image of Switch or use the text "Nintendo Switch." You do not need to take Switch Lite or the OLED model into account.

There is no method for an application to determine which model of Switch it is running on.
