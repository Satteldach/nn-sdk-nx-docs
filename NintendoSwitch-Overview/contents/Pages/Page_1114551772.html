6.1.3 Nintendo-Provided Communication Features (NPLN)

About NPLN

Network Platform for Nintendo (NPLN) is a successor to NEX that provides a mechanism for adding server services like online battle to applications. It is not compatible with NEX.

Nintendo provides the following resources to enable the use of NPLN.

  • A client library for NintendoSDK
  • A game server that provides server services
  • A web tool called the NPLN Dashboard that provides the functionality for managing the server services
Info:

Consider using NPLN instead of NEX if you plan to use any new communication features that Nintendo provides.

Services Provided by NPLN

The following services are provided through NPLN. For more information about each service, see the NPLN Manual included in the NPLN package.

  • Auth
    This service provides authentication for using NPLN.
  • Friends
    A service for using Switch friends in NPLN.
    It can be used to get friend presence information within the application, and for matchmaking between friends.
  • Matchmaking
    A multiplayer invitation feature that performs matchmaking, bringing users together on the internet for gameplay.
    With NPLN, the conditions (rules) for matchmaking are registered on the server via the NPLN Dashboard.
  • Gamesync
    A service for sharing the information needed for establishing online multiplayer gameplay within a group where matched users are participating.
    It can be used for communication to build P2P sessions and for infrequent in-game state synchronization.
  • StunChannel
    A library for transport layer communication.
    You do not need to use StunChannel if you are using the Pia library provided by Nintendo as the higher-level P2P communication library. Use this library if you are developing your own features that are comparable to Pia.
  • Leaderboard
    A mechanism for generating rankings using scores registered by users.
    The scores registered by users are aggregated on the server side. This service can get both the rankings of the top users and the rankings of users near a user's own rank.
  • Messaging
    A service that provides a means for immediately sending data to specified online users.
    You can check for the arrival of data, but this cannot be used in situations where assured arrival is required because its real-time capabilities are limited.
  • Ugcstore
    A data storage service designed to store and publish user-generated content (UGC).
    We are also considering providing a general-purpose data storage service other than Ugcstore.
  • Maintenance
    A mechanism for reporting information about NPLN server maintenance on Switch.
