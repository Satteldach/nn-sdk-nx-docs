Nintendo Switch Dock

Figure 3-1 Appearance of the Nintendo Switch Dock [HAC-007] (Left: Front, Right: Back With Cover Open)

Figure 3-2 Appearance of the Nintendo Switch Dock [HEG-007] (Left: Front, Right: Back With Cover Open)

The Nintendo Switch dock is a bundled accessory that is used to operate the console in TV mode.

In addition to serving as HDMI video and audio output to the TV, it also recharges the Switch console.

The main features of the Nintendo Switch dock are below.

Differences in Behavior When Removed From the Nintendo Switch Dock

The GPU clock rate and the memory clock rate can change depending on whether the Switch system is placed in the Nintendo Switch dock or removed from the dock, as described in Performance Configurations Available to the Application in 2.2 Application Features.

In addition, the system runs on its battery pack, and the following features become enabled when the Switch console is removed from the Nintendo Switch dock.

  • Speakers
  • Built-in accelerometer and motion sensor
  • Built-in LCD panel and touch screen

Joy-Con Grip

Figure 3-3 Appearance of the Joy-Con Grip (Left: Before Attaching the Joy-Con, Right: After Attaching the Joy-Con)

The Joy-Con grip is a bundled accessory that the left and right Joy-Con controllers snap into, creating something shaped like a Classic Controller that can be held in both hands. It has no electronics.

Joy-Con Strap

Figure 3-4 Joy-Con With the Joy-Con Strap

The Joy-Con strap can be attached to the rail on the side of the Joy-Con.

This strap makes it easier to hold the Joy-Con and adds safety when the controller is being waved around. It also makes it easier to press the SL and SR Buttons when the controller is being held horizontally.

Nintendo Switch AC Adapter

An adapter bundled with the system to provide power to the Switch console and Nintendo Switch dock.

Connection to the Switch console and the Nintendo Switch dock is via a USB Type-C terminal.

Nintendo Switch Pro Controller

Figure 3-5 Appearance of the Nintendo Switch Pro Controller

The Nintendo Switch Pro Controller is a wireless controller with the same number of buttons as the controller part of the Switch system in handheld mode. (Wired connections are available for consoles with system version 3.0.0 and later.) It is designed to be easier to hold and operate than the Joy-Con, and is intended to be used when a single player wants to take their time playing through the game. It is not included with the system.

This controller can be connected to the Switch console and used instead of the Joy-Con controllers, but its component devices differ in some ways. For more information, see Table 3-2 Comparison of Component Devices on the Nintendo Switch Pro Controller and the Joy-Con. Whereas the Joy-Con has independent directional input buttons for up, down, left, and right, the Nintendo Switch Pro Controller has a +Control Pad. You can simultaneously press left + right or up + down on the Joy-Con, but you cannot do the same on the Nintendo Switch Pro Controller. Consider this difference when you are implementing applications.

Up to eight controllers, including Joy-Con controllers, can be connected to one Switch system at the same time.

Game Cards

Figure 3-6 Appearance of Game Card

These are dedicated Switch game cards, with a shape that makes them incompatible with previous Nintendo platforms. There is no backup device, and save data is saved to the system memory.

Variations that range in capacity from 2 GB to 32 GB are available. Game cards contain other data besides the application data (for example, data for system updates, header information, and reserved regions), so the actual amount of room for storing the application is less than the capacity of the game card itself.

Table 3-3 Actual Capacity of the Application Storage Region shows how much space is actually available for the application in each capacity game card.
