9.2 Application Development Environments

Several choices are available for the Switch application development environment. Choose based on the development requirements for your application or team. For more information about different environments, see the applicable documentation. You can obtain the environments distributed by Nintendo using the Nintendo Dev Interface.

There are also helpful development tools, aside from those introduced in this topic. For more information, see this link (Nintendo Developer Portal > GETTING STARTED > Nintendo Switch > Middleware).

NintendoSDK

The NintendoSDK is a software development kit for creating applications to run on Nintendo Switch and future Nintendo platforms. A unified development environment for multiple platforms enables the reuse of code and knowledge. The NintendoSDK provides basic functionality. You can incorporate and use any existing team development frameworks if they are available.

NintendoWare

NintendoWare is a collection of libraries and tools that can be used to develop graphics and audio for applications. It provides the basic tools and libraries used by most applications so that developers can focus on the content of the applications. NintendoWare is available within the NintendoSDK as one of the included packages.

NintendoWare Bezel Engine

The NintendoWare Bezel Engine, or Bezel Engine for short, is a Nintendo framework that offers comprehensive support for everything from creating a development environment to submitting a master ROM.

It is based on NintendoWare, with additional useful tools and features designed to facilitate the process of game development. These include the Portal, with features to create new projects, launch executables, and build assets; the MapEditor tool for creating collisions for maps and placing objects within maps; and a physics engine using PhysX. Bezel Engine is designed to enable simple use of these features and NintendoWare.

Developers who have experience using NintendoWare can use it easily, because NintendoWare is used to create features such as graphics and sounds. As your development language, you can use C++ as well as the Lua scripting language. Also included is a dedicated Lua script debugger. All of the runtime library source code for the Bezel Engine has been made public. You can review internal behavior and, if necessary, make internal revisions.

Application developers must devote more than a little time to comply with the guidelines, but the use of Bezel Engine helps reduce that load because it deals with some of the guidelines itself.


Unity

Unity is a comprehensive development environment that enables game production for a variety of platforms, for both 2D and 3D games. Unity offers a rich feature-set to aid in game development, including game previewing, intuitive UI tools, physically based shading, and memory profiling. For more information about the features available with Unity, see the Unity website.

Unity for Nintendo Switch is designed to provide all standard Unity features. In addition to that, it supports a variety of Switch features for the development of games that take advantage of the characteristics of the Switch system. And because games created using Unity can be built using Unity for Nintendo Switch, it is relatively easy to port games created for other platforms so that they run in the Switch development environment, albeit it with some effect on performance.

You can use Unity for Nintendo Switch by adding the Nintendo Switch Support add-on, which is distributed by Nintendo, to the public release version of Unity Editor.

If your purpose is the development of Switch applications, you can use a version equivalent to Unity Editor Pro for free without paying royalties for the use of Unity.

Unreal Engine

Unreal Engine (UE) is a game engine developed by Epic Games. It contains all of the features required for game development and provides a toolset that enables high-quality game experiences.

UE contains not only high-level graphics power, but also several features that represent a major evolution for the development environment. These features include Blueprint, a visual scripting system that allows you to create games without using any code; Cascade, which can freely manipulate millions of particles to create realistic flame and smoke; and Content Browser, which provides functional asset management.

UE is also upgraded for free by Epic Games every few months, and they are constantly adding new features, improvements, and bug fixes. The Switch version includes these latest revisions and is optimized to create games that take full advantage of the performance of the hardware. Note that there may be restrictions on available functionality, depending on the Switch performance configuration.

To use Unreal Engine for Nintendo Switch, you must make a request to Epic Games to get the source code.

For more information about making a request, see https://developer.nintendo.com/group/development/getting-started/g1kr9vj6/middleware/unreal-engine.
