9.1 Development Hardware

This section introduces the various development hardware and the NX development card, which is a game card that can be used during application development.
For more information about purchasing the development hardware, see GETTING STARTED > Nintendo Switch > Development Tools in the Nintendo Developer Portal.

Development Hardware

There are four types (and six distinct varieties) of development hardware: the SDEV/SDEV-D, which is equipped with a wide range of useful features for application development; the EDEV/EDEV-D, which is structurally similar to the Switch retail unit; the HDEV, which provides a way to check the differences in the feel of operations on Switch Lite, which has a different console and screen size than Switch; and the ADEV, which provides a way to check the differences in the OLED model.

Each development hardware system has different characteristics and features, as described below, and you can select the one that best meets your development needs.

SDEV/SDEV-D

The SDEV and SDEV-D (hereafter, unless otherwise specified, "SDEV" refers to both the SDEV and SDEV-D) development hardware have advanced features, including many external interfaces not found on the Switch retail unit that are useful for development. The SDEV motherboard has a built-in, dedicated board for adding extra features, making the SDEV larger than the EDEV.

The unit is designed with an HDMI port for video output. By connecting the SDEV to an external display via this HDMI port, the picture displayed on the unit's LCD screen can be mirrored on an external display. The unit also has a special port for the attachment of a controller for debugging, and an Ethernet jack for connecting to a PC. It has 6 GB of memory, which is 2 GB more than the retail unit (the SDEV-D has 8 GB, which is 4 GB more). However, the unit does not have a battery, so to run, it must be connected to an external power supply via an AC adapter.

It also has a CPU Overclock feature, which can be used to set the CPU clock to a higher rate (1,785 MHz) than what is available on the retail unit (1,020 MHz). For more information about this feature, see NintendoSDK Documents > Features > Controlling the Development Hardware > DevMenu > CPU Overclock.

For more information about the SDEV, see Nintendo Switch SDEV Usage Manual.

EDEV/EDEV-D

The EDEV and EDEV-D (hereafter, unless otherwise specified, "EDEV" refers to both the EDEV and EDEV-D) hardware have a hardware configuration similar to the retail unit and are designed for debugging as well as development. In addition to final testing of applications, the EDEV can also be used for development, although it does not have as many useful development features as the SDEV.

The EDEV is equipped with the bare minimum of features required for development. It can communicate with a PC via a USB cable if connected to a special accessory. You can debug applications from a PC, as you can with the SDEV, and get run-time logs. In addition, the EDEV has a built-in battery just like the retail unit, which lets you experience how the application actually plays when the console is not attached to a cable.

For more information about the EDEV, see Nintendo Switch EDEV Usage Manual.

Figure 9-2 Appearance of the EDEV (with Joy-Con attached)

HDEV

You can use the HDEV when you need to check how the feel of gameplay differs on Switch Lite due to its different overall size and screen size compared to Switch. The HDEV development hardware has the same outward appearance as Nintendo Switch Lite and can run applications that are still under development. Always test your applications using the EDEV or ADEV even after testing them with the HDEV.

For more information about the HDEV, see Nintendo Switch HDEV Usage Manual.

Figure 9-3 Appearance of the HDEV

ADEV

When you need to check for differences in hardware specifications, like housing size, you can use a piece of hardware called ADEV. ADEV is development hardware that has the same appearance as the OLED model, and can be used to run applications during their development. It has 8 GB of memory, which is 4 GB more than the retail unit.

Like the EDEV, the ADEV can be used as an environment for testing applications.

For more information about the ADEV, see Nintendo Switch ADEV Usage Manual.

Figure 9-4 Appearance of the ADEV

Common Features

The different development hardware types all provide the basic (essential) features for application development. When the development hardware is connected to a PC, the following functionality is available. For more information, see NintendoSDK Documents > Features > Controlling the Development Hardware.

  • Run built NX applications.
  • Update the development hardware firmware.
  • Write applications to NX development cards.
  • Install applications in system memory.
  • Control basic operations of the development hardware from the PC (such as installing, starting, and ending applications).

Available Controllers

In addition to the Joy-Con included in the development hardware set, you can also connect commercially available Joy-Con and Nintendo Switch Pro controllers to the devices. The Joy-Con included in the development hardware set is the same as the commercially available Joy-Con.

With the SDEV, you can also connect a commercially available Classic Controller Pro.

Note:

Note that if you use a commercially available Joy-Con or Nintendo Switch Pro Controller with the development hardware and overwrite the firmware, those controllers might not work properly in combination with the Nintendo Switch retail product.


NX Development Cards

NX development cards are game cards that can be used with the development hardware. Unlike game cards, they are available in only 32 GB capacity.

If you plan to sell your application as a card product, you must use an NX development card to confirm operations.
