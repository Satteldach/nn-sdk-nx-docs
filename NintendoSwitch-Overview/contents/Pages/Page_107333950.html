5.3.1 Account Management Applet

The account management applet supports the following features involving accounts inside the application.

  • Selecting users.
  • Adding users.
  • Linking to Nintendo Accounts.

The following two designs have been prepared to display when a user is being selected. Registered users are displayed.

Figure 5-1 Account Selection Screen Mockup

Figure 5-2 Account Selection Screen Mockup (Displaying an Image Specified by the Application)

Thumbnails representing save data can be displayed on this latter screen. As an example, this can be used to display images that indicate the progress in the game, giving users a way to see how others are doing. Because this can encourage communication in skills competitions and the like, we recommend using this latter design instead of the former for the account selection screen.

Info:

For more information about this applet, see Nintendo Switch Account Guide > Application Support for Accounts.
