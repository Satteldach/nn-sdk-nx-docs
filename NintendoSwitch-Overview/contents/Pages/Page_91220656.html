5.5 Setting and Checking From Mobile App

This section introduces a service that uses the mobile app.

Nintendo Switch Parental Controls™

This mobile app, when linked to a Switch console, can manage gameplay on that console. The app enables information such as play time and which games are being played on that Switch to be checked from a smart device.

Figure 5-1 Setting and Checking From the Mobile App

The assumption is that this service will be used by parents or guardians of children playing on Nintendo Switch. Specifically, the following features support children playing on the Switch system.

  • Configure the play timer, which sets how many hours the Switch system can be played in a day.
  • Check what applications have been played on the Switch system and for how long.
  • Restrict the features available on the Switch system (configure Parental Controls).

The play timer can be used to manage play time on the Switch system. It can be used to set the number of hours of play, and the time to stop playing.

The time left on the play timer goes down while the Switch is being played. Notices are displayed on the Switch screen when the play time is approaching the set time, and when the time is exceeded. In addition to displaying these notifications, the Switch system can be forced to stop (see note) when the set time has been exceeded.

Note: The system will enter a state similar to when the HOME Button is pressed or the system is in sleep mode, preventing the Switch system from resuming until the next day.
