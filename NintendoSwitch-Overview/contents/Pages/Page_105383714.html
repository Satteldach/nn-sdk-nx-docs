4.1 Switch and Accounts

Nintendo Switch is structured such that users register to a Switch system, and Nintendo Accounts become linked to the registrants on that system.

Figure 4-1 Structure of Accounts on Nintendo Switch

In this figure, (1) depicts the people who are using the Switch system in the real world, (2) depicts the users registered to the system, and (3) depicts the Nintendo Accounts.

Save data and other resources on the Switch system are managed at the individual user level for those users registered to the system. This means that users can register and use the system even if they are not connected to the network. A Nintendo Account is required to use network features on the Switch system. As many as eight different people can register as users on each Switch system, and each user can be linked to a Nintendo Account.

Accounts Place No Restrictions on Game Design

Switch accounts are purposely structured to place no restrictions on the game design.
An account does not need to be selected when the Switch system is started, so you can design your application to make the selection at any time. You can support the following based on the game design.

  • For applications that do not change the user account during the game, the user selects the account immediately after the title screen.
  • For a fighting game, you can let users play in practice mode without selecting an account, and wait until they enter into the real fight mode, where scores are recorded, to select an account.
  • For titles that feature a collection of minigames, you can switch accounts for each try of each game. In this way, high scores are recorded for each account.
  • For applications like simple party games where there is no need to store save data, you do not need to support accounts at all.

The Switch system supports the simultaneous selection of multiple accounts. This means that scores can be recorded separately for each user when multiple people are playing together at the same time, similar to a sports game in doubles mode.
The standard specification is to select the account after starting the application. You can improve the gameplay experience by making it possible to switch accounts without restarting the application.

The account information that is required when considering game design is described in Nintendo Switch Account Guide. Refer to this information when considering game design.

There are system features in the form of an applet which facilitates the implementation of processes in the application to switch accounts and register new users. For more information, see 5.3.1 Account Management Applet and Nintendo Switch Account Guide.
