9.3 Middleware

Several middleware packages are provided in addition to the application development environments. You can reduce the effort involved in application developed by using effective middleware from among those packages. The different middleware packages are available from the Nintendo Developer Interface. For more information, see the relevant documentation.

NEX

Nintendo offers a library called NEX that provides server services by communicating with the Nintendo game server. It is a multi-platform library supported on the Nintendo 3DS and subsequent Nintendo platforms.

See 6.1.2 Nintendo-Provided Communication Features (NEX).

Info:

New requests to use NEX are no longer being accepted. For more information, see the announcement in the Nintendo Developer Portal.

Consider using NPLN instead of NEX if you plan to use any new communication features that Nintendo provides.

NPLN

Network Platform for Nintendo (NPLN) is a successor to NEX that provides a mechanism for adding server services like online battle to applications. It is not compatible with NEX.

See 6.1.3 Nintendo-Provided Communication Features (NPLN).

Pia

Pia is a game communication engine (a group of peer-to-peer communication libraries) customized for development of real-time P2P communication for gameplay. It is a multi-platform library supported on the Nintendo 3DS and subsequent Nintendo platforms.

nlib

The nlib library supports a variety of features, including threading, file operations, SIMD, reading and writing XML and JSON files, and unit testing. It is a multi-platform library supported on the Nintendo 3DS and subsequent Nintendo platforms, and in environments including Windows, Linux, and OS X.
