5.1 System Menus

The menus that are called by the HOME and POWER Buttons are collectively referred to as system menus. You can call these system menus while playing a Switch application and then return to the application after you have finished.

The following list contains the types of system menus that are available.

  • Entrance (including the Unlock screen)
  • HOME Menu
  • Full Launcher
  • Quick Settings
  • Power Menu

From these system menus you can start or restart applications and system applications and configure simple settings.
