7.1 Save Data Cloud

Save Data Cloud provides a way to take the save data saved on a Switch system and store it on a server.
Switch Online provides a service with Save Data Cloud for the online backup of save data.

Online Backup Feature

The online backup feature allows save data to be copied between a Switch console and a dedicated server.
Save data is linked to a Nintendo Account and stored. If separate Switch consoles are linked to the same Nintendo Account, it is possible to copy save data to another console and resume play.
Users have the following advantages.

  • Even if a Switch console is damaged or lost, save data is retained.
  • The same save data can be used across multiple consoles.
    • It is also possible to automatically download save data that was backed up from a different console.
  • By storing rarely used save data on the server, space can be freed up in Switch system memory.

Supported Applications

The setting to support Save Data Cloud is configured separately for each release version of the application. The setting is configured on the Nintendo Developer Portal.
If supported, users can back up and download (write back) save data an unlimited number of times. Note that users can rewind the state of progress for applications at any time.
If not supported, the online backup feature is not available to users.

Info:
  • Users cannot remove the links to Nintendo Accounts. As a result, save data cannot be copied across Nintendo Accounts.
  • Save Data Cloud is not supported for the demo versions of applications (for applications where Demo was selected for Product Type on the Nintendo Developer Portal).

For more information about implementation considerations, see the Save Data section in NintendoSDK Documents.
