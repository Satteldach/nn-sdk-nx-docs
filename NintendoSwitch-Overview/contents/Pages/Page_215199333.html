10 Application Development Process

This section describes the overall process for developing Switch applications.

It describes the confirmed systems, documentation, and development hardware to use for each development phase.

About Switch Features

Several documents have been prepared to help you understand the characteristics and features of Switch when you begin to consider your development plans.

  • Nintendo Switch Overview
    • This document. Provides general information about Nintendo Switch.
  • Nintendo Switch Guidelines
    • Describes rules to which applications sold for Nintendo Switch must comply.
  • Various Guides
    • These guides describe the features of Nintendo Switch.
Info:

You can use the different documents as follows.

  • Browse the Nintendo Developer Portal online documentation (https://developer.nintendo.com/group/development/g1kr9vj6/online-documents).
  • Download from the Nintendo Developer Portal (https://developer.nintendo.com/group/development/g1kr9vj6/downloads).

Development

  • Adding a product
    • Add products on MY PRODUCTS (https://developer.nintendo.com/group/development/products) on the Nintendo Developer Portal. Use this to submit requests for the features you want to use and to ultimately submit the master ROM for the application.
  • Purchasing development hardware
    • The SDEV, EDEV, and other development hardware listed in 9.1 Development Hardware can be purchased from Development Tools on the Nintendo Developer Portal (https://developer.nintendo.com/group/development/getting-started/g1kr9vj6/development-tools)
  • Getting the development environment
    • Get the SDK and documentation from the Nintendo Developer Portal (https://developer.nintendo.com/group/development/g1kr9vj6/downloads) or the Nintendo Dev Interface.
  • Submitting a request to use network features
    • Submit a request using OMAS (https://omas2.mng.nintendo.net).

Submitting the Master ROM

To submit a master ROM you have created, you must enter application information in MY PRODUCTS on the Nintendo Developer Portal.

Lotcheck is performed by Nintendo after the master ROM has been submitted. The process involves testing to confirm whether the submitted master ROM can be released as a Switch application. Lotcheck checks many items, including whether the application complies with Nintendo Switch Guidelines.
