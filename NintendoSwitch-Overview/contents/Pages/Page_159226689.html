8 E-Commerce

This section provides an overview of the Nintendo Switch system's e-commerce features (for the internet-based digital sales conducted by Nintendo).

Types of Services and Distributed Content

The following types of content and services can be sold and distributed in Nintendo eShop on Switch.

  • Downloadable software
    Downloadable versions of applications that are distributed by Nintendo's servers over the internet.
  • Demo titles
    Downloadable versions of applications distributed for free so people have a chance to try applications as a way of promoting sales.
  • Downloadable content
    Content that can be used indefinitely within a corresponding application after it is purchased outright.
    Example: Additional character for a battle game
  • Subscription service items
    Licenses that enable the use of a service within a corresponding application for only a specific period of time.
    Example: A service ticket that enables the use of online battle mode in the game for 30 days
  • Consumable service items
    A means of selling licenses to a service that can only be used a specific number of times within its corresponding application.
    Examples: A game item that can be purchased any number of times, virtual currency that can be exchanged for items in the game
Info:
  • See Nintendo Switch E-Commerce Guide if you are planning and developing these kinds of products for sale.
  • For more information about patches, which is the mechanism for updating an application after it has been released, see the Nintendo Switch Patch Guide.

Purchasing Content and Services

You can purchase Switch content and services from Nintendo eShop, which you start on the Switch system, as well as from Nintendo's official website.

You can also purchase download codes from retail shops and online stores. These download codes are redeemed for the actual products in Nintendo eShop, which you start on the Switch system, or from Nintendo's official website.

Info:

Some products cannot be purchased and some download codes cannot be redeemed on Nintendo's official website. For more information, see Nintendo Switch E-Commerce Guide.

Relationship Between Accounts and Licenses

To purchase and redeem products on Nintendo eShop, the user account registered in the Switch system must be linked to a Nintendo Account.
For more information about accounts, see Nintendo Switch Account Guide. For more information about the relationship between accounts and licenses, see Nintendo Switch E-Commerce Guide.

Downloaded Data Save Locations

Data that has been downloaded to the Switch system (download software, downloadable content, and patches) can be saved to either system memory or a microSD card.
For more information about the locations where content is saved, see NintendoSDK Documents > Features > Content Save Locations.
