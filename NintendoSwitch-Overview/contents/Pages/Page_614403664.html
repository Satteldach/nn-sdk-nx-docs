- NX-SoC

SoC equivalent to Tegra X1 from NVIDIA.
- Main memory Equipped with 4 GB of LPDDR4X. This memory also serves as VRAM for displaying graphics on the screen. The application can use 3.2 GB of this memory.
- System memory 32 GB of storage. Used to store the downloadable versions of applications and save data.
- Wireless

IEEE 802.11 a/b/g/n/ac and Bluetooth v4.1 are included.

Local communication uses a proprietary protocol based on IEEE 802.11 n.
- Accelerometer This sensor detects changes in inclination and motion.
- Gyroscope This sensor detects changes in angle and rotation speed.
- Cooling fan Fan to cool the device surface and internal components.
- Battery pack Equipped with a 3570-mAh rechargeable battery. Battery run time ranges from approximately 3.0 to 7.0 hours.
Battery life varies depending on the usage conditions and the processing load of the application being played.
