5.2.2 Nintendo Switch Online

This system application provides information about Nintendo Switch Online (Switch Online) to use the service.

(A Switch Online membership is not required for starting this system application.)

This system application mainly provides the following information.

  • Switch Online membership status and membership type.
  • Information about the latest Switch Online services and upcoming software offers.
  • Information about all services and software currently offered on Switch Online.
  • Information about save data currently backed up on Switch Online.
Figure 5-1 Switch Online Mockup Screen

Note:
  • Offers vary depending on the country or region for the Nintendo Account.
  • This system application is not available in some countries or regions.
