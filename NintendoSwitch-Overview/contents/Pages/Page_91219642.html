5.3 Library Applets

Library applets are small, modularized applications that are created for a specific purpose. You can call a library applet while playing a Switch application and then return to the application when the applet closes.

Because this uses a memory region dedicated for library applets, only one library applet can run at a time.

This section describes the following library applets.
