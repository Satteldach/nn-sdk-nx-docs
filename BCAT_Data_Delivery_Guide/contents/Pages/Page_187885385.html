1 Introduction

Objectives and Content

This document describes the specifications of the BCAT (background contents asymmetric sync delivery and transmission) system, used to deliver data to the Nintendo Switch™ (Switch).
Refer to this document when designing or developing applications that incorporate BCAT data delivery.
Although the BCAT system is also related to news delivery, this document will only describe the features for data delivery.

Intended Audience

This document is intended for planners and developers of Switch applications.

Structure of This Document

2 Delivery Specifications describes the delivery specifications.

3 Data Specifications describes the data specifications.

4 Operations describes the life cycle from the start of application development until the release.

Related Documents

For more information about adding the delivery data to the server, see Nintendo Switch BCAT Management Tool Usage Manual.
For more information about creating an application that incorporates BCAT data delivery, see NintendoSDK Documents > Features > System > bcat Library.
