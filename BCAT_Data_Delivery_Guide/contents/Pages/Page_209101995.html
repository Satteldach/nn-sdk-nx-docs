3 Data Specifications

Save Destination

The distributed data (files and directories) is saved to a dedicated region in the Switch system memory.

This region is called the data delivery cache storage.

The data delivery cache storage is created automatically before the application is first run.

It will not be possible to run the application if the data delivery cache storage cannot be created due to insufficient system memory available on the Switch console.

Info

The BCAT Management Tool has a feature for displaying the use rate of data delivery cache storage, shown as the percentage of data delivery cache storage taken up by data that is currently being delivered. Please refer to this usage rate when adding more data for delivery. A description of this feature will be added to the BCAT Management Tool Usage Manual.

Accessing the Save Destination

  • The application can only read data from the data delivery cache storage it has created.
    • The application cannot read data from the data delivery cache storage created by any other application.
  • The application cannot directly write data to the data delivery cache storage.

Deleting the Save Destination

The data delivery cache storage may be deleted by the following end user operations.

  • HOME Menu > Settings > Data Management > Archive Software
  • HOME Menu > Settings > Data Management > Delete Software
  • HOME Menu > Settings > Console > Initialize Console
  • Initialize Console Without Deleting Save Data (available in Recovery Mode)

Value Specifications

Subject Maximum Value Notes
Number of data delivery cache storage regions Up to 1.

The application only has one data delivery cache storage.

It is shared with all user accounts on the Switch system.
Data delivery cache storage size Up to 64 MiB. 4 MiB of this memory is allocated to a management region.
Number of directories Up to 100 directories.

Directories cannot be created within other directories.
Directory size (the total size of all files in one directory). Up to 60 MiB.

Calculated as the sum of the files in the directory, with each file rounded up to 16 KiB.
Files per directory

Up to 100 files.

It is possible to create an empty directory without any delivered files.
Total number of files in all directories Up to 2,000 files.
Size of each file

Up to 60 MiB.

Same as the maximum size for a directory.

Empty files (file size 0) cannot be registered on the server.

For example, you can create three directories that each store 20 files, which are each 1 MiB in size.

File and Directory Name Specifications

Subject Specifications
Character Count
  • Up to 31 characters
Character Types
  • Uppercase and lowercase alphabetic characters
  • Numbers
  • Underscore
  • Hyphens (Only used in directory names.)
  • Periods (Only used in filenames.)
Other
  • Periods cannot be used at the end of filenames.

Notes

  • The application can get the digest value of each file in the data delivery cache storage.
    • By storing the digest value in the save data ahead of time, you can detect file updates and notify users.
  • As soon as a directory is created with the BCAT Management Tool, it is listed in the application by the nn::bcat::EnumerateDeliveryCacheDirectory() function.
    • The directory is listed even if it is empty.
