4 Recommended handling in line with the design of your application

UGC is able to contain personal information, content that infringes on the rights of others, and content that offends other users. As noted in 3 What is handled by Nintendo Switch features and what applications must handle, Nintendo Switch has a minimum baseline set of mechanisms in place to protect users, but in some cases the characteristics of your individual application may mean that you should consider other mechanisms as well. This section uses examples from released applications to introduce fundamental concepts when handling UGC. Use this chapter as reference if you are considering features that handle UGC in your application.

Below are three fundamental concepts to consider when handling UGC.

  • Preventing users from creating inappropriate UGC
  • Preventing users from spreading inappropriate UGC
  • Preventing users from seeing inappropriate UGC

This chapter presents methods of putting these concepts into practice. The bottom of each page shows examples of how some released applications have handled UGC in line with these concepts.

Note

You are not required to implement the fundamental concepts of UGC handling described in this chapter. That said, please consider implementing these concepts to the extent possible in your application, because these are good ideas for any application handling UGC.
