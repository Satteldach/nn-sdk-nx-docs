Purpose and content

This document is aimed at developers of applications that contain UGC (user-generated content). It uses examples to explain what UGC is and what points to keep in mind when handling UGC in Nintendo Switch™ software. We intend this document to be referenced by developers who are planning an application that uses UGC, and are evaluating how best to implement UGC in a way that avoids detriment to the users and to the application.

Many sections in this document provide supporting information for requirements found in the Guidelines. Read this document to deepen your understanding of the Guidelines, or when planning the UGC specifications for your application.

Audience

This document is intended to be read by the lead planners/designers involved in planning an application that handles UGC.

When to read this document

Refer to this document when planning your application.

Structure of this document

  • 2 What is UGC?
    • This section explains what UGC is and what types of UGC exist.
  • 3 What is handled by Nintendo Switch features and what applications must handle
    • This section explains how UGC is handled on Nintendo Switch, covering both what is handled by the system and what is the responsibility of your application.
  • 4 Recommended handling in line with the design of your application
    • This section uses examples from released applications to explain possible ways of handling UGC in your application.

Terminology

This document uses concrete examples from released applications to explain aspects of UGC. Below we explain some features and UGC-related terms which are not available with Nintendo Switch, but do appear in the examples.

Table 1-1 Terms
Term Meaning
StreetPass This is one of the Nintendo 3DS communication features. This feature exchanges data set by the application with other nearby Nintendo 3DS systems. This feature cannot be used by Nintendo Switch applications.
SpotPass This is a communication feature used by both Wii U and Nintendo 3DS. This feature performs background upload or download of data set by the application. This feature communicates with a server, not with other consoles or systems.
Miiverse This is a network service used by both Wii U and Nintendo 3DS. Its objective is for users to post their thoughts and feelings about applications and share them with other users. This feature cannot be used by Nintendo Switch applications.
Exchange of UGC Exchange of UGC refers to sending UGC to another user and/or receiving UGC from another user using the features of Nintendo products. This includes not only one-on-one interactions using internet communication or local communication, but also uploading or publishing UGC to a server where other users download it.
