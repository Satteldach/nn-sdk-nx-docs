9.5 Cannot Detect USB Devices

If the USB device cannot be detected, check the settings and connection according to the type of USB device connection.

Info

If you are using a USB-Ethernet adapter for a wired connection to the internet, consider using wireless communication.

If the USB Device Is Directly Connected to the HDEV Console

Check that the USB device is correctly connected to the HDEV console.
For more information about connecting USB devices, see 6.2 Connecting the HDEV and USB Devices.

If there were no problems with the connection, restart the HDEV.
For more information about restarting the HDEV, see 8.1 Restarting the HDEV.

If the USB device still cannot be detected after performing these operations, confirm that power is being supplied to the USB port by connecting another USB device to the HDEV console that lights up when power is supplied.
If power is not being supplied to the USB port, the HDEV might be damaged. For more information about requesting a repair, see 10 Repair Contact.
