4.2 Components

The various HDEV components have the same names as the components of the Switch Lite retail product. See the Nintendo Switch Overview.

This section describes the names of the various parts of the relay box.

Relay Box
Top View

Number Name Description
1 TV output LED

This LED flashes when the relay box detects an error.
It also lights up temporarily when it receives power from the AC adapter and when it connects to the HDEV system.

Because the HDEV does not support TV mode, this LED does not light up when the relay box is connected to a TV.
2 Console connector

Connects to the USB Type-C™ connector on the bottom of the HDEV.

The plug can be connected in either orientation.
Front

Number Name Description
3

HDMI connector

Not used when connecting to HDEV.
4 USB port (supports USB 3.0 Micro-B) Connects the relay box to a PC via a USB Micro-B to Micro-A cable.
5 AC adapter port

Used to connect the bundled AC adapter.

The plug can be connected in either orientation.
