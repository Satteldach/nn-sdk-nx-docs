6.2.2 Important Information When Connecting USB Devices

When connecting a USB device, read the following important information.

USB 3.0 Support

USB 3.0 is not supported. Even devices that support USB 3.0 have the same behavior as USB 2.0 devices.

Connecting a USB-Ethernet Adapter

The following operations are not supported.

  • Connecting multiple USB-Ethernet adapters

If the HDEV system stops due to these operations, restart the HDEV.
For more information about restarting the HDEV, see 8.1 Restarting the HDEV.
