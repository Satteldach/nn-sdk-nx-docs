1 Introduction

Objectives and Content

You must provide the following two types of application icons for Nintendo Switch™ (hereafter Switch).

  • For Switch
    Mainly used on places like the splash screen, HOME Menu, and user page.
  • For smart device applications

This document provides an overview of Switch application icon images, including information about file formats and considerations needed when designing icons.

Intended Audience

  • Switch application developers
  • Graphic data designers
    Application icons, title logos, main visuals, etc.

Working Environment

  • Any environment where software like Adobe Illustrator CC and Adobe Photoshop CC can run.
  • Development environments where you can display application icons on Switch.
  • Environment for Using AuthoringTool.exe or Authoring Editor
    Note: AuthoringTool.exe and Authoring Editor are automatically installed when you install the NintendoSDK using the Nintendo Dev Interface.

When to Read This Document

Read this document when you are developing Switch applications and creating NX application icons.
