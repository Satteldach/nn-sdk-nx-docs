1 Introduction

Purpose and Content

This documentation provides useful information for planning and developing applications for the Nintendo Switch™ that use NEX.

It covers important considerations for application development and operation, examples of how to implement features, and frequently asked questions.

Read this documentation if your design plans include the use of network features.

Intended Audience

This document is intended for producers and developers of Switch applications that use NEX features.

We recommend that producers read 2 Server Services Functionality and 5 Tips and Tricks. We recommend that developers read everything.

When to Read This Document

Read this document when you are planning or developing Switch applications that use NEX features.
