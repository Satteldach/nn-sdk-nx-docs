4.3 Matchmaking

Score-Based Auto-Matchmaking

Contact Nintendo if the following two conditions apply in your case. Depending on the method used to configure the parameters, you might not receive the intended search results when searching for matchmaking sessions.

  • MATCHMAKE_SELECTION_METHOD_SCORE_BASED will be specified as the selection condition for automatic matchmaking. (Score-based auto-matchmaking.)
  • You are considering some method of use other than with parameters as presented in the example in NX NEX Manual > WebAPI > Matchmaking > API for Auto-Matchmaking by Scoring Feature.

Do Not Unnecessarily Increase the Total Number of Matchmaking Sessions

See 4.1 NEX General Considerations > Number of Data Instances That NEX Can Handle.

Excluding Non-Joinable Matchmaking Sessions From the Search Results

If you are using MatchmakeExtensionClient::BrowseMatchmakeSession to search for and allow the user to select a matchmaking session to join, we recommend excluding password-protected sessions and closed sessions from the search.

Some applications set passwords for matchmaking sessions to perform matchmaking between specific users. If the search results include these kinds of matchmaking sessions that are only open to some users, and matchmaking sessions that are already closed, the number of joinable matchmaking sessions that can be presented to the user may be diminished. As a result, users might repeatedly search for matchmaking sessions, degrading their experience and increasing the load on the server.

Auto-Matchmaking and Using Only One Search Criterion for Matchmaking Sessions

With the auto-matchmaking feature, if only one search criterion has been specified for the matchmaking session, the load on the game server can increase when many users are connected at the same time. If you expect your application will have large numbers of users connected at the same time, consider ways of distributing the load, such as dividing the matchmaking sessions into two or three game modes internally even if the search criteria appear identical to the user. Contact Nintendo during the planning phase if you expect your application will have large numbers of simultaneously connected users, making it difficult to distribute the load.

Error Displayed When the Blocked-User List Is Enabled

If the blocked-user list is enabled, an error occurs when a person uses a method other than auto-matchmaking to try to join a matchmaking session that includes a participant who has added that person to their blocked-user list.

To prevent bad feelings, do not display a message explaining that the person cannot join the matchmaking session because they are on a blocked-user list. Instead, simply explain to the user that they cannot participate in that matchmaking session. We recommend a generic message like "Could not join this group."

If the user continues searching for matchmaking sessions, we recommend that you do not redisplay the session that the user could not join.
