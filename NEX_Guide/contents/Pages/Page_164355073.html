6.1 Login/Common Features

Why do my game server logins always fail?

Check the following.

  • Verify that the appropriate game server ID and access key are being passed to the arguments of the NgsFacade::Login() function.
  • Verify that the appropriate application ID is specified in the NMETA file.
  • Verify that the sample demo runs successfully with the settings configured to connect to the sample demo server. If that fails, there might be a problem with the network and account settings. Double-check the settings.
  • If you can successfully connect to the sample demo server but the login to the game server prepared for the application fails, it might be that the game server is offline for some reason. Access NMAS2 and verify that the game server is online.
  • If error code 2306-0502 is displayed, see the description for this error code in the error code list. (English, Japanese)

Why do I get error code 2306-0801 when my game server login fails?

This error indicates that the error handling for login failures may not be working correctly.
Check whether the NgsFacade::GetLastLoginErrorCode() function is getting error codes correctly when the NgsFacade::Login() function fails.
