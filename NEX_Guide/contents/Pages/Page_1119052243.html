5.6 Friend Presence

The term "friend presence privacy" used on this page is a term specific to the Nintendo SDK friends library. On the Nintendo Switch family of consoles, this setting for changing the presence privacy is shown in the HOME Menu as Display online status to: in the Friend Settings.

If a friend changes their presence privacy setting while playing the application, NEX might not always be able to track changes in friend presence status.

When debugging the application, note the following specification about the presence status of friends.

The presence status can be checked using certain functions and certain notification events, but an outdated status might be referenced in the case of the following combinations of targets and conditions.

Target

  • SubscriberClient::GetUserStatuses()
  • SubscriberClient::GetFriendUserStatuses(const qVector<PrincipalID>&, qVector<SubscriberUserStatusInfo>*)
  • SubscriberClient::UpdateUserStatus() (Only when true is specified for the third argument, isNotify.)
  • MatchmakeExtensionClient::GetFriendNotificationData()
  • MatchmakeExtensionClient::UpdateNotificationData()
  • NotificationEvents::NotificationEvents
    • GameNotificationType1 to GameNotificationType8
    • GameNotificationLogout
    • UserStatusUpdatedEvent

Condition

When Using the Subscriber Feature

If both of the following conditions are met:

  • The friend changes their presence privacy setting while playing the application.
  • The feature for caching friend status is enabled (the SubscriberClient::EnableFriendUserStatusesCache() function has been called).

When Using the Matchmaking and Notification Event Features

If the following condition is met:

  • The friend changes their presence privacy setting while playing the application.

Examples

These examples are based on the following situation.

  • User A and user B are friends.
  • User B is trying to get the presence status of user A.
Case 1

User A starts playing the application with their presence privacy set to public, but then changes it to private while playing.

    • User B will continue to see the status for user A that was shared while user A's presence privacy setting was set to public.
    • The status of user A subsequent to changing the presence privacy setting to private is not shared with user B. Moreover, the outdated status continues to be shared even after user A has signed out of the NEX game server. (The status does not get deleted.)
Case 2

User A starts playing the application with their presence privacy set to private, but then changes it to public while playing.

    • The presence status of user A will continue to not be shared with user B.
    • However, when user A updates their status (changing from online to offline, or vice versa), that new status will be shared with user B.

Notes

  • In the context of this page, setting the presence privacy to public refers to one of the following situations.
    • User A has selected All Friends for Display online status to:
    • User A has selected Best Friends for Display online status to:, and user B is a best friend of user A.
  • In the context of this page, setting the presence privacy to private refers to one of the following situations.
    • User A has selected No One for Display online status to:.
    • User A has selected Best Friends for Display online status to:, but user B is not a best friend of user A.
    • User A has deleted user B from their friend list.

Workaround

Use the following workarounds to get the presence status, taking the setting for presence privacy into account.

  • Disable status caching and use the NEX library to check the status as needed, without depending on NEX library notification events.
  • Compare the status as checked using the NEX library with the status checked using the friends library.

In either case, be careful to comply with the guideline that restricts the frequency of function calls.
