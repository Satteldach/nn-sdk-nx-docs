6.2 Requesting and Preparing a Game Server

How do I make a request to use a game server?

Submit a request on OMAS. An NDID is required in order to log in to OMAS. If you do not have an NDID, contact the NDID administrator in your company.

I have applied for use of a game server. When will I be able to start using it?

Servers are set up within three business days after the OMAS phase has advanced to the server setup phase. If your game server has not been set up appropriately, communicate with your Nintendo contact via the OMAS message boards.

Why did my game server suddenly stop working?

Check that there are no issues with the application and the application runtime environment, and then ask the assignee via the OMAS message board.

Info

Until now, if the game server had not been accessed for a certain period (2 weeks), the game server automatically transitioned into a temporarily suspended state. After entering that state, error 2306-0502 occurred. By operating NMAS (NMAS1), the game server could be brought back online.

This operation is currently discontinued. The game server does not periodically and automatically transition to a temporarily suspended state. However, a game server that is not being used might transition to a temporarily suspended state at irregular times. (For more information, see Nintendo Developer Portal > Technical Information > Announcements > NEX game server to be stopped when not accessed from a development kit for a certain period of time.

The NEX library is linked to the application but is not being used.

If the NEX library is linked to the application but the NEX API is not being called (for example, due to the middleware build being used by the application), do not request the use of NEX on OMAS.

Info

If you link the NEX library, you need to clearly state the use of NEX in SLIM and include a legal notice, even if the application does not call NEX APIs.
