5.1 NEX General Considerations

Do Not Upload Confidential Data to Game Servers

Do not upload confidential game data to servers in any environment.

There is even a risk of a data leak after the application is released even if confidential data is uploaded to environments other than the production environment.

Background

After an application is released, the information contained in the application that is used to log in to the game server (game server ID and access key) is at higher risk of being extracted. Because this extracted information can be used to illegally log in to the game server, the following kinds of data are in danger of being accessed.

  • Matchmaking: strings describing matchmaking sessions and persistent gatherings
  • Data store: data uploaded with DataStoreConstants::PERMISSION_PUBLIC permissions

Workaround

If data that you want to keep confidential must be uploaded to game server, encrypt it. We recommend using BCAT data delivery to distribute the decryption key. BCAT's test delivery function allows for connection restriction by global IP address during debugging.

Checking the Overlay Display of Maintenance Notifications in the Development Environment

In the development environment, you can use NMAS2 to send maintenance notifications that are displayed as overlays.

For more information about maintenance notifications, see 4.5 Server Operations.

Conditions for Displaying Maintenance Notifications as Overlays

To display maintenance notifications as overlays, the following conditions must be satisfied.

  • NEX Conditions
    • For a notification of the start of maintenance, the current time is not later than the game server stop time.
    • For a notification of scheduled maintenance, the current time is not later than the scheduled maintenance time.
    • The application is logged in to a NEX game server.
      • The notification is displayed logging in to the game server. In addition, the notification is displayed each time the user logs in during the available period.
  • System Settings Conditions
    • The system is connected to the network.
    • The user account logged in to the NEX game server is linked to a Nintendo Account.
    • A NSA notification token is registered on the server.
      • It is automatically registered from the HOME Menu or DevMenu if linked to a Nintendo Account.
    • The application is registered on the Switch system.
      • The application must be installed on the Switch console, either in system memory or on a microSD card, or the game card must be inserted. Overlays are not displayed correctly if you are using the development hardware and directly running an application on a PC.

Maintenance Start Notifications

To check notifications of the start of maintenance, change Maintenance Start Notification Event on NMAS2 to Notification On. You cannot specify the game server stop time in maintenance start notification settings on NMAS2.

The game server stop time is set automatically to a time five minutes after Maintenance Start Notification Event has changed from Stopped to Notification On. In other words, notifications of the start of maintenance can be received for five minutes after the change to Notification On.

Notification of Scheduled Maintenance

To check notifications of scheduled maintenance, change Scheduled Maintenance Notification Event on NMAS2 to Notification On. At that time, specify the scheduled maintenance time.

Notifications of scheduled maintenance can be received at any time after this setting is changed to Notification On, until the scheduled maintenance time has passed.

Info

The period for receiving scheduled maintenance notifications in the development environment differs from that of the production environment.

Scheduled maintenance notifications in the production environment can be received starting an hour before the start of maintenance until the scheduled maintenance time has passed.
