  • 2 Server Services Functionality

    Separated the information in Logging In From a Windows Application based on the version of NintendoSDK being used.

      • Subscribers no longer need to be listed because the topics feature has been discontinued.

    In the lead sentence, clarified that "friend presence privacy" is a NintendoSDK friends library term.

8.0 2021-02-12 Changes
  • Development/Usage Overview
    Divided Development and Debugging into three sections: Requesting Use, Setup, and Server Load Considerations. Added that if you want to use NEX in a future patch, you can request to use NEX in OMAS in advance.

    Rephrased wording.
  • NEX General Considerations
    • Added the following information to Number of Data Instances That NEX Can Handle.
      • For matchmaking, noted the need to close and remove matchmaking sessions as appropriate.
      • For Ranking (Ranking2), noted the need to consider both whether periodic resets are enabled and the number of past sessions of data that will be saved when you estimate the total number of scores.
    • In Required Connection Environment for Connecting to the Game Server, added that accessing servers other than the game server may occur.
    • Rephrased wording.
  • Data Store
    Added Making the Scope of Data Update Permissions as Small as Possible.
  • Matchmaking
    Renamed Matchmaking Sessions That Are Not Closed, changing it to Do Not Unnecessarily Increase the Total Number of Matchmaking Sessions. Deleted the description and replaced it with a link to NEX General Considerations > Number of Data Instances That NEX Can Handle.
  • Server Operations
    Added an Info block to Automatically Copying Game Server Settings, noting that the settings are managed per game server, so you must be careful that there are no conflicts among applications that share a game server.
  • Applications for China
    Added Cannot View Statistics in SMAS (statistics for game servers used by applications for China cannot be viewed in SMAS).
  • Requesting and Preparing a Game Server
    Added "The NEX library is linked to the application but is not being used" to the FAQ.
