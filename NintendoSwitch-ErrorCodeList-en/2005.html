2005-0004 This error occurs in the following circumstances.

1.
When copying of directory attributes failed when using a PC to copy data from one microSD card to another microSD card.
Windows Explorer copies directory attributes correctly. However, in some cases other operating systems, including MacOS and its Finder, will not copy directory attributes correctly. There is no issue with copying the data itself.

2.
When there are other specific causes not yet listed.
