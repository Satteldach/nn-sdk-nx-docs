2185-0101 ResultContinuousHighSkinTemperature Forcibly entered sleep mode to avoid low-temperature burns because conditions meeting the following criteria continued for a long time.
• Handheld mode.
• No clear indications of user operations, including button input.
• The estimated surface temperature is at or above a set level.		 Sleep mode was triggered to avoid low-temperature burns.
This error can occur in a normal environment.
To block this feature, disable Thermal Burn Prevention Mode in the development support feature settings of the DevMenu.		 Conditions meeting the following criteria are to be continued for a long time.
• Handheld mode.
• No clear indications of user operations, including button input.
• The system is running hot.		 This error is for analysis and should not be shown to a general user.
