2202-3101 ResultControllerSupportCanceled If you press the HOME Button to return to the HOME Menu while the controller support applet called by the application is running, call another system feature, and then return to the application, the controller support applet will be canceled.
This error falls within specifications when that occurs.
Normally this error is handled in the application. Prompt the user without displaying the error code.
This error is displayed to users when you skip the preceding error handling in the application.		 Handle this error in the application, in conjunction with the controller connection status, without calling the error viewer applet. 1. In tabletop mode, proceed to Controllers from the HOME Menu and set the left Joy-Con to P1.
2. Start the application.
3. After the title screen appears, press any button on the right Joy-Con.
4. When the controller support applet is displayed in the game, press the HOME Button.
5. Navigate to Controllers and select Change Grip/Order.
6. Set the right Joy-Con to P1 and return to the HOME Menu.
7. Restart the application.
