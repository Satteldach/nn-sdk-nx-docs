2621-9999 N/A A general-purpose error message. Error codes configured with generic messages represent errors that are supposed to be fixed at the development stage or handled by the application. For the firmware installed on initial production lot consoles, a message prompting a system update is assigned to 2621-9999. In addition, the 2621-9999 message is always displayed.
For consoles that have had at least one system update, the message is replaced and a generic error message is assigned to 2621-9999. Also, error messages will then be displayed according to the situation.
