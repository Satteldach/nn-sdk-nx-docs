2002-4071 ResultDataCorrupted Corrupted or altered data detected. The ROM (resource data) or downloadable content is corrupted.
If this error occurs when accessing an installed application or downloadable content, it can be resolved by reinstalling the application or downloadable content.
This error does not occur due to an issue with the application, with the exception of cases where excessive access to the storage media causes malfunctioning or data corruption.
For more information about access restrictions on storage media, see Guidelines > File system > Storage media > Limits on frequency and amount of writing to storage media, and also Limit on frequency of reading storage media.
Regarding this error code, Nintendo's website provides guidance on formatting SD cards, exchanging SD cards, redownloading applications, and fixes.
If this error occurs in the development environment while running an NSP file from the host PC, the data in the NSP file on the host PC might be corrupted.
For more information, see NintendoSDK Documents > Features > Building > Creating Application Images > Tool Reference > AuthoringTool > Checking Data Integrity in NSP Files.
