2162-0001 ResultApplicationAbort Error indicating an application abort. Handle this error using the following steps.
1. Use the debugger or Target Manager to check the stack trace symbol.
2. If the abort occurred during the application routine, take another look at the application's source code.
3. If the abort happened in the SDK or a middleware routine, double check the API calls.
4. Submit the stack trace to Nintendo for consultation.

If the stack trace is not displayed, change the application build type to Debug or Develop, and then attempt to reproduce the error.

===

Note that using the crash report allows you to check the stack trace for an abort that occurred on Switch units not owned by the developer.

2162-0002 ResultSystemProgramAbort Error indicating a system program abort. Cannot isolate the cause. When the cause of a fatal error that occurred on development hardware cannot be identified, and Nintendo must be contacted to resolve the issue, consider submitting the log (encrypted error information) obtained by one of the following methods.


Method A.
You can save the log to your PC by executing the following commands at the command prompt.
%NINTENDO_SDK_ROOT%/Tools/CommandLineTools/ControlTarget.exe devmenu -- error export C:\tmp\error_report.bin

For more information, see the DevMenuCommand error subcommands in the following documentation.

- En: https://developer.nintendo.com/html/online-docs/g1kr9vj6-en/Packages/SDK/NintendoSDK/Documents/Package/contents/Pages/Page_424124130.html
- Ja: https://developer.nintendo.com/html/online-docs/g1kr9vj6-ja/Packages/SDK/NintendoSDK/Documents_PartiallyEnglish/Package/contents/Pages/Page_424124130.html


Method B.
You can save the log to a microSD memory card or to your PC via the Export button in the DevMenu Error tab on the development hardware.

For more information, see the following DevMenu documentation.

- En: https://developer.nintendo.com/html/online-docs/g1kr9vj6-en/Packages/SDK/NintendoSDK/Documents/Package/contents/Pages/Page_310877862.html
