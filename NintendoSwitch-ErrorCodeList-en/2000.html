Display Language:
Error Code ? Result Description Solution(for developer) How to reproduce Comments
2000-0000 nn::ResultSuccess This error code indicates success. 1.
This error code might be displayed in the error viewer applet if the following two conditions are met.
• The build type of the application is the release build.
• nn::err::ShowError(nn::ResultSuccess()) was called by the application.
Do not display this error code in the error viewer applet.

2.
This error code might be displayed when CrashReport.exe is run if the following two conditions are met.
• NN_ABORT() was called by the application.
• The crash report created by NN_ABORT() was uploaded to the server by a Switch console with system version 7.0.0 or earlier.
