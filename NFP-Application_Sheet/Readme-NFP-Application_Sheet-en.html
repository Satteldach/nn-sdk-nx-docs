1. Introduction

The purpose of the amiibo Application Sheet is for developers to inform Nintendo about which amiibo figures they are planning to use when developing applications and how those applications will use amiibo.

It is not necessary for all of the details to be finalized before starting development, but please fill in as much information as possible when submitting this form to Nintendo support.

If there are subsequent changes in your application's design or you have finalized its specifications, please revise this sheet and resubmit it. This application sheet must be included in the final submission to Nintendo Lotcheck, along with the Master Data Checklist.
