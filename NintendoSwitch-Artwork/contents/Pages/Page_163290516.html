1 Introduction

Objectives and Content

This documentation introduces the artwork, such as Joy-Con™, available for Nintendo Switch™ application development and for printed materials, and provides the rules and instructions for its use.

Intended Audience

This document is intended for developers of applications and for those associated with printed materials.

When to Read This Document

Read this during application planning and development, and when creating printed materials.

Structure of This Document

The rules when using artwork are included in 2 Rules for Using Artwork.

The following pages in 3 Hardware Images and 4 Icons are based on the folder structure of the artwork data (hardillustration and iconhardillustration).

  • 3 Hardware Images
    • 3.1 Nintendo Switch System
    • 3.2 Joy-Con
    • 3.3 Other Controllers
    • 3.4 Handheld Illustrations
    • 3.5 Accessories
  • 4 Icons
    • 4.1 Hardware Icons
    • 4.2 Button Icons
    • 4.3 System Application Icons
    • 4.4 Other Icons

Required PC Applications

Adobe Illustrator CS6 or later version.

File List

Note:

Filenames are subject to change.

hardillustration Folder

When you open the hardillustration folder, there is a CMYK folder and an RGB folder. The CMYK and RGB format files are stored in their respective folders.

The xxx portion of the filenames is either cmyk or rgb. The YYYYMMDD portion is the date the file was created.
