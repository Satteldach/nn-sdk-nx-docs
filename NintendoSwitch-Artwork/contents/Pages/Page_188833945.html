4.3 System Application Icons

This section describes the system application icons for applications built into the system that can be started from the Nintendo Switch HOME Menu.

The illustrations on this page are identical to those for the system fonts, or Nintendo extended characters.

You are free to use either artwork data or the Nintendo extended characters when developing applications. Use bold lines to match the style of system application icons in the HOME Menu.

Note:

They can be used when you want to call a system feature from within an application, or to illustrate a location on the HOME Menu.
