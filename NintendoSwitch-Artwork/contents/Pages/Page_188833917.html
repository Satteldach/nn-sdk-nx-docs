4.4 Other Icons

This section describes the other icons.

The sleep icon and friend icon are identical to those for the system fonts, or Nintendo extended characters.

You are free to use either artwork data or the Nintendo extended characters when developing applications.

Sleep Icon

This icon represents putting the Nintendo Switch system into sleep mode.

Nintendo Switch Parental Controls™

Icon for the Nintendo Switch parental controls smart device app.

Two versions of this artwork have been created: one with borders and one without.

Use the version with borders when the outline of the icon would otherwise be lost in the background.

The following color is recommended.
