1. Introduction

This Artwork Collection brings together all artwork data for Nintendo Switch™. It brings together the artwork that can be used for purposes such as printed materials and Nintendo Switch application development. For more information, see the Nintendo Switch Artwork Usage Manual.

Contact Information

Contact your Nintendo support representative. For Nintendo titles, contact the Nintendo representative for each title or the Nintendo Artwork Collections representative.

2. Revision History

  • 4.0 [2024-05-31]　
    • Added Contact Information to the Readme file.
    • Hardware images: Added NX_console_large_XXX_YYYYMMDD.ai, which shows an oblique view of the console.
    • Hardware images: Added NX_left_controller_large_XXX_YYYYMMDD.ai, which shows an oblique view of the Joy-Con.
    • Hardware images: Added NX_right_controller_large_XXX_YYYYMMDD.ai, which shows an oblique view of the Joy-Con.
    • Hardware images: Added NX_classic_grip_accessory_large_XXX_YYYYMMDD.ai, which shows an oblique view of the Joy-Con grip.
    • Replaced the icon images in NX_stick_button_XXX_YYYYMMDD.ai, for control sticks and pressing the control sticks, with artwork that includes the part of the stick below the button.
  • 3.0 [2017-04-28]　
    • Hardware images: Added the Joy-Con wheel image NX_controller_with_hand_large_XXX_YYYYMMDD.ai.
    • Hardware images: Added the Joy-Con wheel image NX_controller_with_hand_small_XXX_YYYYMMDD.ai.
    • Hardware images: Added the Joy-Con AA battery pack image NX_Joy-Con_BatteryPack_small_XXX_YYYYMMDD.ai (small only).
  • 2.0 [2017-03-24]　
    • Added Joy-Con hardware images (top-down and isometric views).
    • Added images for other controllers (isometric view of Pro Controller).
    • Fixed overview of hardware and button icons.
    • Added button icons (up/down/left/right on controller).
    • Added Nintendo eShop icons within system application icons, and changed overview.
    • Deleted inverted artwork of controller.
    • Added Post icons.
  • 1.2 [2016-12-19]
    • Added artwork for the system application icon NX_system_icon_XXX_YYYYMMDD.ai, and the miscellaneous icon NX_other_icon_XXX_YYYYMMDD.ai.
  • 1.1 [2016/11/18]
    • Updated the names of the system and accessories.
  • 1.0 [2016/08/31]
    • Initial version.
