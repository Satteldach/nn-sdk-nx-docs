8 Running Applications

Applications installed on the HDEV console can be started from the DevMenu.

Running Installed Applications

Procedure Operation
1

Turn on the HDEV console.

A screen similar to the following is displayed when the DevMenu is started.

If this screen is not displayed, from the menu on the left, select Application.

A list of applications installed on the HDEV console is displayed.
2

Tap the application you want to run.

The selected application starts.
