5 Setting Up NintendoSDK

The NintendoSDK is obtained from the Nintendo server using NDI. NDI downloads the NintendoSDK from the Nintendo server, and then extracts and installs the necessary files.

Installing the NintendoSDK Package

Info

Windows Administrator privileges are required to use NDI.


Procedure Operation
1

Start NDI and select Dev Environments > Add Environment > Create My Own > Install to Disk.

→ →


2

In the Connect to Nintendo Server dialog box, enter the following information.

  • Server: Select Nintendo Developer Portal.
  • Nintendo Developer ID: Enter the NDID you use when logging in to the Nintendo Developer Portal.

Then click the Connect button. When the NDID dialog box is displayed, enter your password to log in.

Info

NDI communicates with the Nintendo Developer Portal because the packages it handles are based on Nintendo Developer Portal permissions.
3

For the platform, select Nintendo Switch. For the tool set, select SystemUpdater. Then click Next.

Info

To install packages other than SystemUpdater and Target Manager, select Standard.
4

Select the version of SystemUpdater you want to install and click Next.
Note: To initialize the HDEV, you must select SystemUpdater version 9.0.0+Build5.0 or later.
5

Enter the path where the environment will be created, and the name of the directory (using the environment name). Then click Next.

Info

The NintendoSDK will be installed in this directory.

To install multiple versions or installation package types of the NintendoSDK, you can create multiple directories.


Info

False Positives From Antivirus Software

When installing various NintendoSDK packages, NintendoSDK files can be detected incorrectly as viruses by antivirus software.
When such false positives occur, exclude the NintendoSDK install destination folder from the virus scan, and try installing again.
6

The packages that are installed by default are displayed. Confirm the list and click Next.
7

Check the type and version of the package to be installed. If there are no issues click Install. Download and installation will begin.

→


8

USB driver installation can be verified during NintendoSDK installation. Install the driver.
9

On the screen shown when NintendoSDK installation is completed, click Finish.

A management screen now appears, listing the actions you can perform in the installed environment.

Keep this management screen open, because it will be used for later procedures.
