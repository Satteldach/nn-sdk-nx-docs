4.1 Development Process for Applications Using amiibo Figures

amiibo compatible applications use the following development flow.

  1. amiibo Usage Request.
  2. Get an access ID if you are using the application-specific region. This access ID will be issued to you when the amiibo usage request is accepted by Nintendo.
  3. Get a Development Environment.
  4. Start application development.

You may acquire a development environment to test the system before submitting an amiibo usage request.
