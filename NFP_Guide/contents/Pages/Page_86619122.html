3.3 Other

Automatic Backups

When an NFP tag is read using the NFP Library, the data in that tag is backed up automatically. If the data in the NFP tag becomes corrupted, this backup data can be recovered for use from the amiibo Settings. The backup data cannot be freely used from the application.

NFP Tag Security

With some exceptions, the data stored in amiibo figures is encrypted and supports HMAC authentication to prevent tampering. However, due to the inherent security limitations of NFC technologies, we recommend that you simply avoid storing data on NFP tags that could result in problems if copied or hacked.

NFP Tag Life

NFP tags are assured to last for 100,000 delete-write cycles.

Lost or Damaged NFP Tags

Note that if an amiibo figure is lost or damaged, the user cannot continue to use the exact same tag.
