3.1.3 Application-Specific Region

The application-specific region is a 216-byte region that the application can read from and write to. Data written to the application-specific region is associated with the amiibo character used. When your application writes data to the application-specific region, include data that is likely to make the user feel like the amiibo product is special, unique, and important. Do not use the application-specific region merely as a data storage device or to store data unrelated to the amiibo character itself.

For more information about applications that can read from and write to the application-specific region, see 3.2.1 Use of the Application-Specific Region.
