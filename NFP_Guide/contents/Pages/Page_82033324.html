6.12 Limitations on Using the NFC Reader/Writer

The NFC reader/writer communicates with the 3DS system using high-frequency IR data transmission. As a result, there may be limitations on the features that can be used during communication between the NFC reader/writer and the 3DS system. Depending on how the application is implemented, the NFC reader/writer and the 3DS system may be unintentionally disconnected, or the application may exhibit a noticeable slowdown. When using the NFC reader/writer, disable unnecessary features to minimize the processing load on the system.

For more information, see the Nintendo 3DS Programming Manual.

Info

Features/system modules affected by NFC reader/writer communication include the camera, YUV/RGB conversion, the microphone, the accelerometer, the gyro, wireless communications, DSP, and the debugging pad. Regardless of whether it is actually used in the application, the debugging pad places a processing load on the system just by being connected to the debugger.
