5.4 NTF File Creation Tool

The NTF File Creation Tool (NTFMaker) enables application developers to create their own NTF files. NTFMaker is intended primarily for creation of NTF files that are not currently provided in the amiibo data list. NTFMaker can also be used to check the values set in an NTF file simply by loading that NTF file in NTFMaker.

In most cases, application developers can develop NFP-compatible titles using only the NTF files currently available in the amiibo data list. This tool can be used to explore and test amiibo features and configurations that are not currently supported.

For detailed usage instructions, see the manual included with NTFMaker.
