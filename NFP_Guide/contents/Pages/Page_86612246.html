1.2 Related Documents
This section provides a list of documents that we recommend familiarizing yourself with when developing an NFP-compatible application. Refer to these documents as needed when developing your NFP-compatible application.
  • amiibo Terminology
    Provides a list of basic amiibo terminology.
  • amiibo Artwork Collection
    Contains amiibo-related logo designs, audio data, screenshots, and so on.
  • amiibo Usage and Lotcheck Sheet
    Fill in details of how you plan to use amiibo products and which amiibo products you will support when developing an amiibo-compatible title, and then submit this sheet to Nintendo.
  • amiibo Data List
    Provides a list of IDs set to each amiibo product and other tag data you will need during application development.
  • The Nintendo 3DS, Wii U, and Nintendo Switch Guidelines
    A summary of guidelines and other requirements that must be followed when developing an NFP-compatible application.
  • 3DS/Wii U Programming Manual: NFP Library, NintendoSDK Documents
    A thorough summary of information related to implementation of NFP-compatible applications.
