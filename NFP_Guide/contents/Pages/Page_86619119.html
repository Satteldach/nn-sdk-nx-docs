3.2.1 Use of the Application-Specific Region

When reading data from or writing data to the application-specific region, the application-specific region of the amiibo product must be empty, or currently only contain data from the application attempting to access the application-specific region. After a particular application writes data to the application-specific region, other applications cannot read from or write to the region until the data in the region is erased using the amiibo Settings application.

However, assigning the same access ID to multiple applications makes it possible for all of those applications to have access to the data in the application-specific region. Please contact Nintendo if you are considering such a plan.
