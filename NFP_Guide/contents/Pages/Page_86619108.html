3.1.1 NFP Tag Regions

An NFP tag is an NFC tag in a special NFP format with two regions: a shared region that is read-only, and an application-specific region in which the application can read and write data.

Figure 3-1 NFP Tag Regions

The regions accessible to the application differ according to the type of amiibo the user touched to the touch point, as shown in the following table.
