2.2.2 amiibo Design

amiibo products can have a wide variety of designs. Not only are there amiibo products for different characters such as Mario and Luigi, there are a variety of amiibo products for the same character for versions of the character with different names, coloring, and so on. (See Figure 2-6 Various Designs for Mario amiibo Products.) The NFP tag in each amiibo contains a unique ID so that amiibo products can be distinguished from one another in the application. For more information about distinguishing amiibo products using those IDs, see 3.1.2 Shared Region.
