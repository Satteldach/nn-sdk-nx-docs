3.2 Accessing NFP Tags

The application must determine what character is associated with the touched amiibo figure. The recommended processes to perform for a particular amiibo depend on whether that amiibo figure's character appears in the application. The differences are shown in the following figure.

  • If the character does not appear in the application (pink in the figure):
    • Only read data to an application from the amiibo figure's shared region.
  • If the character does appear in the application (blue in the figure):
    • The application is free to write original information to the amiibo figure's application-specific region.
