5.3 NFP Tag Creation Set

To create amiibo figures for development, use the following tools and data file.

The process of creating an amiibo figure for development purposes is shown in Figure 5-1 Creating an amiibo Figure for Development. You use noft_writer to write an NTF file containing the amiibo information to a blank tag, which is a tag to which data can be written.

Figure 5-1 Creating an amiibo Figure for Development

Blank Tag

An empty NFP tag.

Development amiibo tags created by using noft_writer to write an NTF file to a blank tag cannot be used on retail game systems. Similarly, you cannot read from or write to a retail amiibo from a development console.

NTF File

The data to be written to the blank tag. Contains factory default-state amiibo data. Bundled in the amiibo data list.

noft_writer

This program runs on development hardware and writes the data from NTF files to blank tags. It cannot write data to retail product tags.

Warning

After an NTF file is written to a tag and locked, it cannot be overwritten. After an NTF file has been written to a blank tag and locked, it is no longer possible to overwrite the data that was entered in the 3.1.2 Shared Region at the factory. Note that this prevents you from overwriting an NTF file even for the same character with different designs because the data is provided in separate NTF data files.
Although overwriting with a separate NTF file is possible if the tag is not locked, note that tags that are not locked have the limitation of being usable only in debugging mode and so forth. For more information, see the noft_writer description of each platform.

Writing can fail if the tag is moved away from the NFC touchpoint while noft_writer is writing data. If that happens, you cannot repair the tag by overwriting the data. Be careful not to move the tag away while writing the NTF file.

noft_writer does not support the NFC Reader/Writer.
