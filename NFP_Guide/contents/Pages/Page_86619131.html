5.5 amiibo Settings

The amiibo Settings application provides a variety of features for working with the data stored on amiibo products. It is embedded in the game system, called by the application, and used like one feature of the System Settings. It is assumed that the amiibo Settings application will be used to register the owner's Mii and amiibo nickname when the amiibo is first used.

The amiibo Settings application supports the following features.

  • Registering and editing the owner's Mii and amiibo nicknames
  • Data management
    • Deleting the data in the application-specific region
    • Resetting the amiibo
    • Restoring the amiibo
      • If the system detects that the amiibo data is corrupted, the data must be restored. Application developers can choose to start amiibo Settings in recovery mode or implement a recovery sequence within the application.
  • Updating NFC reader/writer firmware
    • This feature is only enabled on the Nintendo 3DS, Nintendo 3DS XL, and Nintendo 2DS. If the NFC reader/writer is running an earlier version of the firmware, the NFP library returns an error when it connects to the NFC reader/writer. Have the application call the amiibo Settings feature and update the firmware, or prompt the user to start amiibo Settings and update the firmware manually.
