6.9 Rolling Back the Application-Specific Region

The NFP library contains a function to back up the data of an amiibo that has been read. If the amiibo the user touched to the touchpoint is damaged, it may be restored from this backup data.

If this feature is exploited, the application-specific region may be rolled back in an unauthorized manner.

Figure 6-3 Rolling Back the Application-Specific Region

  1. Get 100pt with device A, and save to amiibo.
  2. Exchange 100pt with an item on device A, and save the item in the application save data.
  3. Remove the amiibo from the touchpoint while device B is writing to it, damaging the application-specific region.
  4. Restore the damaged amiibo data on device A.

Repeat step 2 to 4, generating infinite items in the save data of device B.

Note that the data stored in the application-specific region may be copied in this manner.
