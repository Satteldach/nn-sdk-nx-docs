6.7 Using amiibo Figures at a Storefront and Events

Note the following important information when considering the use of amiibo with non-retail devices in these locations.

  • Storefront
    • Nintendo is currently developing an environment that will allow retail amiibo to be used at Retail Interactive Displays. amiibo may not be used with Retail Interactive Displays until this environment has been prepared.
  • Events
    • Please contact Nintendo support when considering the use of retail amiibo at an event at a store or game show.

There are two types of NFP tags: a retail device version placed on retail amiibo, and a development version created by writing a NTF file using noft_writer. A retail device can only read or write data on a retail amiibo, and a development emulator can only read or write data on a development amiibo. A Retail Interactive Display accesses an amiibo in the same fashion as a development emulator, making it incompatible with a retail amiibo. Development emulators have been used at events in the past. If you are using a development emulator, it cannot read or write a retail amiibo. Contact Nintendo if you are planning to use amiibo at events.
