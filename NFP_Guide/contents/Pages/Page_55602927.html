5.1 NFP Library

The NFP library provides the following features for using amiibo figures from game applications.

  • Detecting NFC tags
    • The NFP library includes support not only for detection of NFP tags but also for any NFC tags supported by the system hardware. For more information about the specific types of NFC tags that can be detected, see the NFP Library section in the programming manual for each platform.
  • Writing and reading NFP tags
    • This feature reads and writes data on NFP tags.
  • Backing up the data from amiibo figures
    • The NFP library automatically backs up the data from an amiibo figure when it is touched, storing it as amiibo Settings save data.
    • If the application detects that the amiibo data is corrupted, the data can be recovered using the NFP library.
    • The latest data stored on the game system is used as the recovery data.
    • For important considerations when using the backup feature to roll back the application-specific region, see 6.9 Rolling Back the Application-Specific Region.
Info

Only one NFP tag can be detected at a time. Simultaneous detection of two or more NFP tags is not supported and may result in problematic application behavior. Improper use of NFP tags with the NFC Reader/Writer may cause them to stop responding and require them to be restarted to function normally.
