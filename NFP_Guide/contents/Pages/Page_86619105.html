3.1 NFP tag

NFP tags are the dedicated NFC tags built into amiibo figures. NFP tags employ a proprietary Nintendo data format and can be read and written using the NFP library.

For more information about data regions in NFP tags, see 3.1.1 NFP Tag Regions. For more information about using NFP tags in applications, see 3.2 Accessing NFP Tags.
