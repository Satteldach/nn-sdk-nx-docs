6.10 Supporting amiibo With Nintendo 3DS Applications

Systems in the Nintendo 3DS family can be classified in the following categories by NFC functionality.

  • Integrated NFC reader/writer
    • New Nintendo 3DS, New Nintendo 3DS XL
  • Does not have an integrated NFC reader/writer (reader/writer sold separately)
    • Nintendo 3DS, Nintendo 3DS XL, and Nintendo 2DS systems.

Nintendo wants titles that support amiibo products to be playable on both the New Nintendo 3DS systems and the existing Nintendo 3DS systems. Nintendo has created a development environment to minimize the development costs associated with supporting the new Nintendo 3DS systems and the existing Nintendo 3DS systems.

However, while the new Nintendo 3DS systems have an integrated NFC reader/writer, the existing Nintendo 3DS systems do not. Developers must pay special attention to display of Help messages to prevent user confusion when using amiibo products. For example, you can create unique notification messages for when an amiibo figure is tapped to the game system for the new and existing Nintendo 3DS systems in addition to unique error messages for the new and existing Nintendo 3DS systems. The amiibo artwork collection and the 3DS Error Code List provide sample images and sample error messages for notifications. Use these samples as needed when creating your own notification messages.

The New Nintendo 3DS has a built-in NFC antenna near the center of the LCD touch screen. Tap an amiibo product near the center of the LCD touch screen to detect the NFP tag. NFP tags may not be properly detected if tapped to locations of the LCD touch screen other than the center.
