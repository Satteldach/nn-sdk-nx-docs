6.2 Respect for Character Images

If you are going to use an amiibo, do nothing to harm the image of the amiibo or its corresponding character. Be mindful of the following points.

General Use of amiibo Figures
  • Do not use the amiibo in clearly offensive ways.
    • Do not use the amiibo in ways that would otherwise make users feel uncomfortable.
If the Character for an amiibo Appears in the Application
  • We recommend writing data related to the character corresponding to the amiibo.
    • For example, parameters relating to the growth of the character and information about its accessories. Avoid using the amiibo figures as a mere means of carrying data around, as if they were SD cards. In other words, do not use them to simply write portions of save data, or to just write data that is unrelated to a specific character and would be the same no matter what the amiibo.
  • We recommend using information about the character corresponding to the amiibo.
    • For example, you can make the character appear in the scene when the corresponding amiibo figure is touched. Avoid using the amiibo figure just to get the user's Mii character, or just to use the character ID as a random number seed.
If the Character for an amiibo Does Not Appear in the Application
  • Do not write to that amiibo figure.
    • When an amiibo figure is touched, the application must check to determine whether the corresponding character will make an appearance. Check as described in 6.3 Application Support for Characters, and if the character does not appear in the application, do not write data to the amiibo figure's application-specific region.
  • Do not damage official brand names or character images.
    • For example, if there is some effect unrelated to the character, do not make the difference of the effect so big that users get the impression that the character is useless. Do not do significant harm to the image of a character in places where the character does not appear.
