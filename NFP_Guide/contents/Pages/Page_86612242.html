1.1 About This Document

The Nintendo Figure Platform (or NFC Featured Platform) (NFP) provides a new way to play games by touching amiiboTM character products with built-in NFP tags (NFC tags formatted for use with the NFP library) to the game device or one of its accessories.

This document is intended for application designers who want to create NFP-compatible applications. We recommend that you read it during the early stages of application planning and design. It provides an overview of the NFP platform and outlines a basic workflow for developing NFP-compatible applications.

This document does not cover using NFC tags in non-amiibo products and does not contain information about creating new types of amiibo products. If you are considering new uses of NFC tags or new amiibo products, contact support@noa.com.
