2.2.1 amiibo Figures and Their Owners

The user in possession of an amiibo figure is called its owner. You can register the owner's Mii and set a nickname for the amiibo. In general, this information is entered to the amiibo in the amiibo Settings the first time the amiibo is used.

Inside the application, the owner's Mii and the owner's self-named amiibo can move together and help each other, reinforcing the sense that this game character is the owner's own character. The goal is to deepen the relationship between players and characters that were previously locked inside the game, and to enhance the game experience.

amiibo Touch & Play: Nintendo Classics Highlights

If the user taps an amiibo character that has not yet been used in this game, they are rewarded with a message that states "Your (amiibo nickname) has received a Nintendo Classic!". Then, when the user taps the game icon on the title screen, a dialog box containing the amiibo's owner and the amiibo's nickname is displayed. The game associated with the game icon can then be started from this dialog box.
