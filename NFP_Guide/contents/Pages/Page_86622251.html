6.3 Application Support for Characters

Users who purchase amiibo products expect to be able to use those products with a variety of applications. In most cases, plan on supporting the widest possible range of amiibo products.

The products that can be used in applications are listed in the amiibo Data List. New amiibo products that are not currently listed in the amiibo Data List may be released in the future. Contact Nintendo for additional information about characters you would like to support that are not currently listed on the amiibo Data List.

Applications can also support amiibo figures that are not for sale, using one of the following methods.

  • Support for amiibo that are not for sale but whose characters are in the amiibo Data List
    • Use the information in the amiibo Data List just as you would for amiibo that have already gone on sale.
  • Support for amiibo whose characters are not in the amiibo Data List
    • If you want to support an amiibo that may be created at a future time:
      • Reserve a character ID for the character you would like to support.
        Contact Nintendo if you want your application to support the amiibo for a character that is not created yet but will be created and go on sale in the future.
      • Get the character ID and use that to support the amiibo in your application.
        Consider the example in Figure 6-1 Supporting Characters Without IDs. In that example, a response to use when a Kirby amiibo is touched has been prepared in the application. This preparation is for the time in the future when Kirby amiibo figures go on sale. Character IDs are required to distinguish among different characters, so the one item that needs to be reserved ahead of time is the character ID.
