3.7.3 Calling the My Page Applet

Friends Features Included in the My Page Applet

The My Page applet is a library applet that provides a collection of user-related information and features.
It includes the friend list feature for checking the list of friends and adding friends.

With the friend list feature, users can do the following.

  • Check the profiles and the presence of friends, set best friends, and delete friends.
  • Send, receive, accept, and delete friend requests.
  • Check the Player History.
  • Check and accept (join) invitations to online play.
  • Change the settings of the Friends feature.
  • Manage the blocked-user list.

Users can start the My Page applet from the HOME Menu on the Switch at any time. It can even be called while an application is suspended without exiting the application.

Calling From an Application

Some of the My Page applet screens can be specified and called from the application. You do not need to close the application to do this, so you can simply return to the application after the user operation has ended.

The following examples show calls to these screens. The application UIs in these figures are merely examples. In addition, the sequence details have been omitted for the purposes of these descriptions, and the layouts are only provisional. The number of screens that can be called may increase or decrease in the future.
