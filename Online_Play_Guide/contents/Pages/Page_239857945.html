1 Introduction

Purpose and Content

This documentation covers the features that can be used to implement online play on Nintendo Switch™ (Switch), and describes how these features are meant to be supported by applications.
These features are described in terms of what they can be used to accomplish in an application, what they can link to, how they are expected to be used, and what readers must know when using them.
In addition, this document describes an overview and implementation method for bans, which are a measure that stop users from using network services.

Intended Audience

This document is intended for planners and developers of Switch applications.

We recommend that planners read all but the following pages. The following pages contain information for developers.

  • 2.3 Application-Level Support
  • The pages intended for developers in 7 Important Information and Tips for Online Play

Information for developers is also presented in the pages under 3.7 Using From Applications.

We recommend that developers read all of the pages of this document.

When to Read This Document

Read this document when planning Switch applications that include communication features using the internet. Before reading this documentation, read the Internet Communication section in the Nintendo Switch Overview.

Structure of This Document

2 Nintendo Switch Online Support describes how to include support for Nintendo Switch Online when developing Switch applications. It also includes 2.3 Application-Level Support, which contains information for developers.
3 Friends describes the Friends feature, which is provided as a system feature.
4 Online Play Save Data describes how to handle save data from online play.
5 Bans (Measure for Stopping Users From Using Network Services) provides an overview of bans and describes how to implement them.
7 Important Information and Tips for Online Play describes tips for developers for online play.
