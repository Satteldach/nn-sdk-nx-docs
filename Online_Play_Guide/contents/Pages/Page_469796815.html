3.1 Definition and Characteristics of Friends

Definition of Switch Friends

Switch friends are users who both want to play together on a long-term basis on the Switch. The specific interpretation of "friend" varies depending on the user. Using the procedures for establishing friends described later, users can create friend relationships both with people they know personally (such as family and friends) and with people that they meet online.

Using the Friends Feature in Applications

Applications can combine the Friends feature and the online play feature to implement ways for users to play with friends. From the perspective of application development, the Friends feature roughly consists of the following two elements.

Element Description
Friend Library This library, nn::friends, provides various APIs for applications to use the Friends feature.
My Page Applet

This library applet displays the User Page and includes the friend list feature for checking the list of friends and adding friends.
Applications specify this applet's startup mode and call specific Friends features. Using this can reduce the implementation load for the UI and processing specific to Friends features.

For more information about the User Page, see the Nintendo Switch System Features Guide.

For more information, see 3.7 Using From Applications.

Features of the Friends Feature

Nintendo Account or Account for China Required

Only user accounts that have linked to a Nintendo Account or an account for China can use the Friends feature. For more information about Nintendo Accounts and accounts for China, see the Nintendo Switch Account Guide.

The Friends feature is provided for individual network service accounts linked to a Nintendo Account or an account for China.

Maximum Number of People

A maximum of 300 friends can be registered per network service account. We recommend that applications have specifications to allow users to have 300 friends, but it is not a problem to segment and use friends for an appropriate reason according to the specification (Example: displaying only 100 friends in order of highest character level).

Friend Information

All friend information is managed on the server. The following four types of information exist per friend.

Type Notes
Network service account attributes

For more information, see the Nintendo Switch Account Guide.
Extended profile Additional information other than the network service account attributes such as nicknames and user icons. Includes history information such as software that has been played.
Records for each friend Stored information about the relationships of the user and each friend.
Settings for each friend Settings that the user can configure for each friend.

For more information about the specific types of information available to applications, see 3.7 Using From Applications.

Scope of Usage

Switch Friends are closed relationships contained within the Switch platform and are basically only used in applications on the Switch platform.

Discrepancy Between Friend Information Obtained by the Application and Information on the Server

In the following types of cases, information obtained by the application may differ from information on the server. Account for this discrepancy when designing your application.

  • When the Switch getting the friend information is not connected to the internet
    • The presence status for the friend is treated as "Offline" regardless of the friend's actual presence status.
  • When the Switch getting the friend information is connected to the internet, but the updated friend information on the server has not synced with the friend information cached in the system
    • There can be a lag of ten or more seconds from the time the friend information is updated on the server to the time the friend information cached in the system is updated. If friend information is referenced before the system cache is updated, there could be a discrepancy with the information on the server.
    • If for some reason the Switch system cannot receive the push notification from the server, this time lag might create a discrepancy with the information on the server until the Switch system triggers synchronization. Synchronization with the information on the server takes place at times like when the user presses the Y Button in the friend list on their User Page to explicitly update the friend information. Discrepancies that result from these factors are baked into the specification.
