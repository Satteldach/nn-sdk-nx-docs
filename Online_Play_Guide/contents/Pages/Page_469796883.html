3.3 Friend Presence

The friend presence feature uses the internet to show the status of friends in real time, such as the status of the application they are playing. This feature is intended to show what applications friends are playing so the user himself or herself can also decide to play.

Information Stored in Friend Presence

Applications can get and use the following information.

Item Description
Presence status This status is one of the three states described in the next section.
Application being played Information about the title of the application the user is playing. Presence can be shared even where the application versions differ or the title is part of a series.
Application-specific region

Using nn::friends::UserPresence::SetAppValue to set the application-specific region is prohibited.

It can be used only for the purpose of maintaining compatibility, such as when rebuilding an already released application with the latest version of the SDK.

Game mode description This text describes what the user is doing in the application. Any text can be set for the application (for example: "Playing stage 1") and it is shown on the User Page.
Time of last play The last time the user was online or playing online.

Presence Status

The presence status can be any of the following.

Status

Description

How It Is Displayed to Users
Offline
  • The Switch is not connected to the internet.
  • The Switch is connected to the internet, but one of the following states apply.
    • Cannot communicate with the friend server due to that server being down, for example.

    • The application is not started.

    • The user account is in the signed out state in the application.

    • The user account is in the signed in state in the application, but presence is set to private.
  • Appears as private.
  • Displayed as "Offline."
Online
  • The Switch can communicate with the friend server, and both of the following states apply.
    • The user account is in the signed in state in the application.
    • The start of online play has not been declared by the application or the middleware.
  • Appears as active.
  • Displayed as "Online."
  • Displayed as "Playing XX."
Online Play
  • The Switch can communicate with the friend server, and both of the following states apply.
    • The user account is in the signed in state in the application.
    • The start of online play has been declared by the application or the middleware.
  • The same as Online.
  • Unique expression in the application.
Info:

Note that even when the Switch can communicate with the friend server, simply starting the application does not result in the online state. The specific user account must be in the signed-in state in the application.

Change Policy to Online Play State

The transitions to Offline status and Online status happen based on whether the user account is signed in or signed out (Open or Close) and on the network connection state.

On the other hand, the transition to Online Play status (nn::friends::PresenceStatus::PresenceStatus_OnlinePlay) happens when the application explicitly calls the API. For more information, see the API Reference for the friends library.

Info:

There are restrictions on the frequency of calls to the API for changing the status to Online Play status. For more information, see Nintendo Switch Guidelines > Accounts > Friends > 0156: Restrictions on frequency of calls to FRIENDS library API.

Because you can use the friends library to get the presence status of friends, the application has a way to determine whether a friend is in Online Play status. As a result, you can implement features inside the application like preferentially showing friends that are currently playing online.

The Online Play status indicates that a person is playing online, but the application is not required to change the status to Online Play for users who have started online gameplay. Transition the status based on the needs of the application.


Presence Privacy Settings

Users can set their presence to private or restrict the scope of public visibility if they do not want friends to know that they are playing online in real time. For more information about in-application support, see 3.7.4 Notes When Supporting the Friends Features > Applying Presence Privacy Settings in Friend Matching.
