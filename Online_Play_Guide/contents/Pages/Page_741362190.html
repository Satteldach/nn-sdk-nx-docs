2.6 Support in Applications for China

Read the information provided on this page if your application is for China and supports online features.

Plan for Paid Online Services in China

It has not yet been determined whether a paid service similar to Nintendo Switch Online will be offered for Switch consoles for China.

OMAS Request for Applications for China

There is no distinction between applications for China and applications for other regions in Automatic Determination of Nintendo Switch Online Policy on OMAS (2.2 Policies) and both are treated the same way.

As a result, in some cases the application policy is determined to be All features require membership even though the application is for China. Users with a Switch system for China cannot subscribe to Nintendo Switch Online, so if the application policy is All features require membership, the services defined as Nintendo Switch Online member-only features are not available to those users. (For more information, see 2.1 Member-Only and Complimentary Features.)

If your application is for China, make sure that you submit a request in OMAS to change the Nintendo Switch Online policy for each applicable feature so the application policy becomes "No features require membership." (The Nintendo Switch Online policies are not changed automatically.) For more information about OMAS requests, see 2.2 Policies.

Support for China Applications

As stated in OMAS Request for Applications for China on this page, if your application is for China, the application policy must be No features require membership.

As stated in 2.3 Application-Level Support > No Features Require Membership, do not handle applications in a way that depends on the status of Switch Online membership.
