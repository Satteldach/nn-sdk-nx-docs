4.2 Recommended Save Destinations for Different Uses

When deciding whether to save data in a network location or the account save data region on a Switch console, consider the nature of your application. We recommend selecting the save destination based on the kind of user experience you want to provide. For example, does it feel natural to manage save data linked to a Nintendo Account? And will users expect this save data to be inherited via a Nintendo Account?

The following sections describe several typical use cases and the recommended method for storing the save data in each case.

Cases Where We Recommend Saving to the Network

We recommend saving data to a network location in the following kinds of cases.

  • Applications that are played primarily in online mode

For the current online services (including smartphone demoware), user activity is typically saved to online storage. Users have specific expectations of these services. To match those expectations, we recommend saving data to the network if you intend to create save data for uses that resemble these kinds of online services.

If assuming an internet connection at all times for your application is too difficult, consider making use of both storage destinations, as described later.

Cases Where We Recommend Using the Account Save Data Regions

We recommend using the system's account save data regions for the online play save data in the following kinds of cases.

  • Applications that are played primarily in offline mode
    • Cases where the application runs mainly in offline mode, which does not require a network service account, and has an online feature as an appended feature.
  • Applications whose save data created in offline mode is intimately connected with the online play aspect of the application
    • Cases where items obtained in offline mode are used in online mode and duplications must be prevented.
      However, to provide a more natural user experience, before making your selection, consider using both destinations to store the save data, as follows.
Info:

If you intend to store the online play save data locally on the Switch console, see 4.3 Notes About Saving Network Service Account Information on the Switch.

Cases Where Using Both Destinations Is Recommended

We recommend saving data both to the network and the system's account save data regions in the following kinds of cases.

  • Applications that do not run in some linked way in offline and online modes
  • Applications that run in a linked way in offline and online modes, but the save data for the two modes can be separated

For applications that do not run in a linked way in the two modes, the save data for offline mode can be saved on the Switch and the save data for online mode can be saved to the network.

For applications that run in a linked way in the two modes but have a specification that allows for the separation of the save data, we recommend storing the save data in different places for offline mode and online mode. That creates the user experience of online play data being managed linked to a Nintendo Account. As an example, consider the following implementation. The behavior of the save data is provided in parentheses.

  • Collect in-game coins when playing the application in offline mode. (The collected game coins are saved on the Switch.)
  • Spend the in-game coins and exchange them for items when playing the application in online mode. (The items are saved to the network.)
  • Create a cache of the items obtained in online mode and make it available also in offline mode. (Destroy this cache when changes to the network service account have been detected.)
