2.1 Member-Only and Complimentary Features

This section describes the member-only online features and complimentary online features of Switch applications. Nintendo may change the definitions of member-only and complimentary features in the future.

Member-Only and Complimentary Features in Applications

The online features provided in Switch applications are either member-only or complimentary.
A mix of member-only and complimentary features may be available in a single application. For more information, see 2.2 Policies.

Member-Only Features

The following Switch application online features are defined as member-only features.
A user must subscribe to Nintendo Switch Online to use the following features.

  • Online battles and online cooperative play
  • Matchmaking Voice Chat
Info:

Matchmaking Voice Chat refers to voice chat using the Nintendo Switch Online app for smart devices. For more information, see Nintendo Switch Voice Chat Guide.

The feature for sending and receiving audio data in the Switch application using voice chat is not included in Matchmaking Voice Chat.

Complimentary Features

The following features are examples of features that are complimentary even though they use online communication.
All users, including those who do not subscribe to Nintendo Switch Online, can use these features.

  • Using Nintendo eShop
  • Adding and managing friends
  • Sharing captured game screens in social media
  • Using the Parental Controls App
  • Online battles and cooperative play using LAN communication
  • Receiving news
  • Receiving data via the BCAT Data Delivery System
  • Receiving patches
  • System updates
  • Transfer users and save data

Handling NEX Features as Member-Only or Complimentary

NEX features other than matchmaking, such as ranking, data store, and subscriptions, may be member-only or complimentary depending on the combination of features used in the overall application.
If NEX matchmaking is used, all NEX features are treated as being member-only.
If NEX matchmaking is not used, all other NEX features are treated as being complimentary.

Handling NPLN Features as Member-Only or Complimentary

As a general principle, in NPLN, features that use online multiplayer are member-only features, and features that do not use online multiplayer are complimentary features.

However, as an exception, all NPLN services for free-to-play applications are to be treated as member-only, regardless of whether they implement online multiplayer using NPLN functionality.
For demo applications, each NPLN feature is handled as a member-only feature if handled that way in the main application, and as a complimentary feature if handled that way in the main application.

Info:

If a pay-to-play application uses NPLN for online multiplayer, the application's Nintendo Switch Online policy is automatically determined by OMAS to be "All features require membership."
To configure features that do not use online multiplayer so that they do not require a Nintendo Switch Online membership, make a Nintendo Switch Online Policy Change Request in OMAS.

Exceptions Where Complimentary Features Are Treated as Member-Only

In some exceptional cases, features that are essentially complimentary are treated as member-only due to the nature of a particular service or how it operates.
Specifically, in the following cases, features might be treated as member-only even though they are originally complimentary.

  • When the functionality for competitive or cooperative online play is provided solely by complimentary NEX features
  • When only complimentary NEX features are used, but their use is expected to significantly increase the load on the game server, for example by exceeding the stipulated guideline restriction on the frequency of calls to the NEX API functions that involve access to the game server

Exceptions Where Member-Only Features Are Treated as Complimentary

Applications Where Features Can Be Complimentary

The following kinds of applications include features that can be treated as complimentary, even though they are essentially member-only.

Free-to-Play Applications With No Purchase Volume Restrictions

In some cases, you can treat all online features as complimentary for games that are free to start but allow users to pay to add elements or continue playing, and which put a limit on the number of purchases.

Info:
  • To use NEX in a free-to-play application, contact your Nintendo support representative in advance. For more information, see Nintendo Switch Guidelines > 0145: Prohibition of using NEX in free titles without Nintendo permission.
  • A free-to-play title that uses NPLN cannot be treated as complimentary, as stated in the Handling NPLN Features as Member-Only or Complimentary section on this page.
Applications That Support Independent Subscriptions

In some cases, you can treat all online features as complimentary if you are running a paid service based on your own subscription method and the Nintendo Switch Online member-only features can be used only within that service.

Treating Some Online Features That Use Independent Servers as Complimentary

When OMAS automatically determines the Nintendo Switch Online policies, as described in 2.2 Policies, the online features that use an independent server are all treated as member-only features.

If you want to treat online features (except those for online battles and cooperative play) that use an independent server as complimentary features, you must submit a change request. For more information, see 2.2 Policies.
