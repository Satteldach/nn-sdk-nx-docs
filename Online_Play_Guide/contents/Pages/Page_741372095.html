1.1 Online Play Support for China Applications

Note the following if your application is for China and supports online play.

  • If you are considering using NEX features in an application for China, see Nintendo Switch NEX Guide > Tips and Tricks > Applications for China. (English, Japanese)
  • Contact Nintendo if you are considering using the Pia library for internet communications in your application for China.
  • If you plan to support online play using an independent server, see the additional information and notes about applications for China in the Nintendo Switch Independent Server Setup Manual. (English, Japanese)

Also, note the important information about applications for China described in various sections of this documentation. Consider the following main points.

Applicable Section Important Notes

2 Nintendo Switch Online Support

  • If your application is for China, ensure the application policy is "no features require membership" by submitting a change request on OMAS for the applicable features.
    • For more information, see 2.6 Support in Applications for China.
3 Friends
  • Currently, a friend relationship cannot be established between a network service account linked with an account for China and a network service account linked with a Nintendo Account.
    • For more information, see 3.2 Establishing Friend Relationships.
4 Online Play Save Data
  • Currently, the Save Data Cloud feature is not offered on Switch for China.
  • With Switch for China and applications for China, substitute "accounts for China" wherever you see "Nintendo Accounts."
5 Bans (Measure for Stopping Users From Using Network Services)
  • There is nothing special to note for applications for China.
  • With Switch for China and applications for China, substitute "accounts for China" wherever you see "Nintendo Accounts."
  • BMAS is available to use with applications for China and accounts for China.
7 Important Information and Tips for Online Play
  • If there is anything to note about applications for China, details will be listed on a page-by-page basis.
