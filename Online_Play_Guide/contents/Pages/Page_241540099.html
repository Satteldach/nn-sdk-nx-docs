2.2 Policies

This section describes the Nintendo Switch Online policies that are set for the various features of an application, and the application policy that is set for the application itself.

Nintendo Switch Online Policies

Online features provided in Switch applications are either member-only or complimentary (see 2.1 Member-Only and Complimentary Features).
The setting that defines whether a feature is member-only or complimentary is called the feature's Nintendo Switch Online policy.

The Nintendo Switch Online policy for each feature in applications under development is managed on OMAS.
In OMAS, each of the following features for the registered application is determined as member-only or complimentary and set to the appropriate Nintendo Switch Online policy automatically.

  • NEX matchmaking
  • NEX ranking
  • NEX DataStore
  • NEX subscriber
  • Other NEX features
  • NPLN
  • Independent servers

Application Policy

OMAS places applications into one of three classifications based on the Nintendo Switch Online policies set for these features. This classification is called the application policy.
The application policy is determined automatically by OMAS.

  • All features require membership
  • No features require membership
  • Some features require membership

The application behavior changes depending on the application policy. For more information, see 2.3 Application-Level Support.

The application policy is set for each release version of an application. It is possible for version 2.0 of an application to have a different application policy than the 1.0 version after patching.
If the application policy is changed for an unreleased patch, the application behavior does not match the post-change policy until that patch is released and applied on the Switch console.

Automatic Determination of Nintendo Switch Online Policies in OMAS

In OMAS, the Nintendo Switch Online policy for each feature and the application policy are automatically determined based on the application's request options.
If any of the following conditions apply, OMAS classifies the application policy as All features require membership.
If none apply, it is classified as No features require membership.

  • NEX matchmaking has been requested.
  • Yes has been selected for Whether online multiplayer is used in the NPLN application.
  • NPLN has been requested, and Free-To-Play? in Application Overview is set to Yes. (The NPLN Use of Online Multiplayer setting does not matter.)
  • Independent servers have been requested.
Info:

OMAS never automatically classifies applications as Some features require membership.

When the application policy must be set to Some features require membership, submit a change request by following the steps in Changing the Nintendo Switch Online Policies later in this document.

In demo versions, the NPLN features are handled as member-only features if handled that way in the main application, and as complimentary features if handled that way in the main application. (For more information, see 2.1 Member-Only and Complimentary Features > Handling NPLN Features as Member-Only or Complimentary.) As a result, in some cases you might need to manually change the Nintendo Switch Online Policy for the demo version in OMAS.

Checking the Nintendo Switch Online Policies in OMAS

If the application has at least one member-only feature, a Nintendo Switch Online policy item is added to the OMAS Release Information page.
If there are no member-only features and the application is classified as No features require membership, the OMAS page for that application does not display any information or items relating to Nintendo Switch Online.

Changing the Nintendo Switch Online Policies

To change the Nintendo Switch Online policy for a feature, you must submit a Nintendo Switch Online Policy Change Request on OMAS.
The same process is used regardless of whether you are requesting a change from a member-only feature to a complimentary feature, or vice versa.
When requests related to NEX or to independent servers are up for re-examination, change requests will also be re-examined.

Changing the Nintendo Switch Online Policy for Applications That Have Started Services

A patch request is required for changing the Nintendo Switch Online policies for an application that has already begun services.
The settings for the independent server or the NEX server might need to be changed when the patch is released, so if you are requesting a patch that will change the Nintendo Switch Online policies, submit a request in OMAS to require installation of the patch.

Registering a Patch After Changing the Switch Online Policy

When you register a patch in OMAS, all requests from the previous version are copied. The Nintendo Switch Online Policy entries are also copied, so you do not need to resubmit this item for the patch.

Using the Same Server in Multiple Applications

When Using the Same NEX Game Server

When multiple applications use the same NEX game server, the Nintendo Switch Online policy setting for each feature must be the same for all applications. Make sure that the Nintendo Switch Online policy for each feature is entered the same way in every request to use NEX features and every request to use an independent server submitted for every application.

When a request is submitted for a new application or patch that will share the same NEX game server being used by another application, the NEX game server will not be updated if the Nintendo Switch Online policies set in the new submission differ from those already submitted for the other application.
In such cases, the phase review process on OMAS stops until the request content matches for all applications sharing the NEX game server.

For example, say that a new request or a patch request is submitted for application A to use the matchmaking feature and the ranking feature. If application B is sharing the same NEX game server and intends to use only the ranking feature (or has already requested to use only that feature), one of the following steps must be taken so the same request information is submitted for both applications.

  • For application B, in addition to the request for ranking, submit a patch request for matchmaking even though that feature will not actually be used.
  • Revise the request for application A by deleting the request for matchmaking and submitting a request for only the ranking feature.

When Not Using the Same NEX Game Server

When multiple applications do not use the same NEX game server but use the same independent server or NPLN server, the Nintendo Switch Online policy setting for each feature does not have to be the same for all applications. Also, the OMAS phase review will not stop.

However, if the application policy of one of the applications requires a membership for some features, the NPLN game server (tenant) must check whether the user is a Nintendo Switch Online member. For this reason, note the following.

  • On the dedicated management tool (NPLN Dashboard), you must set which NPLN features are services that require a Nintendo Switch Online membership.
  • It is not possible to set different settings for each application as to whether a specific NPLN service is a service that requires a Nintendo Switch Online membership.

For more information, see the NPLN Manual included in the NPLN package.

If you will be using an independent server that multiple applications will share, consider that there will be connections from multiple applications when you implement your server.
