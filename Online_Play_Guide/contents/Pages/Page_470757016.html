4.3 Notes About Saving Network Service Account Information on the Switch

The links between user accounts and network service accounts cannot be removed or changed by the user (in system version 6.0.0 and later). However, the links can be removed or changed for repair and customer support reasons.
For this reason, if the save data for online play depends on a network service account, and you intend to save that save data to a save data region on the Switch, you must implement appropriate measures to handle when the network service account changes.

Info:

If the save data for online play does not depend on a network service account, the following steps do not require consideration, even if the data will be saved to a save data region on the Switch.

We recommend taking both of the following steps in your application when any change to a network service account is detected.

  • Inform the user about any effects or restrictions resulting from the change.
  • Either take action to resolve any inconsistencies, or do nothing and stop the application from advancing.

Inform the User About the Impact of the Change

You must inform the user about any effects or restrictions resulting from the change, such as when save data is no longer available, or when some parameter has been reset.

Info:

Contact Nintendo support in advance if you plan to include descriptions of Nintendo Accounts in notifications, such as writing "Nintendo Account" in the message.

This approach helps ensure that the intention of the message is still conveyed even if Nintendo Accounts and related services are extended or changed in the future.

Resolve Inconsistencies, or Do Nothing and Stop the Application From Advancing

If the change to the network service account creates inconsistencies, we recommend taking one of the following three actions. The actions are described in order of how extensively they affect the user, with the first action having the least effect.

Change the save data on the Switch to match the network service account changes.

This action does not require anything on the part of the user and allows the continued provision of the online service.

The following are some examples.

  • Update the network service account ID in the save data on the Switch to match the change.
  • Allow the retention of non-volatile types of online service information (such as rankings) for past network service accounts.

Change the data on both the Switch and the network to match the network service account changes. Do not provide the online service until the information matches.

This action makes the user wait, but it does not require anything on the part of the user and allows the continued provision of the online service.

The following are some examples.

  1. Replace non-volatile types of online service information (such as rankings), that are based on the previous network service account ID, with information based on the current network service account ID.
  2. Update the network service account ID in the save data on the Switch.
  3. Enable the provision of network features after these actions are completed.

Make some or all of the save data on the Switch unavailable.

Perform this action so that the save data stored on the Switch is no longer usable, either in its entirety, or just the part that is dependent on a network service account.

You could use any of the following methods.

  • Wait for the user to re-create the save data.
    • Stop the application from advancing until the user has manually deleted the save data (using the system features). Users could learn how to do this from customer support or from a user community.
  • Design the application to automatically delete the save data.
    • Automatically delete just the inconsistent parts of the save data, or delete it all and create it again.
Note:

The user may lose assets if the application automatically deletes highly valued data such as all save data. For this reason, we strongly recommend making the save data unavailable instead of automatically deleting it (except in the case of cached data).
