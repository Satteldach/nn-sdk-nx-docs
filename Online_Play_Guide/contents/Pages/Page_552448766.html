3.7.5 Supporting the Friend Invitation Feature

This section describes what the application must do to support the 3.5 Friend Invitation feature.

Configuring the Application Metadata

Some of the behaviors of the friend invitation feature vary depending on how the application metadata has been configured in the NMETA file. The following section describes the relevant NMETA parameters.

For more information, see NintendoSDK Documents > Features > Building > Creating Application Images > Writing the NMETA File.

Configuring the Joinable Applications

You can configure the presence group ID in the NMETA file (the PresenceGroupId parameter) so friends can join through invitation even among applications with different application IDs.

For more information, see 3.5 Friend Invitation > Sharing Invitations Among Multiple Applications.

Setting the Behavior When an Invitation Is Received by a Running Application

You can set the RuntimeParameterDelivery parameter in the NMETA file to change the application behavior when an invitation to play the application is received while the application is running.

For more information, see 3.5 Friend Invitation > Joining Through Invitation to a Running Application.

Info:

The setting for RuntimeParameterDelivery is available in NintendoSDK NX Add-On 9.2.0 and later. This parameter cannot be configured in earlier versions.

Application Development

Requesting Use

You do not need to make a request on OMAS to use the friend invitation feature in the development environment.

Development and Debugging

NintendoSDK NX Add-On 9.3.0 or later is required to develop applications that use the friend invitation feature.

The following functions for sending friend invitations are available in NintendoSDK NX Add-On 9.3.0 and later.

  • nn::friends::StartFriendInvitation()
  • nn::friends::StartSendingFriendInvitation()

The following functions for joining through invitations are available in NintendoSDK NX Add-On 9.2.0 and later.

  • nn::friends::GetFriendInvitationNotificationEvent()
  • nn::friends::TryPopFriendInvitationNotificationInfo()
Info:

To join through invitation, you must either install the application on the development hardware, or write the application to an NX development card and run it from there.

For debugging purposes, DevMenuCommand provides a PC-based method to notify the application of the information necessary to join. For more information about the information needed for joining, see 3.5 Friend Invitation.

This feature is available NintendoSDK NX Add-On 9.2.0 and later. For more information, see NintendoSDK Documents > Features > Controlling the Development Hardware > DevMenuCommand > Friends Feature.

Info:

If DevMenu has been selected as the menu to display at startup (Initial Boot Menu), the following issue occurs. This behavior is by design. If you find this inconvenient, change Initial Boot Menu to HomeMenu.

  • The program stops responding if you attempt to join through invitation from the My Page applet started by the nn::friends::ShowFriendList() function.

Support for Guidelines

Applications that support the friend invitation feature must comply with the following guideline in the Nintendo Switch Guidelines.

  • 0188: Prohibition of including UGC in friend invitation feature invitation messages.
    • The invitation message included in the friend invitation (see 3.5 Friend Invitation) must not contain text entered by the user (user-generated content)

The following restrictions do not apply for the friend invitation feature.

  • Restrictions on the frequency of API calls
  • Restrictions on the handling or the sequences of the application after receiving the invitation and before joining online play
