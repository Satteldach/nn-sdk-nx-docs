3.7.2 Friend Information Available to the Application

The following table shows the types of friend information and whether each type can be used in the application.

Type Item Comments
Network service account attributes For more information, see the Nintendo Switch Account Guide.
You cannot get information associated with a friend's Nintendo Account.



Internal ID Do not display to users.

Nickname

Can be used as the nickname for the friend.

If the application keeps personalized profiles, see 3.7.4 Notes When Supporting the Friends Features > Showing Personalized Profiles of Friends and Network Service Account Nicknames Together.
User icon Can be used as the icon representing the friend.
Extended profile

Additional information other than the network service account attributes such as nicknames and user icons. Includes history information such as software that has been played.

None

Can only be used by the system.
Records for each friend Stored information about the relationships of the user and each friend.

None Can only be used by the system.
Settings for each friend Settings that the user can configure for each friend.

Favorite flag

Friends the user sets as best friends are displayed preferentially in the friend list on their User Page. Friends are set as best friends unilaterally. The setting is not conveyed to other people. For more information, including important considerations when using this feature in an application, see 3.7.4 Notes When Supporting the Friends Features > Policy for Using Best Friends.
