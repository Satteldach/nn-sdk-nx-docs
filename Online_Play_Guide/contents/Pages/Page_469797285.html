3.6 Blocked-User List

The blocked-user list registers the players the user does not want to become friends with and the players the user does not want to matchmake with for online play. Each user can decide to add other players to this list for any reason. The application can implement protective measures such as preventing matchmaking by getting this blocked-user list. The blocked-user list is also common to all applications and may contain a maximum of 100 users. Players are not informed when a user adds them to the blocked-user list. Also make sure that applications do not inform players of their registration to this list.

Usefulness

The following happens when a user registers a player to the blocked-user list.

  • Friend requests from the player are not sent to the user.
  • With the NEX default setting, matchmaking with that player no longer occurs.
    • We recommend supporting this same policy in applications that conduct matchmaking without using NEX.
    • There is generally no need to change the default NEX setting, but it can be incompatible in the following kinds of situations in applications that support multiple players. For this reason, there is an option for ignoring the blocked-user list when matchmaking in certain specified modes specified in the application.
      • Joining with friends: A user tries to join with a friend in a game but cannot because someone in the matchmaking session is on the user's blocked-user list, or the user is on someone else's blocked-user list.
      • Large-scale matchmaking (tournaments and other events): Using the blocked-user list, users can wrongly keep others from participating.
      • Rating matchmaking: By registering stronger players to the blocked-user list, users can make it easier to win for themselves and improperly raise their rating.

Consider also introducing other independent measures in your application, based on the assumption that the user might find offense with the blocked user. (Example: Do not display works posted by players on the blocked-user list).

Info:

Unlike NEX, there is no setting offered in NPLN that prevents matchmaking with a user on the blocked-user list. If needed, determining whether a user is on the blocked-user list must be handled by the application following the matchmaking process.

For more information, see NPLN Manual > NPLN Programming Manual > Gamesync.

Using When Not Connected to the Internet

The blocked-user list is managed on the server, but the cache from the last time the system was connected to the server is saved in the system. As a result, applications can get the blocked-user list even when the Switch is not connected to the internet. However, users can only be added to the blocked-user list when the Switch is connected to the internet.

Registration Method

Users can add a player to the blocked-user list using any of the following methods.

Method

Overview
Registration from a friend request Users can add the sender of a friend request from the screen that lists received friend requests in their User Page.
Registration from Player History Users can add a user they played with from the Player History screen in their User Page.
Registration from an application

Users can add any user (including friends) from the application, from the user details screen of the My Page applet.
For more information, see 3.7 Using From Applications.
