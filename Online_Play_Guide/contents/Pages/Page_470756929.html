4.1 Where to Store Online Play Save Data

You can select to store the save data for online play primarily in one of these two places.

  • A network location
  • The account save data regions on the Switch console

Saving to the Network

In this method, the application uses a dedicated storage space independently created on the network. You can use this method by building an independent server or using the data store features of the NEX library.

This region has the following characteristics.

  • Linking multiple Switch consoles to the same Nintendo Account enables the same save data to be shared.
  • Linking to a Nintendo Account that was used on a different console in the past enables that save data to be inherited and continue to be used.
  • System initialization and other features provided by the system do not act to erase this save data, so the application must prepare its own means if necessary.

Saving to Account Save Data Regions on the Switch

In this method, the online play save data is saved to the system's storage region.

This region has the following characteristics.

  • System initialization and other features provided by the system can act to erase this save data.
  • Even when multiple Switch consoles are linked to the same Nintendo Account, each console stores the save data in a different state.
  • The features provided by the Switch system to migrate save data and back up save data to the cloud can be used to copy or transfer save data to a different console.
Info:
  • The Save Data Cloud feature is not currently offered on Switch for China.
  • For more information about the features to migrate save data and back up save data to the cloud, see Nintendo Switch System Features Guide.
