7.1 Advance Consultation for Limited-Time Events and Recommended Implementation

Note the following when implementing a limited-time event in an application.

  • When using NEX or NPLN, a concentrated load on the server might make it impossible to operate a stable service. Discuss with Nintendo in advance.
  • When using NEX, we recommend using BCAT data delivery to distribute schedule information (the date and time when events begin and end).

This is all described in detail below.

Limited-Time Events

The following are examples of limited-time events.

  • Events that enable a game mode that is not normally available, for a limited period of time
  • Events that increase the rewards or reduce the stamina required for playing game modes that are normally available

Why Consultation in Advance Is Required

Limited-time events might cause high server load because many users access the server at the start of the event.

Consult with Nintendo in advance to verify whether this load would affect Nintendo server services such as NEX and NPLN.

Recommendations for Limited-Time Events

For NEX

For applications that use NEX, consider using BCAT data delivery to distribute the schedule information (start and end date and time) for limited-time events. BCAT data delivery is appropriate for the following reasons.

  • BCAT data delivery has several useful features for operations, such as scheduling data delivery, test delivery, and restricting the delivery targets.
  • Using NEX requires maintaining a login with the game server to receive information. With BCAT data delivery, data is received in the background, so the application does not need to consider the server connection status.

With NEX, if schedule information is managed using the following methods, there may be errors in the data because it is not possible to verify the settings ahead of time on a retail device.

  • Method using NMAS that sets an application-specific setting value (nn::nex::UtilityClient::GetIntegerSettings()) on the game server
  • Method using the NEX WebAPI and uploading the setting value to the data store

For NPLN

When using NPLN, the Appconfig service available in NPLN can be used to distribute the schedule information for limited-time events.
As with NEX, you can distribute the schedule information for limited-time events with BCAT data delivery.

For more information about the differences between Appconfig and BCAT data delivery, see NPLN Manual > NPLN Programming Manual > Appconfig.
