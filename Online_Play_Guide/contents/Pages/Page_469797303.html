3.7.1 Features Available to the Application

The application can use the following features to support the Friends feature. These features are described later in the documentation. For more information, including how to implement the various features, see the API Reference included with the SDK documentation.

Info:

Functions for the friends feature may fail if the following conditions are not met.

  • The Switch can access the internet.
  • The target user account is linked to an active network service account.

friends Library Features

Category Feature
Friend Information Get the friend list, which only includes the internal IDs from the network service accounts of other users.
Get the detailed friend list, which includes details about friends and their presence information.
User Information Get the public profile for any network service account, which includes information such as the nickname associated with the user account.
Friend Presence Configure the game mode description.
Declare the beginning of online play.
Declare the end of online play.
Player History Add users to Player History.
Friend Invitation

The receiver of the invitation gets the information for joining that was set by the application when the invitation was sent. (For more information, see 3.5 Friend Invitation.)
Blocked-User List Get the blocked-user list, which only includes the internal IDs from the network service accounts of other users.

My Page Applet Features Associated With the Friends Feature

Category Feature
Friend Information Call the Friend List screen.
User Information Call the screen showing details about users.
Friend Request Call the send friend request process.
Call the screen listing ways to send friend requests.
Call the screen to schedule friend requests during local communication.
Call the screen listing received friend requests.
Friend Invitation Call the screen for selecting friends and for sending an invite to them.
Blocked-User List Call the screen for managing the blocked-user list.

The functions to call these features are included in the friends library.
