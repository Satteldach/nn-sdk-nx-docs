2.4 Use in a Development Environment

This section describes how to use Nintendo Switch Online in an application development environment.

It also describes how to use a web tool to grant Nintendo Switch Online membership licenses to development environment Nintendo Accounts.

Applying Nintendo Switch Online Policies in the Development Environment

The Nintendo Switch Online policies that are set for each application are applied even on the various development environment servers.
The application behavior in those environments is exactly as described in 2.3 Application-Level Support.
The Nintendo Switch Online policy settings are applied in the development environment when the phase on OMAS becomes In Development.

Using Nintendo Switch Online in the Development Environment

You cannot join Nintendo Switch Online from a Nintendo Switch with a development environment Nintendo Account. If you are in a development environment and use the prescribed method for handling errors that occur when Nintendo Switch Online is unavailable, the subscription guide is displayed just like in the retail environment, but you cannot complete the process of obtaining a membership on your Switch.

You can grant licenses comparable to a Nintendo Switch Online membership to Nintendo Accounts in the development environment by using the following dedicated web tool.

Nintendo Switch Online Membership Manager

The Nintendo Switch Online Membership Manager is a web tool for granting Nintendo Switch Online licenses to Nintendo Accounts in the development environment.
You can access the web tool from the following URL. To log in, you need a Nintendo Developer ID.

https://nsom.nntt.mng.nintendo.net/

Linking a Nintendo Account

To configure the settings to grant a Nintendo Switch Online license to a development environment Nintendo Account, you must first link that Nintendo Account to Nintendo Switch Online Membership Manager.

To link a Nintendo Account, log in to Nintendo Switch Online Membership Manager and click Link a Nintendo Account.

Basic authentication is configured on the login page for Nintendo Accounts in the development environment. Note that development environment in this case refers to the dd1 environment. Use the authentication data for a dd1 environment Nintendo Account.
For more information about Nintendo Account authentication in the dd1 environment, see Nintendo Developer Portal > Developer Support > Nintendo Switch > Technical Information > Information for Network Titles.

When the process is completed, the information for the linked Nintendo Account appears on the Nintendo Switch Online Membership Manager page.

Granting Nintendo Switch Online Licenses

The information for the linked Nintendo Account shows whether that account has a license for Nintendo Switch Online.

If Unavailable appears in the Service availability column, that account does not have a license. To grant a new license to that account, click Grant on the right. If Available appears in the Service availability column, the account has a license. If the account has a license, the expiration date is also shown in the Service availability column.

Licenses granted using Nintendo Switch Online Membership Manager remain valid for a period of one year.

Omitting the Process of Checking for Nintendo Switch Online License in Development Environments

You can omit the process of checking for a Nintendo Switch Online license in the development environment by changing the Switch console settings.
For more information, see Omitting the Verification of Network Service Account Credentials (for SDK 5.0.0 or later) in NintendoSDK Documents.

NSA ID Tokens When License Verification Is Omitted

When the process of Nintendo Switch Online license verification is omitted, information about Nintendo Switch Online licenses is not included in the obtained NSA tokens.
Note that NSA ID tokens that do not include information about Nintendo Switch Online licenses are different from the NSA ID tokens obtained when there is no Nintendo Switch Online license.
For more information about how applications are affected, see NSA ID Token Status and Availability of Online Features under 2.3 Application-Level Support.

Note:

If the application policy is Some features require membership, NSA ID tokens can be obtained even if the user does not have a Nintendo Switch Online membership. Those NSA ID tokens will contain information indicating the lack of a license. On the other hand, if you omit the process of checking for a license, the NSA ID tokens will not contain any information about licenses.
For more information about NSA ID tokens, see Nintendo Switch Independent Server Setup Manual > Connecting to an Independent Server > NSA ID Token Specifications.
