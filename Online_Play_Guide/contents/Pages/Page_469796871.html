3.2 Establishing Friend Relationships

With the Switch, a friend relationship is established between two users when both indicate that they want to become friends. (This method of establishing a friend relationship is called mutual recognition.) Specifically, the friend relationship is established using a friend request that indicates the intention of becoming friends and takes one of the following forms.

  • One user sends another user a friend request, and the recipient approves the request.
  • Two users send each other a friend request at the same time.
Info:

A friend relationship cannot be established between a network service account linked with a Nintendo Account and a network service account linked with an account for China. Whether this will change in the future has yet to be determined.

Methods of Sending Friend Requests

The following methods are available for sending friend requests.

Sending Method

Overview
Friend requests using a friend code

With the Switch, one friend code is issued for each network service account. Users can send a friend request by entering the other person's friend code in their User Page.
Schedule friend requests during local communication

The User Page allows users to search for nearby players using local communication and schedule times to send friend requests. Users can search even when the Switch is not connected to the internet, but in such cases the friendships cannot be established (and the players cannot be treated as friends inside the application). The next time the Switch connects to the internet, the official friend requests are mutually sent automatically, and the friend relationship is established for the first time.
Friend requests from Player History

Information about other people the user has played with via online play or local communication is recorded in Player History on the Switch console. Users can send a friend request by selecting the person from the list.
Friend requests from inside applications

Friend requests can be sent from inside applications by calling the screen showing details about users in the My Page applet. For more information, see 3.7 Using From Applications.
Friend requests from the friend candidate feature

Friends using the following services who play on Switch will be suggested in a list.
Users can send a Switch friend request by selecting the person from the list.
To use this feature, both you and the other user must have linked a Nintendo Account to the respective service.

  • Friends in the smart device application (only versions that support this friend candidate feature)
  • Nintendo 3DS friends
  • Nintendo Network ID (Wii U) friends
Note:

Friend requests from the friend candidate feature are not available on Switch for China.
Friend requests from the Nintendo Switch Online app

The Nintendo Switch Online app is a smart device application that provides services linked to Switch games. For more information, see Nintendo Switch Voice Chat Guide. With the Nintendo Switch Online app, users can send friend requests using friend codes.
The Nintendo Switch Online app cannot be used to approve friend requests or to cancel sent friend requests. The operations to approve and cancel friend requests must be performed on Switch.
Info:

A message cannot be included with a friend request.

Friend Request Operations

Users can perform the following operations on friend requests using their User Page.

Request Type Available Operations
Received friend request Accept, delete, or add to the blocked-user list.
Sent friend request Cancel.
Friend request scheduled for sending Cancel.
