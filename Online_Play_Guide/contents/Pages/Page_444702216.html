7.3 Error Handling for the Account Library (for Developers)

When using the account library, be sure that you do not violate the following guidelines for error handling.

  • 0121: Implementing handling when your application is unable to use a network service account
  • 0122: Prohibition of automatically retrying to get network service account ID tokens
  • 0135: Handling Result values returned by account library

Violating the guidelines causes the application to fail Lotcheck (the final testing process for applications, performed by Nintendo). Carefully consider this issue when developing applications.

Background Behind Each Guideline

For more information about each guideline, see the Nintendo Switch Guidelines.

0121: Implementing handling when your application is unable to use a network service account

If the network service account becomes unavailable, the only method of restoring from this state in the application is to call the nn::account::EnsureNetworkServiceAccountAvailable() function.

For this reason, if the application does not follow this guideline, the user experience may suffer greatly if the user cannot continue in the application but cannot determine why the service is unavailable or how to handle it.

0122: Prohibition of automatically retrying to get network service account ID tokens

If this guideline is violated, a large amount of requests may be sent to Nintendo's authentication server in a short period of time. As a result, if the server is affected, various online services provided to the Switch may become unavailable.

0135: Handling Result values returned by account library

Note that there are several problems with ResultNetworkCommunicationError handling.

The procedure for testing the guidelines for ResultNetworkCommunicationError handling is described in the procedure for inducing errors in 2124-3001: Application update is required, but it describes a general test case and this result represents several different communication errors. For this reason, a waiver cannot be issued if you just notify the user in the application that a 2124-3001 error has occurred.

Make sure that you handle the error according to the procedure in the account Library documentation in NintendoSDK Documents, and make sure that the user is appropriately informed of the error.
