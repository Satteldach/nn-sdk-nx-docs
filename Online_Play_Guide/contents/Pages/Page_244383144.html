5.1 Ban Overview

This section describes the ban features and the types of bans.

Ban Features

When users attempt to use specific network services they are banned from using, the necessary authentication procedures fail.
Users cannot use those network services while the ban is in place.

When registering a ban to block the use of a service, you can select either a permanent ban or a limited duration ban. Regardless of your selection, you can remove the ban later.

Ban Types

The ban types are divided based on the following two definition methods.

  • Identification method of the target user
    There are two ways to target users: by targeting a Nintendo Switch system or by targeting an account.
  • Scope of the blocked service using bans
    The two ranges of restrictions for available services are restrictions within specific applications, and restrictions for the system as a whole.

Four ban types are available through combinations of these two options.

Info:

With NPLN, separate from the bans described here, there is also a feature for blocking user access to the NPLN game server (the tenant).

However, if one of the bans described here is set, the user is blocked before accessing the NPLN game server.
For this reason, unless you have a reason for blocking the NPLN services as quickly as possible, you do not need to use NPLN's user blocking feature and can just set a Device App Ban, an NSA App Ban, or some such ban.

For more information about the user blocking feature available in NPLN, see NPLN Manual > NPLN Guide > Blocking Users.

Target Users

Targeting Switch Systems

Users are identified by the Nintendo Switch system. Bans for the application apply to all user accounts on the uniquely specified Switch system.

Targeting Accounts

Users are identified by their accounts. Use is restricted based on a specific network service account and the associated user account.

Blocked Services

Restrictions on Specific Applications

The targeted user can no longer obtain NSA ID tokens for the specific application.
The restriction on getting NSA ID tokens restricts logging in to the NEX/NPLN game server or independent servers.
There are no restrictions on getting NSA ID tokens for applications that have not been added to the ban, even when target users are using those applications.

Features that do not require obtaining NSA ID tokens within an application are not restricted with bans, even if they are online features.

Restriction on Entire System

All authentication processes fail when the targeted user attempts to use network services on the Nintendo Switch.

The error message displayed to the user at this time states that Nintendo has restricted the use of network services.

Details of the Different Ban Types

Device App Ban

This type of ban targets Nintendo Switch systems, and restricts the use of specific applications to a limited scope.
Application developers and publishers can implement this ban from a dedicated management tool (BMAS). For more information about BMAS, see 5.2 Implementing Bans.

Error Codes That Occur When Use Is Restricted

2124-4607
(For system versions prior to 7.0.0, the error code is 2124-4027.)

Device Ban

This type of ban targets Switch systems, and restricts the use of network services for all applications and Nintendo Switch system features.
System bans can only be applied by Nintendo.

Error Codes That Occur When Use Is Restricted

2124-4508
(For system versions prior to 7.0.0, the error code is 2124-4007.)

NSA App Ban

This type of ban targets accounts, and restricts the use of specific applications to a limited scope.
Application developers and publishers can implement this ban from a dedicated management tool (BMAS). For more information about BMAS, see 5.2 Implementing Bans.

Error Codes That Occur When Use Is Restricted

2124-5114

NSA Ban

This type of ban targets accounts, and restricts the use of network services for all applications and Nintendo Switch system features.
System bans can only be applied by Nintendo.

Error Codes That Occur When Use Is Restricted
