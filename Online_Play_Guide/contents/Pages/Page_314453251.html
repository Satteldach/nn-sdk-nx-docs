2.5 Applying Server Settings

This section describes how the features in each application for Nintendo Switch Online are applied on the servers.
It describes both the production environment and the development environment.
In this section, setting refers to the setting for Nintendo Switch Online license verification that is configured in each application and stored in the various servers.

Authentication Server

On the authentication server, the ability to get NSA ID tokens and the kind of information included in the NSA ID tokens varies depending on this setting.

Differentiating Between Applications to Which the Setting Is Applied

The authentication server distinguishes and stores the setting for each release version of the application, based on the content of the OMAS request.
When an application connects to the authentication server, the process of verifying the Nintendo Switch Online license is performed separately for each release version.

Restricting Release Versions When a Patch Is Required

If a request to require a patch has been submitted on OMAS, server access will be restricted on versions of the application earlier than the specified release version when that patch is released in the production environment. This restriction is not applied in the development environment, so any release version of the application can connect to the server.

NEX Game Server

On the NEX game server, the setting determines whether Nintendo Switch Online license verification is performed for each NEX feature.

Differentiating Between Applications to Which the Setting Is Applied

The NEX game server stores one setting per application, based on the content of the OMAS application.
A single setting is stored on the NEX game server even when the OMAS content is different for different release versions of the application.
For an application with multiple release versions, the OMAS content for the latest patch is applied to the setting on the NEX game server.

Note:

In the development environment, you can access the NEX game server with any release version of the application, even if a patch has been submitted on OMAS.

The NEX game server does not store a separate setting for each release version, so if the NEX features that involve Nintendo Switch Online have been changed as a result of the patch, be careful to not connect to the development environment NEX game server with earlier release versions of the application. Differences in the OMAS requests the setting is based on may result in unexpected behavior by the authentication server and the NEX game server.

Restricting Release Versions When a Patch Is Required

As with the authentication server, if a request to require a patch has been submitted on OMAS, server access will be restricted on versions of the application earlier than the specified release version when that patch is released in the production environment. This restriction is not applied in the development environment, so any release version of the application can connect to the server.

NPLN Server

On the NPLN game server (tenant), you can use the dedicated management tool (NPLN Dashboard) to set whether Nintendo Switch Online license verification is performed for each NPLN feature.
For more information, see the NPLN Manual included in the NPLN package.
