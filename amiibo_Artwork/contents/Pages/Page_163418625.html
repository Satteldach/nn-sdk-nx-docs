2 Logos and Icons

This section contains guidelines and considerations for using the amiibo logo or icons in an application.
Contact your Nintendo representative if anything about these guidelines is unclear, or if you want to use a particular effect.

Note: For the Nintendo 3DS family and Wii U only.



Acceptable Uses

  • Use the amiibo logo and icons to represent amiibo, and in UI elements that jump to amiibo-related features.
  • Use the logo whenever possible. Only use the icon when use of the logo is impossible due to space restrictions or when you want to match the effects of other UI elements.
  • Use the amiibo Settings icon for UI elements that take the user directly to amiibo Settings from the application.
  • When using the amiibo icon and the amiibo Settings icon, add descriptive text.
    Always use text that includes the word "amiibo" alongside the icon to clearly indicate that it is related to amiibo.
    When writing "amiibo" in text, always write the entire word in lowercase.
    However, if it is not possible to add descriptive text due to the space limitations, you can use the icon independently without any descriptive text.

Minimum Margin

The amiibo logo is to be surrounded by a minimum margin. As a general rule, this margin area may not contain images or text.
The minimum margin may be compromised when the display space is limited.

The minimum margin is included in the distributed data as a clear rectangle. See the resource for details.

Specified Colors

Note

Use one of the specified colors unless it impairs visibility or there is some kind of technical limitation.
Use an achromatic logo only if none of the specified colors can be used.

Background and Effects

The primary background color is white and the secondary is black.
Ensure that visibility of the logo is maintained when you place it on a background color other than white or black.
You can add a drop shadow or outer glow effect to ensure visibility.
A text outline is generally prohibited.
