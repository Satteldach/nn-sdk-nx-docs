1 Introduction


Objectives and Content

This document describes how to use the logo when using amiibo, the screen images when touching the amiibo to the controller, and how to use sound effects.

Intended Audience

This documentation is intended for planners and application developers.

When to Read This Document

Read this documentation when you are planning or developing applications.

File List

This package has the following structure.
Note: Not all of the files are listed.
