9 Play Report FAQ

FAQ

Q1. I sent a play report from the development hardware, but I can't view it in the play report management tool.

Check the following.

Has the play report been successfully saved to the Switch console?
  • To save play reports, some conditions must be met. (For more information, see 4 Sending Play Reports.)
  • Run the application on a Switch that is not connected to the internet, save the play report, and then check the PlayReport tab in DevMenu.
If play reports are being saved with a user account specified, is that user account linked to a Nintendo Account?
  • That Nintendo Account must opt in and allow the sending of play reports. (For more information, see 4 Sending Play Reports.)
  • Play reports are not sent to the server if the only account linked to the Switch console is a network service account (NSA), which can be readily created using DevMenu.
    • As an exception, the play reports are sent if the User Agreement Check setting has been disabled in the PlayReport tab of DevMenu.
      For more information, see 4 Sending Play Reports > Conditions for Saving and Sending When User Agreement Check Is Disabled in the Development Environment.

Q2. It appears that I cannot get the latest play reports.

Report data saved within a Switch console is not sent while an application has made a network usage request via the NIFM library and that request is being accepted.

For this reason, if an application is using network features, it might take awhile until play report data that was saved is sent to the server.

To check whether this kind of delay is occurring, compare the following two system key times.

  • Time when report data was saved within the Switch console (nc_recorded_at)
  • Time when report data was received by the server (posted_at)
