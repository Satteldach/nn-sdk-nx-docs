7 Play Report Design

Keep the following points in mind when designing event keys and other aspects of the Play Report data (the report data).

Redundant Registration of Data

When dealing with report data, try to avoid designs where the same data is saved redundantly to multiple event keys.

When data is registered redundantly to multiple events, it puts a strain on the server where the data is stored.

That being said, there is no need to go out of your way to avoid duplicates in situations where there is merit to saving the data redundantly. For example, there are situations where you would repeatably need to join tables for data analysis if the data were saved to only one specific event.

Suspending Applications

Call the nn::prepo::AddSessionId() function in the application if you want your analysis of the report data to take the play session into account. The term session refers to the segment between when the application was started and when it was suspended.

You can use this function to add a value to the event that is unique for each session, using a key named in any way, such as session_id.

The term suspended refers to the following for the application.

  • The ending or restarting of the application
  • The transition of the Switch system to sleep mode

The application is not treated as suspended when the HOME Button has been pressed to display the HOME Menu.

Internet Connection Status

To analyze the internet connection status for the Switch itself, call nn::prepo::AddInternetConnectionStatus() from the application.

You can use this function to add the following values to an event, using keys named in any way.

  • Network interface type: None, wired connection, or wireless connection
  • Quality of communication with the access point, on a scale from 0 to 3
  • Frequency band used for wireless connections: None, 2.4 GHz, or 5 GHz

For more information, see the API reference.

Note:

If you call this function while Switch is attempting to make a wireless connection, the following key-value pair is saved to the event.

  • Network interface type: wireless connection (IEEE 802.11)
  • Frequency band used for wireless connections: None

If you call this function after the wireless connection completes, the frequency band used for wireless connections is saved as either 2.4 or 5 GHz, changing from None.

Keep this in mind when analyzing the report data.
