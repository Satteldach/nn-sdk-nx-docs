2 Play Report Overview

The Play Report feature provides a mechanism for collecting and analyzing information about the events in the application using a server.

These play reports can be used in various ways, for example to identify frequently used game features to make the focus of future patches and follow-on products, or as guidelines for how to adjust the balance in a battle game.

To use the Play Report feature, you must first establish the purpose for collecting data and then create an appropriate means of collecting data for that purpose.

The Play Report feature consists of two mechanisms, one for the Switch console (the client) that sends data from the application to the server, and the other for the server that saves the data.
To analyze the data, you must build a separate mechanism for each application.

This documentation describes the preparations required for sending data from the Switch console to the server, how to send the data, and how to check the data that has been sent.
