5 Play Report Web Tool

Web Tool Features

The Play Report web tool has features for the following tasks.

  • Checking sent data
  • Issuing access keys for downloading raw data

To use these features, after logging in to the web tool, in the Title List menu, select the application (title).

Checking Sent Data

The Play Report data (the report data, referred to as simply "data" in the tool) that is sent from the Switch console to the server is accumulated as JSON files in a server (Amazon S3) that is not used for analysis. The report data in this state is called raw data.

System Keys

There are certain keys that are automatically assigned to the report data when the report data is sent from the Switch console to the server. These keys are called system keys.

System keys can be used for analysis.

Name Type Description
application_id Integer

The ID of the application that registered the report.

When this ID is obtained using the method described in 6 Downloading Raw Data, it is obtained as a value converted to int64 type (a 64-bit signed integer). Be careful when using this value because it is converted from hexadecimal to decimal.
event_id String

The value for the event ID specified in the Play Report library when the application saves report data. (Report data is saved in units called events.)
nsa_id

String

The internal ID of the network service account associated with the user account specified when the application saves report data.
The value can be blank (null).

The NSA ID that can be obtained in the play report is scrambled. It cannot be converted to an NSA ID.
Even if a report is from a different application, as long as the network service account is the same, the value of (the scrambled) nsa_id will match.
device_id

String

The device ID.
This information is for system developers at Nintendo.

To determine whether multiple reports are being sent from the same device, use the serial_number system key.

The device ID that can be obtained in the play report is scrambled.
Even if a report is from a different application, as long as the device is the same, the value of (the scrambled) device_id will match.
device_id2

String

The new device ID, created for system convenience.
This information is for system developers at Nintendo.

To determine whether multiple reports are being sent from the same device, use the serial_number system key.

Like device_id, it is a scrambled value.
However, the value does not match device_id.
serial_number

String

The serial number of the Switch console that sent the report data.

The serial number that can be obtained in the play report is scrambled.
Even if a report is from a different application, as long as the serial number is the same, the value of (the scrambled) serial_number will match.
lc_recorded_at TIMESTAMP The time (in UTC) when report data was created, as measured on the Switch console's user-operable system clock.
nc_recorded_at TIMESTAMP

The time (in UTC) when the report data was created, as measured on a network clock.
The value can be blank (null).
operation_mode Integer

The operation mode of the Switch console when the report data was saved. The value is identical to the value for nn::oe::GetOperationMode().

  • 0: Handheld mode
  • 1: TV mode
report_identifier A 36-character string

A unique value for each set of report data.

For more information about using this value, see 8 Play Report Restrictions > Sending Duplicate Data.
posted_at TIMESTAMP The time (in UTC) when report data was received by the server.
application_version Integer

The application's release version.
This value is specified in ReleaseVersion in the NMETA file.
env String

The identifier of the Nintendo platform server environment.

  • dd1: Development environment
  • lp1: Production environment
os_version String

The system version for the Switch console.
This is the value when the report data was sent to the server, not the value when the report data was created.
product_model Integer

The Nintendo Switch console type.

  • 1: Nintendo Switch (HAC)
  • 3: The new model with the longer-lasting Nintendo Switch battery (HAD)
  • 4: Nintendo Switch Lite (HDH)
  • 6: Nintendo Switch OLED Model (HEG)
Info:

For each type of device, the values for the retail product and the development hardware are the same.
rebootless_system_update_version String This information is for system developers at Nintendo.
is_china BOOLEAN

This information indicates the platform region that the Nintendo Switch device is set to use. Can be used for application analysis.

  • If the platform region is China (set to be sold in China), the value of this key will be true.
  • If the platform region is Global (set to be sold outside of China), the value of this key will be false.

Although operation is not assured, in some cases non-Chinese specification game cards can be started on Nintendo Switch consoles for China. In these cases, report data for an application that is not for China might be sent from both consoles for China and from consoles for other regions.

When analyzing report data, you can use this key to determine whether the data was sent by a Switch console for China.

You can review the list of system keys from the Help tab on the right side of the screen after you have selected a raw data ID.

Issuing Access Keys for Downloading Raw Data

To download raw data from the development environment or the production environment, select the S3 tab and issue an Amazon S3 data storage access key (access_key_id). For more information, see 6 Downloading Raw Data.

This access key only contains the permissions to download the raw data for the issued title (GetObject) and to display the list. You cannot perform other operations or download the raw data for another title.

You can delete access keys or reissue deleted access keys using the Play Report web tool.

You can create only one access key for each title.

The user who is the Play Report administrator is responsible for properly managing the issued access keys and sharing them with the necessary members.

Download the raw data using AWS CLI or AWS SDK with the issued access key. For more information about AWS CLI and AWS SDK, see the official AWS website.
