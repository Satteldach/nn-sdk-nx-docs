3 Preparing to Use Play Reports

OMAS Request

To use play reports, you must submit a request on OMAS. Use the following procedure to make the request.

  1. Log in to OMAS.
  2. Open the page for the product release, click the Add Item tab, and then click Play Report.
  3. Specify one person to be the Play Report administrator. Select an NDID from the list that appears on the screen.
  4. Submit the release with the added Play Report request.

Info:

Any of the following NDIDs for the target product on Nintendo Developer Portal (NDP) can be selected as the administrator on OMAS.

  • The NDID of the user who created the target product on NDP
  • The NDID of a user added as a member for the target with Add User on NDP
    • Members added from external companies are excluded.
  • The NDID of a user who belongs to a user group added to the target product on NDP.

Users with the Company Admin role are displayed automatically as users with the Product Admin role for the products from their own company on the Members page on NDP. As a result, even if a user is shown as a member on NDP, that user might not satisfy any of the preceding conditions and it will not be possible to select them as the Play Report administrator in the OMAS request.

If a user with the Company Admin role cannot be selected as the Play Report administrator in the OMAS request, add them as a member of the target product using Add User on NDP.

This specification may be changed in the future.

Note:

You can use the Play Report web tool to create, delete, and reissue access keys for downloading Play Report data saved to the server. For more information, see 5 Play Report Web Tool.

The administrator must be the one who manages the access keys.

NDIDs That Can Use the Web Tool

Only NDIDs that have been granted management permissions for the target title can operate the Play Report web tool. The specifications for granting management permissions were changed in October 2022, as described in the following table.

Current Specifications

Permissions are granted at the time the NDID logs in to the Play Report web tool.

Management permissions are granted to the NDID if that NDID was specified as a Play Report administrator in the OMAS request for the latest release version in the In Development phase or later.
Permissions that have been granted already are not automatically deleted.

Say that you change the Play Report administrators in the OMAS request for release version v2. If you do that, permissions will be granted only for the NDIDs of the administrators specified in the OMAS request for v2 after that version reaches the In Development phase. Permissions will not be newly granted to the NDIDs of administrators specified in the OMAS requests for v1 and earlier.
If you later set a different NDID as a Play Report administrator in the OMAS request for release version v3, permissions will be granted to that NDID. In addition, the NDIDs that were granted permissions in the request for v2 will retain their permissions.
Prior Specifications (Reference)

If the NDID was specified as a Play Report administrator in the OMAS request for any release version that has reached the In Development phase or later, permissions will be granted to that NDID when it logs in to the web tool.

For example, even if you change the Play Report administrators in the OMAS request for release version v2, an NDID that was specified as a Play Report administrator for release version v0 will be granted permissions when it logs in.

For NDIDs that have already been granted management permissions, you cannot delete those permissions on the application development side.

If you need to delete the management permissions for an NDID, contact Nintendo. When doing so, include the target application ID and the NDID.

Preparing the Application

The Play Report library is included in NintendoSDK NX Add-On 10.1.0 and later.

If you are building an applications that supports play reports, we recommend using this version or a later version of NintendoSDK NX Add-On.

Logging In to the Web Tool

The web tool for server operations can be used when the OMAS request is approved.

The URL for the Play Report web tool is https://dg.mng.nintendo.net/.

Enter the NDID and password to log in.

The administrator performs setup when you first log in to the Play Report web tool.

Setup takes approximately five minutes. Wait a while, and then reload the web browser and verify that the application that you requested is displayed.

Note:

The administrator cannot perform server setup if they cannot view the application in OMAS. Change the product's viewing permissions in the Nintendo Developer Portal as needed.

You must be particularly careful when creating a new product that inherits content from an earlier product. Examples include creating a localized version or a demo version.

Info:

Google Chrome is the only web browser supported by the web tool.
