6 Downloading Raw Data

This page describes how to download raw data for users who are developing a mechanism to incorporate raw data in analysis tools provided by the application.

Raw Data Format

The raw data is written to JSON format files. In each file, one event is entered as one record, and multiple events are separated by line breaks.

Sample

The following sample is for a single event. This sample is formatted for readability, but the actual submission does not contain spaces or line breaks. In addition, no actual comments are included.

{
  "application_id": 81985529216486895,     # uint64 => Data converted to int64.
  "event_id": "example",                   # string
  "lc_recorded_at": "2020-03-06 04:41:55", # string
  "nc_recorded_at": "2020-03-06 04:41:55", # string
  "nsa_id": "xxxxxxxxxxxxxxx",             # string, optional
  "report_identifier": "xxxxxxxxxxxxxxx",  # string
  "device_id": "xxxxxxxxxxxxxxx",          # string
  "env": "dd1",                            # string
  "product_model": 1,                      # integer
  "operation_mode": 0,                     # integer
  "os_version": "10.0.0",                  # string
  "rebootless_system_update_version": "0", # string
  "serial_number": "xxxxxxxxxxxxxxx",      # string
  "posted_at": "2020-03-06 04:42:06",      # string
  "application_version": 0,                # integer
  "is_china": false,                       # boolean
  "data": { 
    # Application specific keys and values
  }
}
Info:

Except for the application specific key included in data, the keys are system keys. For more information about system keys, see 5 Play Report Web Tool > System Keys.

Downloading Raw Data

Accessing Amazon S3

The raw data is uploaded to the N. Virginia region endpoint of Amazon S3 (us-east-1) in the format of a GZIP compressed JSON file (*.json.gz).

Access keys for downloading the raw data can be issued using the Play Report web tool. For more information, see 5 Play Report Web Tool > Issuing Access Keys for Downloading Raw Data.

Access Amazon S3 using something like AWS CLI or AWS SDK.

Access Key Policy

The access key contains permissions to view a list of raw data for a title and download the raw data from Amazon S3. It is read-only. Implement access restrictions by adding an inline policy such as the following for the IAM User.

{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "s3:ListBucket",
        "s3:GetObject"
      ],
      "Resource": "arn:aws:s3:::scrambled-0123456789abcdef-dg-nintendo-net*"
    }
  ]
}

Data Layout

Raw data is placed in individual buckets (scrambled-${application_id}-dg-nintendo-net) for each title. For example, for a title with the application ID 0123456789abcdef, the bucket where its raw data is placed is scrambled-0123456789abcdef-dg-nintendo-net.

In addition, the data is divided into folders based on factors like the server environment, event ID, and timestamp.

S3 Path

The files of raw data stored in Amazon S3 have file paths with the following format.

s3://scrambled-${application_id}-dg-nintendo-net/posts/${env}/${application_id}/${event_id}/day=${yyyymmdd}/${env}-${application_id}-${event_id}-${yyyymmdd}-${hour}-${hostname}.${suffix}.json.gz
Parameter Description
application_id

The application ID for the application.

A 16-digit hexadecimal value (lowercase). Does not include the 0x prefix.
env

The identifier of the Nintendo platform server environment.

  • Development environment: dd1
  • Production environment: lp1
event_id

The ID of the event. (For more information, see 4 Sending Play Reports.)
yyyymmdd
hour
(timestamp)

The timestamp. The time zone is UTC.

hour is a two-digit numerical value, with the first digit zero-filled (00, 01, 02, ..., 23).
hostname

The hostname of the Play Report server.
suffix

An integer starting with 0.
This integer can be any number of digits, without any leading zero digits (0, 1, 2, ..., 9, 10, 11, ..., 99, 100, 101, ...).
Sample
s3://scrambled-0123456789abcdef-dg-nintendo-net/posts/lp1/0123456789abcdef/example/day=20170413/lp1-0123456789abcdef-example-20170413-01-ip-192-0-2-123.0.json.gz


AWS CLI Usage Example

This example demonstrates the use of an Amazon S3 access key and the use of AWS CLI to access an S3 bucket storing raw data.

Note:
  • This downloading of raw data is designed to be used to import data to the analysis tools prepared independently for each application. For actual analysis, use the analysis tool to which the raw data was imported. Avoid the practice of redownloading the raw data needed for each round of analysis.
  • The description in this section might not keep pace with the changes made to the AWS CLI specifications, so refer to the AWS official website for the exact specifications.

AWS CLI Settings

This sample uses the aws configure command to configure the access key.
Another way to configure the access key is with the AWS_ACCESS_KEY_ID and AWS_SECRET_ACCESS_KEY environment variables, but that method has been omitted from this sample.

This sample assumes that the following access key was provided by the Play Report web tool.

access_key_id: AKI**************MWQ
secret_access_key: qL+**********************************E0r

Use the aws configure command to configure the access key as follows.

$ aws configure --profile playreport_0123456789abcdef
AWS Access Key ID [None]: AKI**************MWQ
AWS Secret Access Key [None]: qL+**********************************E0r
Default region name [None]: us-east-1
Default output format [None]: json

Displaying the List of Files

Use the aws s3 ls command to show a list of files.

$ aws s3 ls s3://scrambled-0123456789abcdef-dg-nintendo-net/posts/lp1/0123456789abcdef/ --profile playreport_0123456789abcdef
                           PRE sample_key_00/
                           PRE sample_key_01/
                           PRE sample_key_02/

$ aws s3 ls s3://scrambled-0123456789abcdef-dg-nintendo-net/posts/lp1/0123456789abcdef/sample_key_00/ --profile playreport_0123456789abcdef
                           PRE day=20170101/
                           PRE day=20170102/
                           PRE day=20170103/

Getting Files

Use the aws s3 cp command to download files. 

$ mkdir -p 0123456789abcdef/sample_key_00
$ cd 0123456789abcdef/sample_key_00

$ aws s3 cp s3://scrambled-0123456789abcdef-dg-nintendo-net/posts/lp1/0123456789abcdef/sample_key_00/day=20170101/lp1-0123456789abcdef-sample_key_00-20170101-01-ip-192-0-2-123.0.json.gz . --profile playreport_0123456789abcdef
