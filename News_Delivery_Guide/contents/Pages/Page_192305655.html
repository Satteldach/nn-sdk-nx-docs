6 BCAT Management Tool: Setting Items and Setting Rules

This section describes the settings and the setting rules for the BCAT Management Tool.

Info

When the BCAT server is undergoing maintenance or having problems, you might not be able to access the BCAT Management Tool.

For maintenance information, see Network Status on the Nintendo Developer Portal.

News Setting Options

These settings are not directly displayed on the Nintendo Switch system.

Delivery Region

Specific Rules

 Item Description
1 ○


 ○ Overview

Enter an overview of the News item.

It does not appear to the user.

You can enter up to 100 characters.

[Japan-Specific] Enter the software title and the name of the responsible editor. Example: Nintendo eShop Availability_Taro Ninten

Remarks

Enter remarks as needed.

It does not appear to the user.

You can enter up to 400 characters.
3

Application ID for a Related Title

Facilitates the display of News in the Entrance of the Switch system for users who are playing the specified application.
4 ○
Country Group

First specify the delivery region for the News.

Then specify the delivery countries (delivery target countries) for the News.

To exclude a particular country, clear the check box for that country.

The language of the News item to be created is determined by the specified countries.

Info

Country groups (groups that classify the delivery target countries) are created automatically by the system.
5 ○
Screenshot Restrictions

Specify whether to enable captures of the News screen.

Specify Enable captures as long as there is no special reason not to.

Only prohibit captures when you do not want to allow captures of News.
6 ○

Overlap Display of News Titles in List Image

Specify whether to superimpose the title (described later) over the list image (described later) in the Switch Entrance and News List screens.

When Show is selected, a black band is inserted at the bottom of the list image. The News titles are displayed in this black band.

When Hide is selected, the News title is hidden when displaying the list image.

Unless you have reason to do otherwise, specify Show so users can grasp what the News item is about.

Hide can only be set if the News title overlaps with text in the list image.
7 ○
Delivery Start Date and Time

Specify the date and time to start delivery of the News item from the BCAT server (BCAT Management Tool).

News items that have completed the pre-delivery review and the Nintendo review are automatically delivered after this date and time.

For more information about how the review works, see the BCAT Management Tool Operations Manual.

Info

There is a lag of approximately 10 minutes between the start of delivery and the time when the News can actually be displayed on the Switch system.
8 ○

Delivery End Date and Time

Specify the date and time to end delivery of the News item from the BCAT server (BCAT Management Tool).

The News will no longer be delivered from the server after this date and time.

Switch devices that have already received the News are not affected by the arrival of this date and time. If necessary, specify a value for Delivered News Display Term (described later).

The default end date is 30 days after the start of delivery.

Change this value if you want any span other than 30 days.
9

Delivered News Display Term

Set a date and time to stop displaying the News item on the user's Switch system.

Specify a News display term when you must restrict the display period for reasons such as copyright.

If no value is specified, the News can continue to be displayed as long as the user has saved the News to the Switch system.

To delete (hide) a News item that was delivered by mistake, change this value to a past date and time and redeliver the News item.

Note

A News item cannot be overwritten after its Delivered News Display Term has elapsed.

This means you cannot change the display term to a date in the past to temporarily hide a News item that was delivered by mistake and then redeliver a corrected version of the News item to show it again. In these kinds of situations, create a new News item.
10 ○
Alternate Language

Specify the language in which to download the News items when the News items are not available in a language expected by the Switch system.

The defaults are as follows.

  • [Japan-Specific] Japanese
  • [Americas-Specific] US English
  • [Europe- and Australia-Specific] UK English
  • [Korea-Specific] Korean
  • [Hong Kong-Specific] Traditional Chinese
  • [China Specific] Simplified Chinese

Do not change this default value without a good reason. If you cannot avoid changing it, specify just one of the other language choices.

For more information about alternate languages, see 2 News.

Info

The Switch system only downloads News items from the server that match both the country of the Nintendo Account (associated with the user account) and the system language settings.

If the News item written in the language set in the system language settings does not exist on the BACT server, the News will not be downloaded even if the country of the Nintendo Account matches.

However, if an alternate language is specified for News items, News items written in this alternate language will be downloaded in place of the language that matches the system language settings.
11

Related Products

Specify this option if you are introducing products related to the News to users.

You can specify the following kinds of products.

  • Software (applications related to the channel)
  • Downloadable content
  • Merchandise bundles

The following products cannot be specified.

  • Demo versions of applications
  • Service Items
Note

Also see Considerations When Introducing Nintendo eShop Products on this page.

This section describes settings that are directly displayed on the Nintendo Switch system.

For more information about where these items are displayed, see the 3 UI Reference.

Specific Rules

List Image

Upload and specify the image to display in the Switch Entrance and News List.

For more information about layouts and formats, see 5.2 Creating News.
2 ○
Title

The News item title.

You can enter up to 140 characters.
3

Video URL

This sets a main video that will be displayed in a large size at the top of the News item.

Specify the URL of a video uploaded as an eShop Video in NCMS.

Videos must be approved by Nintendo in NCMS, and have statuses set to Process Completed.

Note

Pay attention to the Delivery End Date and Time for the video, which can be set in NCMS. After the delivery end date and time has passed for a video, it can no longer be played from the News item.

If you plan to post a video to a News item that has been set with a delivery end date and time in NCMS, we recommend that you set the value of Delivered News Display Term for the News item so it occurs before this configured delivery end date and time.
4

Main Image

Upload and specify the image to display in the body of the News.

For more information about layouts and formats, see 5.2 Creating News.

If a video URL has been specified, the main image will be used as a thumbnail for the video. If you specify a main video but do not specify a main image, the image registered in NCMS is used as the thumbnail.


You can specify up to two video URLs (and their thumbnails) or main images.

Note

You must specify at least one video URL (and its thumbnail) or one main image. Contact Nintendo support if you cannot meet this requirement.
5

Body

You can enter up to 5,000 characters.


You can use the following tags in the body.

  • Text contained inside <header></header> tags is displayed as a header. You can use these tags up to 10 times per body.
  • Text contained inside <strong></strong> tags is emphasized. There is no limit to how many times these tags can be used.
  • Text contained inside <ita></ita> tags is italicized. There is no limit to how many times these tags can be used.

The tags are counted in the character count. No other tags can be used.

Note
  • Tags cannot be used on text outside of the body such as in titles or footers.
  • Up to two lines can be displayed as a header for text with the <header></header> tags. (The third and subsequent lines are discarded.)
  • Make sure that you perform test delivery before actual delivery and verify that it is displayed as intended. For more information about test delivery, see 5.3 Confirming Before Actual Delivery.

For more information, see Link Button Settings on this page.

Note

Also see Considerations When Introducing Nintendo eShop Products on this page.

Related Videos

These videos are displayed in a smaller size at the bottom of the News item.

As with the URL for the main video, specify the URLs of videos uploaded to NCMS. Alternatively, use Select Title to reference Videos from to search for a video, and specify it.

A maximum of nine URLs may be specified.

The images registered in NCMS are specified automatically as the thumbnails for the videos. You cannot specify another image using the BCAT Management Tool.

Names of Related Videos

If related videos have been set, you can enter a name up to 64 characters for each video.

Specify one of the following.

  • Set a name for all of the videos
  • Do not set a name for any of the videos
    • In this case, the area used for showing the name displays a thumbnail instead.

[Japan-Specific] If you have set a related video, make sure that you enter a name for it.
10
○

Footer Text

You can enter up to 2,300 characters.

The footer is shown below the body text in a smaller and lighter font.

Use characters to enter the copyright and registered trademark symbols (© and ®). Character entity references such as ‘&copy;’ cannot be used.

We recommend using footers for copyright information, notes of low importance, and comments about News.
Consider placing notes about product information in Nintendo eShop so the footers are not too long.


[Japan-Specific] We recommend using the footer for copyright information, editor signatures, and notes.
11

Description of Delivery Region in Footer Text

Specify whether to append the following statement at the beginning of the footer: "This News is created for our Nintendo Account holders in the XXX."

Specify Include unless there is some reason to do otherwise.
12 ○
Rating System

The ratings organization is specified in advance according to the language being used for the News.

If you must describe a ratings organization that cannot be selected using the BCAT Management Tool, we recommend entering this information as text in the footer.


Select No Rating only if the application is not subject to rating (for example, the application involves no gameplay and its purpose is to provide functionality).

Note

If the application has not received a rating, select Rating Pending as the rating value. Do not select No Rating in this case.

For example, if you plan to get a CERO rating for the application, first select CERO as the rating system value. Next, select Rating Pending as the rating value.

Info

You can copy content such as rating values across languages depending on the specified rating system.

Values are not synced when edited after copying, so copy again as required.
13 ○ ○ Rating

Specify the rating for the application.



[Europe- and Australia-Specific] If the News includes a video, always display the rating either in the video or in the News.

Link Button Settings

Link Button Type

You can specify any one of the following links for each News item.

Go to Nintendo eShop

After selecting SHOP as the link button type, specify the type of page the link leads to.

  • Software Details
  • DLC Details
  • Software DLC List
  • Bundle Details
  • Selected Products List
  • Service Tickets List
  • Consumable Items List
  • Nintendo Switch Online Page

If you have selected a link to the Selected Products List page, specify a List Name and Products to Show (Up to 50).

If you have selected a link to the Nintendo Switch Online page, specify the link button text (described later).

If any other type of page is selected, specify only one product. After that, specify the link button text.


Starting a Specific Application

After selecting GAME as the link button type, select the application to start.

If you want to change the behavior of the application when it is started from News, upload a launch parameter binary file (maximum 16 KB).

You can use the launch parameters to do things like give an item related to the News as a present to the user.

Use the nn::oe::TryPopLaunchParameter() function to get the parameters. For more information, see the oe library page in NintendoSDK Documents.


Info
If the application cannot be started, instructions are provided based on the situation.
  • If the corresponding application has never been started on that Switch console, the user is prompted to go to the Nintendo eShop page for purchasing the software.
  • If another application is suspended, the user is prompted to exit that application.
  • If the application is suspended and a launch parameter has been configured, the user is asked if they want to restart the application.
    • If a launch parameter has not been configured, the application resumes at the point where it was suspended.
  • If the game card with the pertinent application is not inserted, the user is prompted to insert the game card.
    • This prompt only occurs if the game card with the application has ever been inserted into that Switch console.
Note
  • Setting a link to start an application that has not yet been released is prohibited.
    Because the application has not yet been installed on any Switch systems, clicking the link would unconditionally start Nintendo eShop, which is inconsiderate to users.
  • You cannot test the flow to start an application from the News delivered to development hardware because News cannot be delivered in the development environment (dd1 environment).
    To emulate the flow, use DevMenu (NintendoSDK System Updater for NX 4.1.0-1.0 or later).
