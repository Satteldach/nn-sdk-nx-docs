3 UI Reference

This section describes the screen transitions leading to News display and the various screens associated with News items.

Note

News screen designs may change without notice.

Screen Transitions Until News Appears

The transitions from the Entrance or the HOME Menu until News appears are as follows. (Does not include returning using B Button.)

When the Nintendo Switch is being used in handheld mode, tapping the image for a specific News item in the Entrance sends you to the News Details screen.

If a link to Nintendo eShop or an application has been configured for the News item, you can activate it from this News Details screen.

Entrance

The Entrance is displayed when the system wakes from sleep mode. Three featured News items appear on the left side of this screen, together with their list images. Pressing the Y Button sends you to the News List screen. If you are using the Nintendo Switch in handheld mode, tapping a specific list image sends you to the News Details screen.

Number Item Description
a
List Image

The image configured for the News item appears automatically.

For more information about image formats, see 5.2 Creating News.5.2 Creating News5.2 Creating News.

News Title

Displays the News item title.

An ellipsis (…) is displayed when the text exceeds the maximum character count.

You can choose which News item titles to display in the Entrance on an item by item basis.

Appears automatically when there is at least one newly downloaded News item.

A News item stops being new when you return to the HOME Menu from the News List, or when you read that News item.

Appears automatically if a video is set as the main image for a News item.

Note: Linked videos are not shown.

HOME Menu

If you press the HOME Button while starting the Nintendo Switch, the HOME Menu appears.

Number Item Description
a
Jump Button for the News List You can jump to the News List from this icon.
b
New Items Mark

Appears when there is at least one newly arrived News item.

However, it does not appear when News items that have already been released are overwritten or updated.

News List

This screen lists the News items. Three featured News items appear at the top. Other News items are sorted from the upper left, in the order of most recently downloaded.

  • Up to 300 News items can be saved. (Depending on the sizes of the downloaded News items, the maximum may be less than 300.)
  • When more than 300 items are downloaded, the oldest items by download date and time are removed.
  • News items that are beyond their display periods do not appear.

News Details

The News Details screen shows the details for the News item that has been selected. For more information about configuration, see 6 BCAT Management Tool: Setting Items and Setting Rules.

Number Item Description
a
New Items Mark

Appears automatically when there are newly downloaded News items.

When you exit the News List, News items that had been marked as new are no longer treated as new.
b
Channel Icon

Crops the channel image data that was applied for in NCMS into a circular shape and displays it.

For more information about icon formats, see 5.2 Creating News.
c
Channel Name

Displays the channel name that was submitted in NCMS. The maximum character count is 64.
d
Publisher The publisher name registered in NCMS. The maximum character count is 64.
e
Delivery Date Displays the delivery start date configured using the BCAT Management Tool.
f
News Title Displays the News item title name, up to a maximum of 140 characters.
g
Main Image or Video

You can place up to two videos or still images.

Note: For videos, you can only set the URL for a video clip that has been registered in NCMS and is within its release period.

Note: For still images, the width is fixed but you can set any height (within the limit).

For more information about video and still image formats, see 5.2 Creating News.
h
Body

Displays the body of the News item, up to a maximum of 5,000 characters.
i
Link Button

You can optionally configure one of the following behaviors for each article.

  • Go to Nintendo eShop
  • Start the application
j
Related Videos

A maximum of nine videos registered in NCMS may be set.
k
Name of Related Video

The name of the related video is displayed up to a maximum of 64 characters.

(Set using the BCAT Management Tool for each video, rather than referencing the video names in NCMS.)
l
Bookmarks

Allows the user to bookmark News items. Up to 300 News items can be bookmarked.

If the bookmark has already been created, removes the bookmark.

Bookmarked News can be viewed from the Bookmark List.
m

"Great!" and "Oh." Buttons

These buttons allow users to express their opinions toward an article.

The default is "unselected."

The user can select either Great! or Oh.
n
Footer

The characters are displayed in a lighter font color than the body text. You can optionally configure up to 2,400 characters.
o
News Item Delivery Region Display Text

The system automatically determines the delivery region based on the News item delivery countries and adds the appropriate text.
p
Rating Icon

The rating icon set for the News item is displayed.
q

View More News

Displays the Channel Details screen. (For more information, see the Channel Details section on this page.)

This screen shows information including the basic information for the News delivery source, currently available News items, and follow/unfollow channel buttons.
r
Related Products

A link to Nintendo eShop can be set.

In channels for specific software, you can set not only the software itself, but also downloadable content and bundles that include that software.

The following content is extracted from NCMS and displayed.

  • Product name
  • Hero banner (a representative image for introducing software that combines the main visual and the title logo)
s
Related Channels

You can set up to ten channels. The following items are listed.

  • Channel icon
  • Channel name
  • Follow/unfollow button for channels

The user can follow and unfollow channels.

Note: You cannot set channels for specific software as related channels.
t
Previous Displays the previous News item.
u
Next Displays the next News item.
v
Information

Displays the Channel Details screen.

Same as the View More News button.

Viewing Restrictions Using Parental Controls Settings

Users can use the parental controls to restrict viewing for News Details.

If viewing is restricted, News Details resembles the following.

The rating information set when creating the News item, and the parental controls settings set by the user, determine whether a News article can be viewed. Application rating information is not applied automatically. Make sure that you set the correct rating for each News article.

Users can temporarily deactivate these restrictions from the buttons on the HOME Menu.

For more information about parental controls, see Nintendo Switch System Features Guide > System Application > System Settings.

Channel List

This list includes the channels for which News items are currently available.

Channels that delivered their first News item less than 168 hours ago are listed first, shown in order starting with the newest of the channels. The rest of the channels are then listed in the order of the freshness of their latest News items.

This screen is only displayed when a Switch console with one or more Nintendo Accounts linked is connected to the internet.

The displayed channels are determined by the country settings of the Nintendo Accounts linked to the Switch console and the system language settings.

View by Channel

This screen shows received News items on a channel-by-channel basis. Select the channel you want to view. The News items for that channel will be displayed.

Number Item Description
a
Unread News Select to display unread News items.
b
New Items Mark

Appears when a channel has at least one newly arrived News item.

However, it does not appear when News items that have already been released are overwritten or updated.
c
Channel Name

Displays the channel name that was submitted in NCMS. The maximum character count is 64.

The channels are sorted in order of the freshness of their News, starting with the channel with the most recently received News.

Note: The displayed channels are the channels that are being followed. However, a channel is not displayed if it has no News to show.
d
View More

Jumps to the channel list.

Note: Only displayed when the console is connected to the internet.
e
View All Available News

Displays the Channel Details screen for the selected channel.

Channel Details

This screen displays basic information about the channel.

You can also set whether to follow or unfollow the channel. (Switches between following and not following the channel.)

This screen is only displayed when the console is connected to the internet.

Number Item Description
a
Channel Icon

Crops the channel image data that was registered in NCMS into a circular shape and displays it.

For more information about icon formats, see 5.2 Creating News.
b

Channel Name

 Displays the channel name that was submitted in NCMS. The maximum character count is 64.
c
Channel Description Displays the description that was submitted in NCMS. The maximum character count is 200.
d
Publisher

The publisher name registered in NCMS. The maximum character count is 64.

Displayed in the format "Publisher: Publisher name."
e
Follow Channel

Use this item to follow and unfollow channels.

Up to 256 channels can be followed.

However, because this number includes channels that are mandatory channels for the system to follow, the number of channels that users can follow on their own is slightly less.
f
Software Information

Starts Nintendo eShop and displays the product page for the related software.
g
Available News Items

Displays up to 300 News items delivered by this channel that are still within their display periods, presented in order starting with the News item with the most recent delivery start time.

Selecting a News item displays the News Details screen for that item.

Note: News items that are past their delivery end time continue to appear if their display period has not yet ended.

Bookmark List

A list of bookmarked News items appears.

This screen is only displayed when the console is connected to the internet.

Number Item Description
a
Bookmarked News

Bookmarked News items are displayed in the order they were bookmarked, from newest to oldest.

Selecting a News item displays the News Details screen for that item.

Note: News items past the display expiration date show a notice that distribution has ended, and details are no longer viewable.
