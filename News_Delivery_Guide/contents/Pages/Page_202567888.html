5.2 Creating News

This section describes the specifications and production rules for the structural elements of News items, including titles, body text, and images.

If you do not follow these instructions, your News items may not be delivered normally, or Nintendo may request that you revise them. Keep that in mind.

Some of the rules that apply to text expressions are described in 4 Notes About Creating News. Also see that section when you create News items.

Title

News titles appear in the Entrance, the News List, and in News Details. This setting is required. Handle this as follows.

  • Focus on using simple expressions.
  • Focus on titles that enable users to understand what the content is discussing.
  • Setting title names that do not convey an accurate impression of the content of the News item or that inappropriately inflate user expectations is prohibited.

The title can be up to 140 characters in length.

We recommend using titles that fit on two lines for [Europe-Specific and Australia-Specific] News items.

Body

The text placed below the video or still image in the News Details screen. You can enter up to 5,000 characters for this text. This setting is optional. Handle this as follows.

  • Adjust the text to ensure sentences are not too long.
  • Do not insert more line breaks than necessary. Text with excessive line breaks will be extended vertically and may be difficult to read.
  • Make sure that you deliver the text to a Switch system and see how it looks, adjusting the text as necessary so it is easy to read, such as by adjusting line breaks.

Tags

You can use the following tags in the body. (The tags are included in the character count.)

  • Text contained inside <header></header> tags is displayed as a header. You can use these tags up to 10 times per body.
  • Text contained inside <strong></strong> tags is emphasized. There is no limit to how many times these tags can be used.
  • Text contained inside <ita></ita> tags is italicized. There is no limit to how many times these tags can be used.
Note
  • Tags cannot be used on text outside of the body such as in titles or footers.
  • Up to two lines can be displayed as a header for text with the <header></header> tags. (The third and subsequent lines are discarded.)
  • Make sure that you perform test delivery before actual delivery and verify that it is displayed as intended. For more information about test delivery, see 5.3 Confirming Before Actual Delivery.

List Image

This is a still image that appears in the Entrance and the News List. This setting is required. Handle this as follows.

  • Create an image that readily conveys the content of the News item.
  • If you cannot create an image for each News item, you can use a hero banner instead.
  • If you plan to set a still image as the main image, we recommend using different artwork for the main image and the list image.

Image Format

Create images in the following format.

Size 358 × 201 pixels.
Format Baseline JPEG. The progressive format is not supported.
Capacity Less than 270 KB.
Color Space YCbCr, RGB, or grayscale. (CMYK and YCCK are not supported.)

The system might display text or other content over a portion of the list image. The overwritten part of the list image will be hard to see.

You can check the image's appearance by using the News_ListImage_Sample.psd file bundled with this document. Please use this file when creating images.

Using low-resolution, blurry images and using images with inappropriate aspect ratios is prohibited.

Main Image

The main image is a video URL or a still image that is shown together with the body text. As a rule, you must set at least one main image.

If a still image is set as the main image, we recommend using different artwork for the main image and list image. It is also possible to shrink the same artwork and set it as the list image.

Info

Up to two text bodies and main images can be set. (For text bodies, the combined maximum is 5,000 characters.)

They are displayed in order from the top as the first main image, the first body text, the second main image, and the second body text.

If you set a second main image but not a first main image, that main image is placed between the two text bodies.

Videos

Set the URL for the (NCMS-approved) video that will be publicly available on Nintendo eShop.

In addition, use either of the following methods to set a thumbnail for the video.

  • Automatically display the thumbnail set in NCMS.
  • Set a separate image from the thumbnail set in NCMS.

When setting a separate image, use the following image format.

Size 800 × 450 pixels (fixed).
Format Baseline JPEG. The progressive format is not supported.
Capacity Less than 2500 KB.
Color Space YCbCr, RGB, or grayscale. (CMYK and YCCK are not supported.)

The Play icon is displayed in the center of the thumbnail. The part overwritten by the icon will be hard to see.

You can check the appearance by using the News_MainImage_Sample.psd file bundled with this document. Please use this file when creating images.

Setting an image that is unrelated to the video is prohibited.

Info

For more information about the format for videos, see the NCMS description.

Still Images

When preparing a tall vertical image, design it with the consideration that the entire image will not fit on one screen.

When setting a still image as the main image, use the following image format.

Using low-resolution, blurry images and using images with inappropriate aspect ratios is prohibited.

Size

800 × 450 pixels (base size).

You can set any height in the range from 1 to 1800 pixels.
If you plan to set multiple main images, the total combined height must be no greater than 1800 pixels.
Format Baseline JPEG. The progressive format is not supported.
Capacity Less than 2500 KB.
Color Space YCbCr, RGB, or grayscale. (CMYK and YCCK are not supported.)
