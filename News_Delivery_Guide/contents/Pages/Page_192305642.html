5 Workflow for News Delivery

This section describes the workflow for delivering News.

List of Tools

The following tools are used in this workflow.

  • A Switch retail unit
    • Used for receiving and displaying News.
  • NCMS
    • A web tool for submitting the information and materials required for delivery via Nintendo eShop.
    • Used to request use of News features.
  • BCAT Management Tool
    • A web tool for creating new items.
    • For more information, see the Nintendo Switch BCAT Management Tool Operations Manual.
