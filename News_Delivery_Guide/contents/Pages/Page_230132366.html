5.1 Applying for a Channel

This page describes how to set up a channel.

Channels can be used to send out information about software titles before they are released, and to send out information for specific software to fans who have played the full or demo versions.

Applying for a Channel

  1. Get the product code on the Nintendo Developer Portal (NDP).
  2. Log in to NCMS. From the dashboard, select Switch > Application News Channel.
  3. Search for and select the software.
  4. Make entries for items on each page according to the settings rules, and then click Save.
  5. Click Submit.
Info

See the NCMS Manual (Japanese, English) for more information.

Notes

  • One channel is set up for each software title.
  • Even for the same software title, a channel for the China sales region must be set up separately from the channel for other regions.
  • You must submit a separate request for each region in the News channel application form.
  • It can take as long as five business days from the time the request is received until it is approved.
  • An email notification is sent after Nintendo approves the request. After that happens, the applicant can use the BCAT Management Tool.
  • The applicant has administration rights to the channel. These rights can be granted by the applicant to a third party with the BCAT Management Tool.

Materials Required to Apply for a Channel

For more information about what gets shown to users, see 3 UI Reference.

Item Name

Description and Rules
Channel Icon

We recommend using an icon that depicts the content of the channel.

Image files can be used for the channel icon if they meet the following conditions.

  • Size: 70 × 70 pixels
  • Format: JPEG
  • Volume: Maximum of 50 KB

Use an icon that can be displayed to all ages, regardless of the rating of the software. Avoid the depiction of blood and things of an offensive nature.

The system crops this icon for display as a circle. Do not place important information in the corners of the icon.

Fill in the sides to create the icon as a square shape. If you do not fill in the sides, you may end up with edge noise.


Info

To see how an icon looks after cropping, see the news_ChannelIcon_Sample.psd file accompanying this document. Use this sample when creating your icons.

Info

A single channel icon is set and shared across regions. The different regions do not show different channel icons, even if you specify a different icon in the News channel request submitted for each region. The icon shown is the icon in the request that was approved last. (The icons in the earlier requests are overwritten.)
Channel Name

You can set up to 64 characters.

Set a name that is appropriate for the News content in the channel.

We recommend using a channel name that enables the user to determine what software the News is for. The following are a few examples.

  • Poor: "Mario"
  • Fair: "Mario Shortcuts"
  • Good: "Mario Kart 8 Deluxe Shortcuts"
Info

In the BCAT Management Tool, there is a name for the channel that is used only in the tool and is separate from the channel name that is shown to users. This management-use channel name is not displayed to users.

The management-use channel name reflects the name of the region where the News channel request was approved last.
Channel Description

You can set up to 200 characters.

Consider an engaging description to introduce the channel. The following are a few examples.

  • A greeting to users
  • An overview of the News topics
  • The purpose for delivering the News
  • An introduction to the News provider
Note

If you mention the planned release date for the software in the introduction, make sure that you replace this language with expressions like "now on sale" or “now available" after the software is released. Otherwise, remove the mention entirely.
Channel Release Start Date

Set the date and time when the channel will begin being shown in the Channel List on the Switch console.

This setting defines the time after which users can follow the channel.

This can be set in the format of year, month, day, and hour.

As a general rule, set the channel release start date to the day you expect to begin delivering News.

Note

The Channel List displays only channels for which News items have been delivered since the specified channel release start date and meeting all of the following criteria.

  • Not being edited.
  • The delivery start date and time has passed.
  • Prior to the display deadline
  • A channel closure date and time has not been set, or has been set but has not yet passed.

Channels that delivered their first News item less than 168 hours ago are listed first in the Channel List and labeled as "New."
Channel Closure Date and Time

If a request with a channel closure date and time set is approved, all News on that channel can no longer be viewed after the specified date and time. In addition, a notification about the channel closure is displayed on the channel details screen two weeks before the scheduled closure.

Note
  • Requests with a channel closure date and time set must be submitted at least 10 business days prior to the closure notification (two weeks prior to the channel closure).
    • Example: If the channel closure date is 2020-03-30, the channel closure notification appears on 2020-03-16, two weeks prior to the closure date. The submission deadline is 2020-03-02, or 10 business days before that.
  • Do not set this item if you do not plan to close the channel.
  • Do not change your channel closure date and time after your channel closure request has been approved.
Note

One Application News Channel request must be submitted per region even for the same title, but channel closure dates and times are shared between regions if the product code is the same. Note that if you set a channel closure date and time for a title for a particular region, the corresponding channel in all regions for the same title is closed at that date and time.

For this reason, setting a channel closure date and time via a request for a single region is not a problem.
News for Demo Title User

Set so that News is delivered to users who have played the demo version.

Info

If you release demo software after a channel has been established and want that channel News to also be delivered to users who have played the demo version, you must reapply to set up a channel.
Specifying News Delivery Target Countries

Select from the following options to set the target countries for News delivery.

  • Automatically set the same countries where the software is being sold.
  • Manually select countries.
News Delivery Target Countries Set the target countries for News delivery.

As a general policy, set the countries where the software is sold as the News delivery target countries.

The channel appears in the Channel List only on Switch consoles linked to Nintendo Accounts in those delivery target countries.
Channels for software for the China sales region appear only on Switch consoles for China that are linked to accounts for China.


Channel Revisions

If you want to revise the content of the request before approval is granted, resubmit the request on NCMS.

If any revisions are made to the items displayed to the user (the channel icon, channel name, and channel description), those revisions are applied the next time News is delivered.

If you want those revisions to also be applied to News that has already been delivered, see 5.5 Revisions After Delivery and resend that News.

Info

If you want to revise your request before Nintendo has granted approval, use the NCMS forum to ask Nintendo to reject the application. Make the revisions, and then resubmit the request on NCMS.
