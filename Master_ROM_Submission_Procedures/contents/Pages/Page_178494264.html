Application Waiver Requests

Figure 6-1 Submitting Waiver Requests

Submit a waiver request when it is not possible to comply with some guideline, as described in 6.2 Checking Compliance With Guidelines, or when an issue that cannot be resolved is detected during the process described in 6.3 Uploading Master ROMs. To submit a waiver request, from the dashboard, select Releases > target release version > Issues.

Figure 6-2 Items Requiring Support

Bugs that require approval because they cannot be addressed or fixed are listed in the Lotcheck Issues and Required Approvals columns. Submit your application after indicating why each of the issues cannot be addressed or fixed.

The results of the reviews for all waiver requests for a product are shown on the dashboard in the Approvals tab.

DLC Waiver Requests

To submit a waiver request for DLC, the procedure is similar to that used for applications. From the dashboard, select Releases > DLC archive release version > Issues.
