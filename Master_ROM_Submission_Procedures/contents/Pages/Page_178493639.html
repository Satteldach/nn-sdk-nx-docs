Entering Master ROM Information for Applications

Figure 6-1 Entering Master ROM Information for Applications

Select target product > Releases > target release version to go to the Lotcheck Request page for that release.

On the Lotcheck Request page for the release, enter the necessary information for Release Info, Features, Test Scenarios, and Age Rating.

Figure 6-2 Master ROM Information Entry Screen for Applications

Release Info

Enter the information needed for the release. For the initial release of the application, make sure that the release version is set to 00. For an application patch, make sure that the release version is 01 or greater.

Target Delivery Format

Select the format in which the application will be sold.

Info:

There will only be physical sales for Hong Kong, Taiwan, and Korea because no decision has been reached yet for the opening of region-specific Nintendo eShops.

Note: Current system restrictions prevent you from selecting only the physical version for Target Delivery Format. Select Physical and Digital, and then select the same regions for Target Sales Region (Digital) that you select for Target Sales Regions (Physical).

Target Sales Regions

Select the regions where the physical and digital versions will be sold.

Info:

For a title that will be sold in either Hong Kong, Taiwan, or Korea, select Asia (Hong Kong, Taiwan, Korea) in Target Sales Regions.

Note: Current system restrictions prevent you from selecting only Asia (Hong Kong, Taiwan, Korea). Select one other region, even if no sales will occur beyond Hong Kong, Taiwan, or Korea.

For Multi-Application Cards

Use this page to select the products and release versions to include on a single card.
You can only select products that have passed Lotcheck. Also, you cannot add multiple instances of the same product.

Note:

All products to be included on a single card must have passed Lotcheck as physical versions. Specifically, the following conditions must be met.
If a multi-application card that has not met the requirements is submitted for Lotcheck, it will fail Lotcheck.
If you are only including an application (v0), the application must have passed Lotcheck as a physical version.
If you are including a patch (v1 or later), that patch must have passed Lotcheck as a physical version (on-card patch).


Features

Describe the application specifications by answering the questions that are displayed. The guidelines that an application must follow will be based on the collected data.

Test Scenarios

Test Scenarios are the testing procedures required during Lotcheck to determine whether the application specifications are as indicated in the submission form.

Depending on the application specifications, Nintendo may request that you submit additional scenarios that can be used to verify application functionality. Prepare the following as data for test scenarios to submit, in conjunction with the play time needed to reach that situation.

  • Within 10 Minutes From Starting the Application for the First Time
    • Enter all application operation procedures for reaching the situation where the specifications can be checked. You can attach videos and images.
  • More Than 10 Minutes After Starting the Application for the First Time
    • Attach save data enabling you to reach the situation within 10 minutes.
    • Enter the operation procedure for using the attached save data.

Age Rating

Enter the rating information that was acquired for the release.

If your application has been rated by a rating organization, submit the results of their rating review in writing from the organization that issued those results, in PDF format.

If the applications will only be sold as a digital version, you can use the International Age Rating Coalition to get multiple IARC-supported ratings at the same time.

For Multi-Application Cards

To set the ratings information for the products on a multi-application card, refer to the following page on the Nintendo Developer Portal.

https://developer.nintendo.com/group/development/help/my-products/multi-application-cards

Entering Master ROM Information for Downloadable Content (DLC)

The procedure for entering master ROM information for downloadable content is similar to the procedure for applications. Select target product > Downloadable Content > target DLC archive release version to go to the Lotcheck Request page for that DLC archive release.

On the Lotcheck Request page for that DLC archive release, enter the necessary information for Release Info, Features, and Test Scenarios. Unlike for applications, you do not need to enter Age Rating information for downloadable content.
