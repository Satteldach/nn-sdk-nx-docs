6 Submitting a Master ROM

Master ROMs that are submitted to Nintendo will be converted to a final product after passing Nintendo's review process, named Lotcheck. This section describes the process for submitting master ROMs to Nintendo's review process.

Note:

The procedure differs in some ways when submitting the master ROM for an application for China. The differences are described in 6.7 Applications for China


Master ROM Submission Procedures

Submitting an Application Master ROM

Figure 6-1 Submitting an Application Master ROM

Because you must submit a separate master ROM for each application release, you must select the release version for the product you submit.

  1. In MY PRODUCTS, from the product list, select the product for which you want to submit a master ROM. The dashboard is displayed.
  2. Select Releases, and then select the target release version for which you are submitting a Lotcheck request.
  3. Enter the master ROM information.
  4. Verify compliance with the guidelines.
  5. Upload the master ROM.
  6. Submit waiver requests.
  7. Submit to Lotcheck.

Submitting a DLC Master ROM

The procedure for submitting a master ROM for downloadable content is essentially the same as the procedure for applications, except that different master ROM information must be entered.

The remainder of this section describes the details of the submission procedure.
