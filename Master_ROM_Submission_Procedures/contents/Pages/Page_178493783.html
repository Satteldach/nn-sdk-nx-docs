Checking Applications for Guidelines Compliance

Figure 6-1 Checking Compliance With Guidelines

Switch applications must comply with the Nintendo Switch Guidelines. When, for unavoidable reasons, guideline compliance is not possible, report the relevant guidelines for which compliance is not possible and submit a waiver request. For more information about the process, see 6.4 Submitting Waiver Requests.

If you have submitted waiver requests, you cannot submit the product to Lotcheck until the requests have been approved.

To view the guidelines to which the application must comply, select target product > Releases > target release version > Guidelines. The applicable guidelines are determined based on the information entered in the procedure described in 6.1 Entering Master ROM Information. Before submitting the master ROM, make sure that the application complies with all of the guidelines that are shown.

Checking Guideline Compliance for DLC

As with applications, downloadable content must be compliant with the Nintendo Switch Guidelines. To view the guidelines to which the DLC must comply, select target product > Releases > target DLC archive release version > Guidelines. Verify that the DLC is compliant with all of these guidelines. If you cannot achieve compliance with one or more guidelines, submit a waiver request.
