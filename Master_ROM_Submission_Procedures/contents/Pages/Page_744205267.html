6.7 Applications for China

The procedure for applications that will be released in China differs in some ways from the procedure for applications that will be released elsewhere.
The following sections describe the differences from the steps of the procedure described in 6 Submitting a Master ROM

Creating Products

You cannot release an application for China using the same ROM that is used for the application in other markets.
For this reason, create the application for China as a separate product from the application for other markets and submit a master ROM that is specific to that product.

Target Sales Region

When entering information in Target Sales Regions in Product Information, Issue Game Code, and Release Info for an application for China, you must clear the check boxes for all other regions and select China only.
You cannot release a common ROM for China and other regions.

Note:

After a game code has been issued, do not edit the release information and change the target sales regions.

China Region Data

Entries must be made in Product Info. Click Edit Data and enter the necessary information.

When all necessary information has been entered, the indicator to the right of China Region Data changes from Incomplete to Complete.

Rating Information

You do not need to set rating information for applications for China.
