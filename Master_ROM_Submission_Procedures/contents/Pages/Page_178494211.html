Uploading Application Master ROMs

Figure 6-1 Uploading Application Master ROMs

From the dashboard, select Releases > target release version > ROM Upload, and then upload the master ROM created in the procedure described in 5 Creating a Master ROM. Uploading the master ROM is a required procedure for Lotcheck submissions. You must also upload when resubmitting the same master ROM to Lotcheck as submitted before.

Uploaded master ROMs undergo an automated ROM check before being submitted to Lotcheck. If any bugs are found during the ROM check, you must either correct them, re-create the master ROM and re-upload it, or submit a waiver request. ROM checks can occur repeatedly.

Info:

If network features have been requested on OMAS, an error occurs if those requests have not been approved. Make sure to confirm that the OMAS requests have been approved beforehand. An OMAS request must be submitted for each release (and each patch). For more information about OMAS, see 4.1 Submitting Usage Requests for Network Features.

Upload Procedure

To upload the master ROM, from the dashboard select Releases > target release version > ROM Upload.

The procedure for uploading master ROMs is as follows.

Figure 6-2 Uploading Application ROMs

  1. Make sure the following conditions are met before uploading a master ROM.
    Errors will be displayed in Bugs > Release Errors when these conditions are not met.
    • A user, who is associated with the company registered as the application's publisher, is performing the upload.
    • A Game Code was issued for the product for which the master ROM is being uploaded.
  2. Select the master ROM to upload with the Select ROM File button.
    You can also add and upload files for additional materials to use in Lotcheck from the Details section.
  3. Click Upload ROM to start the upload.

The ROM check will begin when the upload completes.

Info:

If the application has been compacted, you must submit a NSP file combining the patch and compacted application.
For more information about compacting an application, see Nintendo Switch Patch Guide > Switch Patch Features > Application Compaction and Nintendo SDK Documents > Features > Patches > Application Compaction.

Uploading Additional Materials

Sometimes you must submit additional materials when submitting a master ROM. To upload any necessary materials, click Advanced, which is below the Status line in the ROM Upload screen. Verify that a list of uploaded files is displayed under the submitted file.

Materials Required for Submission

  • amiibo Usage Application and Lotcheck Submission Sheet (Located in Nintendo Developer Portal > Downloads)
    Developers must fill in this document to request amiibo features.
    Submit the required materials as a ZIP file. An upcoming Nintendo Developer Portal update will make it unnecessary to compress these files.

Responding to ROM Check Results

Proceed to the following step when ROM check completes with no bugs found.

If bugs were found in the ROM, you can check the details on the menu on the right, in Bugs.

The list of bugs is also displayed on the Waiver Request Submission screen in Nintendo Developer Portal. Use one of the following procedures to respond if bugs were found.

  • If the bugs can be fixed:
    • Re-upload the master ROM after fixing the bugs.
  • If the bugs cannot be fixed:
    • Submit a waiver request, including the reason why the issue cannot be fixed. For more information about the process, see 6.4 Submitting Waiver Requests.

Uploading DLC Master ROMs

The procedure for uploading master ROMs for downloadable content is similar to the procedure for applications. From the dashboard, select Downloadable Content > target DLC archive release version > ROM Upload and then upload the master ROM for the DLC created in the procedure described in 5 Creating a Master ROM.
