Lotcheck Submission for Applications

Figure 6-1 Submitting to Lotcheck

After the ROM has been uploaded and all waiver requests have been approved, the Submit button for the product is enabled in the menu on the right of the Lotcheck Request page for the target release version. Click the button to submit content uploaded to the Nintendo Developer Portal to Lotcheck.

Request the cancellation of Lotcheck if you need to replace the ROM before the Lotcheck results are known. You can later resubmit the revised version. To request cancellation, click the Cancel Submission button in the menu on the right of the Lotcheck Request page for the release.

Note:

The ROM for release cannot be modified after you have received notification that it has passed Lotcheck. Any subsequent bug fixes must be released as patches.
Contact Nintendo if you need to completely replace the release ROM for some reason.

Lotcheck Submission for DLC

Only one package of DLC (one NSP file) can be submitted at a time to Lotcheck. For this reason, make sure that the NSP file you create for the DLC contains all of the content that will be tested in Lotcheck at the time. Each time the submitted NSP file passes Lotcheck, you can then submit the next NSP file.
The Lotcheck submission procedure for downloadable content is similar to that for applications. Select target product > Releases > target DLC archive release version and then click the Submit button in the menu on the right of the Lotcheck Request page for that DLC archive version.

Support for the Lotcheck Environment

During the Lotcheck process, the environment used is sometimes different from the development environment (dd1) of the application. If the following description applies to your application, make sure that the Lotcheck environment is supported.

Applications Using BCAT Data Delivery

Register data required for running the application to the BCAT management tools in the sp1 and sd1 environments, then start delivery. For more information about the BCAT management tool URL and how to add data, see BCAT Management Tool Usage Manual.

Responding to Lotcheck Results

After the Lotcheck process is complete, the Lotcheck result for the release (pass or fail) will be displayed in target product > Releases > Status for the application or the DLC archive release. For more information about the displayed status information, see 2 Nintendo Developer Portal.

Issues appear in the Lotcheck Bugs column when the submission fails Lotcheck. Use one of the following procedures to respond in that case.

  • If the issue can be fixed:
    • Resubmit to Lotcheck after implementing the fix.
  • If the issue cannot be fixed:
    • Submit a waiver request, including the reason why the issue cannot be fixed. For more information about the process, see 6.4 Submitting Waiver Requests.
