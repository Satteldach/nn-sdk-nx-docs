4.1 Submitting Usage Requests for Network Features

To use network features in your application, submit usage requests for the features on OMAS. After the requests are approved, you can use a development environment that has those network features. Get approval for all of the network features your application will use before you submit the application to Lotcheck. You can verify the status of each request by checking the phase displayed on OMAS.

Network Features Requiring Usage Requests

The following network features require the submission of usage requests on OMAS.

  • NEX
  • BCAT, which will be supported in future
  • Independent Server
  • E-Commerce

For more information about the usage requests for NEX, independent servers, and e-commerce, and about using the development environments, see the related documents.
