4.2 Creating Visual Studio Projects

Applications are developed using Visual Studio projects that use NintendoSDK. This section describes the processes of getting NintendoSDK and creating a Visual Studio project.

Getting NintendoSDK

Use the Nintendo Dev Interface to install the NintendoSDK to a developer PC. The Nintendo Dev Interface is a tool for downloading and installing the development environments available from Nintendo. You need an internet connection to use the Nintendo Dev Interface. The Nintendo Dev Interface can be obtained from the Nintendo Developer Portal.

You need an NDID to use the Nintendo Dev Interface.

Use a version of NintendoSDK that supports master submissions.

Creating Visual Studio Projects

Select NintendoSDK Application Project in the Visual Studio new project wizard and follow the steps to create a project.

For the detailed procedure, see NintendoSDK Documents > Tutorials > Creating New Projects.
