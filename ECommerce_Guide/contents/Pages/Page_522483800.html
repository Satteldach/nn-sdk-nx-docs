7.3 Limitations and Important Information

Limitations on Subscription Service Items

The following limitations exist when selling subscription service items on Nintendo eShop.

Limitation Content Limitation
Maximum service period You can specify any number of days in the range from 1 day to 730 days.
Subscription service item term that can be purchased You can specify a term of at least one minute and no more than half of the number of days of the maximum service period, rounded down.
For example, if the maximum service period is 360 days, the maximum term that can be purchased for the subscription service item is 180 days.
Number of subscription service item courses that can be purchased Up to 10
Number of items that can be added to a single course Up to 20

Contact Nintendo if your plans cannot be executed with the preceding limitations.

System-Based Limitations

There are several system-based limitations.

  • The application cannot determine whether the user has purchased an item. The EC applet does not return the result of whether a purchase was made to the application.
  • Independent servers cannot directly request purchases from Nintendo eShop.
    • However, it is possible to use the API for adding licenses to grant a license to a specific user for compensation purposes. For more information, see 7.2 Mechanisms.
  • Sometimes the API for subscription service items returns temporary errors for reasons such as the maintenance of services provided by Nintendo.

Using Independent Servers to Cache Validity Periods

To reduce the amount of traffic to the Nintendo eShop server, consider caching the validity period on an independent server. For example, if your application does not display the remaining validity period, consider implementing a process where the application contacts the Nintendo eShop server when the validity period cached on the independent server expires to check if there is a valid validity period or license available.

In case of an operation like a refund, you cannot shorten or cancel the user's validity period. This specification might change in the future.
