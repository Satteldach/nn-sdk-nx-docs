7.2.3 Sharing Licenses

License information for subscription service items is linked to the Nintendo Account of the user who purchased the items to facilitate management of that license information.
The following two methods are available for sharing license information for Nintendo Accounts.

  • Device-based sharing
  • Account-based sharing

Setting the Scope of License Sharing

Using OMAS, you can select whether to provide subscription service items under the device-based sharing model or under the account-based sharing model for each course ID.

Device-Based Sharing

Device-based sharing shares the license (validity period) with other Nintendo Accounts on the Switch system. However, the following conditions must be met to share the license on the device.

  • The Switch system is set as the primary console of the Nintendo Account that owns the active license.
  • Other accounts on the device have their user accounts linked to their Nintendo Account.
Figure 7-4 Device-Based Sharing

When implementing the application, you can choose whether the Nintendo Account with the validity period can use the service on consoles that are not the primary console (the part indicated by a triangle in the diagram).

Note

If a Nintendo Account with an active subscription is on a Switch that is no longer a primary console, the subscription is no longer available on that console. Only one Nintendo Switch can be registered as a primary console. Unregistering does not automatically transfer primary console status to a different Switch.

Info

For more information about primary consoles, see 9.2 Relationship Between Nintendo Accounts and Licenses.

Multiple Accounts With Licenses on the Same System

If a device-based shared license already exists on a Switch system, other Nintendo Accounts claiming that Switch as its primary console cannot activate another license (because there is already one available). The API for starting to use a license returns an error.

If multiple device-based shared licenses exist due to linking a Nintendo Account with an active license, the license reference API will return information associated with the license that has the longer validity period. However, consumption of the subscription duration continues for the license with the shorter validity period.

This specification applies to activation of licenses. Purchasing licenses is not affected by the status of Nintendo Accounts.

Account-Based Model

In the account-based model, licenses are not shared with other Nintendo Accounts and only the licenses for your own Nintendo Account are referenced.

With the account-based model, licenses are also available on Switch consoles that are not the primary console.
