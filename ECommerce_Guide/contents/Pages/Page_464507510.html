4 Workflow From Development to Distribution

This page describes the e-commerce feature workflow from development to distribution.

Nintendo provides two main management tools for developing and distributing applications that support e-commerce features.

Online Title Management System (OMAS) is a tool for application developers to request the e-commerce features they want to use and get the necessary server settings.

Nintendo Content Management System (NCMS) is a tool for application developers to provide the information required for selling applications, downloadable content, service items, and other products in Nintendo eShop. You can use an NDID to log in to either system.

The following diagram shows an overview of the process for developers and Nintendo to use the OMAS and NCMS management tools to submit requests and configure settings.

Table 4-1 Management Tool Relationship Diagram

Number Operator Operations
1 Application developers In OMAS, request the e-commerce features for the application that is being developed.
2 Nintendo Review and approve the OMAS request. Configure server settings and issue a client ID or secret as needed.
3 Application developers

Submit the data for applications and downloadable content to Nintendo for Lotcheck.
4 Application developers In NCMS, register sales information for applications, downloadable content, service items, and other items.
5 Nintendo

Review and approve the sales information provided by the application developer. Distribute approved sales information and products such as applications in the production environment.
