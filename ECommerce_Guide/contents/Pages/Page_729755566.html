6.3.1.1 Compensation API

A client ID/secret for compensation is required for using this API. For more information, see 6.3.1 Compensation Method.

API for Checking Transactions

Request

GET /v1/recompense/transactions?nsa_id={nsa_id}&application_id={application_id}&item_id={item_id}&page={page}&per_page={per_page}
Authorization: Basic {base64(clientId:clientSecret)}
PARAMETER REQUIRED VALIDATION DESCRIPTION
nsa_id Required Alphanumeric
16 characters		 The NSA ID of the user being compensated.
application_id Required Alphanumeric
16 characters		 Application ID of the title to be compensated.
item_id Optional Alphanumeric
Between 1 and 16 characters		 Item ID of the item to be compensated.
page Options Integer

The page number to get. Pages are sorted by date and time, and can be obtained starting from the newest.
per_page Optional Integer The number of transactions that can be received per page.

Response

STATUS CODE 200
BODY 
transactions:
[
{
 "transaction_datetime": 0,
 "contract_id": "string",
 "application_id": "string",
 "item_id": "string",
 "nsa_id": "string",
 "reason_code": "RECOMPENSE",
 "reason_description": "string",
}
]
PARAMETER DESCRIPTION
transaction_datetime Transaction date (in epoch milliseconds).
contract_id A value that serves as the identifier for the transaction.
Used to check that a value specified by the compensation API is entered.
application_id Application ID of the title to be compensated.
item_id Item ID of the item to be compensated.
nsa_id The NSA ID of the user being compensated.
reason_code Fixed to RECOMPENSE.
reason_description Special Notes

Error Codes (Some)

Error Code Name Reason for Occurrence
1503 unauthorized
  • Occurs if the client_id/secret is not valid.
  • Occurs if an attempt was made by a client without permission to check the license for the title specified by application_id.
1520 invalid application id
  • Occurs if the specified application_id does not exist.
1530 invalid item id
  • Occurs if the specified item_id does not exist.

Compensation API

Request

POST /v1/recompense/transactions
Authorization: Basic {base64(clientId:clientSecret)}
Content-Type:application/json


{
  "contract_id": "string",
  "nsa_id": "string",
  "application_id": "string",
  "item_id": "string",
  "reason_description": "string"
}
PARAMETER REQUIRED VALIDATION DESCRIPTION
contract_id Required Alphanumeric
Between 1 and 24 characters

A value that serves as the identifier for the transaction.

  • The request cannot specify a contract_id for which a request has already been made. Create a new contract_id for every act of compensation. Specify the value as shown in the following example.
    • {nsa_id}{sequence number}
nsa_id Required Alphanumeric
16 characters		 The NSA ID of the user being compensated.
application_id Required Alphanumeric
16 characters		 Application ID of the title to be compensated.
item_id Required Alphanumeric
Between 1 and 16 characters		 Item ID of the item to be compensated.
reason_description Optional
Special Notes

Response

STATUS CODE 200
BODY 
{
 "transaction_id": "string",
 "transaction_type": "ADD_RIGHT"
 "transaction_datetime": 0,
 "contract_id": "string",
 "application_id": "string",
 "item_id": "string",
 "nsa_id": "string",
 "reason_code": "RECOMPENSE",
 "reason_description": "string",
}
PARAMETER DESCRIPTION

transaction_id
(To be removed.)

Transaction ID
Example: 5b6d2d99-a470-4119-9d4a-3cd4870951ee
transaction_type Fixed to ADD_RIGHT.
transaction_datetime Transaction date (in epoch milliseconds).
contract_id The contract_id specified in the request.
application_id Application ID of the title to be compensated.
item_id Item ID of the item to be compensated.
nsa_id The NSA ID of the user being compensated.
reason_code Fixed to RECOMPENSE.
reason_description Special Notes

Error Codes (Some)

Error Code Name Reason for Occurrence
1503 unauthorized
  • Occurs if the client ID/secret is not valid.
  • Occurs if an attempt was made by a client without permission to grant a license to application_id.
1520 invalid application id
  • Occurs if the specified application_id does not exist.
1530 invalid item id
  • Occurs if the specified item_id does not exist.
1551 duplicate contract id
  • Occurs if the request uses a contract_id that has been used already.
1552 no purchase history
  • Occurs when an attempt is made using the client ID for compensation to grant rights to an nsa_id for which there is no purchase information in the past via the _RECOMPENSE client.
