8.7 Important Information When Displaying Prices

Important Information When Displaying Product Price Information Within Applications

Price Information

If you will be displaying product price information in the application, do not embed the price information in the application. Instead, make sure that you display the information obtained by the feature for getting information. If you embed the price information in the application, the price displayed in the application may differ from the price displayed before purchase in Nintendo eShop. However, there is no issue with the method of caching price information obtained by the feature for getting information, and then using it.

Showing That Tax Is Included

In some countries and regions, you must indicate that tax is included in the price when showing prices inside an application. Indicating that tax is included means displaying text such as "the prices for all of the products include tax." You can get the actual message from inc_tax_message included in the response for the feature for getting price information, described in 8.6 Getting Price Information, and the response for the feature for getting consumable service item information, described in 8.4 Consumable Service Items. inc_tax_message is null for countries and regions where it is not necessary to indicate that tax is included in the price. Unless this is null, make sure that you display the obtained message as is, without any modifications.

Note that the countries and regions where it is not necessary to show that tax is included might change in the future. If showing that tax is included becomes necessary, inc_tax_message will change from null to a string.

Testing inc_tax_message

If inc_tax_message has changed from null to a string, check that the string is displayed by testing in the dd1 environment (the development environment) using an inc_tax_message that is not null.

In the dd1 (development) environment, inc_tax_message takes a dummy message, instead of null, for countries and regions where you do not need to show that tax is included. Showing Temporary Discounts

When a temporary discount is set in NCMS, the price of the product is discounted for the set period of time and the discount is displayed in Nintendo eShop. While the temporary discount is in effect, the discount information is entered in discount_price. You can use this discount information in the application to display discount promotions.

To test the display of discounts in the dd1 (development) environment, Nintendo must configure certain settings. Contact Nintendo support if you want to perform this testing.

Note
  • The value in discount_price becomes available after the start of the temporary discount period, so after it becomes available, the value in start_datetime refers to a time in the past. In other words, you cannot use start_datetime to promote future discounts.
  • The information obtained by the features is cached on the server for about 10 minutes, so it is possible for discount_price to be included in the result even though the discount period has actually already ended. Use the value of end_datetime to end the discount promotion at a more accurate time in your application.
