9.2 Relationship Between Nintendo Accounts and Licenses

This section describes how product license information is managed and shared using a Nintendo Account and a Nintendo Switch.

For more information about accounts, including Nintendo Accounts, see the Nintendo Switch Account Guide.

Product Purchases and Licenses

A user account must be associated with a Nintendo Account to either purchase a product from Nintendo eShop or to use a download code.
Purchased licenses never disappear, even if the Nintendo Account country or region is changed.

A Nintendo Account can be associated with user accounts on multiple Nintendo Switch consoles. The ability to use a product depends on whether it has been registered to a primary console, as described in the following section.

Info

In the development environment, downloadable content that has been installed using DevMenu or DevMenuCommand is not managed at the preceding level of individual Nintendo Accounts.
This downloadable content can be used by applications not associated with a Nintendo Account.

Primary Console

The primary console is the Switch console that is usually used by a certain Nintendo Account. A single Nintendo Switch can be registered as a primary console for a single Nintendo Account.

Use the following method to register a primary console.

  • Start Nintendo eShop for a Nintendo Account that has not yet been registered for a primary console.

You can use the following methods to unregister a primary console.

  • From Nintendo eShop on the Switch, select your account icon, and in Primary Console, select the option to unregister the primary console.
  • Using a browser, go to the Nintendo Account settings page, select Shop Menu, and then select the option to unregister the primary console.
    • Unregistering using this method is currently possible only one time per year.
  • Initialize the console while connected to the internet.
  • Use Transfer Your Save Data.
    • The primary console will be changed to the migration target console.

The scope of your ability to share licenses among other user accounts associated to a console depends on whether that console is the primary console for the Nintendo Account with the license. This procedure is described in more detail in the following section.

Licenses for Downloadable Software and Downloadable Content

License information for downloadable software and downloadable content is managed at the Nintendo Account level.

If a user account registered on the Switch console is linked to a Nintendo Account that has the license for downloadable software or downloadable content, the following user accounts can use that downloadable software or downloadable content.

  • User accounts linked to the Nintendo Account holding the licenses
    • If the console is not the primary console, there are certain restrictions, as described later in the document.
  • All user accounts on the primary console of the Nintendo Account holding the license

Using Content From Switch Consoles Not Registered as the Primary Console

Downloadable software and downloadable content is available on Switch consoles not registered as the primary console (the non-primary Switch) by the Nintendo Account holding the license. However, the following usage restrictions apply to Switch consoles that have not been registered as the primary console.

  • The Switch must be connected to the internet.
    • Authentication of the usability of downloadable content and downloadable software must occur when starting a title, even when starting from a game card. This authentication information is valid for a set time, and the validity period can be extended while the Switch is connected to the internet.
    • When the authentication information expires, the software is suspended. The software can be resumed by connecting to the internet and updating the authentication information.
  • As a general rule, only one system can run the downloadable software licensed to a Nintendo Account at the same time.
    • If two or more Switch consoles begin playing a downloadable software game at the same time using the same Nintendo Account, gameplay stops on all but one console. The same is true if the various Switch consoles start different downloadable software titles.
    • If one of the consoles on which the game is being played is the primary console, that console receives priority, meaning that the software is suspended on the non-primary consoles.
    • If several Switch consoles are playing the software and the primary console is not one of them, the console that started last takes precedence (and gameplay stops on consoles that started earlier).
Info

As an exception, under the following circumstances, one Nintendo Account may use downloadable software or downloadable content on multiple Switch consoles.

  1. The downloadable software title is started on a Switch console and then that console disconnects from the internet.
  2. A different console from the one in step 1 starts that downloadable software using the same Nintendo Account.

This exception arises because if a Switch disconnects from the internet while the authentication for using the downloadable software or downloadable content is valid, it is impossible to detect whether multiple Switch consoles are using that downloadable software or downloadable content.

On a non-primary Switch console, only the account that has the license can use the downloadable software or downloadable content. Other user accounts on that Switch console (accounts other than the one with the license) cannot use the downloadable software or downloadable content.

When downloadable software or downloadable content has been authenticated for use on a Switch that is not the primary console, no other user except the authenticated user can sign in. This limitation will affect the title if it has been implemented with a feature for multiple users to sign in or for users to take turns in the game. For more information, see the Nintendo Switch Account Guide.

Info

The same state occurs when authenticating and using downloadable content on a Switch other than the primary console, even when starting from a game card. The users who can sign in change during a downloadable content purchase when purchasing downloadable content at a later date.

Losing Licenses for Downloadable Software and Downloadable Content

The licenses for downloadable software and downloadable content held by a Nintendo Account are normally not lost, but it is possible for the content to no longer be available to the user account. The following example presents a specific case where this issue occurs.

Prerequisites

Assume that the following two user accounts are registered on Switch A.

  • User account X, which is linked to Nintendo Account X that has registered Switch A as the primary console.
  • User account Y.

At this point, user account Y can use the downloadable software and downloadable content for which Nintendo Account X owns licenses to.

Operations that cause user account Y to lose usage permission

If you perform any of the following actions, user account Y can no longer use the downloadable software and downloadable content for which Nintendo Account X owns licenses to.

  • Unregister Switch A as the primary console for Nintendo Account X.
  • Delete user account X from the Switch.
  • Delete Nintendo Account X.

Notes

Even if Switch A is unregistered as the primary console for Nintendo Account X, the data for downloadable software and downloadable content, that was already downloaded on Switch A, will not be deleted. If Nintendo Account X registers Switch A again as its primary console, the user account Y on Switch A will regain access to the downloadable software and downloadable content.

There are cases like this one where downloadable content that at one time was available becomes unavailable, so implement your application in a way that does not cause any issues.

Service Item Licenses

Although the license information for service items can be managed by Nintendo Accounts, the license to use the services are shared as follows.

Kinds of Service Items Scope of Shared Licenses
Consumable Service Items

A license can only be used for the Nintendo Account that purchases the service item.

When a Nintendo Account is associated with multiple Switch consoles, whether a license can be used on multiple Switch consoles depends on whether you use an independent server controlled method or a user save data controlled method.

  • With the independent server controlled method, the license can be used on any Switch because that license is managed on an independent server.
  • With the user save data controlled method, the license cannot be used on multiple Switch consoles, except if the save data has been transferred, because the license is saved to the user save data.

For example, a "sturdy sword" is sold as a consumable service item for use in the game. If you use an independent server to manage licenses, that sturdy sword can be used on any console as long as the same Nintendo Account is used because you are accessing the independent server using the same Nintendo Service Account. If you use user save data to manage licenses, that sturdy sword cannot be used if the license for that sturdy sword has already been saved to save data created by a user account for the Nintendo Account that purchased the sword in the first place. Even if you created save data on another Switch console associated with that Nintendo Account, you cannot obtain that sturdy sword.

For more information, see 6.1 Overview.
Subscription Service Items

One of the following two license types is set for each service (course).

  • Account Type Sample
    • You can only use the Nintendo Account that purchased the service.
    • If the same Nintendo Account is linked to multiple Switch consoles, the licenses are shared between Switch consoles.
  • Device-Based Sharing Type Sample
    • Any other accounts on the primary console for the Nintendo Account that purchased the service can also use that service.

For more information, see 7.2.3 Sharing Licenses.
