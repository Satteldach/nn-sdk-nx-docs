9.1.1 Solutions to Frequently Seen Errors

General

The API returns HTTP status code 401.

See solution.

Check whether the client ID and secret are specified correctly.

The client ID and secret are different values in each environment. Consider this fact when submitting content to Lotcheck and when releasing services in the production environment.

The API fails for some accounts.

See solution.

Check that the account is sending the request to a subscription or consumable service item API endpoint corresponding to an existing Nintendo platform server environment.

Also note that when handling the internal ID (the sub value) included in an NSA ID token as a number, if the ID contains any leading zeros, those zeros may be deleted. The API fails if the leading zeros have been deleted from the NSA ID specified for the parameter in the API request. For this reason, we recommend handling internal IDs (sub values) as strings.

Error 2811-6200 occurs when opening Nintendo eShop in the development environment.

See solution.

Error 2811-6200 occurs if the firmware version of the development hardware does not meet the version requirement for opening Nintendo eShop.

If you are using Nintendo eShop, use the latest version of the firmware as shown on the Nintendo Developer Portal in Master ROM Submission Information > Firmware Version Required for Testing.

Error 2811-6001 occurs when jumping to eShop.

See solution.

This problem may occur for the following reasons.

  • The jump accessed an unpublished product page.
  • The jump accessed the page for a product that is not available in the country/region of the user (the Nintendo Account) that made the eShop jump.
  • The jump accessed nonexistent NsUid product information.

If necessary, rework the implementation of the application or change the NCMS settings.

Subscription Service Items

Error 1230 is returned when the API is called to activate a subscription service item license.

See solution.

Check whether the Nintendo Account associated with the nsa_id specified in the API request has registered the Switch console that sent the request as the primary console.

For more information about adding a primary console, see 9.2 Relationship Between Nintendo Accounts and Licenses.

Error 2811-6001 occurs when jumping to eShop in the development environment.

See solution.

It is possible that one or both of the following NCMS settings are not configured correctly.

  • The Platform of the dd1 title is not set to Nintendo Switch downloadable software or Nintendo Switch game card/downloadable software.
  • The Distributing Countries Reference Type of the subscription item is not set to Refer Main Title.

Make changes to correct the settings, and then distribute again. For more information about these settings, see 4.2.1 NCMS Settings for Development.

Consumable Service Items Using the Independent Server Controlled Method

The API returns error 1503 (unauthorized).

See solution.

The network service account specified for the NSA ID token included in the request header, might be different from the network service account specified for the network service account internal ID token configured for the request path.

Make sure that the same network service account is specified.

Error 9510 is returned when an API call is made.

See solution.

There may be a problem with the NSA ID token included in the request header, or the request may have been configured incorrectly.

X-NINTENDO-NSA-ID-TOKEN: Bearer {nsaIdToken}

Make sure the token includes "Bearer" as shown in the preceding example.
