6.2.2.2.2 Getting License Information

Overview

This API gets the license information (the purchase transactions) for the specified application and the specified user.

Purchase Transaction Status

Purchase transactions can have the following two statuses.

Status Description
PURCHASED The state where an item has been purchased on Nintendo eShop but has not been consumed.
CONSUMED

The state where the status has been changed by the API that updates the license information and the item has been consumed.

Request

GET /v1/applications/{applicationId}/accounts/{nsaId}/rights?sort={sort}&status={status}&page={page}&per_page={per_page}
Authorization: Basic {base64(clientId:clientSecret)}
X-NINTENDO-NSA-ID-TOKEN: Bearer {nsaIdToken}
Name Description Data Type Parameter Type

Required/

Optional

 Default
(Optional is the only default)		 Example Remarks
applicationId Specify the application ID of the application with the license information you want to get. string path Required
"01004b9000490000"

Do not add 0x to the beginning of the application ID.

Only use lowercase for letters.
nsaId Specify the internal ID (string) of the network service account in the NSA ID token as is, including the leading 0. string path Required
"0123456789abcdef" Only use lowercase for letters.
sort

Specifies the condition for sorting the obtained purchase transaction results. The following values can be specified.

  • purchased_datetime_desc
  • purchased_datetime_asc

Specify purchased_datetime_asc to get the results sorted in ascending order of purchase transaction date.

Specify purchased_datetime_desc to sort the results in descending order.

 string query Optional "purchased_datetime_desc" "purchased_datetime_asc"


status

Gets purchase transactions with the specified status. The following values can be specified.

  • PURCHASED
  • CONSUMED
 string query Optional


"PURCHASED"

 If status is omitted, both PURCHASED and CONSUMED purchase transactions are retrieved.
page Specifies the number of pages of the purchase transaction list to get. number query Optional 0 10 page values begin from 0.
per_page Specifies the number of license information entries to display per page. number query Optional 100 20
X-NINTENDO-NSA-ID-TOKEN Specify the NSA ID token. string header Required
"eyJqa3UiO...oDM9OBOtw"

"Bearer" must be added as a prefix.

The token has an expiration date. To extend the expiration date, you must get the token again and update the value.

Response

Name Description Data Type Format Example Null Values Allowed? Notes
total_results The number of purchase transactions retrieved. number Integer value 2 Cannot be null

Indicates the number of rights included in the page. It does not represent the total number of rights that could possibly be obtained.
rights An array of purchase transactions. array hashmap

Cannot be null

right_id The purchase transaction identifier (Right ID). string

A string of up to 36 characters.

 "ed610969-fe8f-4e0c-8d62-da7bdbd35897" Cannot be null

nsa_id The NSA ID that has the license. string Text "0123456789abcdef" Cannot be null

item_id The item ID of the purchased service item. string Text "SAMPLEITEM0001" Cannot be null For more information about the format, see 6.1 Overview > Restrictions on the Number of Consumable Services and Item IDs.

purchased_date_time The date and time that the purchase transaction occurred. number Epoch milliseconds 1585741152000 Cannot be null

status The status of the purchase transaction. string
  • PURCHASED
  • CONSUMED
 "PURCHASED" Cannot be null

country The country information for the purchase transaction. string Two-character country code (ISO 3166-1 Alpha-2) "US" Cannot be null

curl Request Samples (dd1 Environment)

For simplicity, the k option is used to skip SSL authentication. A CA certificate can be obtained by following the instructions in 9.1 Using Independent Servers.

curl -k \
"https://sugar.ws.dd1.ss.nintendo.net/v1/applications/{application_id}/accounts/{nsa_id}/rights?status=PURCHASED&page=0&per_page=10" \
--basic --user {clientId}:{clientSecret} \
-H 'X-NINTENDO-NSA-ID-TOKEN: Bearer {nsa_id_token}'
