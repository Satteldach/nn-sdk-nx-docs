7.2 Mechanisms

This page uses the following diagram to describe the various procedures that are required for using subscription service items.

Figure 7-3 Overview of Subscription Service Items

Purchasing Subscription Service Items

Subscription service items are purchased from Nintendo eShop. Applications can use the jump to eShop API to jump to Nintendo eShop.

Nintendo eShop does not return purchase information to the application. However, as long as the application is running, it can receive notifications of purchases. For more information, see 2.4 Service Item Purchase Notification Feature.

Requesting and Providing Services

The independent server receives a service provision request from the application, connects to the Nintendo eShop server to check for license information for the subscription service item, and then provides the service. This process is described in detail later.

Referencing Licensing Information

The independent server gets license information from the Nintendo eShop server by sending a request to reference the license information.

For more information about the API for referencing license information, see 7.4.3 API Reference.

Starting to Use the License

The license for a subscription service item purchased on Nintendo eShop is not activated immediately at the time of purchase. The license becomes activated when the independent server sends a request to the Nintendo eShop server to activate the license.

For example, if a license has been purchased to connect to the network and use a service for one day in an application, that one-day license does not begin when it is purchased and run for 24 hours from that time, but instead begins when the user starts the application following the purchase and explicitly selects the option to begin using the service.

Granting Licenses as Compensation

Compensations grant licenses to users, at no charge, when users are affected by issues with applications or the independent server that cause services to be unavailable to users for a period of time. A mechanism is provided that allows the independent server to grant a subscription service item license to a specific user as compensation.
It uses a server API where the independent server sends a request to Nintendo eShop. For more information about this API, see 7.4.3.5 Add License API.

Note

Only use this API for compensation purposes in the production environment.
