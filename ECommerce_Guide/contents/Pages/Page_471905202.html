6.2.2.1 Online Tool for Error Settings

Overview

This tool makes it possible to force the server APIs for consumable service items to return error responses.

After using this tool to configure errors, you can make any API functions other than 6.2.2.2.4 FOR DEBUGGING: API for Mandatory Error Settings and 6.2.2.2.5 FOR DEBUGGING: API for Clearing Mandatory Error Settings return any errors.

Note the following points when using this tool.

  • This tool can only set errors in the dd1 environment.
  • After an error has been set using this tool, the message element of the error response is set to NULL.
  • Using 6.2.2.2.4 FOR DEBUGGING: API for Mandatory Error Settings and 6.2.2.2.5 FOR DEBUGGING: API for Clearing Mandatory Error Settings overwrites any error settings configured using this tool.

How to Use

Logging In to the Tool

Access the tool at the following URL.
https://sugar.ws.dd1.ss.nintendo.net/debug/forcedError

The tool is protected with Basic authentication. To authenticate your session, specify the client ID and secret issued for your application as the user name and password, respectively. Use the client ID and secret corresponding to the dd1 environment.

Info

This tool uses a server certificate signed by Nintendo's private certificate authority.

Setting Errors

Enter the following settings in the tool, and then select Set. If the operation is successful, "success" is displayed in the RESULT area in the tool.
If an error code has already been specified, that error code will be overwritten.

Tool Setting Input Value
NSA ID

Specify the internal ID of the network service account for which to set the error.
You can get this value from the NSA ID token or from the support numbers displayed on the Switch system.
For more information about getting the NSA ID from the support numbers displayed on the Switch system, see the Nintendo Switch Independent Server Setup Manual.
ERROR CODE Specify the last four digits of the error code to trigger.

Clearing Errors

In the tool, in NSA ID, specify the internal ID of the network service account for which to clear the error.
Select Clear. If the operation is successful, "success" is displayed in the RESULT area in the tool.
