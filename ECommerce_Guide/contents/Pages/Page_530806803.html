8.2 Titles and Bundles That Include Titles

This section describes the use of the feature for getting information within the application to get information about titles and about bundles that include titles.

Overview

A feature is available for getting price information for titles.
Getting information for bundles that include titles is essentially the same as getting information for titles. Bundles that include titles is a general term for the following products.

  • A bundle of a title and downloadable content
  • A bundle of a title and a consumable service item
  • A bundle of multiple titles
  • A bundle of multiple titles and DLC
Note

The feature described later for getting lists of title information cannot be used to get information about bundles that do not include titles, such as bundles that combine two pieces of downloadable content.

Implementation

Get information about titles using the following feature.

Getting Information For Multiple Products

The feature for getting lists of title information can get all of the products associated with the specified application ID in a single request. For example, consider an application ID that has the following product mix.

  • Title (normal version)
    • A bundle of the title plus downloadable content #1
    • A bundle of the title plus downloadable content #2
    • A bundle of the title plus a consumable service item
  • Title (deluxe version) with bonus promotional code
    • A bundle of the title plus downloadable content #1
    • A bundle of the title plus downloadable content #2
    • A bundle of the title plus a consumable service item

In this case, the following information is included in the response of the feature for getting lists of title information. Note that each individual product has both an ns_uid_title and an ns_uid. The ns_uid_title value is the ID that identifies the title, and ns_uid is the ID that identifies the item associated with the title. It is the ns_uid that you must specify for the ID when you use the API for jumping to eShop. The item tag information that has been set for each individual product can be obtained as item_tag. In the following example, item tag information has been set for every product, and the application can use the values to differentiate the product information.

Product ns_uid_title ns_uid item_tag
Title (normal version) Title 70010000000001 70010000000001 key = "variation", value = "normal_title"
Title + downloadable content #1 70010000000001 70070000000001 key = "variation", value = "normal_aoc_bundle_1"
Title + downloadable content #2 70010000000001 70070000000002 key = "variation", value = "normal_aoc_bunde_2"
Title + consumable service item 70010000000001 70070000000003 key = "variation, value = "normal_consumable_bundle"
Title (deluxe version) Title 70010000000002 70010000000002 key = "variation", value = "deluxe_title"

Title + consumable service item 70010000000002 70070000000006 key = "variation, value = "deluxe_consumable_bundle"
Note

As the preceding example demonstrates, you can set multiple products for a single application ID (in this case, a normal version and a deluxe version). However, contact Nintendo if you are considering using this approach.

In addition, if you are using the feature to get information about downloadable content or consumable service items within the application, note that you can only get information for items associated with a single product (in the preceding example, the normal version of the title). You cannot get items associated with other products (in the preceding example, the deluxe version of the title).
