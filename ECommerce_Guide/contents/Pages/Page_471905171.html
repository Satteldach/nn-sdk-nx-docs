7.4.3.4 API for Starting to Use the License

Overview

This API starts using a license that has not yet been used. It can only be used for subscription service items in the fixed term format.

Device-Based Sharing Type Requests

POST /v1/courses/{course_id}/accounts/{nsa_id}/right?edi={edi}
Authorization: Basic {base64(clientId:clientSecret)}
Name Description Data Type Parameter Type

Required/

Optional

 Default
(Optional is the only default)		 Example Notes
course_id Specify the course ID that you want to start using the license for. string path Required
"aa5e5131d43ba0d4"
nsa_id Specify the internal ID (string) of the network service account in the NSA ID token as is, including the leading 0. string path Required
"0123456789abcdef"
edi Use it to have the Nintendo eShop server uniquely identify user devices. This value can be obtained from the NSA ID token. string query Required
"b9ba95edb80621793f05efb46df37d37af4571d3548c5aed75bc6e595a57a719"

When the course ID specified by the parameter is the ID for a device-based sharing type course, the use of the license begins for accounts other than the one specified in the API request if all of the following conditions are met.

  • Account A specified by the nsa_id parameter does not have a license on that console (regardless of whether the use of the license has begun).
  • Besides account A, there is also account B on the console specified by the edi parameter.
  • The console specified by the edi parameter is set as the primary console for account B.
  • Account B has a license that it has not started using.

In this case, the license held by account B that it has not started using becomes activated.

Response

Name Description Data Type Format Example Null Values Allowed? Notes
active Whether the license has been activated. boolean true: Activated / false: Not activated true Cannot be null
nsa_id NSA ID. string Text "0123456789abcdef" Cannot be null
start_datetime License activation time. number Epoch milliseconds 1585699200000 Cannot be null
expiration_datetime Expiration date of the license. number Epoch milliseconds 1588291200000 Cannot be null
auto_billing_applied Whether automatic renewal is ongoing. boolean true: Automatic renewal agreement exists / false: No automatic renewal agreement true Cannot be null

If there is a license to start the service

{
  "active": true,
  "nsa_id": "0123456789abcdef",
  "start_datetime": 1585699200000,
  "expiration_datetime": 1588291200000,
  "auto_billing_applied" : true

If there is no license to start the service

The HTTP status code 4XX will be returned.

Supplemental Information

If Error 1230 is returned, the system may not have the privileges required to call this API.

If you are using a device-based sharing type, make sure that the system used to make the request is registered as the primary console in the user’s Nintendo Account. You can check the primary console on Nintendo eShop.

In the production environment, always use the API for checking whether a license is available before making a call to the API for starting to use that license.

curl Request Samples (dd1 Environment)

For simplicity, the k option is used to skip SSL authentication. A CA certificate can be obtained by following the instructions in 9.1 Using Independent Servers.

Device-Based Sharing Type Sample

curl -k \
"https://mandom.ws.dd1.ss.nintendo.net/v1/courses/{course_id}/accounts/{nsa_id}/right?edi={edi}" \
--basic --user {clientId}:{clientSecret} \
-X POST
