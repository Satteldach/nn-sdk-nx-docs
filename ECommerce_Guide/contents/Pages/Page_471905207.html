6.2.2.2.3 Updating License Information

Overview

This API updates the status of the license information (the purchase transactions) for the specified application and the specified user.

Request

PUT /v1/applications/{applicationId}/accounts/{nsaId}/rights
Authorization: Basic {base64(clientId:clientSecret)}
X-NINTENDO-NSA-ID-TOKEN: Bearer {nsaIdToken}
Content-Type:application/json

[
  {
    "right_id": "(String; Globally unique right ID)",
    "status": "(String; the status of the transaction; PURCHASED, CONSUMED)"
  }
]
Name Description Data Type Parameter Type

Required/

Optional

 Default
(Optional is the only default)		 Example Remarks
applicationId Specifies the application ID for the titles whose licenses you are updating. string path Required
"01004b9000490000"

Do not add 0x to the beginning of the application ID.

Only use lowercase for letters.
nsaId Specifies the internal ID (string) of the network service account in the NSA ID token as is, including the leading 0. string path Required
"0123456789abcdef"

Specify the internal ID (string) of the network service account in the NSA ID token as is, including the leading 0.

Only use lowercase for letters.
right_id Specifies the purchase transaction identifier (Right ID). string body Required
"ed610969-fe8f-4e0c-8d62-da7bdbd35897"

Get the right ID using the API for getting license information.
status

The status of the purchase transaction after the change. Specify CONSUMED to set the status to consumed.

 string Required
"PURCHASED" The status cannot be changed from CONSUMED to PURCHASED.
X-NINTENDO-NSA-ID-TOKEN Specifies the NSA ID token. string header Required
"eyJqa3UiO...oDM9OBOtw"

"Bearer" must be added as a prefix.

The token has an expiration date. To extend the expiration date, you must get the token again and update the value.
Content-Type Fixed to Content-Type:application/json. string header Required
"application/json"

Response

204 No Content

curl Request Samples (dd1 Environment)

For simplicity, the k option is used to skip SSL authentication. A CA certificate can be obtained by following the instructions in 9.1 Using Independent Servers.

curl -k \
"https://sugar.ws.dd1.ss.nintendo.net/v1/applications/{application_id}/accounts/{nsa_id}/rights" \
--basic --user {clientId}:{clientSecret} \
-H 'Content-Type: application/json' \
-H 'X-NINTENDO-NSA-ID-TOKEN: Bearer {nsa_id_token}' \
-X PUT -d '[{"right_id":"{right_id}","status":"CONSUMED"}]'
