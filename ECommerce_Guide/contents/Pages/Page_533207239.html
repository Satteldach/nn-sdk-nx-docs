7.4.3.3 License Information Reference API (Account Type)

Overview

For an account-type course, this function references the following kinds of licenses held by the requesting account.

  • Available licenses
  • Licenses in their validity period (The validity period begins when an available license is activated by the independent server.)

Request

GET /v1/courses/{course_id}/accounts/{nsa_id}/right
Authorization: Basic {base64(clientId:clientSecret)}
Name Description Data Type Parameter Type

Required/

Optional

 Default
(Optional is the only default)		 Example Notes
course_id Specify the course ID that you want to get license information for. string path Required
"aa5e5131d43ba0d4"
nsa_id Specify the internal ID (string) of the network service account in the NSA ID token as is, including the leading 0. string path Required
"0123456789abcdef"

Response

Name Description Data Type Format Example Null Values Allowed? Notes
active Whether the license has been activated. boolean true: Activated / false: Not activated true Cannot be null
nsa_id NSA ID string Text "0123456789abcdef" Cannot be null
start_datetime License activation time. number Epoch milliseconds 1585699200000
Only returned when the license has been activated.
expiration_datetime Expiration date of the license. number Epoch milliseconds 1588291200000
Only returned when the license has been activated.
reserved_minutes Remaining time on licenses not yet used number Minutes 600
Only returned when the license has not been activated.
auto_billing_applied Whether automatic renewal is ongoing. boolean true: Automatic renewal agreement exists / false: No automatic renewal agreement true Cannot be null
Temporary.

Whether in the grace period.

 boolean true: In the grace period / false: Not in the grace period false Cannot be null For more information, see 7.2.1 Automatic Renewal.

If there is a license and it is in use

{
  "active": true, 
  "nsa_id": "0123456789abcdef",  
  "start_datetime": 1585699200000,
  "expiration_datetime": 1588291200000,
  "auto_billing_applied": true,
  "temporary": false
}

If there is a license but it has not begun to be used

{
  "active": false, 
  "nsa_id": "0123456789abcdef",
  "reserved_minutes": 600, 
  "auto_billing_applied": false,
  "temporary": false
}

If there is no license

{
  "active": false,
  "auto_billing_applied": false,
  "temporary": false
 }

curl Request Samples (dd1 Environment)

For simplicity, the k option is used to skip SSL authentication. A CA certificate can be obtained by following the instructions in 9.1 Using Independent Servers.

curl -k \
"https://mandom.ws.dd1.ss.nintendo.net/v1/courses/{course_id}/accounts/{nsa_id}/right" \
--basic --user {clientId}:{clientSecret}
