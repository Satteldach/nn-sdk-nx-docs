4.1 Usage Request on OMAS

Before you begin development of e-commerce features, submit an e-commerce feature usage request on OMAS to get the necessary server settings.

Using OMAS, you can request the following e-commerce features.

  • Downloadable content
  • Consumable service items
  • Subscription service items
  • The feature for getting information within applications (which must indicate the product that is using this feature)

After you submit the e-commerce request and Nintendo approves the request, the requested features are available for use in the development and production environments.

Info

You do not need to make a request on OMAS to use shop jumps that do not use the feature for getting information within applications.

Considerations When Requesting E-Commerce Features

  • When submitting course requests for subscription service items, do not change the maximum service period after server configuration is complete (that is, after you pass through the server configuration phase in OMAS). If you want to set a different maximum service period, submit a new course request. Contact Nintendo if you need to change a maximum service period that has already been set.
  • If the subscription service item is going to be shared with another application, the other application must also submit an e-commerce request. In Course ID for Subscriptions > Usage, clearly indicate that this course has been issued for another application. To facilitate a smooth Nintendo approval process, make it clear in the overview that you will be using shared subscription service items.
  • If you are using an independent server, a request for an independent server must be submitted in OMAS. To use consumable service items controlled by independent servers or subscription service items, you must use an independent server.
  • The content from an OMAS request is applied to all environments: development, Lotcheck, and production. Separate settings for just one environment like the development environment are not possible.

ID and Secret Issued After OMAS Approval

Information needed for development appears in OMAS after the e-commerce request is approved and the server settings phase has ended. This section describes that information.

Course ID for Subscription Service Items

A sixteen-character alphanumeric course ID is issued when you are using subscription service items and have submitted a course request using Course Information for Service Tickets. The issued course ID is used in NCMS settings.

Service Item Client ID/Secret

When either a consumable service item or a subscription service item request has been submitted, client IDs and secrets used for service items are issued in E-Commerce Client Information.

Service items that use an independent server require a client ID and secret for accessing the Nintendo eShop server from the independent server. Each environment, such as development or production, has a different client ID and secret.

Info

A client ID/secret for the development environment is issued even when the control method being used is the user save data controlled method, which does not involve the use of an independent server. This is for debugging purposes.

For security reasons, there are some restrictions for checking issued client IDs and secrets on OMAS. Development and Lotcheck environments have no particular visibility restrictions for client IDs and secrets. They are visible on OMAS if the title information is visible. Visibility in the production environment, however, is restricted in the following way.

Environment Viewable Criteria
Development and Lotcheck environments (dd1, sd1, and sp1)

A Nintendo developer ID user that can view the title in OMAS.
Production Environment (lp1)

A Nintendo developer ID user associated with that title's publisher and who is a Title Administrator for that title.

Client IDs and Secrets for Compensation

Client IDs and secrets for compensation are issued in E-Commerce Client Information when you are using the user save data controlled method for consumable service items and you have selected to use the compensation feature.
