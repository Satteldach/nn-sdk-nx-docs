3.3 Selling Bundles and Sets

Bundles

When a combination of products is sold as a single product, this combined product is called a bundle.

Currently, some bundles consist of a combination of downloadable software and other products, and other bundles consist of a combination of multiple pieces of downloadable content.
The following table summarizes the support status for bundles of downloadable software and other products.

Restrictions on Bundles

  • Up to 31 products can be included in one bundle.
  • To sell a bundle in a country or region, all of the products included in that bundle must be able to be sold in that country or region.
  • You cannot include downloadable content and consumable service items in the same bundle.
  • On the Nintendo eShop bundle details page, you can jump to the details page for each product included in that bundle. Note: If the products included in the bundle are hidden in Nintendo eShop, the bundle details page for the bundles (or the products included in the bundle) is not displayed properly.
    For more information about configuring hidden items in Nintendo eShop, see 8.1 Common > Configuring Hiding Content in Nintendo eShop.
Note
  • For bundles that include 12 or more products, a bug might occur when the product is sold if the bundle satisfies both of the following conditions. If you want to use this kind of specification, contact Nintendo.
    • The bundle includes downloadable content.
    • The downloadable content in the bundle contains DLC that comprises two or more pieces of content.
  • There is a upper limit for each currency in the Nintendo eShop balance. Users cannot purchase products that are priced higher than the balance limit. Consider this limitation if you are considering selling expensive products.
    For more information about the maximum balance for each currency, see 8.7 Important Information When Displaying Prices > Nintendo eShop Currencies and Maximum Balances.

Restrictions When Selling Multiple Downloadable Software Items as a Bundle

  • You cannot include downloadable software in a bundle if the software will be released after the bundle is released.
  • Although you can include multiple pieces of downloadable content along with downloadable software in a bundle, you cannot include consumable service items.
Note

Only Nintendo can set bundles of multiple downloadable software items. Contact Nintendo if you are considering selling this type of product.

Behavior During Purchase When the User Already Owns Products in a Bundle

If the user already owns all products in the bundle, it cannot be purchased. If the user attempts to purchase a bundle that includes products that they already own, a warning message is displayed. However, this behavior involving a warning message and inability to purchase varies for bundles with consumable service items. Set Sales

A set sale is the method of selling a set of downloadable software and downloadable content without selling each component separately. The difference from a bundle is that the set contains downloadable software and downloadable content that is not sold separately.
For example, you can use this feature when you want to sell sets of downloadable software and downloadable content A or downloadable software and downloadable content B without selling the downloadable content separately.

Note the following points when selling products as sets.

  • Unlike bundles, set sales are limited to a combination of downloadable software and downloadable content.
  • The maximum number of downloadable content pieces included in a set is 10.
Note

Set sales can only be configured by Nintendo. Consult with Nintendo if you want to use set sales.

Behavior During Purchase When the User Already Owns Products in a Set

Users cannot purchase the set if they already own all the products included in the set. Also, unlike bundles, if users purchase a set where they already own some of the products included, no warning message is displayed.
