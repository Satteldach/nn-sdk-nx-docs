Note the following information about this table.

  • This list is not necessarily up to date. In addition, this list is not comprehensive and does not encompass all current countries or regions of sale.
  • The Nintendo official online shops and other e-commerce sites do not sell all products sold in Nintendo eShop in the same way.
  • The same application can be released in multiple regions at different times. However, patches cannot be distributed at different times in different regions.
  • It is not possible to purchase products on the Nintendo official online shop using the web applet from within an application.

Contact Nintendo support in each region to get the latest and more accurate information about sales in each region.

For more information about the China region, see 3.6 Nintendo eShop Specifications for China.
