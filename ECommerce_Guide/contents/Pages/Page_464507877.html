Discounts

You can distribute products sold on Nintendo eShop at a discount price from their original sales price. Nintendo eShop provides two kinds of discounts: temporary discounts and owner discounts.

When a discount is applied, both the before discount price and the discounted price appear in Nintendo eShop. Note that if multiple discount settings overlap, the highest discount rate is applied.

Temporary Discounts

Temporary discounts are a mechanism to offer product discounts for a set period of time.

Owner Discounts

The owner discount is a mechanism where owning specific downloadable software or downloadable content is a condition (one of the discount criteria) for discounting another product (discount target).

Owns the package version of the application cannot be used as one of the discount criteria.

Buyer Benefits

When a user purchases a product in Nintendo eShop, you can provide a separate product as a bonus for the purchaser. There are two methods for granting buyer benefits: a privilege grant and a promotional code.

Privilege Grants

You can use a privilege grant to provide the license to a corresponding product (the privilege target) as a bonus when a user purchases a specific product (the privilege criteria).

The purchaser does not have to perform operations such as entering download codes in Nintendo eShop to get the license.

Only products sold on the Switch Nintendo eShop are available for granting privileges.

Only users who have made purchases can obtain licenses with privilege grants.

Promotional Codes

You can use a promotional code to display the code for using a bonus product when a user purchases a specific product (privilege criteria). Nintendo assumes the following uses for this functionality.

  • Offering promotions for use outside the Switch
    • Download codes for other platforms, such as the 3DS
    • Codes for use with application-specific service tickets
  • Offering promotions to someone who is not the purchaser

Consider using promotional codes for situations where you cannot use a privilege grant, such as when the applicable product is not sold in the Switch Nintendo eShop.

You can set up to five promotional codes.

Download Code

A download code is a code that you can enter in Nintendo eShop to redeem the corresponding downloadable software or downloadable content. It consists of a 16-digit alphanumeric code.

Consult with Nintendo if you want to use download codes.

Pre-Order

This method provides a way to sell pre-orders for products before the delivery date (before the play start date).

This method was previously pre-purchase but has since been changed to pre-order.
With pre-purchase, payment was settled at the time the order was placed. With pre-orders, payment is settled 7 days before the application's launch (or immediately if the pre-order is placed within 7 days before the application is distributed).

Patch Information Leaks and Countermeasures

The system of pre-order allows not only downloadable software but also patches to be delivered before the delivery date (before the play start date). With downloadable software, the delivered content cannot be accessed until the delivery date. But with patches, there is a possibility of the content being accessed by malicious users prior to the play start date. As a countermeasure to this leaking of information, you can wait to deliver the patch until on or near the delivery date. Consider holding off on the delivery of the patch especially if the patch contains highly confidential information.

Info

Settings can be configured to prevent access to the content of the patch during the course of pre-orders. Contact Nintendo if you are considering using this feature.

Season Pass

The season pass is a mechanism for getting the licenses to multiple items of downloadable content, including content scheduled to be released in the future, with one purchase. For content that has not yet been distributed at the time of sale, only the license is sold in advance. The downloadable content associated with the obtained license become available when that content is later distributed. For more information, see 5.4 Season Pass.
