2.3 Feature for Getting Information Within Applications

The feature for getting information within applications allows the application to get information about products sold through Nintendo eShop like the following. For more information, see 8 Feature for Getting Information Within Applications.

  • Titles and Bundles That Include Titles
  • Downloadable content
  • Consumable Service Items
  • Subscription service items

The following use cases can be achieved by using this feature in combination with the feature described in2.2 Jump to Nintendo eShop.

  • Displaying items within the application and browsing to a specific item page.
  • From the demo version, browsing to the bundle product page and to the standard version of the product.
  • On-sale items for temporary discount, along with the discount prices, are displayed in the application.

In addition, by using this feature in combination with the feature to hide items in Nintendo eShop, you can set the following conditions for purchasing items.

  • Ensure that an application-specific account has been created before purchasing.
  • Provide sufficient description of the item content before purchasing.
  • Divide items according to where they can be purchased within the progress of the game.

For more information about this hide feature, see 8.1 Common > Configuring Hiding Content in Nintendo eShop.
