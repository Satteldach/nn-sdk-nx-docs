7.4.3.6 API for Getting License History

Overview

This API gets the license history for the specified network service account and course ID. It can only be used with account-based courses.

One way to use this API is with users who have not started the application for a long time. In such cases, you could used this API to reference the past license history and grant the user privileges based on how long the license has expired.

Request

GET /v1/courses/{course_id}/accounts/{nsa_id}/right/history
Authorization: Basic {base64(clientId:clientSecret)}
Name Description Data Type Parameter Type

Required/

Optional

 Default
(Optional is the only default)		 Example Notes
course_id Specify the course ID that you want to get the license history for. string path Required
"aa5e5131d43ba0d4"
nsa_id Specify the internal ID (string) of the network service account in the NSA ID token as is, including the leading 0. string path Required
"0123456789abcdef"
page Specify the get start position for paging, by page number. integer query Optional 0 0
per_page The number of items to be acquired per page. integer query Optional 100 10 The maximum is 300.
Info

Up to 300 sets of license history data can be obtained at any one time, which is the maximum value that can be set for per_page. To obtain more than 300 sets of license history data, use the page element and split the process into multiple requests.

Response

Name Description Data Type Format Example Null Values Allowed? Notes
nsa_id NSA ID string Text "0123456789abcdef" Cannot be null
start_datetime License activation time. number Epoch milliseconds 1585699200000
Only returned when the license has been activated.
expiration_datetime Expiration date of the license. number Epoch milliseconds 1588291200000
Only returned when the license has been activated.
reserved_minutes Remaining time on licenses not yet used number Minutes 600
Only returned when the license has not been activated.
auto_billing_applied Whether automatic renewal is ongoing. boolean true: Automatic renewal agreement exists / false: No automatic renewal agreement true Cannot be null
Temporary.

Is it during the automatic renewal grace period?

 boolean true: In the grace period / false: Not in the grace period false Cannot be null For more information, see 7.2.1 Automatic Renewal.
status The license status. string Text "active" Cannot be null
  • active: A currently valid license.
  • expired: An expired license.
  • unused: A not yet activated license.
Info

If there are multiple usage histories, they are returned in the order each license was created.

curl Request Sample (dd1 Environment)

For simplicity, the k option is used to skip SSL authentication. A CA certificate can be obtained by following the instructions in 9.1 Using Independent Servers.

curl -k \
"https://mandom.ws.dd1.ss.nintendo.net/v1/courses/{course_id}/accounts/{nsa_id}/right/history" \
--basic --user {clientId}:{clientSecret}
