7.4 For Developers

Registering Primary Consoles for Development Hardware

For device-based sharing type items, you must register the primary console on Nintendo eShop using one of the following methods.

  • Use the DevMenuCommand feature for registering the primary console.
  • Register in the shop menu of DevMenu.
  • Start Nintendo eShop and complete the initial startup sequence. After completing the initial startup sequence, set the primary console in Account Information.

Adding Licenses in a Development Environment

Use one of the following procedures to add licenses in the development environment.

  1. Use the API described in 7.4.3.5 Add License API to grant a license to any account.
  2. Use NCMS to sell subscription service items on the development environment (dd1) Nintendo eShop, and to purchase subscription service items from the development environment Nintendo eShop.
    For more information about sales methods for Nintendo eShop in the development environment, see 4.2.1 NCMS Settings for Development.

Testing Error Handling

The subscription service item server APIs may sometimes fail, such as when the Nintendo eShop server is down for maintenance. For more information about API responses when an error occurs, see 7.4.3.1 Overview.

The following two methods are available for testing error handling.

  • Set errors for a specified account using the Web tool.
    • 7.4.2 Online Tool for Error Settings
  • Set errors for a specified account using the server API for debugging.
    • 7.4.3.9 FOR DEBUGGING: API for Mandatory Error Settings
    • 7.4.3.10 FOR DEBUGGING: API for Clearing Mandatory Error Settings

Although the implementation of error handling is generally handled by the independent server, if an error is defined in the Nintendo Switch Guidelines as to be displayed in the application, use the error viewer applet to display the error to the user. For more information about calling the error viewer, see the following section.

NintendoSDK NX Add-On 7.0.0 or later

Use nn::err::MakeErrorCode() to generate an error code for the subscription service item. For the second parameter, specify the code value included in the error response from the server API.

Code 7-1 Calling the Error Viewer Applet in NintendoSDK NX Add-On 7.0.0 or Later
nn::err::ErrorCode err = nn::err::MakeErrorCode(nn::err::ErrorCodeCategoryType::SubscriptionService, 1234); // 1234 is the code included in the error response from the API.
nn::err::ShowError(err);

Versions earlier than NintendoSDK NX Add-On 7.0.0

To display the appropriate error message in the error viewer applet, call nn::err::ShowError(ErrorCode errorCode) with 2621 (the category code for a subscription service item) specified for the category public variable of the nn::err::ErrorCode structure, and set the code value included in the server API error response specified for the number public variable.

Code 7-2 Calling the Error Viewer Applet in Versions Earlier Than NintendoSDK NX Add-On 7.0.0
nn::err::ErrorCode err;
err.category = 2621; // Subscription service item error category.
err.number = 1234; // Set code included in the error response of the API.
nn::err::ShowError(err);
