6.2.1 Mechanisms

This section describes how independent server-controlled consumable service items work on the Nintendo Switch.

Mechanisms for Consumable Service Items Using the Independent Server Controlled Method

The following figure shows the mechanism for consumable service items using the independent server controlled method.

Figure 6-3 Overall Schematic of Independent Server-Controlled Consumable Service Items

Purchasing Consumable Service Items

Consumable service items are purchased in Nintendo eShop on the Switch. When the purchase of a consumable service item is completed, that purchase transaction is recorded in Nintendo eShop.

Confirming Purchases and Updating License Information

The application sends a request from the independent server to the Nintendo eShop server to confirm the user's purchase and update the license information. To be specific, the following procedure is performed.

  1. Purchase transactions are referenced.
  2. The license information for consumable service items is saved.
  3. The license information is updated for the requesting user.

The individual steps in this procedure are described later.

Times When Purchase Information Is Checked

The application checks the purchase information mainly at the following times.

  • When consumables licenses need to be updated after the application starts
    • Check for purchases that were made before the application started.
  • After returning from a jump to Nintendo eShop
    • Check for purchases made in a jump to eShop.

Referencing Purchase Transactions

The independent server sends a request to the Nintendo eShop server using a server API to get a list of purchase transactions for each user.

Info

Nintendo never deletes purchase transactions from the Nintendo eShop server or modifies the status of purchase transactions. For example, if you ever need to invalidate licenses after a certain period of time after a purchase has elapsed, implement support for this situation in the application using the country/region and purchase date information included in the response obtained as described in 6.2.2.2.2 Getting License Information.

Saving License Information for Consumable Service Items

Independent servers can get unprocessed purchase transactions (see 6.2.2.2.2 Getting License Information) and grant licenses to users as appropriate based on those transactions. This license information must be managed on the independent server.

Also, the independent server needs to request status changes from Nintendo eShop for transactions that have had licenses granted. When the status change has been accepted, those transactions will be obtained with the "Consumed" status during subsequent retrievals of the transaction list.

Info

Status information for purchase transactions can only be used for filtering purposes when getting license information. Status updates on Nintendo eShop cannot be used to manage addition of licenses to user accounts. On the independent server, use the right_id value to manage whether a license has been granted for a particular transaction. For more information about right_id values, see 6.2.2 For Developers > Adding Licenses to Accounts.

Service Provision

Independent servers handle the provision of services to Switch applications.

Always provide services to users based on the license information managed on the independent server.
