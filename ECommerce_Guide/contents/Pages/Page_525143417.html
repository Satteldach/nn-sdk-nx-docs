4.3 Lotcheck

To distribute an application that has completed development, you must submit the master ROM to Nintendo and it must pass Lotcheck. This page describes information to note when submitting a master ROM to Lotcheck for applications with e-commerce features.

For more information about creating and submitting a master ROM, see Nintendo Switch Master ROM Submission Procedures. For more information about Lotcheck, see Nintendo Switch Lotcheck Procedures. Nintendo Switch Master ROM Submission Procedures contains descriptions of not just master ROMs for applications, but also master ROMs for downloadable content.

For more information about building master ROMs for downloadable content, see NintendoSDK Documents > Features > System > aoc Library > Creating Downloadable Content.

If you are using an independent server, you must configure the settings for the independent server for use in the Lotcheck environment. For more information, see the Nintendo Switch Independent Server Setup Manual. For more information about configuring independent servers for use in the Lotcheck environment, see 9.1 Using Independent Servers > Independent Server Environment.

Lotcheck for Downloadable Content

For applications that support downloadable content, a master ROM of the downloadable content must also be submitted to Lotcheck. If downloadable content is still in development, submit preliminary content to Lotcheck. Downloadable content submitted in the preliminary state can later be replaced with the same version.

Preparation

To distribute content in the production environment, the content you created in the development environment must first pass Nintendo Lotcheck. You create submission files using Authoring Tool, combining content and metadata at the same time.

If the content metadata contains tags, be careful not to enter duplicate tag values in the submission files. If there are duplicates, an error will occur at submission time. For more information about tags, see NintendoSDK Documents > Features > System > aoc Library.

Multiple submission files cannot be submitted to Lotcheck at the same time. You cannot submit the next submission files to Lotcheck until the files from the previous submission have either passed or failed Lotcheck.

If you are using feature for getting information within applications, you must configure NCMS settings in the Lotcheck environment. For more information, see NCMS Settings for Lotcheck later on this page.

Info
  • Multiple submission files cannot be submitted to Lotcheck at the same time. Submit the second submission file after the first one passes.
  • You cannot update only the tags. To update the tags, update the version of the content.

Submission

From the Nintendo Developer Portal, submit the master ROM of the downloadable content.

Updating

A version can be set for each piece of content. If you are updating content that has already passed Lotcheck, you must resubmit the updated content with a later version than the previous submission.

Note
  • When updating downloadable content, the submission files do not need to include content that has not been updated from the previous submission. Package and submit only the updated content.
    For example, if your build system unexpectedly makes changes to content that has not actually been updated, submitting the resulting package causes the downloadable content to be unnecessarily updated in the production environment. This increases the size of distributed data and results in higher loads on the Nintendo eShop server. For this reason, avoid unnecessary updates of downloadable content.
  • Because these processes are complicated, you must be especially careful when submitting or updating downloadable content to be included in season passes. For more information, see 5.4 Season Pass.

NCMS Settings for Lotcheck

NCMS settings must be configured in the Lotcheck environment for each product that uses the feature for getting information within applications. Nintendo copies NCMS settings from the development environment (dd1) to the Lotcheck environment (sd1/sp1) to perform Lotcheck for these features. For this reason, NCMS settings in the development environment must be configured before submitting to Lotcheck. For more information about NCMS settings for the development environment, see 4.2.1 NCMS Settings for Development.

Also note the following.

  • Add sales information for all sales regions that will have an actual production environment release.
    • Lotcheck will incorporate dd1 titles for all sales regions to which the product will be released.
  • For dd1 title applications, service items, and downloadable content, use the Process Completed status in NCMS.
    • Any status other than Process Completed indicates that incorporation into the Lotcheck environment will fail.
    • The status can be changed after Lotcheck is complete.
