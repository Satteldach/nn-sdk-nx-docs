5.5 On-Card Downloadable Content

On-Card Downloadable Content

By using the on-card downloadable content mechanism, you can produce game cards that contain both an application and downloadable content that have passed Lotcheck. This can be used to release the full version of an already-released application. However, the following restrictions apply.

  • Updates to this on-card downloadable content cannot be distributed from Nintendo eShop. If you need to update the content, use a patch.
  • On-card downloadable content cannot be purchased in Nintendo eShop. As a result, an owner discount cannot be applied to this content. For more information about owner discounts, see 3.4 Sales Options (Discounts, Buyer Benefits, Download Codes, Pre-Orders, Season Passes) > Owner Discounts.

For more information about on-card downloadable content, see NintendoSDK Documents > Features > System > aoc Library > On-Card Downloadable Content.
