4.2.1 NCMS Settings for Development

Similar to the production environment, sales data for the development environment Nintendo eShop is configured on NCMS. To use NCMS, you must request and receive approval for the use of e-commerce for the application in OMAS.

https://ncms3.mng.nintendo.net/ncms3/home/dashboard

Note the following when using NCMS for development.

  • The URL is the same for both development and production environments.
    Make sure that you do not set development environment information in the production environment.
  • Settings must be configured for each environment.
    You cannot copy settings between the development environment and production environment.
  • The settings must be configured per region.
    Unlike the production environment, the feature for copying to a different region is unavailable.
  • You cannot delete items that have been registered.
    If you want to delete an item, use alternative methods such as terminating sales for that item or removing it from the list of targets for distribution.

Products That Can Be Set in NCMS for Development

The following products can be configured for sale in the development environment NCMS.

Product Purchase Usage
Consumable Service Items Possible In-app display, purchase, and usage verification
Subscription Service Items Possible In-app display, purchase, and usage verification

Downloadable Content

 Possible In-app display, purchase, and usage verification
DLC + DLC Bundle Possible In-app display, purchase, and usage verification

Titles

 Not possible In-app display
Bundles Containing a Title Not possible In-app display
Info

Only Nintendo can configure bundles that include multiple titles. Contact Nintendo support to be able to configure sales in the development environment NCMS.

Purchasing and Removing Rights for Downloadable Content

DLC and DLC bundles can be purchased in the development environment Nintendo eShop. You can also download and install them.
You can also use DevMenuCommand to delete the purchased rights. DLC and DLC bundles can be repurchased after rights are deleted. For more information about deleting purchase rights, see NintendoSDK Documents > Features > Controlling the Development Hardware > DevMenuCommand > Shop Features.

DLC that has already been purchased can also be redownloaded in the development environment Nintendo eShop. However, you need to register the title ROM to redownload the DLC. For more information about registering ROMs, see (Optional) Registering a ROM.

Note

Do not purchase bundles of multiple titles. Attempts to purchase them will result in an error 2137-4035 in Nintendo eShop.
To resolve this error, use DevMenuCommand to delete the purchased license.

NCMS Settings

All of the following steps must be taken before you can set the sales settings for service items and downloadable content and check the in-app behavior in the development environment.

Setting When Settings Are Required

Set NCMS license
  • When first using NCMS for development
  • When adding or editing user accounts (NDIDs) that operate applications in the development environment in NCMS
Add title
  • When you first add service items or downloadable content to applications
Add and distribute service items or downloadable content
  • When adding or distributing service items or downloadable content
  • When changing sales information for service items or downloadable content
Distribute titles
  • When first adding and distributing a service item or downloadable content
  • When adding or deleting types of products (service items or downloadable content) to distribute in Nintendo eShop in the development environment
Add the development hardware serial number
  • When adding development hardware accessible in the development environment Nintendo eShop.

After ensuring support for all of these settings, use the jump to eShop feature to check the behavior of the content registered to the development Nintendo eShop.

Detailed information about each setting in the table is provided in the following sections.

Setting the NCMS License

The user needs the following permissions to set sales information for titles in the development environment in NCMS. Use the User Management menu in NCMS to grant permissions.

  • Basics
    • NCMS Usage
  • Price-related permissions(dd1)
    • Browse Price/Discount
    • Applicant Price
    • Authorizer Price
Note

User management rights are required for granting permissions. For more information, see the NCMS manual.

Info

The permissions are applied across titles. For this reason, you do not need to set permissions each time you add a title.

Adding Titles

Titles for use in the development environment can be registered from the Add New dd1 Title menu in NCMS.

Info

You can also open the page for registering titles from the following URL.

https://ncms3.mng.nintendo.net/ncms3/develop/setup

After you finish adding the title, it is shown in the dd1 Title List at the bottom of the NCMS dashboard. After you have finished adding the title, access the page for the title from this list.

Adding and Distributing Service Items or Downloadable Content

The method for adding items differs between service items and downloadable content. This section describes each process.

Adding and Distributing Service Items

Information for service items distributed in Nintendo eShop in the development environment can be registered using either Service Ticket or Consumable Service on the title page.

Added content is not immediately distributed in the development environment Nintendo eShop. It is applied when Distribute to dd1 is used. To modify added data after it has been distributed, select Start Edits, and then make your changes.

Data cannot be removed after that service item data has been distributed. If you want to hide added consumable service item data that was configured incorrectly, configure the following settings.

Subscription and Consumable Service Items Set a future date for the information release date.
Tickets and Consumable Services Remove the target ticket or consumable service from the ticket or consumable services list, as described later.
Note

When adding subscription service items, set Distributing Countries Reference Type to Refer Main Title. If this setting is not configured, the item does not appear in the development environment Nintendo eShop.

Consumable ID

When registering a consumable service in NCMS, you must set a 16-digit alphanumeric Consumable ID. By default, this ID is set automatically by NCMS. Enter a string only when you are using the feature for getting application information and the application uses the Consumable ID to identify consumable services. When entering a Consumable ID, you must set a value that is unique among all applications. More specifically, we recommend using initial codes. For example, if the application's initial code is ABCDE, set the ConsumableID to something like abcdeservice0001, with abcde set at the beginning. If the ID that you enter is already used by a different application, registration fails.

Note

The application can use the same Consumable ID for different regions. However, to distribute the consumable service in that case, you must be able to distribute to dd1 in all of the regions that use this same Consumable ID.

Adding and Distributing Downloadable Content

The ROM (NSP file) for the DLC must be registered when doing any of the following.

  • Purchasing or downloading downloadable content
  • Testing aoc_indexes using the feature for getting information within applications for downloadable content

For more information about this feature and about aoc_indexes, see 8.3 Downloadable Content.

(Optional) Registering a ROM

Use the ROM Upload Tool to upload ROMs to the dd1 environment. Access the ROM Upload Tool from either of the following locations, and log in using your NNID.

  • Log in to dd1 NCMS, and select Downloadable Content > AOC ROM Data > ROM Upload.
  • https://door-d4c.mng.nintendo.net/

Complete the following steps to operate the ROM Upload Tool and upload the ROM.

  1. From the list of titles, select the application you want to upload.

    Info

    If the application cannot be found, confirm the following.

    • You have applied for use of e-commerce features on OMAS, the application has been approved, and the e-commerce server configuration is complete.
    • The title can be viewed on OMAS.
  2. Upload the ROM (NSP file) for the downloadable content from the upload form.
  3. Verify that the workflow has changed to Submission, and click Submit.
  4. Check that the workflow has changed to Complete.

Adding and Distributing Items

Complete the following procedure to add downloadable content.

  1. From dd1 Title List in NCMS, select the title you want to add.
  2. Select the downloadable content menu in the left pane, click the Add New button, and save the basic information.
  3. From the AOC ROM Selection menu, select the downloadable content you want to add and select Save and Next.
  4. Set the release countries, price, game page release date, language-specific information, and image assets according to the guidance.

  5. Select the ROM Information menu in the left pane, and then select Distribute to dd1.

    Info

    If the message "ROM not found. Upload to D4C" is displayed even though the ROM was added, run Update ROM Info.

(Optional) Adding and Distributing Bundles

Select the Bundle menu, select New Bundle Entry and configure the settings, and then select Distribute to dd1.

Distributing Titles

This process is separated into the process for linking registered titles with downloadable content or service items and the process for distribution. This section describes each process.

Linking Registered Titles With Downloadable Content or Service Items

For downloadable content, select Title > Optional Menu > Add-on content list, and add the downloadable content to the downloadable content list for the title.

Service items are automatically linked to the title when you add the service item. At this point, the service item is registered to Optional Menu > Course Order or Consumable Service Order.

Distribution

From Title, run Distribute to dd1. To change the registered information after distribution, use Start Edits.

(Optional) Registering and Distributing Product Information for a Title or Title Bundle

If you are adding a title to NCMS to get information within the application, you must add the title ROM. For more information, see (Optional) Registering a ROM.

Adding the Development Hardware Serial Number

The development environment Nintendo eShop restricts access based on the serial number of the development hardware. To remove access restrictions, add the serial number of the development hardware in ACL Config for the title. Because the access restrictions are applied when you update the serial number, the title does not need to be redistributed.

Info

You can check the serial number of the development hardware in HOME Menu > Settings > System > Serial Information. (It will look something like XAL10002556849.)
