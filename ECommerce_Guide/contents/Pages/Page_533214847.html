3.2 Payment Methods

Payment for Products

Payments are made using the balance in the Nintendo Account. The following table indicates the process for adding to the balance. Users can add the remaining amount if the balance is insufficient at the time of purchase.

Adding to the Balance Description
Nintendo eShop Card Add to the balance by entering the prepaid number in Nintendo eShop. For example, a user purchases a 1000-yen Nintendo eShop Card from a retailer or e-commerce site, and then enters the number on Nintendo eShop to add 1000 yen to the balance.

Credit Card

Add to the balance by entering a credit card number. The credit card information is saved in Nintendo eShop.
PayPal

Add to the balance using PayPal.

If the downloadable software or downloadable content is free, Free Download is displayed in lieu of a price, and downloading the product does not decrease the remaining balance.

Info

The currency is determined based on the country of residence and region that has been configured for the Nintendo Account. For example, if the country of residence and region is set to JP, the currency is yen. If it is set to US, the currency is USD.
