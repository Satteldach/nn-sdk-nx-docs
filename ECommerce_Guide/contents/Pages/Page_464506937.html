1 Introduction

Objectives and Content

This document describes the e-commerce features provided in Nintendo Switch™ (henceforth Switch), presenting them in greater detail than in the Nintendo Switch Overview.
Nintendo Switch Service Item Programming Manual version 12.0 has been merged into this document.

Intended Audience

This document is intended for producers and developers of Switch applications that use e-commerce features. For more information about reading this page, see the following section, Structure of This Document.

Structure of This Document

2 Application E-Commerce Features summarizes what applications can do by using the e-commerce framework. 3 Sales Using Nintendo eShop summarizes information about Nintendo eShop as a venue for selling products. Information about sales formats, such as bundles, discounts, or download codes, is also described. Read through the preceding pages first when considering application plans or sale content.

4 Workflow From Development to Distribution describes the workflow starting with applying to use the e-commerce features through completing preparations for the development environment and releasing the product. After you have checked this section and understood the development workflow, check the 5 Downloadable Content, 6 Consumable Service Items, 7 Subscription Service Items, and 8 Feature for Getting Information Within Applications pages depending on which features your application uses, and then proceed with development.

Finally, other information for developers is summarized in 9 (Reference) Reference Information for Developers. If you are responsible for implementing the applicable features, pay particular attention to this content.

Important Information

When planning, developing, and releasing an application that uses e-commerce features, observe all associated laws and regulations.
