Important Information About Jumping to eShop

Application Processing While Jumping to eShop

Starting the EC applet from within the application does not interrupt the application's processing. The EC applet is terminated when a user makes or cancels a purchase in Nintendo eShop. Note that the EC applet does not return any results to the application. That is, the application cannot determine whether a product was purchased as a result of a jump to eShop.

Nintendo eShop Page Transition After Jumping to eShop

The user can access only the products accessible from the post-jump to eShop product page. For example, after a jump to the download software details page, the user can access the downloadable content list on the page, but cannot access other downloadable software.

Jumps That Require the Feature for Getting Information Within the Application

When using the following API functions, you must use the feature for getting information within the application to get the ID (the ns_uid) that specifies the product to display. For more information, see 8 Feature for Getting Information Within Applications.

  • ShowShopProductList()
  • ShowShopProductDetails()
  • ShowShopConsumableItemDetail()
  • ShowShopSubscriptionDetails()

In addition, by setting the items to private in Nintendo eShop and using the preceding API, you can limit the purchase avenues so that downloadable content and consumable service items can be purchased only via jump to eShop. For more information, see 8.1 Common.
