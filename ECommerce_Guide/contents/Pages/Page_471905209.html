6.2.2.2.5 FOR DEBUGGING: API for Clearing Mandatory Error Settings

Overview

This API clears the error set using the API for mandatory error settings. This API can only be used in the development environment.

Request

DELETE /v1/debug/forcedError/{nsa_id}
Authorization: Basic {base64(clientId:clientSecret)}
Parameter Parameter Type Optional Description

nsa_id

 path No

Specify the internal ID (string) of the network service account in the NSA ID token as is, including the leading 0.

Response

204 No Content
