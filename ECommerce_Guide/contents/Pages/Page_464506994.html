2.1 Content and Service Types

The application can use the Switch e-commerce features to support development of the following content and services.

Type Description
Downloadable Content The functionality for selling a license for content that is purchased outright and can be used indefinitely after it is bought.
Consumable Service Items

The functionality for selling a license for using services a limited number of times, such as virtual currency. The following methods are available.

  • Independent server controlled method
  • User save data controlled method
    • This method does not use an independent server.
Subscription Service Items The functionality to sell licenses to use a service for only a specific period of time. An independent server is required in order to provide this service.

Details about these various types of content and services are described in other sections of this document.

Note

If you want to use an independent transaction method instead of Nintendo eShop for selling content or services, contact your Nintendo support representative in advance.
