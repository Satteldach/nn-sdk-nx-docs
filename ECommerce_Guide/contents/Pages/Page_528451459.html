7.1 Overview

Subscription Service Items Overview

Subscription service items provide services to users using the following steps.

  1. The user purchases a subscription service item in Nintendo eShop.
  2. The independent server checks Nintendo eShop to confirm the user license.
  3. The independent server provides the service to the user.
Figure 7-1 Subscription Service Items Overview

You need an independent server to provide subscription service items.

Fixed Term Format and Monthly Format

Subscription service items use one of the following formats.

  • Fixed term format
    • Any fixed duration. 1 hour, 30 days, and so on. The minimum unit is 1 minute.
  • Monthly format
    • Duration of one calendar month. The minimum unit is 1 month.

There are 31 days in May but 30 days in June, so a fixed term format item set for 30 days and a monthly format item set for 1 month would work as follows.

  • Fixed term format: A 30-day subscription service item is purchased and starts use at 10:00, May 1. The validity period ends at 09:59 on May 31.
  • Monthly format: A one-month subscription service items is purchased and starts use at 10:00, May 1. The validity period ends at 09:59 on June 1.

The following table summarizes the major differences between the fixed term format and monthly format.

Type Duration Availability of Automatically Renewed/Non-Automatically Renewed Purchases Activating the License (Starting the Valid Period)
Fixed term format Any fixed duration, such as 1 hour or 30 days

Both automatically renewed and non-automatically renewed

 Can be activated at any time from the application.
Monthly format Duration of one calendar month Automatically renewed only

Automatically activated after purchase from Nintendo eShop.
Info

Currently, the monthly format only supports a duration of 1 month. In the future, this feature will support other durations, such as 3 months.

For more information about the monthly format, see 7.2.2 Monthly Format.

Activating Fixed Term Format Services

The status of the user licenses kept on the Nintendo eShop server are in one of the following three states.

  • No license
    The subscription service item has not been purchased, or the valid period has ended.
  • Has license
    The license has been purchased but the validity period has not started.
  • Valid period
    The license has period during which it is valid. This period is managed by the Nintendo eShop server.

The basic flow is as follows.

  1. When a user purchases a subscription service item in Nintendo eShop, the status changes to "has license."
  2. The independent server sends a request to the Nintendo eShop server to activate the license.
  3. When the use of the license begins, the status of the license on the Nintendo eShop server changes to "valid period."
  4. The independent server provides the service, checking the Nintendo eShop server to confirm the validity period.
  5. If a user purchases a subscription service item while the status of the license is "valid period," the validity period for that license will be extended.
  6. If the valid period expires, the status of the license reverts to "no license" and the process returns to step 1.
Info

If a user purchases a subscription service item while the status of the license is "has license," the period for that license will be cumulative. When the independent server begins using that license, the validity period represents the total of all of the licenses.

Subscription service items support the automatic renewal process. For more information, see 7.2.1 Automatic Renewal.

Even with automatic renewal, the user license status is still in one of the preceding states. If an automatic renewal agreement is in effect, the agreement is renewed and the validity period is extended before the period expires. The validity period is extended if the subscription service item is purchased in Nintendo eShop while the renewal agreement is in effect.

Note

After purchasing a subscription service item in Nintendo eShop, if the purchased license is not used for 150 days, Nintendo will automatically activate that license.

Format for Selling Subscription Service Items

Subscription service items are sold on the page that lists service tickets in the details for the application in Nintendo eShop.

The application can use the API for jumping to eShop to land on the page with the list of service tickets, or to land on a specific service item. The purchase process is run in Nintendo eShop.

Sales Unit

Subscription services that are offered in Nintendo eShop are called courses. The licenses and validity periods for subscription services are managed separately for each course. Courses are identified by course IDs issued by Nintendo. For more information, see 4.1 Usage Request on OMAS.

In Nintendo eShop, subscription service items are organized into separate pages for each course, and sold as individual items.
When adding items from NCMS, first add the course, and then add the items that come under that course. You must configure the following settings for each item.

  • Sales Price
  • Sales Period
  • Granted Licenses

Free Trial Flags and Purchase Limits

You can set the following two options for service items.

Option Description
Free Trial Flag

Specify on for the item if there will be a free trial.
When on is specified, the item is clearly displayed as a free trial in Nintendo eShop.
Purchase Limit Limits the number of times each Nintendo Account can purchase the item (purchasable number).

For example, to prepare a service item that can be used for free only the first time as a promotion, set the free trial flag to on and set the purchase limit to 1.

Configure the options in NCMS. For more information about configuring the setting, see NCMS Manual > Submitting Sales and Promotional Information > Submitting Service Tickets (Switch Only).

Restrictions on the Number of Times a Subscription Service Item Can Be Purchased

You can limit the number of times each subscription service item can be purchased by each Nintendo Account. This limit is called the purchase limit. The number of times the item can be purchased while the purchase limit is enabled is called the purchasable number.
For example, if you set the purchasable number for a subscription service item to 1, that item can be purchased only once by each Nintendo Account.

The purchase limit settings are configured on NCMS. For more information about configuring the setting, see NCMS Manual > Submitting Sales and Promotional Information > Submitting Service Tickets (Switch Only).
The maximum purchasable number that can be configured is 20. The presence of a purchase limit and the purchasable number can be changed even after a subscription service item goes on sale.

Important Information When Setting Purchase Limits

Note the following information when setting purchase limits.

  • The number of purchases is counted only while a purchase limit is set. The purchases are not counted if the purchase limit is disabled.
  • The configured purchase limit cannot be reset. For this reason, if you want to reset the number of purchases for a subscription service item that has already been released and then set a new purchase limit, you must create a new subscription service item.
  • The purchase limit does not apply when you use the following methods to obtain a subscription service item. You can obtain the item even if a purchase limit has been set and the purchasable number has reached the maximum. Even if you obtain the item, it will not be counted toward the number of purchases.
    • Using a download code
    • Using a privilege grant

Maximum Service Period

The maximum service period is the maximum period that a user can own the item. A maximum service period is set individually for each course. Users cannot possess licenses and validity periods that exceed this maximum service period. The following restrictions apply.

  • Items cannot be selected in Nintendo eShop if the maximum service period is exceeded.
  • An error occurs if the maximum service period is exceeded while using a download code.
  • The call to the 7.4.3.5 Add License API fails and generates an error if the maximum service period is exceeded.
Note

If you only sell items that add licenses of the same length as the maximum service period, users who have purchased that item cannot purchase the item again until the validity period for the item has expired. Pay careful attention to the maximum validity period and the number of days you offer licenses for.

Use OMAS to set the maximum service period for each course.

Sharing Courses With Multiple Applications

You can sell subscription service items with the same course ID in multiple applications.
License information is managed for each user by the course ID, which allows sharing the license information between applications.

Compensation Support

After a license for a subscription service item has begun being used, the period of use cannot be paused. As a result, if problems occur with the application or independent server, there may be a period when users cannot use the service even though they have the license to do so.
If this happens, Nintendo will not compensate users with additional licenses. If you want to compensate users, support the process independently for each application.

Granting License as Compensation

There is an API for adding licenses that you can use when incidents occur and you want to extend the expiration date managed in Nintendo eShop. For more information about this API, see 7.4.3.5 Add License API.

Note
  • Do not use the API for adding licenses for any purpose other than providing compensation.
  • For uses such as first-time-free promotions, use the service item options. For more information, see Free Trial Flags and Purchase Limits.
  • You cannot use the add license API for monthly format items.
