7.4.3.11 FOR DEBUGGING: API for Changing the License Information

Overview

This API changes the license information for the specified network service account and course ID.
With this API, you can, for example, change an activated license back to the unused state.

This API can only be used in the development environment.

Request

PUT /v1/courses/{course_id}/accounts/{nsa_id}/right
Authorization: Basic {base64(clientId:clientSecret)}
Parameter Description Data Type Parameter Type Required/Optional Default (Optional is the only default) Example Notes
course_id The course ID for which to change the license information. string path Required
"aa5e5131d43ba0d4"

nsa_id

The internal ID of the network service account in the NSA ID token (a string).

 string path Required
"0123456789abcdef"

Specify in this format, including the 0 at the start.
start_date The time to activate the use of the license. number query Optional null 1585699200000

Specify in units of epoch milliseconds.

If you specify start_date, also specify expiration_date.
expiration_date The time to deactivate the license. number query Optional null 1588291200000

Specify in units of epoch milliseconds.

If you specify expiration_date, also specify start_date.
reserved_minutes A period of the license that has not begun to be used. number query Optional null 30

Specify in units of minutes.

If you specify reserved_minutes, you cannot specify start_date and expiration_date.

Specifying Parameters For Different Uses

This section describes the primary uses for parameters and how to specify them. You can change license information independently of the current license status.

This API can be used to change a license that has been activated by the user into a license in the grace period (if there is an automatic renewal agreement). For more information about grace periods and automatic renewal, see 7.2.1 Automatic Renewal.

Usage How to Specify the Parameters
Change the license to the state where it has not yet been activated by the user. Specify only reserved_minutes as a query parameter.
Change the license to the state where it has been activated by the user

Specify the following query parameters.

  • A start_date earlier than the current time
  • An expiration_date later than the current time
Change a license that was activated by the user to the expired state
(if there is no automatic renewal agreement)

Specify the following query parameters.

  • A start_date earlier than the current time
  • An expiration_date later than the start_date, but earlier than the current time
Change a license that was activated by the user to one in the grace period
(if there is an automatic renewal agreement)

Automatic Purchase Processing When expiration_date Has Changed

In the development environment, even if you change expiration_date using this API, automatic purchase processing will be performed based on the expiration_date specified before the change. For more information about automatic purchase processing, see 7.2.1 Automatic Renewal.

To synchronize automatic purchase processing with the changed expiration_date, complete the following procedure.

  1. Sign in to Nintendo eShop using the Nintendo Account that has the license.
  2. Select the user icon in the upper-right corner to open the account information.
  3. Open Your Subscriptions.

After completing these steps, automatic purchase processing will be performed for the changed expiration_date at minute 55 of each hour.
