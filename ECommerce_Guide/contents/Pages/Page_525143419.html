4.4 Distribution

After completing Lotcheck, use NCMS to submit product information for the production environment. The product information is reviewed by Nintendo before the product is made available. For more information, see the NCMS Manual.

For registering products in NCMS, also see the following notes.

  • Actual product information can be registered in NCMS before the product passes Lotcheck.
  • The name of the product purchased by the user is included in the receipt sent to the email address registered to the user's Nintendo Account and displayed in Account Activity under Shop Menu on the screen for the Nintendo Account settings. If a product name changes after being available for purchase, the display name does not change for products purchased before the change.
  • Courses can be shared between applications by setting the course ID of a subscription service item set in one application in other applications. You cannot configure application-specific settings for shared courses.

eShop Sales Tools

eShop Sales Tools (SST) are online tools provided for getting preliminary sales figures for products. To use it, you must have an NDID. Note the following information when using SST.

  • Do not treat the information as official sales data.
  • You cannot check the number of purchases in real time. There is a lag of several hours.
