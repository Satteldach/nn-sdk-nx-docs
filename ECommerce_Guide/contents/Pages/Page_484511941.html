6.1 Overview

There are two methods for implementing consumable service items. The following section provides an overview and the specifications that are common to both methods.

Providing Consumable Service Items

There are two ways to provide consumable service items.

  • Independent Server Controlled Method
  • User Save Data Controlled Method

The independent server controlled method is the mechanism for managing sold licenses on an independent server. If you want to sell consumable service items, first consider providing services with the independent server controlled method.

The user save data controlled method is the mechanism for managing sold licenses in save data. You can use the user save data controlled method when selling consumable service items without using an independent server, but there are many restrictions. For more information about the user save data controlled method, see 6.3 User Save Data Controlled Method.

Overview of Consumable Service Items Using the Independent Server Controlled Method

The mechanism for managing consumable service items using the independent server controlled method provides services to the user via the following process.

  1. Users purchase consumable service items on Nintendo eShop.
  2. When providing services to users, the independent server gets user purchase data from the Nintendo eShop server.
  3. The independent server then updates user license information based on the acquired purchase data.
  4. The independent server provides services to users based on the user license information maintained on the independent server.
Figure 6-1 Overview of the Independent Server Controlled Method

For a mechanism like this, which uses the independent server controlled method, you must configure an independent server. When developing an independent server, see Nintendo Switch Independent Server Setup Manual.

Overview of the User Save Data Controlled Method

The mechanism for managing consumable service items using the user save data controlled method provides services to the user via the following process.

  1. Users purchase consumable service items on Nintendo eShop.
  2. The Switch application gets the user purchase information from Nintendo eShop.
  3. The Switch application references the purchase information and saves the license information to the user save data.
Figure 6-2 Overview of the User Save Data Controlled Method

Although an internet connection is required for applying the consumable service item license purchased on Nintendo eShop to the user save data, the items can be used offline after this data has been saved.

This method does not require the use of an independent server. However, it does require the use of the libraries made available in the NintendoSDK. For more information, see NintendoSDK Documents > Features > System > ec Library > Consumable Service Items Client Libraries.

Selling Consumable Service Items on Nintendo eShop

The sales data for consumable service items is added using the Nintendo Content Management System (NCMS). For more information about the settings to use with NCMS, see 4.2.1 NCMS Settings for Development.

Consumable Services

Consumable services are services identified at the Consumable ID level.

For example, to sell virtual currency and in-game items as two kinds of consumable service items, you begin by creating the following two types of consumable services.

  • Consumable Service Name: Gold
  • Consumable Service Name: In-game item

The consumable ID is configured when creating a consumable service in NCMS. You must add consumable services to the Consumable Service List for a title in NCMS to distribute those consumable services.

Consumable Service Items

Even when consumable services are sold in bundles, for the sake of convenience, they are called consumable service items. These consumable service items can be identified by their item IDs.

Consumable service items are listed in Nintendo eShop on separate pages for each type of consumable service. For example, say there is a consumable service called "Gold" and you create the consumable service items Gold 1G and Gold 2G that are associated with that consumable service. Those two items, Gold 1G and Gold 2G, will appear on the Gold page in Nintendo eShop.

The item ID is a value that is configured when creating a consumable service item in NCMS. Specify a string in NCMS that the application can use to identify purchased consumable service items. The format is a single-byte alphanumeric string of 1 to 16 (case-sensitive) characters. Nintendo eShop uses the application ID in combination with this item ID to identify product information. As a result, item IDs do not have to be unique across applications.

Limitations on Repeat Consumable Service Items Purchases

You can limit the number of times each consumable service item can be purchased by each Nintendo Account. This limit is called the purchase limit. The number of times the item can be purchased while the purchase limit is enabled is called the purchasable number.
For example, if you set the purchasable number for a consumable service item to 1, that item can be purchased only once by each Nintendo Account.

The purchase limit settings are configured on NCMS. For more information about configuring the setting, see NCMS Manual > Submitting Sales and Promotional Information > Submitting Consumable Services (Switch Only).
The maximum purchasable number that can be configured is 20. Purchase limits and the number of available purchases can be changed even after the consumable service item goes on sale.

Important Information When Setting Purchase Limits

Note the following information when setting purchase limits.

  • The number of purchases is counted only while a purchase limit is set. The purchases are not counted if the purchase limit is disabled.
  • The configured purchase limit cannot be reset. For this reason, if you want to reset the number of purchases for a consumable service item that has already been released and then set a new purchase limit, you must create a new consumable service item.
  • The purchase limit does not apply when you use the following methods to obtain a consumable service item. You can obtain the item even if a purchase limit has been set and the purchasable number has reached the maximum. Even if you obtain the item, it will not be counted toward the number of purchases.
    • Purchasing a bundle that includes consumable service items
    • Using a download code
    • Using a privilege grant

Displaying a Purchase Period For a Consumable Service Item

If a consumable service item will be sold for a limited time, the period of availability is displayed. If a purchase period is configured for a consumable service item, the period until the time sales of that item ends appears in Nintendo eShop.

Options to Configure Images and Descriptions for Consumable Service Items

By default, both an image and a description is set for a consumable service, but only an item name is set for a consumable service item. For example, if you plan to sell a virtual currency, you would set an image and a description of the virtual currency in the consumable service, but for the consumable service item you would set only the unit of the currency as the item name.

On the other hand, if for example you were selling bundles of items that can be used in the application, you might want to add an image or a description for each bundle. In this case, you could make each bundle its own consumable service. However, that approach increases the number of consumable service items and it becomes harder to find the bundle you want. To avoid this issue, you can use the option to configure images and descriptions for consumable service items instead of consumable services. The following examples show what happens with that option enabled and disabled.

Restrictions on the Number of Consumable Services and Item IDs

There are the following limitations when selling consumable service items on Nintendo eShop.

Limitation Content Limitation
Number of consumable services that can be sold at the same time Up to 20
Number of item IDs that can be sold at the same time Up to 20 for each consumable service
Format of item IDs that can be added

A single-byte alphanumeric string of 1 to 16 (case-sensitive) characters

Because of these restrictions, a maximum of 400 consumable service items can be sold at the same time for any one application.

Info

There is an upper limit on the number of consumable services, so if you are selling multiple bundles, instead of creating a consumable service for each bundle, you may want to consider preparing a single consumable service for the bundles and then selling each bundle as a separate consumable service item, using the option to set an image and description for each item.

The system also imposes the following limitations.

  • When the EC applet is started from the application, it does not return the result for whether a purchase was made.
  • Independent servers and Switch applications cannot directly make purchase requests to the Nintendo eShop server.
