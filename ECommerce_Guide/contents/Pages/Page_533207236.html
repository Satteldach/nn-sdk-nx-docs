7.4.3.2 License Information Reference API (Device-Based Sharing Type)

Overview

This API references the following licenses for device-based sharing courses.

  • Available licenses
  • Licenses in their validity period (The validity period begins when an available license is activated by the independent server.)

The API consists of the following functions.

  • Function that specifies a Nintendo Account
  • Function that does not specify a Nintendo Account
Info

Use the function that does not specify a Nintendo Account to display information for licenses other than the licenses that are currently active to the user. For example, if Nintendo Accounts A and B are linked on the same console, both of the following pieces of information are displayed.

  • Activated licenses for Nintendo Account A
  • Unactivated licenses for Nintendo Account B

Function That Specifies a Nintendo Account

This function gets the following license information for the specified course ID.

  • License information for all accounts linked to the requesting Switch
    • However, the accounts with licenses must have that Switch set as their primary console.
  • License information for the requesting account, regardless of the requesting Switch
    • By specifying the always_include_self option, described later, the license status can be obtained for an account even if the console is not set as its primary console.

Device-Based Sharing Where Multiple Accounts on the Same System Have the License

When multiple Nintendo Accounts have the same Switch console set as the primary console and they all have a license, this API gets the license information for the account that satisfies the following conditions.

  • The account with the longest license (the greatest expiration_datetime value) among those accounts that have started using their license
  • If none of the accounts have started using their licenses, the account with the longest license (the greatest reserved_minutes value)
Info

For more information about this case, see 7.2.3 Sharing Licenses.

Using the Same License From Multiple Switch Consoles

The always_include_self option enables an account with the license to use that license regardless of the primary console setting. However, it is also possible to get a service on multiple Switch consoles using the same license, as follows.

  • The account that has the license uses the service on a Switch console that is not set as the primary console for that account.
  • Accounts other than the one with the license use the service on the Switch set as the primary console for the account with the license.

curl Request Samples (dd1 Environment)

For simplicity, the k option is used to skip SSL authentication. A CA certificate can be obtained by following the instructions in 9.1 Using Independent Servers.

curl -k \
"https://mandom.ws.dd1.ss.nintendo.net/v1/courses/{course_id}/accounts/{nsa_id}/right?edi={edi}" \
--basic --user {clientId}:{clientSecret}

Example:

[

    "active":true,
    "nsa_id":"0123456789abcdef",
    "start_datetime": 1585699200000,
    "expiration_datetime":1588291200000,

  },
  { // This account has a license, but it has not yet been used.
    "active": false,
    "nsa_id": "123456789abcdef0",
    "reserved_minutes": 600,
    "auto_billing_applied": false,
    "temporary": false
  },
  { // Account with expired license.
    "active": false,
    "nsa_id": "0000123456789abc",
    "auto_billing_applied": false,
    "temporary": false,
  }
]
  • License information for accounts included in the response is sorted in the following order.
    1. Accounts that have started using a license.
      When multiple accounts have started using a license, the accounts are listed in order with the account with the largest expiration_datetime value listed first.
    2. Accounts that have a license but have not yet started using it.
      When multiple accounts have the same conditions, accounts for which the reserved_minutes values are largest are listed first.
    3. Accounts with expired licenses.
  • Accounts that have never added a license are not listed.
    • Only accounts that started using a license that has expired are listed.
  • Unlike the response of 7.4.3.3 License Information Reference API (Account Type), with this API function the nsa_id value is included among the elements even for accounts for which the license has expired.
  • When no accounts are listed for the Switch console that sent the request, an empty array is returned as the response.
