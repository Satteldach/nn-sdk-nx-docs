7.4.3.9 FOR DEBUGGING: API for Mandatory Error Settings

Overview

This API allows API functions that are not for debugging that take an nsa_id as a parameter to return the specified error code for the Nintendo Account linked with the specified network service account.
When an error is set using this API function, the message in the error response becomes null.
This API can only be used in the development environment. Use it to confirm behavior when errors occur, for debugging purposes.

Request

PUT /v1/debug/forcedError/{nsa_id}?error_code={error_code}
Authorization: Basic {base64(clientId:clientSecret)}
Parameter Parameter Type Optional Description

nsa_id

 Path No

Specify the internal ID (string) of the network service account in the NSA ID token as is, including the leading 0.
error_code Query No Specify the last four digits of the error code to trigger.

Response

201 Created
