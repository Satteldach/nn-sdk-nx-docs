4.2 Preparations for Development

As you begin development, see sections in this page that are relevant to the e-commerce features you are using. You can also reference the following documents.

  • NintendoSDK Documents > Features > System > aoc Library
  • Nintendo Switch Independent Server Setup Manual
  • NintendoSDK Documents > Features > System > ec Library > Consumable Service Items Client Libraries

This page describes the features that you may need in the development environment such as the development environment Nintendo eShop, dummy EC applet, and adding funds, and the considerations for those features.

Using Nintendo eShop in the Development Environment

If you are using any of the following features, you must add sales information to the development environment Nintendo eShop.

  • Consumable Service Items
  • Subscription Service Items
  • Feature for Getting Item Information Within Applications

As with the production environment, sales data for the development environment Nintendo eShop is configured in NCMS. For more information about the sales information settings in NCMS, see 4.2.1 NCMS Settings for Development.

Switching Between Nintendo eShop and Dummy EC Applet

The dummy EC applet is a tool for checking the parameters of the jump to eShop API in the development environment.

If the development hardware is initialized with a firmware version to which "+ Prod" is not affixed, the EC applet starts by default when Nintendo eShop is called. If "+ Prod" is affixed to the firmware version used for initialization, Nintendo eShop starts.

You can use one of the following methods to switch from the dummy EC applet to Nintendo eShop.

  • Use the switch-shop command in DevMenuCommand, and configure it so that Nintendo eShop opens on the development hardware.
  • Change the Shop > Valid Shop option in DevMenu so that Nintendo eShop opens on the development hardware.
Info

For more information about DevMenuCommand and DevMenu, see NintendoSDK Documents.

Note
  • Depending on the version of the NintendoSDK firmware on the development hardware, it may not be possible to start Nintendo eShop. Make sure that you use the latest version of the firmware required for ROM testing. You can find the latest version on the Nintendo Developer Portal in Technical Information > Master Submission Information > Firmware Version Required for Testing.
  • When opening the Nintendo Switch Online page in the development environment Nintendo eShop, error 2813-0013 occurs and you cannot perform any operations on that page. This behavior is by design.

DevMenu Warning Messages

If the warning message "Warning: application background tasks are too heavy" is displayed in the dummy EC applet, the behavior of Nintendo eShop may not be normal. For more information, see NintendoSDK Documents > Features > System > ec Library > EC Applet Usage > Considerations When Calling the EC Applet.

Checking Content Registered on Nintendo eShop Using Development Hardware

Applications are not searchable from Nintendo eShop when it is opened from the HOME Menu. To access the registered application or the list of downloadable content, start the application with the jump to Nintendo eShop feature implemented. The following eShop jump functions can be used for testing purposes.

  • nn::ec::ShowShopApplicationInformation() // Jumps to the application details in eShop.
  • nn::ec::ShowShopConsumableItemList() // Displays a list of consumable service items.
  • nn::ec::ShowShopSubscriptionList() // Displays the list of subscription service items.
  • nn::ec::ShowShopAddOnContentList() // Jumps to the list of downloadable content in eShop.
Info

Using Nintendo eShop in the development environment requires a Nintendo Account for the dd1 environment. Prepare this environment in advance.

Considerations When Checking Purchases

When Nintendo eShop is called from inside the application, no result is returned to the call target indicating whether the user has made a purchase. This behavior is the same in both the development and production environments. The behavior is the same regardless of whether the call target is Nintendo eShop or the dummy EC applet.

Info

The purchase notification feature is supported for both consumable service items and subscription service items. For more information, see 2.4 Service Item Purchase Notification Feature.
