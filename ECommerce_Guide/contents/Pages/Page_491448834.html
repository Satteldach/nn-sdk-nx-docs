9.1 Using Independent Servers

Overview

This section describes the independent servers used for e-commerce. For more information about independent servers, see the Nintendo Switch Independent Server Setup Manual.
If you are using the following items, you must use an independent server.

  • Consumable service items managed by the independent server
  • Subscription service items

To use these service items, you must make an OMAS request. For more information, see 4.1 Usage Request on OMAS.

Accessing Independent Servers From Applications

The following settings are required in order to get the token required to access an independent server.

  • The application ID in the application’s NMETA file
  • The network service account on the development hardware
    A Nintendo Account is required for using consumable service items, so you must create a network service account by linking the Nintendo Account to a Switch user account.

For more information, see the NintendoSDK Manual and the Nintendo Switch Independent Server Setup Manual.

Independent Server Environment

There are separate server environments for development servers, for Lotcheck, and for users in general. Note: The fully qualified domain name (FQDN) for the API endpoint is different for the service item server in each environment. You must change the request destination depending on the environment used by the independent server. For more information, see the Nintendo Switch Independent Server Configuration Manual.

Environment Identifier Description
dd1 The environment application developers use for development.
dp1 An environment for special uses. Normally, it does not need to be considered.
sd1 The environment used for Lotcheck.
sp1 The environment used for Lotcheck.
jd1 This environment is used by Nintendo for verifying compatibility of already released applications with new versions of the system firmware before they are publicly released.
lp1

An environment offering services for general users.
Note

Note that Lotcheck uses either the sd1 or sp1 environment based on the inspection stage.

Client IDs and Client Secrets

A client ID and a client secret are needed to access the API endpoints for consumable service items and subscription service items from an independent server. For more information about how tokens are issued, see 4.1 Usage Request on OMAS.

CA Certificates

To use the server API for subscription service items and consumable service items, you must trust the following Nintendo private CA.

Issuer CA Certificate
Nintendo CA - G3

Use the following.

  • NintendoCA-G3.pem
  • NintendoCA-G3.der
Info

These CA certificates are used on the Switch and have already been installed.
