8.4 Consumable Service Items

Overview

The following features are available.

  • Feature for getting consumable service information
  • Feature for getting consumable service item information

Feature for Getting Consumable Service Item Information

You can use this feature to get the following information for consumable service items.

  • Consumable service information (such as virtual in-game currency)
    Information including identifiers for various consumable services (Consumable ID), and so forth. The Consumable ID is set in NCMS.
  • Consumable service item information (such as 100 points of virtual in-game currency)
    Information for all consumable service items linked to the specified Consumable ID. This information includes the identifiers (ns_uid) for displaying each consumable service item in Nintendo eShop.

Features for Getting Consumable Service Item Information

Request

URL Path

/v1/consumables/{consumableId}/items

Parameter

Parameter Description Data Type Parameter Type

Required/

Optional

 Default Example Notes
consumableId

Consumable service identifier (consumable ID).

 string path Required

aubabwsqfh6f36hx

 Specify the consumable ID acquired with features for getting consumable services information.
country ISO 3166-1 alpha-2 country code. string query Required

{country}

 Specify this value using a ShopServiceAccessor alias replacement.
lang Language Codes in IETF language tag format. string query Required
en-US Specify information for the language used by the application or the system language. If the specified language is available, the response is in that language. If the specified language is not available, the response is returned in the default language (for example, en-US in the US).
onsale_only

true: Only get items with "onsale" sales status.

false: Also get items with a sales status other than "onsale."

 boolean query Optional true true Specify whether the item is available for purchase in the Nintendo eShop. For more information about this parameter, see 8.1 Common.
offset Start position for the items to get. integer query Optional 0 0 Use when splitting the request into multiple times.
limit Number of items to get. integer query Optional 100 10

A value in the range from 1 to 100 can be specified.

Path Example:

/v1/consumables/aubabwsqfh6f36hx/items?country={country}&lang=en-US

In this example, "aubabwsqfh6f36hx" is the consumable ID acquired with the feature for getting consumable service information. "en-US" is a string obtained from the system language.

Note

The limit parameter defines how many consumable service items can be obtained at a time, but the maximum is 100 items.

To obtain information on more than 100 items, use the offset element and split the process into multiple get operations. For a usage example of limit and offset, see 8.1 Common.
