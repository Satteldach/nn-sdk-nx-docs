8.5 Subscription Service Items

Overview

The following features are available.

  • Getting lists of course information from the Nintendo eShop server
  • Getting information about subscription service items associated with a specified course from the Nintendo eShop server

Implementation

Use the feature for getting course lists to get the list of courses associated with an application ID. Then use the feature for getting the list of subscription service items to get the list of items for the specified course. You can also use the Shop Jump API to specify the item identifier (NsUID) obtained here.

Note

The limit parameter defines how many subscription service items can be obtained at a time, but the maximum is 100 items.

To obtain information on more than 100 items, use the offset element and split the process into multiple get operations. For a usage example of limit and offset, see 8.1 Common.

Info

Because the items are not named, control the order in which items are displayed using grant_minutes and grant_months, or with item_tags as in the preceding example.

About automatic_renewal_notice

If you are showing items that are automatically renewed and their prices in your application, you must display the text obtained by automatic_renewal_notice in the application. In some countries and regions, items that are automatically renewed cannot be sold, and they are replaced by regular items. This text is designed to draw attention to this fact. The application cannot determine whether items have been replaced this way, so simply display the text that is obtained. The text is translated based on the response lang.

About max_purchase_count and Subscription Service Items That Are Free the First Time

max_purchase_count provides information about the maximum number of times a subscription service item can be purchased, so you can use it to distinguish those items that are free the first time.

Note

Note that max_purchase_count always returns the maximum purchase count that was set for the item. As a result, if max_purchase_count is set to 1 for an automatically renewed item that is free the first time, the Nintendo Account that purchased that item gets max_purchase_count=1 as the response even though no more of the subscription service item can be purchased. To purposefully not display a subscription service item in your application after it has been purchased, have the application determine whether that item has been purchased.
