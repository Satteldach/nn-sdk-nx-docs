3.6 Nintendo eShop Specifications for China

Overview

This page describes the Nintendo eShop specifications for China.

General

Payment Methods

All of the methods for adding funds in 3.2 Payment Methods are unavailable. Only the method of using WeChat Pay for purchasing products is available. When purchasing a product, a QR code is displayed in Nintendo eShop. The user performs the payment transaction by using WeChat Pay, in the WeChat application on their smart device, to scan the displayed QR code.

Parental Controls

Parental controls cannot be used to restrict product purchases in Nintendo eShop. Items can be purchased regardless of age.

Sending Email

Receipt emails and emails for promotional codes are not sent. Instead, the user can check their purchase history for the past two years in Nintendo eShop. Promotional codes can be verified from the purchase history.

Selling Methods

Configure sale settings for the product in NCMS. The region is China. The supported language is Simplified Chinese, and the currency unit is ¥ (yuan). Products are only sold in Nintendo eShop.

Note

You cannot use the same application ID for sales settings for China and other regions. Because the region cannot be changed after registering a product in NCMS, be careful during registration.

Available Features

The information described in 3.4 Sales Options (Discounts, Buyer Benefits, Download Codes, Pre-Orders, Season Passes) also applies to China, but the following restrictions apply to pre-orders in China.

  • Pre-orders are limited to the 7 days before the release date.
  • The pre-order, the settlement of payment, and the download of the ROM all start at the same time. Settlement occurs at the time of pre-order and cannot be canceled.

In addition, features such as getting the application information are available.
Automatic renewal and monthly format subscription service items are not supported, and there are no plans to support them in the future.

Development Environment

Creating an Account For China

To use Nintendo eShop for China, you must create an account for China. For more information about creating accounts for China, see NintendoSDK Documents > Guide to Setting Up the Environment > Creating an Account For China in the Development Environment.

Transactions for Testing

Transactions for products in the development environment (dd1) are performed by reading the QR code displayed in Nintendo eShop. The WeChat application is not required. Complete the transaction by using a smart device QR code reader to read the QR code, which displays the transaction screen webpage. Upon payment, the smart device displays 测试商品 ("test product") for the product name.
