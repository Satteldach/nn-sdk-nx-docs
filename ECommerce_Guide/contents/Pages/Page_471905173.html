7.4.3.7 FOR DEBUGGING: API to Remove User Licenses

Overview

This API deletes licenses for all course IDs of the Nintendo Account linked with the specified network service account.
This API can only be used in the development environment. Use it to reset permissions data that was already added, for debugging purposes.

Request

DELETE /v1/accounts/{nsa_id}/right
Authorization: Basic {base64(clientId:clientSecret)}
Parameter Parameter Type Optional Description

nsa_id

 path No

Specify the internal ID (string) of the network service account in the NSA ID token as is, including the leading 0.

Response

200 OK
