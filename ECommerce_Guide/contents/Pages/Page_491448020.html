2.4 Service Item Purchase Notification Feature

Service Item Purchase Notification

There is a mechanism while the application is running to send notifications to users for service items, including both consumable service items and subscription service items.
The flow from notification through reference to purchase information is as follows.

  1. When the user purchases a service item or redeems a download code on Nintendo eShop or an e-commerce site, a purchase notification is sent to all Switch consoles that the Nintendo Account that made the purchase is linked to. (Arrival of the notification is not assured.)
  2. A notification (an event signal) arrives if the application is running and is ready to receive notifications. If the application is not running or is not ready to receive notifications, the notification is canceled.
  3. If the notification is received, Switch queries the Nintendo eShop server for the latest information. Note that this event acts only as a trigger to check the Nintendo eShop server, and the provided information does not necessarily include the newest purchase information.

Important Information

  • In some cases, notifications may not reach the application for the following kinds of reasons.
    • Purchases are made at a time other than when the application is running and ready to receive notifications.
    • There are network or server problems.
  • Make sure that you implement a sequence in your application to check for purchase information even without the arrival of notifications.
  • If the system is in sleep mode, notifications are received on waking.
  • Notifications also are received if Nintendo eShop is opened from the HOME Button on the Switch and a purchase is made while the application is running.
  • Purchase notifications are also sent for purchases made by users other than the user using the application. The purchase information can be referenced to check which NSA ID made the purchase.
  • The purchase notification and purchase information disappears when the application is restarted.

How to Use
