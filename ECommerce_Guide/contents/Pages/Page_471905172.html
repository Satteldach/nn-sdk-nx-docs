7.4.3.5 Add License API

Overview

This API adds licenses, for the specified course IDs, to the Nintendo Account linked with the specified network service account. It can only be used for subscription service items in the fixed term format.

If a user that is granted a license already had a valid license for that service, the validity period of the license is automatically extended.

Info

Licenses added using this API function are not displayed in the purchase history on Nintendo eShop.

Request

POST /v1/courses/{course_id}/accounts/{nsa_id}/transactions
Authorization: Basic {base64(clientId:clientSecret)}
Content-Type:application/json

{"additional_minutes":"3600", "reason_code":"APPLICATION","reason_description":""}

reason_code

Set the code that indicates the reason for adding a license.

There are some restrictions on which codes can be used as a reason_code. Use either of the following codes.

  • RECOMPENSE: For compensation
  • APPLICATION: For all other purposes

curl Request Samples (dd1 Environment)

For simplicity, the k option is used to skip SSL authentication. A CA certificate can be obtained by following the instructions in 9.1 Using Independent Servers.

curl -k \
"https://mandom.ws.dd1.ss.nintendo.net/v1/courses/{course_id}/accounts/{nsa_id}/transactions" \
--basic --user {clientId}:{clientSecret} \
-H 'Content-Type: application/json' \
-X POST -d '{"additional_minutes":"3600", "reason_code":"APPLICATION","reason_description":""}'
