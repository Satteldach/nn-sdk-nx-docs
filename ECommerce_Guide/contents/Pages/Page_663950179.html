8.6 Getting Price Information

Overview

A feature is available for getting price information for the following items. Use this feature if you want to show the prices for products.

  • Titles, bundles of a title and downloadable content, and bundles of a title and a consumable item.
  • Downloadable content, and bundles of downloadable content.
  • Subscription service items
Info

Do not use this feature to get the price information for consumable service items. The price information for consumable service items is included in the response of the feature for getting consumable service item information, so use that feature for this purpose.

For more information about displaying price information, see 8.7 Important Information When Displaying Prices.

Obtainable Discount Information

The discount_price that comes in the response of the feature for getting information contains a price that takes the temporary discount into consideration. This price does not take owner discounts into consideration. Consider, as an example, the case were the following discount conditions all apply.

  • A temporary discount of 40% off during August 10-20
  • An owner discount of 60% off for users that purchased the predecessor to a particular title

The feature for getting price information returns this 40% off price, but when the user goes to Nintendo eShop to actually purchase the title, eShop shows this 60% off price. For more information about discounts, see 3.4 Sales Options (Discounts, Buyer Benefits, Download Codes, Pre-Orders, Season Passes).

URL Path Specifications

Feature for Getting Price Information

This function gets the price information for the specified application and the specified items.

Request

URL Path

/v1/applications/{applicationId}/contents/prices

Parameter

Name Description Data Type Parameter Type

Required/

Optional

Default
(Optional is the only default)

 Example Remarks
applicationId

Application ID.

 string path Required
{applicationId}

Use the ShopServiceAccessor alias replacement feature.

To get the price information for an application other than the one that is running, specify the application ID.
ns_uids Array of ns_uid objects. long array query Required
70050000000001

Up to 100 items can be specified.

To specify an array, specify something like ns_uids=70050000000001&ns_uids=70050000000002.
country Nintendo Account country code. string query Required
{country} Use the ShopServiceAccessor alias replacement feature.
lang Language Codes in IETF language tag format. string query Required
en-US For more information, see 8.1 Common > lang Parameter.

Example:

/v1/applications/{applicationId}/contents/prices?country={country}&lang=ja&ns_uids=70050000000001&ns_uids=70050000000002

The preceding example is a request for price information for two products (ns_uids 70050000000001 and 70050000000002). Note that the name of the field where you specify ns_uid values is ns_uids (with an "s").
