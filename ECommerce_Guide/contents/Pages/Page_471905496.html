8 Feature for Getting Information Within Applications

This section describes the feature for getting information within applications. The application can get information for products sold in Nintendo eShop to implement specifications such as displaying this information in the application or directing the user to the page for a specific item in Nintendo eShop using the jump to eShop functionality.

Begin by reading 8.1 Common.
Next, refer to the following pages depending on the kind of information.

  • 8.2 Titles and Bundles That Include Titles
  • 8.3 Downloadable Content
  • 8.4 Consumable Service Items
  • 8.5 Subscription Service Items

For more information about getting and displaying prices, see 8.6 Getting Price Information and 8.7 Important Information When Displaying Prices.
