16.0 2022-01-12 Changes
  • General
    Fixed typos. Fixed inconsistencies in terminology.

    • Revised the table in Bundles to show that downloadable software can be sold as a bundle with other downloadable software.

  • 7.1 Overview

    In Overview, noted that this API can be used only with fixed-term subscription service items.

  • 8.1 Common

  • 8.3 Downloadable Content

  • 8.7 Important Information When Displaying Prices
