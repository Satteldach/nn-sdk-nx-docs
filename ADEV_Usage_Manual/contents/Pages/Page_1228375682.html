9.11 ADEV Not Recognized on PC

The ADEV cannot connect to the PC if it has been initialized in PROD MODE. If that is the case, start the ADEV in safe mode.

For more information about starting the ADEV in safe mode, see NintendoSDK Documents > Guide to Setting Up the Environment > NX > Development Hardware Setup > Initializing the ADEV > When ADEV Initialization Fails > Manually Activating Safe Mode.
