4.2 Components

The various components of the ADEV, the Nintendo Switch dock, and the Joy-Con have the same names as in the retail unit. See the Nintendo Switch Overview.

This section provides the names of the various parts of the Relay Box-A.

Relay Box-A
Top View

Number Name Description
1 TV output LED

Illuminates when the Relay Box-A is correctly connected to a TV.
In addition, this LED flashes when the Relay Box-A detects an error.

It also lights up temporarily when it receives power from the AC adapter and when it connects to the ADEV system.
2 Console connector

Connects to the USB Type-C™ connector on the bottom of the ADEV.

The plug can be connected in either orientation.
Front

Number Name Description
3

HDMI connector

Used to connect an HDMI cable.

During TV mode, connects to a TV and outputs video and audio from the ADEV to the TV.
4 USB port (supports USB 3.0 Micro-B) Connects the relay box to a PC via a USB Micro-B to Micro-A cable.
5 AC adapter port

Used to connect the bundled AC adapter.

The plug can be connected in either orientation.
