4.4 Important Information During Wireless Communication

Make sure that you review the following important information before using wireless communication with the ADEV.

WLAN Access Point Channels

Wireless communication cannot be performed if any of the following channels have been selected for the wireless LAN access point.

  • Channels 100 to 140
  • Channels 149 to 165 (the primary channel band used by WLAN access points in North America)

Make sure that none of these channels are selected when the WLAN access point channel settings are configured automatically.

Some specifications for the WLAN access point can cause automatic channel switching.

Distance During Use

If two development hardware units are too close together or a Switch system is too close to the WLAN access point, the wireless performance may deteriorate due to interference or a strong input signal.
If this happens, separate the devices by at least one meter.
