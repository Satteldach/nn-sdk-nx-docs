9.7 Unresponsive Joy-Con

If the Joy-Con is not responding, complete the following operations depending on the state of the Joy-Con.

If the Joy-Con Is Detached From the ADEV Console

Reset the Joy-Con if the player LED is lit but the buttons are unresponsive.
Press the SYNC Button on the Joy-Con to reset it.

If the player LED on the Joy-Con is not lit, pair the Joy-Con.
For more information about pairing the Joy-Con, see 5.6 Pairing the Joy-Con.

If the Joy-Con Is Attached to the ADEV Console

Any Joy-Con controllers attached to the ADEV cannot be used when the ADEV is in TV mode. Switch the ADEV to handheld mode or remove the Joy-Con controllers from the ADEV.

For more information about switching to handheld mode, see 8.4 Switching Between Handheld and TV Modes.
