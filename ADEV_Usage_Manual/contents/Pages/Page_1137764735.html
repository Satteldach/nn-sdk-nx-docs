8.5 Switching the Menus That Appear at Startup

When you turn the ADEV on, the DevMenu (a menu set specifically for development hardware) starts automatically by default.
This section describes how to change the HOME Menu that appears when the console is turned on to the menu for the production model.

  1. In DevMenu, select Debug > Launch Mode Settings and set Initial Boot Menu to HomeMenu.
  2. Restart the ADEV system after changing the settings.


To then start DevMenu from the HOME Menu, run DevMenu Application, which is installed during ADEV initialization.

Info

You can also start DevMenu from the HOME Menu using the following procedure, in NintendoSDK Firmware for NX 8.0.0-5.0 and later.

  1. In the HOME Menu, tap the Sleep icon on the lower right.
  2. While the screen indicating that the console is about to enter sleep mode is displayed, simultaneously press the L Stick or the R Stick, together with the + Button or the - Button.
