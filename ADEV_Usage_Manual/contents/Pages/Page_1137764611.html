5.6 Pairing the Joy-Con

To use Joy-Con controllers that have not previously been connected to the ADEV, you must first register (pair) the controllers to the ADEV.

Information for up to 10 controllers can be registered in the ADEV, the same as with the Switch retail unit.

Before using the Joy-Con, complete the following procedure to pair the Joy-Con.

  1. Turn the ADEV on.
    For more information about turning the ADEV on, see 5.2 Turning the ADEV On and Off.

  2. Check that the DevMenu is displayed on the ADEV's LCD screen, or that the application is running.

  3. Attach the Joy-Con to the ADEV console.
    Attach Joy-Con (R) to the right rail and Joy-Con (L) to the left rail.

    The Joy-Con pairing completes within one second.

  4. Check whether you can operate the Joy-Con.

    When pairing is complete, you can operate the Joy-Con attached to the ADEV console.

  5. Remove the Joy-Con from the ADEV console.

  6. Check the Joy-Con player LED.

    If pairing is complete, the player LED corresponding to the assigned controller number lights up.

    Info

    For more information about player LED lighting patterns, see the Nintendo Switch Controller Guide.
    If the Joy-Con still do not respond after completing this procedure, see 9.7 Unresponsive Joy-Con.
