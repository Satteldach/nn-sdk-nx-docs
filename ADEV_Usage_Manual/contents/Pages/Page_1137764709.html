7.3 Running Applications

You can use DevMenu to start applications that have been installed on the ADEV or written to an NX development card.

This section describes how to run and close applications.

Running Applications

  1. Turn the ADEV on.
    For more information about turning the ADEV on, see 5.2 Turning the ADEV On and Off.

  2. Check that the DevMenu Application screen appears.
    If the Application screen does not appear, select Application from the menu.

    A list of applications installed on the ADEV is displayed.

  3. Select the application to start.

    The selected application starts.

Closing Applications

  1. Press the HOME Button on the Joy-Con while the application is running.

    The DevMenu appears.

  2. Put the focus on the running application and click the Close button in the upper-right corner of the window.
    The following confirmation message appears: "Close the suspended software?"


  3. Select Close.
