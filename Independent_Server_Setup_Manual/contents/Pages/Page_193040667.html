9 Independent Server Operation

User Support

When managing accounts on an independent server, handle user support in either of the following ways so accounts can be identified on the independent server when users make inquiries.

  1. Use the number for customer support that can be checked on the Switch system.
    You can only use this method if the independent server associates users with network service accounts.
  2. Prepare a unique user identifier and display it inside the application.

Using the Number for Customer Support That Can Be Checked in the Switch System

About Support Numbers

The number for customer support (the support number) is an identification number that has an interchangeable, one-to-one relationship with the network service account ID (NSA ID).

The support number is a 21-digit number, with groups of four digits separated by hyphens. (Example: 0710-7470-7068-7643-0078-6)
The first 20 digits represent the internal ID of the network service account, and the final digit separated by a hyphen is the check digit.

The method for converting the support number to the NSA ID is described later on this page in Converting Support Numbers to Network Service Account Internal IDs.

Info

You can calculate the support number from the NSA ID, but the support number must not be displayed inside the application.

The support number is meant only for referencing the user on the Switch system.

Viewing the Support Number on the Switch System

To check the support number, go to the HOME Menu and select Settings > User > (if multiple users have been registered, select one) > Number for Customer Support.

Info

In system version 9.0.0 or later, the location where Number for Customer Support is displayed was changed to be shown below User Support.

Converting Support Numbers to Network Service Account Internal IDs

The network service account included in the support number is expressed as a decimal number. It is possible to compare this with the network service account's internal ID, which is obtainable from the NSA ID token, by converting the decimal number to a hexadecimal value.

For example, if the support number is 0710-7470-7068-7643-0078-6, 07107470706876430078 is converted to 62a2cef36edd36fe, which is the network service account's internal ID.

The check digit is generated from the first 20 digits of the support number using the modulus 10, weight 3 algorithm. To be specific, it is calculated using the following method.

  1. Assuming the rightmost position is odd, extract the odd number positions.
    1. Reading from the right, replace the even number positions in 0710-7470-7068-7643-0078 with X.
      X7X0-X4X0-X0X8-X6X3-X0X8
    2. Remove the hyphens (-) and Xs from the string in a.
      7040086308
  2. Again assuming the rightmost position is odd, extract the even number positions.
    1. Reading from the right, replace the odd number positions in 0710-7470-7068-7643-0078 with X.
      0X1X-7X7X-7X6X-7X4X-0X7X
    2. Remove the hyphens (-) and Xs from the string in a.
      0177767407
  3. Add up the odd position values requested in step 1, and multiply it by 3.
    (7 + 0 + 4 + 0 + 0 + 8 + 6 + 3 + 0 + 8) * 3 = 108
  4. Add up the even position values requested in step 2.
    (0 + 1 + 7 + 7 + 7 + 6 + 7 + 4 + 0 + 7) = 46
  5. Add up the values from steps 3 and 4.
    108 + 46 = 154
  6. Get the remainder after dividing the result from step 5 by 10, and subtract that remainder value from 10. (However, it is zero if the calculation result is 10.)
    10 - (154 mod 10) = 6
Info

The Ban Management System (BMAS) provided by Nintendo can also be used to convert the support number to a network service account internal ID. For more information about BMAS, see Nintendo Switch Online Play Guide.

Preparing an Unique User Identifier for Display Inside the Application

If your independent server uses identifiers other than the network service account internal IDs to manage users, consider providing your own unique user identifiers that can be used for support.

If you prepare your own unique identifiers, you must use the application to display those identifiers.

Supporting Bans (Measure for Stopping Use of Network Services)

The measure of stopping users from using network services is called a ban. For more information about bans, see Nintendo Switch Online Play Guide.

Banned users cannot get NSA ID tokens, so they cannot access independent servers either.
If you design your application so that the settings about the services provided by an independent server only can be changed from inside the application, remember that banned users cannot change those settings.
One way to deal with this limitation is to establish some avenue outside of the application for making contact. By using the previously mentioned support number, you can identify the network service account internal ID of the inquirer.
