7 Lotcheck

About Lotcheck

Lotcheck is the final testing process on the application that is performed by Nintendo. In principle, Switch applications must undergo the Lotcheck process and pass the tests before being released. Both the development hardware and a retail unit are used for this Lotcheck process, depending on the tests being performed. For more information, see the Nintendo Switch Lotcheck Procedures.

If the application being tested supports an independent server, the Lotcheck process also debugs the application including the server system before release. If you are developing an application that supports an independent server, you cannot use the production environment (lp1) to check how the application operates before its release. Nintendo's various server services are assured to work if they are used appropriately, but the application is responsible for ensuring that the independent server will work in the production environment and the other environments. Lotcheck includes a process that tests whether the logic for switching between independent server environments works correctly.

This testing uses the dedicated Lotcheck environments (sd1 and sp1), which cannot be provided to application developers. In the same way, debugging in the production environment prior to release is not possible because Lotcheck includes a test of the release of the independent server.

Preparing an Independent Server For Lotcheck

Nintendo uses two dedicated server environments for the Lotcheck process on applications. These environments are named sd1 and sp1.

When you submit your application for Lotcheck, first prepare an independent server that will run properly under both environments. Prepare this server before you submit your master ROM to Lotcheck. You can remove the server after your application has passed Lotcheck. Note: You must prepare an independent server for Lotcheck not just the first time you submit an application, but also when you test update data.

Note the following when preparing an independent server for Lotcheck.

  • If the submitted ROM passes Lotcheck, that ROM will be produced and shipped without any modifications. Avoid writing any special settings or processes for Lotcheck into your application.
    For example, do not submit a ROM where the application only accesses an independent server for Lotcheck.
  • We recommend restricting the access settings to the independent server using IP addresses and other methods so that there is no unexpected access during the Lotcheck process. At the same time, make sure that you allow Nintendo to access the independent server.
    The IP address used during Lotcheck is posted on the Nintendo support page for developers.
  • If you will be using an independent server for Lotcheck that has already gone live, make sure that users are not adversely affected by the access to the server from Nintendo.

Providing Access to Independent Servers When Switching Environments With DNS

Lotcheck accesses the independent server for several of the network tests on the submitted application. If the independent server connection target needs to be changed using DNS, complete either of the following procedures so Nintendo can access the independent server meant for Lotcheck during Lotcheck.

  1. Preparing a DNS Server That Can Be Used for Lotcheck
  2. Providing the Domain Name, IP Address, and CNAME Record for the Independent Server That Lotcheck Will Use

Enter this information for the product release in Features > Independent Servers > Name Resolution on the Nintendo Developer Portal.

Info

For the network services operated by Nintendo such as NEX/NPLN and Nintendo eShop, the libraries and system features connect to the appropriate environment according to the environment identifier set in the Switch system. For more information, see 6 Server Environments.

For this reason, there are usually no issues if you submit information specific to the independent server for the prepared DNS and record data.

For more information about the different methods, see the following sections.

Preparing a DNS Server That Can Be Used for Lotcheck

With this method you prepare a DNS server to enable appropriate access to the independent server and then submit the IP address for that DNS server to Lotcheck. Lotcheck then occurs, using that specified DNS server.

We recommend that you choose this method if preparing a DNS server is an option.

Note the following when using this method.

  • Are there restrictions for IP address access to that DNS server?
    • The list of global IP addresses used for Lotcheck is posted on the Nintendo support site. Enable access from those global IP addresses before Lotcheck begins.
  • Is the prepared DNS server recursive query set to a public DNS?
    • To use network features on Switch, you must be able to resolve the name of the Nintendo server.
    • The Nintendo server DNS record is not public, so configure a recursive query to the public DNS.

Providing the Domain Name, IP Address, and CNAME Record for the Independent Server That Lotcheck Will Use

Prepare a DNS server for changing the independent server that Lotcheck will connect to.

We will then add the domain name, IP address, or CNAME record for the independent server to the Nintendo DNS server, based on the information you submit.

Removing the Independent Server's IP Address Access Restrictions

If IP access restrictions are set for the independent server, make sure that you remove those access restrictions for the global IP addresses used by Lotcheck before the Lotcheck process begins. The list of global IP addresses used for Lotcheck is posted on the Nintendo support site.

Also note that connections to independent servers will be made from Japan, the United States, and Germany for Lotcheck.

Potential Problem

In the past, there were cases where an independent server was shut down for maintenance during the Lotcheck process without prior notification. The Lotcheck process encompasses regions outside of the region in which the Lotcheck documentation was submitted. Inform Nintendo well in advance when maintenance is planned.
