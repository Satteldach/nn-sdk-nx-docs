5.8 Account API

Always run the account functions from an independent server.

User API

This API is used to get profiles for accounts for China.

Requested Domains

Set the account for China environment for which to get the profile as the request destination for the account API. Use the iss value for the ID token to identify the environment of the account for China.

Environment Identifier Requested Domains
td1 -
jd1 jd1-api.accounts.nintendoswitch.com.cn
dd1 dd1-api.accounts.nintendoswitch.com.cn
dp1 dp1-api.accounts.nintendoswitch.com.cn
sd1 sd1-api.accounts.nintendoswitch.com.cn
sp1 sp1-api.accounts.nintendoswitch.com.cn
lp1 api.accounts.nintendoswitch.com.cn

Request Specification

HTTP Method/Path
HTTP method GET
Path /2.0.0/users/me
Request Parameters
Item Required? Description
Authorization Y

Bearer access token.

Response Specification

The response is returned in application/json format. If the request succeeds, the following properties are returned in the response.

Item Type Required Permission Description
id string -

The internal ID of the account for China.
This ID is unique within accounts for China (but uniqueness across server environments is not ensured). It never changes.

country string user.basic

The user's country of residence. The format is ISO 3166-1 alpha-2.

Fixed as CN for accounts for China.
language string user.basic

The language used by the user.
Indicated by the Locale value (a hyphenated value comprising the language code, represented in IS 639-1, connected by a hyphen (-) to the country code, represented in ISO 3166-1 alpha-2).

Fixed as zh-CN for accounts for China.
timezone object user.basic

The user's time zone. It includes the following information.

  • id: Expressed as a string (such as"Asia/Shanghai").
  • name: Expressed as a string (such as"Asia/Shanghai").
  • utcOffsetSeconds: Value that indicates the UTC offset in seconds.
  • utcOffset: Value that indicates the UTC offset.
gender string user.basic

The user's gender.

  • unknown (Not registered)
  • male
  • female
birthday string user.birthday

The user's date of birth. The format is YYYY-MM-DD.

Accounts for China have the information of year and month only, and the value of day (DD) contains dummy information.

Sample

GET /2.0.0/users/me HTTP/1.1
Host: dd1-api.accounts.nintendoswitch.com.cn
Authorization: Bearer ey...
 
HTTP/1.1 200 OK
Content-Type: application/json; charset=UTF-8
{
    "id": "89d19564ae22a3ff",
    "language": "zh-CN",
    "birthday": "1988-07-31",
    "country": "CN",
    "gender": "male",
    "timezone": {
        "utcOffsetSeconds": 28800,
        "name": "Asia/Shanghai",
        "id": "Asia/Shanghai",
        "utcOffset": "+08:00"
    }
}

If the request fails, the following error is returned.

Item Description
status HTTP Status Code
errorCode
Value Description
invalid_token Error that occurs if the access token is invalid or has expired.
insufficient_scope Error that occurs if an attempt is made to do something for which permission has not been granted.
detail

Text describing the content of errorCode.
