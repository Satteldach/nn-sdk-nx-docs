10.1 Authorization Page: Sample of the Authorization Management Page

Information submitted when the usage request was made is displayed to the user in the authorization page and the authorization management page. The following shows how the sample image and submitted information is displayed on the authorization page and the authorization management page.

Number in the Image Description
1 The name of the application.
2 The application logo.
3

Shows the following information.

  • Company or developer name
  • Location of the company or developer
  • Application URI
4

Displays a list of the permissions used.
The user cannot edit the mandatory items.
5

Displays how the information is handled.
If a privacy policy URI or EULA URI has been submitted, an authorization page for PC browsers links to them.
