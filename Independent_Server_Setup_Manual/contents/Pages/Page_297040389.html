10.4 Countries of Residence Allowed for Nintendo Accounts


Info

When an application policy is All Features Require Membership, the independent server is accessed only from accounts residing in countries in the table where Switch Online Membership is ○.

When an application policy is No Features Require Membership or Some Features Require Membership, the independent server is accessed from accounts residing in all countries that can be configured in Nintendo Accounts.

However, when an account residing in a country where Switch Online Membership is not ○, and connects to an independent server from an application where the application policy is Some Features Require Membership, the information (nintendo.hm) included in the NSA ID token for whether the account has a Switch Online membership is always false.

Country codes are based on the ISO 3166 standard.
