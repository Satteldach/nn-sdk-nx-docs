1 Introduction

Purpose and Content

This document describes the procedure for configuring independent servers for Nintendo Switch™ (Switch) and how to link independent servers to the network services provided by Nintendo.

The term independent server refers to a server that is not provided by Nintendo but to which applications on the Nintendo platform can connect. It is configured and operated independently.


Intended Audience

This document is primarily intended for server developers. Some content is also intended for planners and developers of Switch applications.

When to Read This Document

Read this document when configuring a game server that provides independent services for a Switch application.

Related Documents

This document contains information about communication and e-commerce features available on the Switch platform. Before reading this document, see the Nintendo Switch Overview, which presents an overview of these features.

Also, the Nintendo Switch Account Guide provides an overview of accounts on Switch. Before reading this document, see the Nintendo Switch Account Guide.

You basically need an independent server to implement the mechanism for service items provided by Nintendo. For more information about implementing the service item mechanism in your application, see this document and the Nintendo Switch E-Commerce Guide.
