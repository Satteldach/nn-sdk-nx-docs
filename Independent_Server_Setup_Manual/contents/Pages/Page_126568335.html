4 Linking With Nintendo Accounts

This section describes linking with Nintendo Accounts.

A mechanism provided with Nintendo Accounts complies with OAuth2.0 (RFC 6749) and OpenID Connect for authenticating and authorizing external services.
External services can use the Nintendo Account linking feature to realize plans like those described in 4.1 Implementable Plans.
Note that this process of linking external services with Nintendo Accounts is optional and not required if only network services will be provided on the Switch.
In addition, linking with Nintendo Accounts in this way does not substitute for the authentication mechanism described in 3 Connecting to an Independent Server. Regardless of whether linking with a Nintendo Account is supported, if the Switch application uses an independent server, you must support authentication using the NSA ID token.

Info

This feature is available for applications outside the China market. For applications for China, see 5 Linking With Accounts for China.
