4.7 API Reference

Provided API

This page describes the API specifications provided by Nintendo Accounts. All of the APIs described here are run from the independent server. Requests are made to two types of domains.

API

 Description Requested Domains

4.7.1 Authorization Requests

These are requests to perform the procedure for user authorization. This description is about authorization for web applications. If the application type is Switch, see NintendoSDK Documents.


 accounts.nintendo.com

4.7.2 Token Requests

A request to get an access token or an 4.7.3 ID Tokens.


 accounts.nintendo.com

4.7.4 Account API

This API is used to get Nintendo Account profiles.


 api.accounts.nintendo.com

4.7.5 API for getting the history for canceling user authorization

The API for getting the user authorization cancellation history.


 accounts.nintendo.com
4.7.6 ID Conversion API

The API for converting NAID to PPID. For more information, see 4.6 Migration From NAID to PPID.


 accounts.nintendo.com
