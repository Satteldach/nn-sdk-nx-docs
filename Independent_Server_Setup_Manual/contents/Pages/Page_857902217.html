5.2 Authorization Page: Sample of the Authorization Management Page

The information submitted when the use request was made is displayed to the user in the authorization page and authorization management page. The following shows how the sample image and submitted information is displayed on the authorization page and the authorization management page.

Number in the Image Description
1 The name of the application.
2 The name of the application logo.
3

Displays the following information.

  • Company or developer name
  • Location of the company or developer
  • Application URI
4

Displays a list of the permissions used.
The user cannot edit the mandatory items.

Authorization Management Page for Nintendo Switch
