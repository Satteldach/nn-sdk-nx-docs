4.7.1 Authorization Requests

Request Specification

HTTP Method/Path
HTTP method GET
Path /connect/1.0.0/authorize
Request Parameters
Item Specification Method Required? Description
client_id query Y

Specifies the client ID issued by Nintendo. A different ID is issued for each server environment.
response_type query Y

Represents the response format of the authorization request. You can specify multiple parameters separated by spaces.
If either token or id_token is included in the format, the authorization response is returned as a URL fragment.

Value Description
code Indicates that the authorization response contains an authorization code.
token Indicates that the authorization response contains an access token.
id_token Indicates that the authorization response contains an ID token.
scope query Y

Represents the scope requested for authorization. More than one parameter can be specified by separating them with spaces. You must have prior approval from Nintendo to use scope.
redirect_uri query Y

Specify the preregistered URL-encoded URL redirect.
This redirect_uri must exactly match the value that was submitted. An error occurs if you add or modify a path or query.
state query Y

Set to the null character or a string. You cannot simply omit the parameter.
The same state value that came with the authorization request is contained in the authorization response, unmodified.
It can be used as a measure against CSRF attacks and to maintain the context before and after the authorization request.
nonce query N

Optional parameter that can be added.
The same nonce value that came with the authorization request is contained in the id_token, unmodified.
It is used to prevent replay attacks when an ID token is obtained as the result of the authorization request.

For Switch Applications

Authorization requests from Switch applications use the nn::account::CreateNintendoAccountAuthorizationRequest function. For more information, see NintendoSDK Documents.
The following table shows the request parameters for requests made by Switch applications.

Property Description
client_id

For Switch applications, the client_id associated with the application ID is resolved automatically, so it does not need to be specified.
response_type For Switch applications, code id_token is specified automatically.
scope

Specify the range for which authorization is requested.
redirect_uri

Resolved automatically for Switch applications so it does not need to be specified.
state

Specify any value.
nonce Specify any value.

Response Specification

If the authorization request is successful, the response is returned as a redirect to the specified redirect URI.
If response_type=code, the authorization response is included as a query string.

GET /connect/1.0.0/authorize?client_id=0123456789abcdef&nonce=nonce&redirect_uri=http%3A%2F%2Flocalhost&response_type=cod&scope=user.basic%20user.birthday%20user.email%20user.links.nintendoNetwork.id%20openid%20offline&state=state HTTP/1.1
Host: e97b8a9d672e4ce4845ec6947cd66ef6-sb.accounts.nintendo.com
 
HTTP/1.1 302 Found
Location: http://localhost?session_state=db..&state=..&code=ey..

If token or id_token is included in response_type, the authorization response is included as a URL fragment.

GET /connect/1.0.0/authorize?client_id=0123456789abcdef&nonce=nonce&redirect_uri=http%3A%2F%2Flocalhost&response_type=code%20id_token%20token&scope=user.basic+user.birthday%20user.email%20user.links.nintendoNetwork.id%20openid%20offline&state=state HTTP/1.1
Host: e97b8a9d672e4ce4845ec6947cd66ef6-sb.accounts.nintendo.com


HTTP/1.1 302 Found
Location: http://localhost#session_state=db..&state=..&code=ey..&access_token=ey..

If the authorization request succeeds, the following properties are included in the response.

Item Description
code

The authorization code used to get an access token. Included when response_type=code is specified.
id_token

The ID token for authenticating the user. Included when response_type=id_token is specified. It can only be obtained when scope=openid has been specified.
access_token

The token for accessing the account API. Included when response_type=token is specified.
token_type The format of the access token. Fixed to Bearer.
expires_in Represents the period of validity of the ID token or access token.
state

The state value specified when the authorization request was made.
session_state

A string that transparently indicates the state of the login session issued by the Nintendo Account.

scope

A list of the user-authorized scope values included among the values specified in the authorization request.

If the authorization request fails, the response is returned as a redirect to the specified redirect URI. In addition, the following error information returns as a query string.

Item Description
error
Error Codes Description
unauthorized_client Error that occurs when the specified response_type is invalid.
consent_required Error that occurs if the user rejects authorization.
invalid_scope

Error that occurs when an invalid scope has been specified.
access_denied Generic error indicating failure of the authorization request.
error_description

Text describing the error item.
state

The state value specified when the authorization request was made.

If the specified redirect URI is invalid or the redirect is otherwise not possible, the response is the error page with the content of the error.
