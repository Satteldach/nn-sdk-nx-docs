3.3 Nintendo Switch Online Support

Nintendo Switch Online

Nintendo Switch Online is a paid online service provided by Nintendo.

For an overview of Nintendo Switch Online, see Nintendo Switch Overview. For more information about supporting Nintendo Switch Online when developing Switch applications, see the Nintendo Switch Online Play Guide and the Nintendo Switch Guidelines, in addition to this document.

On OMAS, services provided by independent servers are automatically determined to be services that require a Nintendo Switch Online membership. However, you can submit a change request on OMAS for the target feature, and if this request is approved, all or some of the services provided by the independent server can be provided as services that do not require a Nintendo Switch Online membership.

Applications with online play are classified into three categories: All features require membership, No features require membership, or Some features require membership. This classification is called the application policy. For more information about these classifications, see the Nintendo Switch Online Play Guide.

Information About Nintendo Switch Applications for China

It is undecided whether a paid online service equivalent to Nintendo Switch Online will be offered for the China platform region.

In the meantime, follow the same application policy as for Nintendo Switch consoles for other regions to determine whether an NSA ID token can be obtained and the specifications that apply.

Because Nintendo Switch systems for China cannot join Nintendo Switch Online, submit a request in OMAS to change the application policy to No features require membership.

All Features Require Membership

If the application policy is All features require membership and the user has not subscribed to Nintendo Switch Online, NSA ID tokens cannot be obtained in the Switch application.

The provision of services is determined based on whether an NSA ID token can be obtained, so no special handling is required by the independent server.

For more information, see the Nintendo Switch Online Play Guide.

No Features Require Membership

When the application policy is No features require membership, NSA ID tokens can be obtained in the Switch application regardless of whether the user has subscribed to Nintendo Switch Online.

No special handling is required by the independent server because there is no need to determine whether to provide services based on the Nintendo Switch Online membership status.

For more information, see the Nintendo Switch Online Play Guide.

Some Features Require Membership

When the application policy is Some features require membership, special handling according to the user's membership status is required by both the independent server and the Switch application.

Note the following when using an independent server together with a game server (NEX or NPLN).

  • In some cases, the application policy is Some features require membership even if all of the services provided by the independent server involve a Nintendo Switch Online membership.
    • This can be the case when the NEX/NPLN services do not require a Nintendo Switch Online membership.
    • Because the application can get NSA ID tokens in such cases, the user's Nintendo Switch Online membership status must be determined.
  • In some cases, the application policy is Some features require membership even if none of the services provided by the independent server involve a Nintendo Switch Online membership.
    • This can be the case when the NEX/NPLN services require a Nintendo Switch Online membership.
    • Although the application policy is Some features require membership, the ability to get an NSA ID token can be used to determine whether all services can be provided.

NSA ID Token Specifications

When the application policy is Some features require membership, the NSA ID token for that application includes the following properties.

Element Type Obtainable Value Description
nintendo.opp string Fixed as MEMBERSHIP_REQUIRED.

A value representing policy information about whether a Nintendo Switch Online membership is required for online play.
nintendo.ph string Fixed as GAME_SERVER.

Information representing where the determination is made whether to provide services based on Nintendo Switch Online membership status.

When this element exists and has the value GAME_SERVER, it might be necessary to make the determination on the independent server side.

If the independent server is being used in combination with NEX/NPLN, it might not be necessary for determination to be made by the independent server. For more information, see Nintendo Switch Online Play Guide > Nintendo Switch Online > Application-Level Support > Some Features Require Membership.
nintendo.hm bool true or false

A value representing whether there is a subscription to Nintendo Switch Online.

For more information about Nintendo Switch Online memberships in the development environment, see Nintendo Switch Online Play Guide > Nintendo Switch Online Support > Application-Level Support > Use in a Development Environment.

Handling by the Independent Server

Based on the preceding information, perform handling for providing member-only services on the independent server using the following steps.



  1. Determine the nintendo.ph value of the NSA ID token.
    • When there is no nintendo.ph value or if the value is something other than GAME_SERVER.
      • Determine that all services can be provided.
    • If a nintendo.ph value exists and matches GAME_SERVER, move to the next judgment.
  2. Determine the nintendo.hm value of the NSA ID token.
    • When the nintendo.hm value exists, and it is true.
      • Determine that all services can be provided.
    • When the nintendo.hm value exists, and it is false.
      • Return an error to the client and prompt the user with a notification when receiving a use request for a service that requires a Nintendo Switch Online membership.
      • If the service does not require a Nintendo Switch Online membership, determine it to be available.
    • When the nintendo.hm value is blank, or is a value other than true or false.
      • Handle it as a thrown exception.

This handling method has the following advantages.

  • If a single independent server is shared between applications with some services exclusive to subscribers, and applications with all services either available or not available to subscribers, there is no need to change the logic for determination.
    • For applications with some services exclusive to subscribers, handling based on membership status can be performed by determining the nintendo.hm value.
    • For applications with all services either available or not available to subscribers, all services can be determined to be available by determining that the nintendo.ph value does not exist. Also, for applications with all services exclusive to subscribers, the NSA ID token itself cannot be obtained when there is no Nintendo Switch Online membership.

Handling in Applications

If it is determined on the independent server that a service cannot be provided because the user is not a member of Nintendo Switch Online, make a notification of that fact in the Switch application.

Make this notification using nn::account::ShowLicenseRequirementsForNetworkService(). This function is available in NintendoSDK NX Add-On 4.4.0 and later.

Call nn::account::ShowLicenseRequirementsForNetworkService() to enable a jump to the purchase page for Nintendo Switch Online membership on Nintendo eShop. In the development environment, Nintendo Switch Online memberships are not sold on the real Nintendo eShop, so if you want to check the behavior for the return value indicating a successful purchase (nn::ResultSuccess), use the EC test applet. You do not need the EC test applet to check the cancellation of a purchase (nn::account::ResultCancelledByUser).

Currently, the Nintendo Switch Online information page is not displayed if nn::account::ShowLicenseRequirementsForNetworkService() is called while the user is a member of Nintendo Switch Online.


Confirming Purchase Success (nn::ResultSuccess)

  1. Using either DevMenu or DevMenuCommand, change the shop that runs on the development hardware to the EC test applet (Dev Shop).
  2. Call nn::account::ShowLicenseRequirementsForNetworkService() from within the application.
  3. Start the EC test applet and, with that applet running, use the Nintendo Switch Online Membership Manager to grant a license to Nintendo Switch Online.
    • For more information about the Nintendo Switch Online Membership Manager, see the Nintendo Switch Online Play Guide.
  4. In the EC test applet, press the A Button to end the applet.
    • nn::ResultSuccess is returned to the application.
Info

Do not determine that a user is a member of Nintendo Switch Online based on the return of nn::ResultSuccess by the nn::account::ShowLicenseRequirementsForNetworkService() function. Instead, re-acquire the NSA ID token and reevaluate the membership status based on the value of nintendo.hm in that NSA ID token.

Confirming Purchase Cancellation (nn::account::ResultCancelledByUser)

nn::account::ResultCancelledByUser is returned to the application when any of the following actions occur after calling nn::account::ShowLicenseRequirementsForNetworkService() from within the application.

  • The applet is terminated without jumping to Nintendo eShop from the Nintendo Switch Online subscription information screen that appears when calling nn::account::ShowLicenseRequirementsForNetworkService().
  • The B Button is pressed in the EC test applet to end the applet (if the shop that is running on development hardware is the EC test applet).
  • Nintendo eShop is terminated as is, after starting when the real Nintendo eShop is the shop that starts on development hardware.
