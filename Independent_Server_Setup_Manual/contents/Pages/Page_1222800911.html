4.7.6 ID Conversion API

Request Specification

HTTP Method/Path
HTTP method GET
Path /connect/1.0.0/api/ppid/encode
Request Parameters
Item Specification Method Required? Description
Authorization header Yes

The Bearer access token (grant_type=client_credentials).

ppid:encode must be allowed as a scope value.

With the ppid:encode scope, permission is granted across the board to all clients, so there is no need to submit a usage request.
ids query Yes

Specifies the NAID to convert.

Use commas to delimit multiple IDs. The maximum number of IDs that can be specified in a single request is 100.

Response Specification

The response is returned in application/json format. If the request succeeds, the following properties are returned in the response.

Item Type Description
items array

You can use an array of pairs of publicId (unique NAID shared among clients) and pairwiseId (PPID that is unique only within the client).

Item Type Description
publicId string

Represents the NAID.
pairwiseId string

Represents the PPID.
sectorIdentifier string

Represents the partition range of the PPID ID space. This string normally contains the client ID value.

Sample

GET /connect/1.0.0/api/ppid/encode HTTP/1.1
Host: e97b8a9d672e4ce4845ec6947cd66ef6-sb.accounts.nintendo.com
Authorization: Bearer ey...
 
HTTP/1.1 200 OK
Content-Type: application/json; charset=UTF-8
{
    "items": [
        {
            "publicId": "e8745dc0d6a1262f",
            "pairwiseId": "003HQLKCT4JSX5QVDYRUUSPPMBYQ"
        },
        {
            "publicId": "780c99cb9d740e56",

        }
    ],
    "sectorIdentifier": "d7182b68b11e2bee"
}

The following error is returned if the request fails.

{
  "status": 401,
  "title": "Unauthorized",
  "type": "https://accounts.nintendo.com/problems/unauthorized",
  "instance": "https://accounts.nintendo.com/connect/1.0.0/api/ppid/encode?ids={ids}",
  "detail": "Unauthorized"
}
Item Description
status The HTTP status code.
Title Title indicating the content of the error.
type

The error type.
instance Contains the request URI value.
detail

Text describing the details of the error.
