5 Linking With Accounts for China
Note

Due to revisions to the law concerning the protection of personal information, Nintendo has temporarily stopped accepting usage requests for linking with accounts for China.

This section describes linking with accounts for China.

A mechanism provided with accounts for China complies with OAuth2.0 (RFC 6749) and OpenID Connect for authenticating and authorizing external services.

This process of linking external services with accounts for China is optional and not required if only network services will be provided on the Switch.

In addition, linking with accounts for China in this way does not substitute for the authentication mechanism described in 3 Connecting to an Independent Server. Regardless of whether linking with an account for China is supported, if the Switch application uses an independent server, you need to support authentication using the NSA ID token.

Info

This feature is only available for applications for the China market. For applications for non-Chinese regions, see 4 Linking With Nintendo Accounts.
