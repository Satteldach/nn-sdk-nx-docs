2 Overview

Network Service Accounts and Nintendo Accounts

The Switch network system uses two accounts: the network service account and the Nintendo Account. For more information about these different accounts, see the Nintendo Switch Account Guide.

The Nintendo Account is explicitly created by the user and is used not only by Switch but also by smart device applications and multiple services like My Nintendo.

The network service account is created automatically when a Nintendo Account is linked on a Switch device, and is used to identify users when using network services on the Switch.

Independent servers generally identify users on a Switch by network service accounts and provide services accordingly. The service for linking Nintendo Accounts, described later, is an optional feature. It provides a way to use the Nintendo Account information and to share the user's data across platforms.

Network service accounts and Nintendo Accounts are different accounts, so you must consider the following points.

  • The internal IDs used to identify accounts are different.
    Web services used from PC browsers and the like cannot get the internal IDs of network service accounts. As a result, if you want to share user data between a Nintendo Switch application and a web service, the Nintendo Account linking service must be supported both on Switch and the web service.
  • There is no way to ensure that the network service account and the Nintendo Account associated on the independent server are held by the same individual.
    There is a 1:1 relationship between network service accounts and Nintendo Accounts, but that information is not available to the independent server. In addition, the associations between network service accounts and Nintendo Accounts can be removed and changed by operations by Nintendo.
    For these reasons, if your independent server will associate network service accounts with Nintendo Accounts, note that the Nintendo Account associated with a network service account might at some point be removed or changed.
    To deal with associations made in error between network service accounts and Nintendo Accounts, we recommend adding the functionality to unassociate and reassociate the Nintendo Accounts associated with users managed on the independent server.

Information About Nintendo Switch Applications for China

Nintendo Switch consoles for China use a different account system than Switch for other regions.

Nintendo Switch consoles for China cannot link with Nintendo Accounts. Nintendo Switch consoles for China must log in to a WeChat (messenger application) account to use network services. A network service account identical to the account on Nintendo Switch systems for other regions is created at this time.

Services for Independent Servers

This document describes the following two services, which are provided for independent servers.

Authentication Service for Switch Network Service Accounts

The authentication service for network service accounts for Switch (hereafter authentication service) ensures the validity of the Switch client connecting to the independent server.

The authentication service is implemented by authenticating, with the independent server, the NSA ID token obtained from the Switch application. As a result, it must be supported by both the Switch application and the independent server.

When using an independent server, the NSA ID must be obtained in the application according to the guidelines. Sending the NSA ID token to the independent server and authenticating it is not mandatory, but it is strongly recommended.

The NSA ID contains the ID for identifying the user (network service account). Use this ID to provide the appropriate service based on the user.

For more information about the authentication service, see 3 Connecting to an Independent Server.

Linking Service for Nintendo Accounts and Accounts for China

The linking service for Nintendo Accounts and accounts for China is a service that provides functionality to application-specific services to do things like sign in with these accounts and obtain profile information.

For more information about the plans and features that you can implement, see these following sections.

  • 4 Linking With Nintendo Accounts
  • 5 Linking With Accounts for China

The account linking service is an optional feature, and if it is not needed to implement plans, you do not need to support it.

You must support the authentication service to use the account linking service in a Switch application. Note that the account linking service is not a replacement for the authentication service.

Nintendo Platform Server Environments

Server services provided by Nintendo platforms exist in multiple environments.

The development-specific environment called dd1 is used during development, but the service provided to users in the production environment is called lp1 when the product is released. In addition, specialized environments (sd1, sp1) are also used during Lotcheck (the final inspection for products at Nintendo).

The independent server provides services for appropriate environments based on the timing at which these environments are used.

For more information, see 6 Server Environments, 7 Lotcheck, and 8 Independent Server Development.
