3.1 Authentication Mechanism

When connecting to an independent server, authentication is performed using the NSA ID token issued from the Nintendo authentication server.

NSA ID tokens assure external servers that not only the network service account but also the device and the application have been properly authenticated. In addition, you can provide services to users by decoding these NSA ID tokens to get the IDs that identify the network service accounts (the network service account internal IDs).

When an application requests an NSA ID token, that NSA ID token must pass through Nintendo authentication before it is issued. As a result, the application can handle the result of authentication based on the response to the NSA ID token issue request.

In addition, NSA ID tokens are signed by Nintendo, so the independent server can verify that the connecting party is a properly authenticated client by verifying the NSA ID token sent from the connecting application.

Conditions for Obtaining NSA ID Tokens

For an application to obtain an NSA ID token, it must satisfy the following conditions. If the conditions are not satisfied, an error occurs and you cannot obtain the NSA ID token.

  • A request for the relevant application was sent through OMAS, and that request was approved.
    • If this condition is not satisfied, Error 2124-4606 occurs.
  • The target sales region set for the applicable release in Nintendo Developer Portal and Nintendo Switch console platform region are an acceptable combination.
    • If this condition is not satisfied, the following errors occur.
      • 2124-4621 (for system version 9.1.0 and later)
      • 2124-7400 (for system version prior to 9.1.0)
Info

The platform region is the region where the system is used, set for the system itself. There are currently two platform regions: Global and China. For more information, see NintendoSDK Documents.
In the production environment, Nintendo Switch consoles sold for China are configured with China as the platform region, and Nintendo Switch systems sold for other regions are set to Global.

Information About Nintendo Switch Applications for China

The network service account internal ID linked to Nintendo Switch consoles for China does not overlap with any network service account internal ID linked to Nintendo Switch consoles for other regions. As a result, the network service account internal ID is unique across Nintendo Switch consoles for China and other regions.
