5.3 Usage Requests
Note

Due to revisions to the law concerning the protection of personal information, Nintendo has temporarily stopped accepting usage requests for linking with accounts for China.

Making a Request

If you want to link with accounts for China, you must make a request through Nintendo. Email the information in Requests to Nintendo support using the following link.

  • https://developer.nintendo.com/group/development/contact
    • Refer to the Nintendo support contacts listed under Development Questions and use the contact that corresponds to the region for you, the developer.
Info
  • Unlike the Nintendo Account linking requests, the requests to link accounts for China are not supported on OMAS.
  • Before making a usage request to Nintendo, submit a request for the target application in OMAS. This request must be submitted in OMAS because the application must be registered on Nintendo's authentication server to enable the link with account for China feature.
  • The feature for linking an account for China is currently only available for Switch applications. In the future, it will also support web applications and smart device applications.

About the Client ID and Client Secret

If the request is accepted, Nintendo will issue a client ID and client secret.
Keep this information in a safe place because it is required for linking with accounts for China.
Different values are issued for the client ID and client secret for each Nintendo platform server environment. Note that it is necessary to use a different client ID and client secret than used for development for Lotcheck and release.

Info

Nintendo and Tencent (the company that manages the WeChat accounts required for creating an account for China) review the content of the request prior to issuing a client ID and client secret. Submit your request well in advance, because the review process may take some time.

Sharing Link Settings

The settings for the feature of linking with accounts for China can be shared across all applications. Alternatively, the settings can be shared among multiple applications. When making the request, consider sharing the settings in the way that works best for the provision of services.

The following types of cases can be considered as examples.

  • Using shared settings in Switch applications belonging to a series
  • Linking accounts unique to the development company to accounts for China, and enabling login with accounts for China to those independent accounts from multiple Switch applications released by that company

The following table shows the differences between sharing and not sharing the settings for linking accounts for China.

  • It is not possible to share link settings between Nintendo Accounts and accounts for China.

Prohibitions

Prohibition of Saving Client IDs and Client Secrets to a Switch Application

Nintendo Switch applications do not need to handle client IDs or client secrets during the authorization sequence for Nintendo Switch applications.

Because of the security issues, it is prohibited to save client IDs or client secrets within a Switch application. It is also prohibited not only to embed client IDs and client secrets within the code of a Switch application but also for Switch applications to get that data from a network.
