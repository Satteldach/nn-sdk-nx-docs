4.1 Implementable Plans

Independent servers can use the Nintendo Account linking feature to implement plans such as the following.

Signing In Using Nintendo Accounts

This feature provides the independent server with the functionality for signing in using Nintendo Accounts. With this feature, users can be safely authenticated without the need to independently manage user IDs and passwords. Nintendo Accounts can be used to sign in users not only from Switch, but also from PC browsers and smart device browsers. However, the Nintendo Account linking feature is not authorized for use in projects that are unrelated to Switch applications.

Using APIs Provided by Nintendo Accounts

This feature provides the independent server with Nintendo Account-based API resources. You can use the API to get registered information for Nintendo Accounts.
