4.2 Usage Requests

Making a Request

To use the Nintendo Account linking feature, submit a Nintendo Account linking request on OMAS. For more information about OMAS, see the OMAS2 Manual. Nintendo reviews usage requests. The review process can take time, so submit your request well in advance. If the request is approved, a client ID and a client secret will be issued.

To change the content of the request, for example to add a scope value or a redirect URI, edit the submitted request and resubmit it. Nintendo will then review the request again based on the changes. Note that the contents of the request are updated when re-review is approved, including for the production environment. If you have any requirements for the timing, contact Nintendo separately.

Sharing Link Settings

The settings for the Nintendo Account linking feature can be shared across application types. Alternatively, the settings can be shared among multiple applications. When making the request, consider sharing the settings in the way that works best for the provision of services. The following types of cases can be considered as examples.

  • Standardizing settings when there is a web application that links to a Switch application
  • Using shared settings in Switch applications belonging to a series
  • Linking accounts unique to the development company to Nintendo Accounts, and enabling signing in with Nintendo Accounts to those independent accounts from web applications and multiple Switch applications released by that company.

The following table shows the differences between sharing and not sharing the settings for the Nintendo Account linking feature.

Item When Settings Are Shared When Settings Are Not Shared
Client ID/secret

For applications that share settings, a common client ID and secret can be used in each separate environment.

 A separate ID is issued for each application and application type.
User authorization agreement If approval has been granted to any application or application type where the settings are shared, approval is also granted to the other applications and application types. Approval is required for each application and application type.
List of services displayed on the Nintendo Account authorization management page Displayed as a single service for applications and application types with shared settings. Displayed as an approved service for each application and application type.

Settings for services

(such as name, logo image, and scope of permissions)

 Settings are standardized for applications and application types that share settings. The settings can be changed for each individual application and for each type of application.
Note

When you support authorization from multiple applications and application types that do not share settings on a single independent server, that independent server manages multiple client IDs and secrets for one environment. Note that if some settings are incorrect, authorization might not be performed appropriately.

Review and Approval

Nintendo reviews the contents of the request. During the review process, Nintendo might request additional information or ask questions about the content of the request. If the review finds no issues with the content of the request, the use of the feature is approved.

The Nintendo Account linking feature is only provided when it is required for services related to Switch applications. For this reason, it will generally not be approved for use in cases such as the following.

  • The feature will be incorporated into programs (middleware) created for provision to an unspecified number of developers.
    (It is all right for the application developer to subcontract an outside company to create a program that will be incorporated into its own application.)
  • The Nintendo Accounts will be used for signing in to websites unrelated to applications sold on Switch.

About the Client ID and Client Secret

If the request is approved, a client ID and a client secret is issued by Nintendo. This information can be checked on OMAS inside the approved Nintendo Account Linking Request.

Info

The only people who can check the Nintendo Account Linking Request information are the user who made the request and the designated Company Administrator in that user's company.

One set of client ID and client secret is issued for each Nintendo platform server environment. Keep this information in a safe place because it is required for linking with Nintendo Accounts. Different values are issued for the client ID and client secret for each Nintendo platform server environment. Note that it is necessary to use a different client ID and client secret than used for development for Lotcheck and release.
