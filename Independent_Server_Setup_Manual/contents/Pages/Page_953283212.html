4.3 Presentation of the Nintendo Account

Presentation of Nintendo Account (in Switch Applications)

The guidelines prohibit the use of the term "Nintendo Account" in Switch applications. For more information, see Nintendo Switch Guidelines > 0208: Prohibition of using Nintendo Account-related terms.

Presentation of Nintendo Account (in External Services)

Avoid the use of the term "Nintendo Account" as much as possible in external services that are accessed via computer or smart device. If you cannot avoid some kind of reference to Nintendo Accounts, for example because you are providing a service that users can sign in to using their Nintendo Account, comply with the following information.
As a general rule, the Nintendo Account can be presented in either of the following ways.

  1. Using only text, such as "Nintendo Account" or "Sign In"
  2. Using the Nintendo corporate logo

If you need to present the Nintendo Account differently, contact Nintendo at https://developer.nintendo.com/group/development/contact.

Presenting Only Text, Like "Nintendo Account" or "Sign In"

This method is for cases where the user interface has a link for signing in using a Nintendo Account, and that link is either a text link or an image that contains only text. If the link includes a logo or another non-text element, see the section about using a Nintendo corporate logo.

If users are not explicitly told that they will be signing in using their Nintendo Account, make sure that you present the "Nintendo Account" text. If it is clear that the Nintendo Account will be used to sign in, it is acceptable to only present the "Sign In" text.

Representing "Nintendo Account" with another name, such as "Nintendo," is prohibited.

Using the Nintendo Corporate Logo

There is no special icon or logo for the Nintendo Account.
However, if you want to use a logo for the user interface for signing in with a Nintendo Account, you can use the Nintendo corporate logo, as described later. (You must consult with Nintendo and get its approval to use this logo.)

For each separate service in which you want to use the Nintendo corporate logo, contact Nintendo at https://developer.nintendo.com/group/development/contact.

If Nintendo determines that the use of a logo would be visually easier to understand, the company will provide its Nintendo corporate logo along with guidelines for its use.

An example is the case where a service supports signing in using multiple external accounts, and not just the Nintendo Account. However, even in this case, Nintendo might decide to not approve the use of its corporate logo after a comprehensive investigation.

Note

Incorporating Nintendo corporate logos obtained from places like the Nintendo official website in your services without the permission of Nintendo is prohibited.

Corporate Logo Provided by Nintendo

If Nintendo has approved the provision of its corporate logo, the following data is provided.

  • Logo image data (in AI file format)
  • Guidelines for using logo images
Note
  • You must comply with the guidelines for using logo images.
  • Discard the logo data and guidelines when your service has finished using the logo.
  • Using the logo data and guidelines in multiple services is prohibited. Make a separate request for each service in which you want to use the logo data.
