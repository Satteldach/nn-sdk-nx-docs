4.7.5 API for getting the history for canceling user authorization

Request Specification

HTTP Method/Path
HTTP method GET
Path /api/1.0.0/unauthorized_histories/{client_id}
Request Parameters
Item Specification Method Required? Description
Authorization header Yes

The Bearer access token (grant_type=client_credentials).
unauthorizedHistory:anyUsers must be allowed as a scope value.
With the unauthorizedHistory:anyUsers scope, permission is granted across the board to all clients, so there is no need to submit a usage request.
client_id path Yes The target client ID.
count query No

Specifies the maximum number of items to get per page. The default is 50. The maximum is 1000.
If cursor is specified, this parameter will be ignored. When cursor is specified, the count value specified in the first request is inherited.
cursor query No

Parameter when performing pagination.
If there are more responses than the number specified by count, the nextCursor value included in the response is specified and pagination is performed.

filter.unauthorizedAt.$gte

 query

Y (see note)

Specifies the time in UNIX timestamp format. Gets the authorization cancellation events that occurred at or after this specified time.
Only events after December 1, 2021 can be obtained for the history.

Note: Unnecessary if cursor is specified.

filter.unauthorizedAt.$lt

 query Y (see note)

Specifies the time in UNIX timestamp format. Gets the authorization cancellation events that occurred before this specified time.

Note: Unnecessary if cursor is specified.

Response Specification

The response is returned in application/json format. If the request succeeds, the following properties are returned in the response.

Item Type Description
items array

An array that includes the following objects.

Item Type Description
userId string

Represents the Nintendo Account identifier.

Note

There are two types of Nintendo Account identifiers, as listed below, and the identifier that can be obtained differs depending on when the link with the Nintendo Account started. For more information, see 4.6 Migration From NAID to PPID.

  • NAID: An ID that is unique across all clients. (A 16-digit alphanumeric with lowercase letters.)
  • PPID: An ID that is different for every client. (A 28-digit alphanumeric with uppercase letters.)
clientId string

Represents the client ID.
scope array

An array of scope for which authorization was canceled.
unauthorizedAt number

The time at which the user canceled authorization.
The format is a UNIX timestamp.


itemsPerPage number Indicates the number of elements in the items array included in the response.
count number Indicates the count value specified when the request was made.
nextCursor string

The parameter for performing pagination.
If there is not another page, this parameter is not included in the response. This provides a way to determine whether there is another page.
