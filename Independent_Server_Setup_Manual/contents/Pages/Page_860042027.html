5.5 Authorization Requests

These are requests to perform the procedure for user authorization.
Currently, authentication requests can only be sent from Switch applications. For more information about implementing applications, see NintendoSDK Documents.

Request Specification

Authorization requests from Switch applications use the nn::account::CreateNintendoAccountAuthorizationRequest function. For more information, see NintendoSDK Documents.
The following table shows the request parameters for requests made by Switch applications.

Item Description
scope

Represents the scope requested for authorization. More than one parameter can be specified by separating them with spaces.
You must have prior approval from Nintendo to request such authorization.
state Set to the null character or a string. You cannot simply omit the parameter.
The same state value that came with the authorization request is contained in the authorization response, unmodified.
It can be used as a measure against CSRF attacks and to maintain the context before and after the authorization request.
nonce Optional parameter that can be added.
The same nonce value that came with the authorization request is contained in the id_token, unmodified.
It is used to prevent replay attacks when an ID token is obtained as the result of the authorization request.
Info

The following properties are resolved automatically for Switch applications, so there is no need to specify them in the request parameters.

  • client_id: The client_id associated with the application ID is resolved automatically.
  • redirect_uri: Automatically resolved as a custom URI at nintendo://${application ID}.app.

Response Specification

If the authentication request succeeds, the Switch application can obtain the following values.

Item Description
code

The authorization code used to get an access token.
id_token

The ID token for authenticating the user. It can only be obtained when scope=openid has been specified.
state

The state value specified when the authorization request was made.
scope

A list of the user-authorized scope values included among the values specified in the authorization request.
