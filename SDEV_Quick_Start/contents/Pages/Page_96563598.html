9 Running Built Applications (For Non-Developers)



Running Applications

This page describes the process for executing applications for non-developers who do not have Visual Studio.

The example uses the GfxPrimitiveRenderer sample. Get the NSP file for the GfxPrimitiveRenderer sample from a developer. An NSP file is an application executable file.

Info

For more information about creating NSP files, see NintendoSDK Documents > Tutorial > Application Development.


Info

You can also install applications on the SDEV console, and run applications on the SDEV alone.

For more information about the process, in the SDEV Usage Manual, see Installing Applications and Running Applications on the SDEV.



Procedure Operation
1

From the Start menu, start Target Manager (described later).
2

Right-click the target pane, and from the shortcut menu, select Add Target.
3

In the dialog box, select the SDEV you want to connect and click OK.



The default name of the SDEV is the MAC address or the serial number of the unit.

Info

For more information about checking the serial number, see 6 Initializing the SDEV.
4

The selected SDEV appears in the target pane. Right-click the target and select Connect to Target.



The connection is successful when the status changes from Not connected to Connected.
5

Confirm that the target is connected. Right-click the target and select Load executable file.


The Load executable file dialog box appears. Select an application executable file (NSP file) and click OK.

Note: Target Manager

Target Manager (both Nintendo Target Manager and Nintendo Target Manager 2) is software for managing the development tools connected to a PC.

You can use it to register an SDEV to a PC and run built applications on SDEVs.


If you run an application on the SDEV from Visual Studio, Target Manager starts automatically (either Nintendo Target Manager itself or, in the case of Nintendo Target Manager 2, the Nintendo SDK Daemon program).

If you are operating the SDEV without using Visual Studio, manually start Target Manager from the Start menu.


Info

For more information about the features of Nintendo Target Manager and Nintendo Target Manager 2, see NintendoSDK Documents > Features > Controlling the Development Hardware > Target Manager/Target Manager 2.
