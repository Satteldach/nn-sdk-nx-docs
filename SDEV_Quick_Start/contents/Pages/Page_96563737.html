4 Using Nintendo Dev Interface

About Nintendo Dev Interface

Nintendo Dev Interface (NDI) is a tool to set up and manage the development environment.

Installing NDI

Info

You must have Windows administrator rights to install NDI.


Procedure Operation
1

Download the NID installer package from the Nintendo Developer Portal.
2

Double-click the installer from the downloaded package to run it.
3

Select the language for installation.
4

Follow the installer instructions to configure the program.

You can change the installation path from this screen.

On this screen, specify shortcut creation and registration to the Start Menu.

If you select Add NDI installation directory to PATH environment variable, the path to the NDI program will be added.

This option is useful when calling NDI functions from a command line.

To start the installation, click Next to proceed.

Note: NDI requires .NET Framework 4.6.2 to run.
If .NET Framework 4.6.2 is not installed, its installer starts.
Follow the instructions to install .NET Framework 4.6.2.

5

To finish the installation, click Close.

Note: If you have installed .NET Framework 4.6.2 using the preceding procedure, restart Windows before you start Nintendo Dev Interface and run it from the Start menu.

A shortcut to the program will be added to the Start menu.
