1. Introduction

This package provides lists, such as the amiibo ID data list, and tag data (NTF files) used during development.

Back to top

2. Notes

This package sometimes includes information about products in the lineup that have not been announced yet, so please handle this information carefully.

When working on planning and specifications, see the separately provided NFP Guide or NFP Planning and Operations Manual, and the Guidelines for each platform.

The NTF files included in this package are for use during development only and are incompatible with the data used in production amiibo products.

If you need the translated name for each amiibo, specify that on the amiibo Usage Application Sheet.

Back to top

3. How to Use NTF Files

For information about the procedure for writing an NTF file to an NFP tag, see the description for noft_writer provided for each platform.

noft_writer is included in the SDK or the NFP library package associated with the SDK for each platform. The development hardware mentioned in the NoftWriter description is different for each platform. See the information for the platform that you are using in your development.

The NTF files in this package and the NFP tags to which they are written can be used on any platform, regardless of the platform used for writing.

4. NTF Files for Debugging

The NTF files stored in ntf/Debug/ are special NTF files that are configured for debugging use. The parameters configured in each file are shown in the following table.

For more information about the tests to conduct using these files, see the guidelines for each platform.

NTF FilenameCharacter IDNumbering IDSeries IDNFP TypeFormat VersionDescription
NVL-DUM1_00_00.ntf0xFA00006500025502

Used as an amiibo with a non-retail product reserved character ID.

NVL-DUM4_00_00.ntf0x000000650042550255

Used as an amiibo with a non-retail product reserved format version.

Note: Writing this NFT file with the NoftWriter causes a verification error. The write is successful, so ignore the error.

5. Package Structure

This package has the following structure.
Note: Not all of the files are listed here. 

amiibo_DataList/
    |
    +- amiibo_DataList_yyyymmdd.xlsx           … Data list.
    |
    +- ntf/
    |    |
    |    +- SeriesID_00/                       … Folder for the series indicated.
    |    |    +- NVL-XXXX_00_00.ntf            … NTF file.
    |    |    +- ...
    |    |
    |    +- Debug/
    |    |    +- NVL_DUM1_00_00.ntf            … NTF files for debugging.
    |    |    +- ...
    |    |
    |    +- List/
    |         +- amiibo_DataList_yyyymmdd.csv  … CSV file used with NoftWriter. For more information, see the NoftWriter Manual.
    |
    +- Readme-amiibo_DataList-yyyymmdd.html    … This readme file.
